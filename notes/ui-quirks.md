# Известные глюки UI MindBox

## «Некорректное значение» в condition-фильтрах

В правой панели condition-блока вместо реальных значений (статусов
заказа, ID продуктов, имён сегментов) может появиться надпись
**«некорректное значение»**. Это **не** баг условия в самом сценарии,
а временный глюк отрисовки: конкретные значения справочников не
подтянулись (асинхронная загрузка справочников или старый кеш).

**Как обнаружено.** Встретилось 2026-05-05 при описании сценария
`Warming-Up-2Order` (блок B29). Сначала UI показал три строки
«некорректное значение». После повторного захода прямой ссылкой на тот
же `blockId` отрисовалось корректно (Оформлена/Оплачен | Оплачена |
Доставлена).

**Что делать.** Если в скрине condition-блока вместо реальных
статусов/значений видно «некорректное значение»:

1. Не записывать это в `filters_detail` буквально.
2. Перезагрузить страницу или открыть тот же блок прямой ссылкой ещё раз.
3. Сравнить с другим блоком в этом же сценарии, где такое же условие
   повторяется (в каскадных сценариях обычно повторяется на каждой
   ступени) — текст должен совпасть.

**Прямая ссылка на конкретный блок:**

```
https://<тенант>.mindbox.ru/scenarios/<scenarioId>/view?blockId=<uuid>
```
