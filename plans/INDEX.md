# Утверждённые планы

Хранилище утверждённых пользователем планов работ. Каждый файл —
снимок плана на момент утверждения. План добавляется сюда **после**
того, как пользователь сказал «утверждаю» / «погнали» / эквивалент
в plan-mode.

## Конвенция

- Имя файла: `YYYY-MM-DD-краткое-описание.md`. Дата = день утверждения,
  описание — kebab-case на латинице или транслите.
- Плану соответствует одна задача / одно изменение. Если задача
  большая и разбита на этапы — отдельный файл на каждый этап (с одной
  и той же датой и суффиксом `-step1`, `-step2`).
- Содержимое = ровно то, что утвердил пользователь (без изменений
  «пост-фактум»). Если по ходу реализации план поменялся — добавь
  новый файл-план рядом, не правь старый.
- Этот `INDEX.md` — карта. Сверху более свежие планы.

## Как использовать

- Перед тем как браться за задачу из старого плана — сверься с этим
  файлом и открой плановый файл целиком.
- При коммите изменений по плану упоминай имя файла-плана в commit
  message, чтобы из истории можно было найти контекст.
- Старые / выполненные планы не удаляй — они полезны как история
  решений (что выбрано, что отвергнуто, почему).
