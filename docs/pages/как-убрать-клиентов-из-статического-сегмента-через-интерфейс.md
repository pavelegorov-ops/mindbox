# Как убрать клиентов из статического сегмента через интерфейс

Инструкция подходит для удаления из статического сегмента клиентов по фильтру.

Об удалении из сегмента с помощью файла — в статье [Как по файлу убрать клиентов из статического сегмента](как-по-файлу-убрать-клиентов-из-статического-сегмента).

По шагам:

1. Строим фильтр в разделе «Клиенты»:

![Снимок экрана 2022-07-08 в 19.51.55.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-07-08%20%D0%B2%2019.51.55.png)

2. Выделяем найденных клиентов или отмечаем чекбоксы вручную:

![Снимок экрана 2022-07-08 в 19.52.27.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-07-08%20%D0%B2%2019.52.27.png)

3. Кликаем «Убрать из сегмента», выбираем сегментацию, из которой убираем клиентов, и нажимаем «Удалить»:

![Снимок экрана 2022-07-08 в 19.52.45.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-07-08%20%D0%B2%2019.52.45.png)

4. Появляется ссылка на задачу:

![Снимок экрана 2022-07-08 в 19.30.53.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-07-08%20%D0%B2%2019.30.53.png)

5. Ждём её завершения:

![Снимок экрана 2022-07-08 в 20.03.26.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-07-08%20%D0%B2%2020.03.26.png)

- Сегмент убирается из ’Текущих’ сегментов в карточке клиента.  
  Также в ’Истории’ отмечается время выхода из сегмента:

![Снимок экрана 2022-07-08 в 20.06.12.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-07-08%20%D0%B2%2020.06.12.png)
