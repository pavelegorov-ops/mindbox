# Что такое «Подарочные карты»

Подарочные карты представляют собой форму предоплаченных карт, которые можно использовать для покупки товаров или услуг.

Они могут выдаваться в качестве бонусов для укрепления лояльности к бренду или продаваться как подарочные сертификаты.

## Защита подарочных карт с помощью CVV

CVV-код используется для дополнительной проверки владения картой при оплате заказов подарочной картой. Это помогает:

- подтвердить, что заказ оформляет пользователь, владеющий реквизитами карты.
- снизить риск мошеннических списаний при утечке номера карты.

Для использования CVV:

1. [Импортируйте пул подарочных карт](https://help.mindbox.ru/docs/gift-card-pools-import) с требованием CVV: укажите true в колонке **IsCvvRequired**.
2. Укажите значения CVV при [импорте подарочных карт](https://help.mindbox.ru/docs/gift-cards-import).

При оплате заказа подарочной картой из пула с требованием CVV — его передача в операции обязательна. Если передан некорректный CVV, то оплата подарочной картой невозможна. [Подробнее](https://developers.mindbox.ru/docs/%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%B0-%D1%81-%D0%BF%D0%BE%D0%B4%D0%B0%D1%80%D0%BE%D1%87%D0%BD%D1%8B%D0%BC%D0%B8-%D0%BA%D0%B0%D1%80%D1%82%D0%B0%D0%BC%D0%B8-%D0%B2-%D0%BE%D0%BF%D0%B5%D1%80%D0%B0%D1%86%D0%B8%D1%8F%D1%85-%D1%81%D0%BE%D1%85%D1%80%D0%B0%D0%BD%D0%B5%D0%BD%D0%B8%D1%8F-%D0%B7%D0%B0%D0%BA%D0%B0%D0%B7%D0%BE%D0%B2).

## Как происходит работа с картами

### Хранение карт

Подарочные карты группируются в [пулы](gift-card-pools-import.md).

Пулы хранятся в виде продуктов, которые создаются автоматически при [импорте](gift-card-pools-import.md):

![Снимок экрана 2023-12-20 в 00.13.42.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-12-20%20%D0%B2%2000.13.42.png)

![Снимок экрана 2023-12-20 в 00.15.36.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-12-20%20%D0%B2%2000.15.36.png)

Список [карт](gift-cards-import.md) открывается по ссылке со страницы пулов. В режиме редактирования карты можно посмотреть дополнительную информацию по ней:

![Снимок экрана 2024-01-16 в 18.35.43.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202024-01-16%20%D0%B2%2018.35.43%281%29.png)

### Продажа карт

Карты перед выдачей должны быть предварительно [загружены](gift-cards-import.md) на проект.

Продавать можно только карты в статусе «Не активирована».

Когда подарочная карта приобретается клиентом, у него появляется заказ с продуктом-пулом:

![Снимок экрана 2023-12-27 в 13.13.51.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-12-27%20%D0%B2%2013.13.51.png)

Карта активируется.

Если карта выдается магазином, она также должна быть активирована. Для этого можно провести ее покупку как заказ анонимного покупателя.

Возможные ошибки при продаже подарочных карт описаны в [статье для разработчиков](https://developers.mindbox.ru/docs/%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%B0-%D1%81-%D0%BF%D0%BE%D0%B4%D0%B0%D1%80%D0%BE%D1%87%D0%BD%D1%8B%D0%BC%D0%B8-%D0%BA%D0%B0%D1%80%D1%82%D0%B0%D0%BC%D0%B8-%D0%B2-%D0%BE%D0%BF%D0%B5%D1%80%D0%B0%D1%86%D0%B8%D1%8F%D1%85-%D1%81%D0%BE%D1%85%D1%80%D0%B0%D0%BD%D0%B5%D0%BD%D0%B8%D1%8F-%D0%B7%D0%B0%D0%BA%D0%B0%D0%B7%D0%BE%D0%B2?isFramePreview=true#%D0%B2%D0%BE%D0%B7%D0%BC%D0%BE%D0%B6%D0%BD%D1%8B%D0%B5-%D0%BE%D1%88%D0%B8%D0%B1%D0%BA%D0%B8).

### Применение карты

Использовать в заказе можно только карты в статусе «Активирована».

Клиент частично оплачивает покупку картой:

![Снимок экрана 2023-12-27 в 13.19.30.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-12-27%20%D0%B2%2013.19.30%281%29.png)

После того, как номинал карты полностью потрачен, она автоматически переходит в статус «Погашена».

Возможные ошибки при оплате заказов подарочными картами описаны в [статье для разработчиков](https://developers.mindbox.ru/docs/%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%B0-%D1%81-%D0%BF%D0%BE%D0%B4%D0%B0%D1%80%D0%BE%D1%87%D0%BD%D1%8B%D0%BC%D0%B8-%D0%BA%D0%B0%D1%80%D1%82%D0%B0%D0%BC%D0%B8-%D0%B2-%D0%BE%D0%BF%D0%B5%D1%80%D0%B0%D1%86%D0%B8%D1%8F%D1%85-%D1%81%D0%BE%D1%85%D1%80%D0%B0%D0%BD%D0%B5%D0%BD%D0%B8%D1%8F-%D0%B7%D0%B0%D0%BA%D0%B0%D0%B7%D0%BE%D0%B2?isFramePreview=true#%D0%B2%D0%BE%D0%B7%D0%BC%D0%BE%D0%B6%D0%BD%D1%8B%D0%B5-%D0%BE%D1%88%D0%B8%D0%B1%D0%BA%D0%B8-1).

## Как начать использовать карты

2. [Импортировать карты](gift-cards-import.md)
3. [Доработать операции](https://developers.mindbox.ru/docs/%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%B0-%D1%81-%D0%BF%D0%BE%D0%B4%D0%B0%D1%80%D0%BE%D1%87%D0%BD%D1%8B%D0%BC%D0%B8-%D0%BA%D0%B0%D1%80%D1%82%D0%B0%D0%BC%D0%B8-%D0%B2-%D0%BE%D0%BF%D0%B5%D1%80%D0%B0%D1%86%D0%B8%D1%8F%D1%85-%D1%81%D0%BE%D1%85%D1%80%D0%B0%D0%BD%D0%B5%D0%BD%D0%B8%D1%8F-%D0%B7%D0%B0%D0%BA%D0%B0%D0%B7%D0%BE%D0%B2) сохранения заказа с учетом добавления на проект карт.
4. [Включить модуль](billing-modules.md#vklyuchit-i-vyklyuchit-modul) программы лояльности.

[Ценовые и неценовые промо в ритейле](https://mindbox.ru/academy/education/retail-loyalty-medvedev/), чем плохи массовые скидки и почему персональные промоакции более полезны для бизнеса.
