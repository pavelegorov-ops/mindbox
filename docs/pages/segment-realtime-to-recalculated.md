# Как сделать из реалтайм сегмента клиентов пересчитываемый

Нельзя поменять тип сегментации после того, как она была создана. При этом может появиться необходимость учитывать динамику числа клиентов в изначально реалтайм сегменте.  
В таком случае нужно настроить новый сегмент по такому же фильтру с пересчетом по расписанию.

Это можно сделать двумя путями:

1. [Скопировать условия реалтаймового сегмента](как-клонировать-сегмент-по-фильтру):  
   используем тот же фильтр и создаем сегмент по [инструкции](segment-client-filter-recalculate.md).
2. Создать новый пересчитываемый сегмент, используя в фильтре изначальный реалтаймовый: применяем фильтр вида «Сегмент — Название изначального сегмента» и создаем сегмент по [инструкции](segment-client-filter-recalculate.md):
