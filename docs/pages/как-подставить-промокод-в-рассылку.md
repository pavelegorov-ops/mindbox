# Как подставить промокод в рассылку

Рассмотрим два способа отправки промокодов клиентам через рассылки.

## Через рассылку по файлу

Для этого создайте файл со списком адресов и промокодом для каждого адреса, и сделайте рассылку по этому файлу с помощью [инструкции](how-to-use-manual-import-in-campaigns). Данным способ промокод подставляется как кастомный параметр. Например, `${CustomParameters.SkidkiWithPromo01102021}`.

Удобно, если промокоды нужно отправить разово.

## Через пул промокодов

Данный способ удобен, если нужно выдавать промокоды автоматически, или вручную на регулярной основе.

1. Создайте пул промокодов по [инструкции](как-добавить-промокоды-в-проект)

   Пул должен быть в статусе «Можно использовать».
2. Выдайте промокоды клиентам:

   - вручную [по инструкции](как-выдать-промокоды-из-пула-вручную-по-фильтру),
   - в [шаге сценария/операции](%D0%BA%D0%B0%D0%BA-%D1%81%D0%BE%D0%B7%D0%B4%D0%B0%D1%82%D1%8C-%D1%81%D1%86%D0%B5%D0%BD%D0%B0%D1%80%D0%B8%D0%B8-%D0%B8%D0%BB%D0%B8-%D0%BE%D0%BF%D0%B5%D1%80%D0%B0%D1%86%D0%B8%D1%8E-%D1%81-%D0%B2%D1%8B%D0%B4%D0%B0%D1%87%D0%B5%D0%B8-%D0%B8-%D0%BE%D1%82%D0%BF%D1%80%D0%B0%D0%B2%D0%BA%D0%BE%D0%B8-%D0%BF%D1%80%D0%BE%D0%BC%D0%BE%D0%BA%D0%BE%D0%B4%D0%B0.md).
3. Скопируйте название параметра из пула промокодов, как показано на скриншоте. В этом виде параметр подставляется в рассылку:

   ![Снимок экрана 2021-05-11 в 22.17.03.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-05-11%20%D0%B2%2022.17.03.png)

[Чем полезны промокоды](https://mindbox.ru/academy/education/kak-primenyat-promokody/): собирают и обогащают клиентскую базу, стимулируют совершить целевое действие, персонализируют скидки.
