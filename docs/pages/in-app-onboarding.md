# Как добавить онбординг в мобильное приложение

**Цель механики** — в первый вход пользователя рассказать ему про разделы приложения (корзина, главное, профиль и т.д.) и обучить его использованию различных функций (как добавить в избранное, как оставить обратную связь, где посмотреть баланс программы лояльности).

## Как это работает

1. Пользователь устанавливает приложение и заходит в него в первый раз.
2. По мере того, как пользователь переключается по разным вкладкам и совершает разные действия, он видит формы In-App, помогающие ему погрузиться в приложение

## Шаги настройки

Некоторые настройки на этой странице требуют обновления SDK приложения до версии 2.14.0. Для обновления SDK версии обратитесь к вашим разработчикам.

### 1. Продумайте механику онбординга

Выделите от 3 до 5 этапов пользовательского пути в вашем приложении. Подумайте, какими вопросами чаще всего задаются новые пользователи на каждом этапе, и отберите самые важные из них (по одному вопросу на этап).

Пример пользовательского пути:

|  |  |  |
| --- | --- | --- |
| Этап | Возможные вопросы пользователей | Наполнение In-App |
| Вход | - Где найти все актуальные акции? - Как получить скидку на первый заказ? - Как работает доставка и возврат? - Какие бренды здесь представлены? - Есть ли примерка? - и т.д. | Где находится раздел со всеми акциями |
| Открытие карточки товара | - Как забронировать товар? - Можно ли вернуть товар, если он не подошел? - Как узнать, подойдёт ли размер товара? - Где находятся отзывы? - и т.д. | Как забронировать товар |
| Добавление товара в Корзину | - Можно ли оплатить товар частями? - Есть ли бесплатная доставка? От какой суммы? - Как применить промокод? - и т.д. | Как оплатить покупку частями |
| Профиль пользователя | - Где посмотреть бонусы? - Где посмотреть статус заказа? - Как связаться с поддержкой? - Как изменить адрес доставки? - Как отменить или изменить заказ? - и т.д. | Где посмотреть баланс программы лояльности |

### 2. Заведите нужные операции

По умолчанию In-App показывается сразу после входа в приложение. Чтобы показывать формы In-App на других шагах пользовательского пути (в корзине, профиле и т.д.), на каждый из этапов необходимо завести операции.

- Если операций по добавлению товара в корзину и посещения разных страниц приложения еще нет, заведите операции [по инструкции](https://help.mindbox.ru/docs/in-app-location) для нужных разделов.
- Если операции по просмотру товаров и категорий товаров еще нет, заведите операции [по инструкции](https://help.mindbox.ru/docs/%D0%BA%D0%B0%D0%BA-%D0%BD%D0%B0%D1%81%D1%82%D1%80%D0%BE%D0%B8%D1%82%D1%8C-%D1%82%D0%B0%D1%80%D0%B3%D0%B5%D1%82%D0%B8%D0%BD%D0%B3-in-app-%D0%BF%D0%BE-%D0%BF%D1%80%D0%BE%D0%B4%D1%83%D0%BA%D1%82%D1%83-%D0%B8%D0%BB%D0%B8-%D0%BA%D0%B0%D1%82%D0%B5%D0%B3%D0%BE%D1%80%D0%B8%D0%B8-%D0%BF%D1%80%D0%BE%D0%B4%D1%83%D0%BA%D1%82%D0%BE%D0%B2).

Разработчики должны настроить вызов операций в приложении и выпустить новый релиз приложения.

### 3. Создайте In-App для каждого этапа

Создайте формы In-App для каждого этапа по [инструкции](in-apps.md).

#### Внешний вид формы

Создайте дизайн формы. Например, добавьте скриншот функции, о которой рассказываете клиенту. Если это оплата заказа частям — покажите, как выглядит нужная кнопка.

С техническими рекомендациями к размеру и формату картинки для In-app можно ознакомиться [здесь](in-apps.md#shablon-modalnoe-okno).

![in-app-onboarding-form.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/in-app-onboarding-form.png)

#### Общие настройки

- Выберите приложения, в которых будет отображаться форма, и даты показа.
- Укажите частоту всплывания **«Всего один раз»**, чтобы не беспокоить пользователя онбордингом еще раз.
- Включите настройку **«Приоритетный In-App»**, чтобы в первый вход пользователю показалась именно эта форма, а не какая-либо другая с таргетингом на вход или операцию. Приоритетный In-App будет игнорировать [лимиты по количеству In-App](in-app-frequency-control.md) в сутки или в сессию, выставленные на проекте.

![in-app-onboarding-general.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/in-app-onboarding-general.png)

#### Условия всплывания

1. Для формы In-App, которая покажется при входе в приложение, выберите **«Спустя время после попадания в таргетинг»**, например, через 30 секунд. Это необходимо, так как в первый вход всплывают различные системные окна (например, для разрешения получать мобильные пуши), In-App онбординга не должен мешать и перекрывать их.

![in-app-onboarding-frequency-1.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/in-app-onboarding-frequency-1.png)

2. Для форм, которые покажутся при переходе в другие разделы, поставьте вариант **«Сразу при попадании в таргетинг»**

![in-app-onboarding-frequency-2.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/in-app-onboarding-frequency-2.png)

#### Таргетинг

1. Для формы In-App, которая покажется при входе в приложение, укажите только условие **«Количество входов в приложение равно 1»**, чтобы он показался только в первый вход в приложение

![in-app-onboarding-targeting-1.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/in-app-onboarding-targeting-1.png)

2. Для всех остальных форм:

- Укажите условие **«Количество входов в приложение равно 1»**, чтобы они отобразились только в первых вод в приложение.
- Выберите операцию, соответствующую этапу онбординга.

![in-app-onboarding-targeting-2.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/in-app-onboarding-targeting-2.png)

### 4. Протестируйте формы

Чтобы понять, правильно ли отображается In-App, добавьте сегмент с тестовым клиентом в таргетинг In-App. Подробнее в [статье](in-apps.md#kak-protestirovat-in-app).

### 5. Запустите формы

Когда формы готовы, запустите их:

![in-app-onboarding-start.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/in-app-onboarding-start.png)

Онбординг готов

Созданные In-App’ы покажутся только один раз в первый вход в приложение после того, как пользователь совершит целевые действия.

![in-app-onboarding-list.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/in-app-onboarding-list.png)
