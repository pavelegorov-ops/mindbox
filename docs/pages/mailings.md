# Какие бывают рассылки

## По способу отправки рассылки могут быть:

- **Массовые** (ручные). Получатели известны сразу, отправка происходит по фильтру/сегменту/файлу. Подробнее о создании массовых рассылок - в статье ["Как создать массовую email-рассылку"](email-mass).
- **Автоматические**. Отправка происходит только при попадании клиента под условия сценария или срабатывании операции. Сама рассылка указывается в шагах сценария или операции. Подробнее о создании автоматических рассылок - в статье ["Как создать автоматическую email-рассылку"](email-trigger.md).

Увидеть все существующие на проекте рассылки можно в разделе «Список кампаний». Для удобства их можно отфильтровать по папке, каналу, статусу, а также найти по названию.

![mailings-channel.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/mailings-channel.png)

## По каналам коммуникации рассылки могут быть:

- Email
- SMS
- Viber
- MobilePush
- WebPush

## Разделение рассылок на тематики

На проекте можно создавать [тематики](как-создать-тематику-рассылки).

Они будут доступны в рамках каждого канала:

![76247406e6fe0d2f8aaaee6e1613a34bт-тематика.jpg](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/76247406e6fe0d2f8aaaee6e1613a34b%D1%82-%D1%82%D0%B5%D0%BC%D0%B0%D1%82%D0%B8%D0%BA%D0%B0.jpg)

При выборе тематики рассылка будет отправляться не просто подписанным на канал, а подписанным на канал именно в этой тематике.

## Профиль рассылки

От профиля зависит, игнорируем ли валидность контакта, статус подписки, наличие в глобальной контрольной группе (если она включена); шлём ли только ожидающим подтверждения подписки (при включённом Double Opt-In).

Описание каждого профиля дано в интерфейсе.

![762476396ca0feaf3ba39ccdd3e60d37т-профиль.jpg](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/762476396ca0feaf3ba39ccdd3e60d37%D1%82-%D0%BF%D1%80%D0%BE%D1%84%D0%B8%D0%BB%D1%8C.jpg)

В автоматических рассылках можно выбрать профиль "Транзакционный"**.Транзакционные рассылки** отправляются вне зависимости от статуса подписки, валидности контакта, наличия в глобальной контрольной группе.  
Такие рассылки очень важны для клиента, чаще всего он сам их запрашивает.

## Демо-режим

Каждый канал коммуникаций - это отдельная тарифицируемая услуга.

В демо-режиме можно создавать рассылки и отправлять **тестовые** письма.

![762531828b0dd880a0c2ba91cdb4da67демо.jpg](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/762531828b0dd880a0c2ba91cdb4da67%D0%B4%D0%B5%D0%BC%D0%BE.jpg)

Боевое использование и отправка рассылок предоставляются при включении тарификации услуг.

Для этого обратитесь к менеджеру вашего проекта.

## Начальные настройки для отправки рассылок

### Email-рассылки

На проекте должен быть заведён как минимум один [отправитель](как-настроить-добавить-изменить-отправителя-в-email-рассылке).  
Для домена отправителя нужно [сгенерировать](как-сгенерировать-dkim-из-системы) и [настроить](как-настроить-dkim-и-dmarc) DKIM.  
Нельзя отправлять рассылки с отправителем, у которого не подтверждён DKIM.

### SMS-рассылки

На проекте должен быть хотя бы один SMS-отправитель. Для этого [добавьте SMPP-соединение](как-подключить-sms-рассылки) с провайдером.

### Viber-рассылки

На проекте должен быть хотя бы один Viber-отправитель. Для этого [добавьте SMPP-соединение](как-подключить-viber-рассылки) с провайдером.

### MobilePush-рассылки

Об интеграции с mindbox для настройки мобильных пушей - в руководстве ["Мобильные пуши"](https://developers.mindbox.ru/docs/mindbox-sdk).

### WebPush-рассылки

Об интеграции с mindbox для настройки вебпушей - в руководстве ["Вебпуши"](https://developers.mindbox.ru/page/webpush).

## АБ-тестирование рассылок

АБ-тестирование позволяет сравнивать разные варианты рассылок: части подписчиков отправляется один вариант письма, части другой. В течение установленного времени собираются данные. Далее оставшейся части подписчиков отправляется выигрышный вариант.

В тестирование также можно добавить контрольную группу, которой рассылка отправляться не будет.
