# Как найти рассылки, связанные с заказом

Задача: отобрать сообщения, отправленные по заказу. Например, информирование об оплате и доставке.

На вкладке **Данные** → **Статусы рассылок** строим фильтр:

![Снимок экрана 2024-08-05 в 11.38.40.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202024-08-05%20%D0%B2%2011.38.40.png)

Только отправки рассылок:

![Снимок экрана 2024-08-05 в 11.38.59.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202024-08-05%20%D0%B2%2011.38.59.png)

#### Какие рассылки попадают в фильтр

В операции/сценарии должно быть минимум два шага:

- отправка рассылки на контакт основной или из заказа;
- действие с заказом:

![Снимок экрана 2021-11-06 в 00.05.55.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-11-06%20%D0%B2%2000.05.55.png)

Подходят все шаги, кроме «Получить список заказов».
