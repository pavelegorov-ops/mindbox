# Как настроить бесшовный переход в мобильное приложение

В email-канале ссылки могут вести в мобильное приложение. Для удобства пользователей предпочтительнее открывать их сразу на нужной странице приложения без перенаправления на сайт. А для сбора статистики по рассылке нужно также сохранять клики.

Данный функционал полностью поддерживается с помощью **универсальных ссылок**.

Универсальные ссылки автоматически открываются наиболее оптимальным способом: клик переведет на нужную страницу приложения, мобильную или десктопную версию браузера в зависимости от устройства клиента и наличия у него приложения.

Доступно для клиентов, полностью перешедших на [Mindbox SDK](https://developers.mindbox.ru/docs/mindbox-sdk).

Для запуска:

1. Полностью настроите интеграцию сайта и приложения по [инструкции](https://developers.mindbox.ru/docs/universal-links).
2. Укажите на проекте домены, клик по которым должен поддерживать бесшовный переход в приложение.
3. Перейдите в раздел **Настройки** → **Рассылки** → **Универсальные ссылки**:

![универсальные.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D1%83%D0%BD%D0%B8%D0%B2%D0%B5%D1%80%D1%81%D0%B0%D0%BB%D1%8C%D0%BD%D1%8B%D0%B5.png)  
4. Добавьте нужные домены и сохраните изменения:

![Снимок экрана 2022-10-26 в 21.58.08.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-10-26%20%D0%B2%2021.58.08.png)

#### Как указывать ссылки

Укажите домен и поддомены, на которых расположены универсальные ссылки.

Например:

- example.com — только сайт, без поддоменов;
- *.example.com — только поддомены;
- one.example.com — только поддомен one.

Сразу после добавления ссылки в список проверяется, всё ли настроено на сайте и готово для работы универсальных ссылок.

Если нужны доработки, даются рекомендации по дальнейшей настройке:
