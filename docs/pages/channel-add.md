# Как создать канал

**Канал** — это средство объединения точек контакта в группы.

Сами каналы также можно группировать.

Каналы можно добавить вручную по одному, следуя этой инструкции, или импортировать группой с использованием файла csv по [инструкции](channel-import).  
Вторым способом можно добавить только дочерние каналы.

Для добавления канала через интерфейс выполняем следующие шаги:

1. Открываем раздел **Настройки** → **Клиенты и действия** → **Каналы**:

![каналы.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%BA%D0%B0%D0%BD%D0%B0%D0%BB%D1%8B%282%29.png)

2. Нажимаем «Добавить»:

![каналы.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%BA%D0%B0%D0%BD%D0%B0%D0%BB%D1%8B%281%29.png)

3. Заполняем поля:

![Снимок экрана 2021-07-13 в 18.10.09.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-07-13%20%D0%B2%2018.10.09.png)

*Внешний ID* — используется в интеграциях.  
*Название* — название канала, будет отображаться в общем списке и фильтрах.  
*Системное имя* — подставится автоматически, можно указать свое. Нужно для внутреннего хранения.  
*Критерии объединения точек контакта в этот канал* — комментарий; необязательно.  
*Входит в канал* — необязательно, если канал без родительского.

4. Нажимаем «Добавить».

- Канал успешно добавлен в систему:

![Снимок экрана 2021-07-13 в 18.10.59.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-07-13%20%D0%B2%2018.10.59%281%29.png)

- Теперь он доступен в механиках, например, в фильтре по действиям:

![Снимок экрана 2021-07-13 в 18.11.56.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-07-13%20%D0%B2%2018.11.56.png)
