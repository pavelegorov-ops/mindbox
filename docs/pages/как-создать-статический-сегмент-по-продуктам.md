# Как создать статический сегмент по продуктам

Один из возможных [сегментов по продукту](segments-products.md) — статический.

Сначала создаём сегментацию, потом сегмент(ы) в ней.

По шагам:

1. Переходим в раздел **Данные** → **Сегментации**:

![Снимок экрана 2023-01-15 в 19.20.03.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-01-15%20%D0%B2%2019.20.03.png)

2. Нажимаем «Добавить» → «Статическую по продуктам»:

![Снимок экрана 2023-01-15 в 19.20.34.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-01-15%20%D0%B2%2019.20.34.png)

3. Заполняем название и описание.

Также можно поменять автоматически сгенерированные системное имя и внешний идентификатор сегментации (могут понадобиться в механиках):

![Снимок экрана 2021-08-31 в 14.01.14.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-08-31%20%D0%B2%2014.01.14.png)

4. Добавляем сегмент(ы).

Заполняем название. Системное имя проставляется автоматически при клике по строке, внешний идентификатор генерируется при сохранении сегмента:

![Снимок экрана 2021-08-31 в 14.02.25.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-08-31%20%D0%B2%2014.02.25.png)

Запустить можно только сегментацию, в которой есть хотя бы один сегмент

5. Чтобы сегментация появилась в фильтрах и её можно было использовать в механиках, нужно её активировать.

Для этого нажимаем «Запустить в работу»:

![Снимок экрана 2021-08-31 в 14.02.40.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-08-31%20%D0%B2%2014.02.40.png)

Статус сегментации меняется:

![Снимок экрана 2021-08-31 в 14.03.06.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-08-31%20%D0%B2%2014.03.06.png)

В активной сегментации можно редактировать только названия имеющихся сегментов и добавлять новые; удалять сохраненные сегменты нельзя
