# Как выгрузить категории продуктов

Чтобы выгрузить категории:

1. Перейдите в раздел **Данные** → **Продукты**:

![Снимок экрана 2021-08-24 в 14.37.32.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-08-24%20%D0%B2%2014.37.32.png)

2. Отметьте любой продукт с помощью чекбокса и нажмите «Экспорт» → «Категорий продуктов»:

![Снимок экрана 2023-03-06 в 22.23.00.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-03-06%20%D0%B2%2022.23.00.png)

Кнопка экспорта доступна только при выборе хотя бы одного продукта.

- Ставится задача:

![Снимок экрана 2023-03-06 в 22.23.14.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-03-06%20%D0%B2%2022.23.14.png)

- Файл доступен после завершения задачи. В описании — ссылка на операцию экспорта:

![Снимок экрана 2023-03-06 в 22.24.27.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-03-06%20%D0%B2%2022.24.27.png)

В файле — названия и внешние идентификаторы всех категорий и их родительских категорий в csv-формате.

### Выгрузить категории продуктов в JSON или XML

Чтобы получить выгрузку в других форматах, нужно создать для них отдельные операции.

Для этого:

1. В меню экспорта нажмите «Добавить экспорт»:

![Снимок экрана 2023-03-06 в 22.25.22.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-03-06%20%D0%B2%2022.25.22.png)

2. Заполните настройки операции:

![Снимок экрана 2023-03-06 в 22.26.18.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-03-06%20%D0%B2%2022.26.18.png)

В качестве точек интеграции доступны:

- «Административная панель Mindbox».  
  Операции с этой точкой добавляются на проект в выпадающий список экспортов.
- Пользовательские точки интеграции.  
  Операции с остальными точками интеграции нельзя ставить из интерфейса проекта, но их можно вызывать по API.
- Экспорт появляется в списке:

![Снимок экрана 2023-03-06 в 22.54.36.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-03-06%20%D0%B2%2022.54.36.png)
