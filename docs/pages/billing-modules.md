# Как пользоваться разделом «Подписка и оплата»

Страница детализации счетов содержит данные по оплате подписки за текущий и предыдущие месяца, информацию по тарифу, количество билингуемых сущностей на проекте, возможные модули для подключения и их стоимость.

Чтобы открыть раздел, перейдите в **Профиль пользователя** → **Подписка и оплата:**

![детализация.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%B4%D0%B5%D1%82%D0%B0%D0%BB%D0%B8%D0%B7%D0%B0%D1%86%D0%B8%D1%8F.png)

### Прогноз детализации

![подписка-и-оплата.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%BF%D0%BE%D0%B4%D0%BF%D0%B8%D1%81%D0%BA%D0%B0-%D0%B8-%D0%BE%D0%BF%D0%BB%D0%B0%D1%82%D0%B0.png)

Выберите интересующий месяц в верхнем правом углу страницы.

**Услуги**

Стоимость модулей. Зависит от тарифа и количества клиентов.

**Расширения**

Стоимость хранения данных сверх лимита.

**Итого**

Сумма услуг и расширений плюс НДС.

### Общая информация

**Счет**  
Статус оплаты счета по каждому месяцу.  
Для неоплаченных счетов выводится число, до которого их нужно оплатить, и сумма.  
На странице текущего месяца - список месяцев, по которым требуется оплата.

**Статус подписки**  
Возможные статусы:

- Ознакомительный период до дд.мм.гггг
- Активна с дд.мм.гггг
- Приостановлена с дд.мм.гггг

**Схема оплаты**  
Подробнее в статье по [схемам оплаты](billing-subscription-and-payments)

**Срок оплаты**  
На выбранный месяц.

**Данные для тарификации**  
Какое количество данных берётся при расчёте стоимости.

Есть два варианта:

- максимальное за месяц (количество клиентов/действий смотрится по максимальному значению за весь месяц);
- на последний день месяца.

**Версия тарифа**   
Версия тарифа на выбранный месяц.

Есть возможность сравнить цены текущего тарифа с самым новым.  
Для этого кликните на «Сравнить с новым тарифом».

**Документы**  
Закрывающие документы (детализация, акты, счета) за выбранный месяц. Доступно после выставления счета за месяц.

**В вашем аккаунте**

Клиенты — все клиенты, включая невалидных и отписанных.

Заказы — все заказы в базе.

Действия — все действия из категорий "Личные действия" и "Действия в отношении клиента".

Переходы между сегментами — попадание и выпадание в пересчитываемых и статических сегментах по клиентам.

Действия и переходы между сегментами — сумма предыдущих двух полей.

Учётные записи — пользователи административного интерфейса (не учитывая персонал Mindbox).

### Включить и выключить модуль

Со страницы детализации можно самостоятельно управлять используемым функционалом и его оплатой.

Модули сгруппированы в разделы *CDP*, *Лояльность*, *Персонализация* и *Рассылки*. По каждому из них дана стоимость без НДС, вычисленная по текущему базовому модулю.

Нажмите «Подключить»:

![Снимок экрана 2022-11-13 в 22.45.44.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-11-13%20%D0%B2%2022.45.44.png)

После нажатия нужно дополнительно подтвердить действие:

![Снимок экрана 2022-11-13 в 22.46.13.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-11-13%20%D0%B2%2022.46.13%281%29.png)

Начиная с версии тарифа 5.0 оплата модуля считается исходя из количества дней, когда модуль был включен. В старых тарифах стоимость считается за полный месяц независимо от дня подключения.

Опция доступна для персонала с группой безопасности «Владельцы».

### Запустить тарификацию

Подключать модули можно только при действующей подписке. Поэтому при включении модуля до окончания ознакомительного периода, стартует и подписка:

![image 10.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/image%20%2810%29.png)

Опция доступна для персонала с группой безопасности «Владельцы».

### Отменить подписку и удалить проект

На странице также можно отменить подписку:

![Снимок экрана 2022-11-13 в 22.59.45.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-11-13%20%D0%B2%2022.59.45.png)

После подтверждения отмены сразу отключаются все модули. Данные проекта, включая клиентов и их действия, удаляются через 30 дней.

![Снимок экрана 2022-11-13 в 23.00.13.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-11-13%20%D0%B2%2023.00.13.png)

Опция доступна для персонала с группой безопасности «Владельцы».
