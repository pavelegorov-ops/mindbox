# Как заменить стандартную страницу отписки на лендинг на сайте

**Есть 2 варианта создания нестандартной страницы отписки:**

1. Создание страницы для отписки на стороне сайта - создается лендинг в стилистике сайта, где клиент видит логотип компании и может заполнить поле для комментария о причине отписки;
2. [Создание брендированной страницы отписки с помощью конструктора Mindbox](branded-unsubscribe-page.md).

## Создание страницы для отписки на стороне сайта

Для использования страницы для отписки потребуется:

1. Создать пустую страницу на сайте;
2. Установить [код трекера](https://developers.mindbox.ru/docs/%D1%82%D1%80%D0%B5%D0%BA%D0%B5%D1%80) на страницу;
3. В рассылке в ссылке отписки добавить параметр [Ticket](%D1%82%D0%B8%D0%BA%D0%B5%D1%82.md) для перехода и авторизации клиента на сайте. Сайт должен уметь его распознать и далее использовать в запросах.

В рассылке параметр со страницей отписки и тикетом будет выглядеть так:

```
Для изменения подписок воспользуйтесь <a href="https://домен.ru/personal/unsubscribe/?token=${Ticket.EmailAuthenticationTicket}">ссылкой.</a>
```

4. В настройках письма отметить ссылку как ссылку отписки.
