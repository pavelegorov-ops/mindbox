# Как создать пересчитываемый сегмент по продуктам

Один из возможных [сегментов по продукту](segments-products.md) — по фильтру пересчитываемый.

## Создание сегмента

1. Перейдите в раздел **Данные** → **Продукты**:

   ![Снимок экрана 2021-08-31 в 13.10.58.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-08-31%20%D0%B2%2013.10.58.png)
2. Постройте фильтр нажмите кнопку «Применить»:

   ![Снимок экрана 2021-08-31 в 13.12.55.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-08-31%20%D0%B2%2013.12.55.png)
3. Нажмите «Создать сегмент»:

   ![Снимок экрана 2021-08-31 в 13.14.12.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-08-31%20%D0%B2%2013.14.12.png)
4. Заполните основные данные:

   - Название сегментации.
   - Системное имя генерируется автоматически. Можно задать собственное значение.
   - Тип — **пересчитываемая**.
   - Дополнительно (необязательны для заполнения):
     - Описание сегментации.
     - Внешний идентификатор. Генерируется автоматически с возможностью задать собственное значение.

   ![Снимок экрана 2021-08-31 в 13.32.01.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-08-31%20%D0%B2%2013.32.01.png)
5. Если сегментация должна пересчитываться автоматически, включите пересчет по расписанию:

   - **Каждый день**. Укажите, в какое время будет запускаться ежедневный пересчет.
   - **По дням в неделю**. Установите день недели и час, в который сегмент начнет пересчитываться.
   - **По дням месяца**. Установите день месяца и час, в который сегмент начнет пересчитываться
   - При необходимости установите период [автоостановки сегмента](segments-autostop.md).

   Совет

   Пересчитывайте сегменты ночью, когда нагрузка на базу данных снижена.
6. «Пересчет по событиям» — событие будет инициировать проверку клиента на то, должен ли он попасть в сегментацию/выпасть из него. Работа событий описана в [статье](product-segmentations-events.md).
7. Нажимаем «Создать».

   ![segment-product-recalculate-save.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/segment-product-recalculate-save.png)

## Как пересчитать сегмент раньше срока

Через фильтр

Добавьте сегмент в фильтр и перейдите в режим редактирования:

![segmentation-product-how-to-recalculate-1.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-07-08%20%D0%B2%2019.14.37.png)

Нажмите «Сохранить и пересчитать»:

![segmentation-product-how-to-recalculate-2.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-10-20%20%D0%B2%2018.35.12.png)

Через раздел «Сегментации»

- Перейдите в раздел **Данные** → **Сегментации** и найдите нужный сегмент.
- Откройте меню дополнительных действий и нажмите «Пересчитать с приоритетом»:

![segmentation-product-how-to-recalculate-3.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/segment-client-filter-early-recalculate.png)
