# Как работает шаг «отправить рассылку на контакт из заказа»

Иногда пользователи указывают получателем заказа другого человека. Например, это если это подарок или легче осуществить оплату с другого аккаунта. В таком случае номер получателя можно передать при оформлении заказа, а потом в механике настроить отправку коммуникации на этот номер:

![Снимок экрана 2021-11-17 в 22.26.46.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-11-17%20%D0%B2%2022.26.46.png)

#### Как это работает

Сообщение будет отправлено на указанный номер, даже если его нет у нас в базе. При этом новый клиент не создастся; действие выдастся тому клиенту, который оформлял заказ, с указанием номера получателя в подробностях рассылки.

Данные получателя не используются для изменения данных существующего клиента.

Если настроена отправка на контакт из заказа, но этот контакт не передан, то будет осуществлена отправка на основные контакты.

#### Особенности при отправке мобильных пушей

Получатель должен быть в базе Mindbox.

В заказе нужно передать его мобильный номер. По нему находим карточку клиента, определяем наличие установки приложения и отправляем в него пуш с информацию о заказе.
