# Как настроить каскадную рассылку с отправкой пуша в «Кошелек»

**Задача:** отправить коммуникацию для реактивации клиентов с использованием приложения «Кошелек».

Для решения задачи настроим [сценарий](what-is-workflow.md):  
Сначала отправляем email-рассылку. Если письмо не доставлено — пуш в приложение «Кошелек». Если пуш не доставлен — шлем sms-рассылку.  
Для мотивации к заказу выдаем 500 баллов с временным ограничение и высылаем напоминание через 7 дней, если клиент не совершил заказ за это время.

Перед созданием сценария:

Создайте [автоматические email-рассылки](email-trigger.md), автоматические [sms-рассылки](%D0%BA%D0%B0%D0%BA-%D1%81%D0%BE%D0%B7%D0%B4%D0%B0%D1%82%D1%8C-sms-%D1%80%D0%B0%D1%81%D1%81%D1%8B%D0%BB%D0%BA%D1%83.md) и [вебхуки](%D0%BA%D0%B0%D0%BA-%D0%BE%D1%82%D0%BF%D1%80%D0%B0%D0%B2%D0%B8%D1%82%D1%8C-%D0%BF%D1%83%D1%88-%D0%B2-%D0%BF%D1%80%D0%B8%D0%BB%D0%BE%D0%B6%D0%B5%D0%BD%D0%B8%D0%B5-%D0%BA%D0%BE%D1%88%D0%B5%D0%BB%D0%B5%D0%BA.md) для сценария.

Создаем сценарий.

#### Первая ветка

![Снимок экрана 2022-01-08 в 20.28.18.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-01-08%20%D0%B2%2020.28.18.png)

- Запуск — по расписанию, каждый день:

![Снимок экрана 2022-01-08 в 20.05.23.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-01-08%20%D0%B2%2020.05.23.png)

- Группа шагов — выдача 500 баллов:

![Снимок экрана 2022-01-08 в 20.05.38.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-01-08%20%D0%B2%2020.05.38.png)

- Условие — валидный email и подписка на канал email:
  - да — продолжаем ветку;
  - нет — переходим ко второй ветке.

![Снимок экрана 2022-01-12 в 17.49.44.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-01-12%20%D0%B2%2017.49.44.png)

- Группа шагов — отправить email-рассылку.
- Ожидание — 15 минут.
- Условие — email доставлен, то есть нет неотправки и недоставки письма:

  - да — продолжаем ветку;
  - нет — переходим ко второй ветке.

![Снимок экрана 2024-08-05 в 10.32.55.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202024-08-05%20%D0%B2%2010.32.55.png)

- Ожидание — 7 дней.
- Условие — нет заказов последние 8 дней:
  - да — продолжаем ветку.

![Снимок экрана 2022-01-08 в 20.30.49.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-01-08%20%D0%B2%2020.30.49.png)

- Группа шагов — отправить вторую email-рассылку.

#### Вторая ветка

![Снимок экрана 2022-01-12 в 17.54.01.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-01-12%20%D0%B2%2017.54.01.png)

- Условие — есть карта. Фильтруем по наличию карты типа «Кошелек» или по дополнительному полю. Зависит от того, как на проекте отбираются клиенты с приложением:
  - да — продолжаем ветку;
  - нет — переходим к третьей ветке.

![Снимок экрана 2022-01-08 в 20.32.50.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-01-08%20%D0%B2%2020.32.50.png)

- Группа шагов — вызов вебхука с пушом для отправки в приложение.
- Ожидание — 10 минут.
- Условие — пуш доставлен. Проверяем по наличию технического действия:
  - да — продолжаем ветку;
  - нет — переходим к третьей ветке.

![Снимок экрана 2022-01-08 в 20.33.03.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-01-08%20%D0%B2%2020.33.03.png)

- Ожидание — 7 дней.
- Условие — нет заказов последние 8 дней (скопируйте условие из первой ветки):
  - да — продолжаем ветку.
- Группа шагов — вызов вебхука с напоминанием.

#### Третья ветка

![Снимок экрана 2022-01-08 в 20.37.26.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-01-08%20%D0%B2%2020.37.26.png)

- Условие — валидный мобильный номер и подписка на канал sms:
  - да — продолжаем ветку.

![Снимок экрана 2022-01-08 в 20.46.20.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-01-08%20%D0%B2%2020.46.20.png)

- Группа шагов — отправить sms-рассылку.
- Ожидание — 7 дней.
- Условие — нет заказов последние 8 дней (скопируйте условие из первой ветки):
  - да — продолжаем ветку.
- Группа шагов — отправка повторной sms-рассылки с напоминанием.
