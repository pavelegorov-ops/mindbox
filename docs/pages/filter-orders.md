# Найти заказы за период

Общие шаги для фильтров по [заказам](what-is-an-order.md):

- Переходим на страницу **Данные** → **Действия**:

![Снимок экрана 2021-03-31 в 17.32.20.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-03-31%20%D0%B2%2017.32.20.png)

- На странице [действий](action.md) представлены все действия всех клиентов. Для начала отберем действия заказов:

![Снимок экрана 2021-04-06 в 14.40.03.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-04-06%20%D0%B2%2014.40.03.png)

- Такой фильтр покажет **все** действия заказов. Поэтому отбираем заказы с помощью фильтра по [первому действию заказа](filter-orders-first-action.md):

![Снимок экрана 2021-04-06 в 14.28.42.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-04-06%20%D0%B2%2014.28.42%281%29.png)

- Указываем нужные [статусы](filter-orders-status.md):

![Снимок экрана 2021-04-06 в 14.29.31.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-04-06%20%D0%B2%2014.29.31%282%29.png)
