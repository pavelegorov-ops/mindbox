# Как подставить в рассылку повторяющийся баннер

**Задача**: есть баннер, который повторяется из рассылки в рассылку. В какой-то момент он может поменяться, и он должен замениться во всех рассылках.

**Решение**: создать шаблон этого блока и настроить его вывод через шаблонизатор в описании продукта.

По шагам:

- **Создаем продукт**

[Вручную](product-add.md) или через [импорт yml-фида](yml-import.md).

- **В описании у него — верстка нашего блока:**

![Снимок экрана 2023-03-17 в 10.06.27.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-03-17%20%D0%B2%2010.06.27.png)

Ограничения на количество символов в описании нет.

Параметры в описании будут выведены как обычный текст, то есть не будут обработаны.

- **Используем в рассылке параметр** `${Products.SearchInIdentity("c1").GetByValue("N").Description}`

c1 — название внешней системы;  
N — внешний идентификатор продукта в этой внешней системе.

![Снимок экрана 2023-03-17 в 10.11.03.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-03-17%20%D0%B2%2010.11.03.png)

Параметр выводит «описание» продукта в письмо — оно содержит код, который трансформируется в верстку.

![Снимок экрана 2023-03-17 в 10.14.59.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-03-17%20%D0%B2%2010.14.59.png)

Если что-то поменяется в блоке, просто отредактируйте описание продукта.
