# Как исключить клиента из Глобальной контрольной группы

[Глобальная контрольная группа](%D1%87%D1%82%D0%BE-%D1%82%D0%B0%D0%BA%D0%BE%D0%B5-%D0%B3%D0%BB%D0%BE%D0%B1%D0%B0%D0%BB%D1%8C%D0%BD%D0%B0%D1%8F-%D0%BA%D0%BE%D0%BD%D1%82%D1%80%D0%BE%D0%BB%D1%8C%D0%BD%D0%B0%D1%8F-%D0%B3%D1%80%D1%83%D0%BF%D0%BF%D0%B0.md) — это клиенты, которые временно не получают массовые коммуникации при стандартном профиле рассылки.  
Можно выделить сегмент клиентов, на основании которого будет формироваться контрольная группа, то есть [ограничить выборку](%D0%BA%D0%B0%D0%BA-%D0%BE%D0%B3%D1%80%D0%B0%D0%BD%D0%B8%D1%87%D0%B8%D1%82%D1%8C-%D0%B2%D1%8B%D0%B1%D0%BE%D1%80%D0%BA%D1%83-%D0%B3%D0%BB%D0%BE%D0%B1%D0%B0%D0%BB%D1%8C%D0%BD%D0%BE%D0%B9-%D0%BA%D0%BE%D0%BD%D1%82%D1%80%D0%BE%D0%BB%D1%8C%D0%BD%D0%BE%D0%B9-%D0%B3%D1%80%D1%83%D0%BF%D0%BF%D1%8B.md).

![image](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-03-22%20%D0%B2%2014.18.16.png)

Но если клиенту, который попал в контрольную группу, необходимо отправлять все коммуникации без исключения, то его необходимо будет исключить из выборки.

### Механика попадания в КГ

Есть системная сегментация Измерение эффективности рассылок, состоящая из двух сегментов Основная группа и Контрольная группа.

![image](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-03-22%20%D0%B2%2013.59.48.png)

При попадании в базу данных Майндбокс клиенты могут попасть как в Основную группу сегментации Измерение эффективности рассылок, так и в Контрольную группу (при условии, что он также есть в выбранном в КГ сегменте).  
Если клиент из Основной группы со временем попадает в выбранный в настройках КГ сегмент, то он переходит в Контрольную группу сегментации Измерение эффективности рассылок в тот же момент.  
Когда время тестирования контрольной группы завершается, клиент выходит из сегмента Контрольная группа и возвращается в Основную группу сегментации Измерение эффективности рассылок.

### Как исключить клиента из КГ

Исключить клиента из Глобальной контрольной группы вручную можно только если КГ настроена на определенный сегмент, а не на всю базу. Так как при исключении клиента из этого сегмента, он автоматически выпадает из Глобальной контрольной группы.  
В настройке контрольной группы выборка идет всегда по реалтайм сегменту. То есть в сегменте есть фильтр и клиенты попадают в него в реальном времени — в момент, когда подходят под условия. Сегмент для выборки можно сделать по исключению домена в емейле или по наличию в истории клиента определенного шаблона действия. Если необходимо, чтобы в КГ не попадали сотрудники компании, то можно в выборке исключить конкретный домен, например

![image](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-03-26%20%D0%B2%2014.22.40%281%29.png)

Или же можно выдать списку клиентов определенный шаблон действия, по которому их можно сегментировать и включить в список КГ, например

![image](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-03-22%20%D0%B2%2013.00.48.png)

Поэтому, чтобы исключить клиента из сегмента выборки КГ необходимо, чтобы он перестал соответствовать его условиям. То есть если в сегменте указано условие по наличию шаблона действия, то у конкретного клиента, которого хотим исключить из КГ, нужно это действие удалить из истории.  
После того, как клиент перестанет входить в сегмент выборки КГ, он выпадет из сегментации «Измерение эффективности рассылок» (в которую входит сегмент Контрольной группы) в 00.00 следующих суток.

![image](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-03-22%20%D0%B2%2013.17.45.png)
