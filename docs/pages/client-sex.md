# Как определяется пол клиента по имени

Если для пользователя передано [стандартное](client-fullname.md) имя или отчество, по нему автоматически определяется и записывается в анкету пол клиента.

**Правила автоматического заполнения:**

- Работает только при создании или редактировании клиента **через импорт или из операции**, при изменении карточки вручную — нет;
- Применяется, **только если значение пола не передано явно**. При противоречии со справочником, приоритет отдается данным из вызова/импорта;
- Прошлое значение **может быть перезаписано**, если новое имя входит в список стандартных для другого пола.
