# Как импортировать клиентов в статический сегмент

Эта задача доступна в случае, если у вас создана и запущена [статическая сегментация по клиентам](segment-client-static.md).

Клиент не может **одновременно быть в нескольких сегментах одной сегментации**: при добавлении в сегмент Б, он автоматически выходит из сегмента А.

1. Переходим на страницу **Сегментации**:

![Снимок экрана 2023-01-15 в 19.20.03.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-01-15%20%D0%B2%2019.20.03.png)

2. Нажимаем «Импорт»:

![Снимок экрана 2023-01-15 в 19.32.41.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-01-15%20%D0%B2%2019.32.41.png)

3. Выбираем операцию «Импорт статических сегментов клиентов».  
   Для скачивания доступен шаблон файла с примером:

![Снимок экрана 2021-08-25 в 19.15.52.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-08-25%20%D0%B2%2019.15.52.png)

На странице импорта и в шаблоне даны названия столбцов для файла:

- идентификаторы клиентов (email, мобильный номер, внешние ID, номер дисконтной карты) — выбираем один из них;
- внешний идентификатор сегментации **SegmentationExternalId**;
- внешний идентификатор сегмента **SegmentExternalId**.

4. В файле импорта обязательно оставляем колонку с одним из идентификаторов клиента.

В базе обязательно должны быть клиенты с указанными идентификаторами, иначе при обработке файла их строки упадут с ошибкой

**Сегментацию и сегмент либо выбираем в настройках, либо добавляем в файл колонки SegmentationExternalId и SegmentExternalId с их внешними идентификаторами.**

Удобнее первый способ: меньше сложностей с наполнением файла. Второй способ может подойти, если хотите загрузить одним файлом клиентов в разные сегменты.

#### 4.1. Первый вариант — Указываем сегментацию в настройке операции.

#### 

- В настройках выбираем сегментацию и сегмент:

![Снимок экрана 2021-08-25 в 19.20.53.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-08-25%20%D0%B2%2019.20.53.png)

- В файле оставляем один столбец — идентификаторы клиентов, например, email:

![Снимок экрана 2021-08-25 в 19.24.57.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-08-25%20%D0%B2%2019.24.57.png)

#### 4.2. Второй вариант — Указываем сегментацию в файле.

- В настройках операции сегментацию и сегмент не выбираем:

![Снимок экрана 2021-08-25 в 19.27.10.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-08-25%20%D0%B2%2019.27.10.png)

- Находим внешний идентификатор сегментации и сегмента в разделе сегментаций (понадобятся для файла):

![Снимок экрана 2021-08-25 в 19.29.45.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-08-25%20%D0%B2%2019.29.45.png)

- В файле оставляем три столбца: идентификаторы клиентов, например, email (**CustomerEmail** ), внешний идентификатор сегментации (**SegmentationExternalId** ), внешний идентификатор сегмента (**SegmentExternalId** ):

![Снимок экрана 2021-08-25 в 19.33.30.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-08-25%20%D0%B2%2019.33.30.png)

Если указать разные сегментации в настройках операции и в файле, приоритетней будут данные из файла

5. Добавляем подготовленный файл и вписываем комментарий (по желанию; поможет найти задачу в списке).  
   Нажимаем "Добавить задачу":

![Снимок экрана 2021-08-25 в 19.35.02.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-08-25%20%D0%B2%2019.35.02.png)

- Появляется сообщение о добавлении задачи и ссылка на неё:

![Снимок экрана 2021-08-25 в 19.35.33.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-08-25%20%D0%B2%2019.35.33.png)
