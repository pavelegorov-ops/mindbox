# Что произойдет с идентификаторами клиента после объединения?

Основным уникальным ID останется тот, который был у приоритетного клиента. Другой ID сохранится в истории. ID хранящийся в истории по прежнему можно использовать при вызовах через API и импорте данных. Все MindboxID тоже хранятся в истории и могут использоваться для обмена данными (приоритет в выборе того, какой MindboxID оставить у клиента не учитывается).

Важно. Если в настройках Уникального ID стоит флаг “Не объединять клиентов с разными ID”, то поиска по ID в истории нет.
