# Как создать статический сегмент по клиентам

Создаем [статический сегмент по клиентам](segments-clients.md#3-%D1%81%D1%82%D0%B0%D1%82%D0%B8%D1%87%D0%B5%D1%81%D0%BA%D0%B8%D0%B9):

1.Заходим в раздел **Данные** → **Сегменты**:

![Снимок экрана 2023-01-15 в 19.20.03.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-01-15%20%D0%B2%2019.20.03.png)

2. Нажимаем на **Добавить → Статическую по клиентам**:

![Снимок экрана 2023-01-15 в 19.20.23.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-01-15%20%D0%B2%2019.20.23%281%29.png)

3. Заполняем имя и описание сегментации.  
   Системное имя и внешний идентификатор формируются автоматически, можно ввести свои значения.

- Название используется для отображения в интерфейсе проекта;
- системное имя используется при фильтрации в [шаблонизаторе](%D0%BA%D0%B0%D0%BA-%D0%B2%D1%8B%D0%B2%D0%B5%D1%81%D1%82%D0%B8-%D0%BF%D0%BE%D0%BB%D0%B5-%D1%82%D0%BE%D0%B2%D0%B0%D1%80%D0%B0-%D0%B8%D0%B7-%D1%81%D0%B5%D0%B3%D0%BC%D0%B5%D0%BD%D1%82%D0%B0.md).
- внешний идентификатор используется в операциях, поэтому в него записывается GUID.

![Снимок экрана 2023-01-15 в 19.22.48.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-01-15%20%D0%B2%2019.22.48.png)

4. Добавляем сегменты

Именно в них будут загружаться клиенты:

![Снимок экрана 2023-01-15 в 19.23.05.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-01-15%20%D0%B2%2019.23.05.png)

Для запуска сегментации в ней должен быть минимум один сегмент.

5. Нажимаем **Запустить в работу**

После запуска нельзя редактировать системное имя и внешний идентификатор.

![Снимок экрана 2023-01-15 в 19.23.32.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-01-15%20%D0%B2%2019.23.32.png)

В работе можно использовать только запущенные сегментации.  
Черновые сегменты недоступны в фильтрах и механиках.

Для выхода без запуска сегментации нажмите «Сохранить и выйти».

---

Можно добавить клиентов в сегмент [через фильтр](как-добавить-клиентов-в-статический-сегмент-через-интерфейс) или импортировать их [по файлу](как-импортировать-клиентов-в-статический-сегмент) (только имеющихся в базе).

Клиент не может **одновременно быть в нескольких сегментах одной сегментации**: при добавлении в сегмент Б, он автоматически выходит из сегмента А.

[Сегментация клиентов](https://mindbox.ru/academy/education/kak-segmentirovat-klientov/) — клиентская база на основе каких-либо признаков: гендера, количества покупок, суммы потраченных денег.
