# Действие-пометка при удалении клиента из базы

Создадим шаблон действия для удаления клиентов.

Для этого воспользуемся общей [инструкцией](template-create.md), поменяв лишь категории на нужные для нашей задачи.

Пример настройки:

![template-delete-client.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/template-delete-client.png)

- **Название** — то, как ШД будет отображаться в системе.
- **Тип** — стандартный.
- **Системное имя** — генерируется автоматически. Можете указать другое латиницей.
- **Кампания** — та, в которой удобно завести шаблон.
- **Категории I-III уровней** — Действия в отношении клиента → Коррекция ошибок и другие технические действия → Актуализация и дополнение данных.
- **В каком случае выдается и как используется** — информация в системе, для вашего удобства.
- **Теги** — необязательно.

  

Более подробная пошаговая инструкция по созданию шаблона действия — [в статье](template-create.md).
