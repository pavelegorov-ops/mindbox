# Как импортировать клиентов

Для загрузки клиентов на проект достаточно подготовить файл в корректном формате и поставить задачу на импорт.

Если нужно добавить клиентов со специальным шаблоном, в определенной точке контакта или с датой в прошлом, эти данные можно задать в расширенных настройках или в файле. Эти способы рассматриваются [отдельно](clients-import.md#rasshirennye-nastrojki).

## Импорт клиентов

[](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/финал-сокр-импорт%20клиентов.mov)  
*Подбираем названия для колонок с email, именем, фамилией, датой рождения и подпиской на Email. На проект уже добавили дополнительное поле для оценки, но нет полей для хранения внешнего идентификатора, хобби и комментария. Создаем для них дополнительные поля — они также появляются в списке.*

1. На вкладке **Клиенты** нажимаем «Импорт» → «Импорт клиентов»:

   ![Снимок экрана 2022-06-08 в 19.26.45.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-06-08%20%D0%B2%2019.26.45.png)
2. Выбираем операцию «Импорт клиентов»:

   ![Снимок экрана 2022-09-07 в 22.30.11.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-09-07%20%D0%B2%2022.30.11%281%29.png)  
   *Для скачивания доступен шаблон с примером. Также на странице появляются данные по всем возможным полям для загрузки: их название, описание и обязательность с примерами принимаемых форматов.*
3. Подготавливаем файл.

В первой строке указываются названия полей, в которые нужно загрузить данные по клиенту.  
Формат — .csv  
Кодировка — по умолчанию utf-8. Можно проверить кодировку своего файла с помощью текстовых редакторов вроде Notepad++, VS Code и т.д.

Рассмотрим все поля, которые можно передавать в файле.

### Базовые поля

Есть на всех проектах.

В файле должен присутствовать хотя бы один идентификатор клиента: почта, телефон, внешний идентификатор. Остальные поля необязательны.

- Email — Email-адрес
- IsEmailConfirmed — [Email подтвержден](email-and-mobile-confirmation.md)
- MobilePhone — Мобильный телефон
- IsMobilePhoneConfirmed — [Мобильный телефон подтвержден](email-and-mobile-confirmation.md)
- DiscountCard — [Номер дисконтной карты](discount-cards-import.md)
- Area — Идентификатор [зоны](areas-import.md) клиента
- LastName — Фамилия
- FirstName — [Имя](client-fullname.md)
- MiddleName — [Отчество](client-fullname.md)
- FullName — [ФИО](client-fullname.md#pravila-obrabotki-pri-peredache-fio-v-pole-fullname)
- Sex — [Пол](client-sex.md)
- BirthDate — Дата рождения
- IsSubscribed — Глобальная [подписка](subscriptions.md)
- IsSubscribedByEmail — Подписка в точке контакта Email
  - то же по всем другим каналам (SMS, Viber, MobilePush, WebPush), например IsSubscribedBySms
  - при добавлении [тематики](%D0%BA%D0%B0%D0%BA-%D1%81%D0%BE%D0%B7%D0%B4%D0%B0%D1%82%D1%8C-%D1%82%D0%B5%D0%BC%D0%B0%D1%82%D0%B8%D0%BA%D1%83-%D1%80%D0%B0%D1%81%D1%81%D1%8B%D0%BB%D0%BA%D0%B8.md), появляется колонка по подписке на тематику в канале, например IsSubscribedByEmailOnNews

    Примечание

    Если на вашем проекте используется [мультибренд](https://help.mindbox.ru/docs/multibrand), `IsSubscribed`, `IsSubscribedByEmail` и `IsSubscribedByEmailOnNews` будут подписывать клиента на бренд точки контакта. Подробнее в [разделе](clients-import.md#kak-podpisat-klientov-na-brend).

### Дополнительные поля

Если не хватает базовых полей, добавьте [дополнительные](additional-data). Просмотрите их список или уточните у коллег, не создавали ли они уже поля для вашей задачи, чтобы не хранить данные в нескольких местах одновременно.

После добавления поля его название появляется в списке. Обновите страницу, чтобы его увидеть. Имя формируется следующим образом: **CustomFieldСистемноеИмяПоля**

Если вы создаете дополнительное поле типа «Уникальный идентификатор», название сформируется в виде: **ExternalIdentityСистемноеИмяПоля**

## Расширенные настройки

Подходит для случаев, когда нужно импортировать клиентов с собственным действием, точкой контакта или временем, а также для добавления клиентов при загрузке в сегмент.

Можно указать в настройках (сработает для всех в файле) или в файле (значение для каждого клиента будет браться из данных в его строке).

Расширенные настройки:

![Снимок экрана 2023-06-26 в 10.28.12.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-06-26%20%D0%B2%2010.28.12.png)

- Точка интеграции — источник данных. По умолчанию — Административная панель Mindbox.
- Точка контакта. По умолчанию определяться автоматически по точке интеграции. Можно заменить на любую другую.
- Сегментация — статический сегмент, в который будут добавлены все клиенты из файла. Можно выбрать существующий или создать новый.
- Действие-источник — с каким действием клиент попадет в базу.

### Как подписать клиентов на бренд

При использовании мультибренда на проекте бренд точки интеграции определяет бренд подписки клиента, которая передается через поля: `IsSubscribed`, `IsSubscribedByEmail` и `IsSubscribedByEmailOnNews`.

Если необходимо подписать клиентов на несколько брендов одновременно, импорт нужно загрузить повторно для каждого бренда.

1. Определите точку интеграции вашего бренда. Для этого перейдите в раздел «Интеграции».
2. Выберите бренд через фильтр и подберите точку интеграции для импорта. Например, необходимо подписать клиента на рассылки бренда Demo. Возьмем для этого точку интеграции сайта:

   ![clients-import-multibrand-sub.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/clients-import-multibrand-sub.png)
3. Укажите эту точку интеграции в «Расширенных настройках» импорта:

   ![clients-import-multibrand-sub-settings.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/clients-import-multibrand-sub-settings.png)

### Использовать другой шаблон действия

Если нужного шаблона ещё нет на проекте, [создайте](template-create.md) его заранее или перейдя по ссылке со страницы импорта. Категории укажите, исходя из бизнес-задачи.

**У всех в файле одинаковый шаблон**  
Указываем в настройках:

![Снимок экрана 2023-06-26 в 10.40.40.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-06-26%20%D0%B2%2010.40.40.png)  
*Задаем свои шаблоны для создания.*

**У клиентов в файле разные шаблоны**  
Указываем в файле с помощью колонки SourceActionTemplate для действия-источника и LastUpdateActionTemplate для действия редактирования.

Действие редактирования можно указать только в файле и только с шаблоном категории «Личное действие».  
В остальных случаях изменения клиента сохраняются без записи действия.

Вписываются системные имена шаблонов:

![](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/Снимок%20экрана%202022-09-08%20в%2017.20.15.png)
*Задаем свои шаблоны только для создания.*

В настройках при этом отмечаем пункт «Брать значение из файла»:

![Снимок экрана 2023-06-26 в 10.44.06.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-06-26%20%D0%B2%2010.44.06.png)

### Использовать другую точку контакта

Если нужной точки ещё нет на проекте, [создайте](point-of-contact-add.md) её заранее или перейдя по ссылке со страницы импорта.

**У всех в файле одинаковая точка контакта**  
Выбираем в настройках точку интеграции с нужной точкой или указываем ее явно:

![Снимок экрана 2023-06-26 в 10.50.35.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-06-26%20%D0%B2%2010.50.35.png)

**У клиентов в файле разные точки контакта**  
Указываем в файле с помощью колонки SourcePointOfContact для действия-источника и LastUpdatePointOfContact для действия редактирования. Вписываются внешние идентификаторы точек:

![](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/Снимок%20экрана%202022-09-08%20в%2017.54.26.png)

В настройках отмечаем пункт «Брать значение из файла»:

![Снимок экрана 2023-06-26 в 10.51.11.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-06-26%20%D0%B2%2010.51.11.png)

### Использовать другое время

Отдельной настройки по времени нет, поэтому можно указать только с помощью колонки SourceDateTime для действия-источника и LastUpdateDateTime для действия редактирования:

![Снимок экрана 2022-09-08 в 18.00.21.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-09-08%20%D0%B2%2018.00.21.png)

Если не включать в файл данные столбцы, действия запишутся по времени выполнения задачи импорта.
