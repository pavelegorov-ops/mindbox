# Отчет по тарифицируемым данным

Для просмотра показателей о выставленном счете перейдите в раздел: **Аналитика → Биллинг → Отчет по тарифицируемым данным:**

![биллинг.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%B1%D0%B8%D0%BB%D0%BB%D0%B8%D0%BD%D0%B3.png)

### Назначение отчета

Одна из составляющих [стоимости подписки](billing-recommendations.md) — хранение действий и переходов между сегментами сверх лимита.  
Проверить, есть ли на вашем проекте превышение по этим пунктам, можно в [детализации счетов](billing-modules.md) ('Расширения').

При этом в разделе выводятся максимальные показатели за месяц — по ним и будет считаться подписка. Если удалить данные, изменения не отобразятся в разделе до следующего месяца.

Отчет позволяет узнать фактическое число действий и переходов на данный момент и удостовериться, что их количество уменьшилось к началу следующего расчетного периода, а также посмотреть разбивку по шаблонам действия и сегментациям.

### Как построить отчет

Укажите нужные даты и нажмите на кнопку «Сформировать»:

![Снимок экрана 2023-01-23 в 10.29.34.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-01-23%20%D0%B2%2010.29.34.png)

#### Диапазон дат

- Отчет показывает прирост действий за выбранный период. То есть для получения полного количества данных на текущий момент, нужно будет выбрать даты со времени запуска проекта.
- Правая граница не включается в отчет.

### Как читать отчет

Удаленные действия и сегменты не попадают в отчет.

В полученном файле будут листы:

- «Количество действий по месяцам» — новые действия в каждый месяц с разбивкой на шаблоны трех категорий;
- «Доля категорий действий от общего количества за период» — доля шаблонов из категории от числа тарифицируемых за период;
- «Сегменты. Переходы по месяцам» — новые переходы в каждый месяц;
- «Сегменты. Количество переходов» — доля переходов по сегментам от общего числа за период.

#### Действия

Тарифицируются действия с категориями «Личные действия клиента» и «Действия в отношении клиента».

Чтобы посмотреть общее число за период построения, в таблице не должно быть выбрано поле «Дата»:

![Снимок экрана 2023-01-23 в 11.00.31.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-01-23%20%D0%B2%2011.00.31.png)

Чтобы посмотреть разбивку с шаблонами действия, в таблице нужно выбрать поле «Шаблон действия»:

![Снимок экрана 2023-01-23 в 11.00.59.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-01-23%20%D0%B2%2011.00.59.png)

Доля каждого шаблона:

![Снимок экрана 2023-01-23 в 11.17.10.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-01-23%20%D0%B2%2011.17.10.png)

#### Сегменты

Тарифицируются переходы между пересчитываемыми и статическими сегментами клиентов.

Чтобы посмотреть общее число за период построения, в таблице не должно быть выбрано поле «Дата»:

![Снимок экрана 2023-01-23 в 11.23.59.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-01-23%20%D0%B2%2011.23.59.png)*Здесь же — разбивка по сегментам и доля каждого за период.*
