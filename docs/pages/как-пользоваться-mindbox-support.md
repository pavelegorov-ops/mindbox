# Как пользоваться Mindbox Support

Каждый клиент Mindbox может обратиться за помощью с решением текущих задач в системе в техническую поддержку.  
За всеми проектами закреплены специалисты тех.поддержки, которые оперативно ответят на вопросы чата по будням с 10 до 19 по Мск.

### Как написать в Поддержку

На каждой странице системы есть зеленая кнопка справа внизу.

![image](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-09-02%20%D0%B2%2017.51.49.png)

В открывающемся меню можно создать новый чат или перейти в один из открытых ранее

![image](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-09-02%20%D0%B2%2017.53.47.png)

Можно написать на почту [support@mindbox.ru](mailto:support@mindbox.ru), ваш запрос попадет к нам в систему и будет обработан так же быстро, как и чат.

**Скорость первого ответа тех.поддержки в чате в среднем 5 минут**, поэтому текущие вопросы по системе удобнее и оперативнее решать прямо в чате.

Ниже приведем примеры с какими видами задач вы можете обратиться в Поддержку.

### Какие задачи можно решить через Поддержку

В чате поддержки можно получить консультацию/помощь/рекомендации по:

- построению фильтров в Клиентах/Действиях/Продуктах/Картах/Промокодах
- созданию сегментов по всем сущностям
- параметрам в шаблонах рассылки (динамическая верстка)
- проверке корректности условий промоакций
- заведению пулов промокодов
- проверке работы продуктовых рекомендаций
- настройке сценариев
- настройке и тестированию рассылок/голосований
- формированию отчетов
- поиску нужного раздела в системе
- механикам, которые можно настроить в Mindbox.

Приоритет Mindbox Support - обучение клиента всем тонкостям системы для полноценной работы. Поэтому у нас есть постоянно обновляющийся каталог статей ([Хелп](https://help.mindbox.ru/docs)) для большинства кейсов работы. Эти статьи специалисты тех.поддержки приводят в качестве инструкций для наиболее распространенных вопросов и задач.

В Поддержке вы можете задать любой вопрос по работе системы, но корректность работы интеграции, заведение сложных механик и финансовые вопросы лучше уточнять напрямую с менеджером проекта.
