# Отчет «Сравнение сегментов клиентов»

Отчет помогает сравнить все сегменты клиентов по ключевым показателям. Полезен для поиска интересных закономерностей или для оценки, какая стратегия работы лучше, если для разных сегментов разный подход.

Для построения отчета необходимо перейти в раздел **Аналитика → Основные → Сравнение сегментов клиентов:**

![сравнение.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D1%81%D1%80%D0%B0%D0%B2%D0%BD%D0%B5%D0%BD%D0%B8%D0%B5.png)

**Сравнение состава сегментов по показателям:**

- Возраст
- Количество покупок
- Общая сумма покупок
- Пол
- Средний чек

**Просмотр отчета**

Откроем excel файл с результатом отчета и посмотрим результаты.

1. Выберем параметр:

**Пример использования отчета:**

- Сегменты «пользователи iOS» и «пользователи Android» могут иметь разные распределения по группам среднего чека. Если отчёт фиксирует существенность различия, то разным группам пользователей можно рекомендовать товары с разной ценой, что повысит продажи в обоих сегментах.
- Сегменты «Смотрели продукты категории X» и «Купили продукты категории X» могут существенно различаться по половой и возрастной структуре. Зная это, можно лучше настроить персонализацию почтовых рассылок и настроек платного трафика.
- Сегменты «Участники программы лояльности» и «Не участники программы лояльности» должны иметь существенные различия по количеству покупок. Таким образом проверить, оказалась ли программа лояльности интересной наиболее выгодным клиентам.
- Если нужно сравнить контрольную группу и основную — насколько равномерно они распределены.
