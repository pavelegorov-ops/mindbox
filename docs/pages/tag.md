# Как создать тег действий

Теги позволяют дифференцировать между собой шаблоны действий.

1. Переходим в раздел **Настройки** → **Клиенты и действия** → **Шаблоны действий**:

![action-templates-interface.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/action-templates-interface.png)

2. Нажимаем «Добавить» → «Тег действия»:

![action-templates-add-tag.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/action-templates-add-tag.png)

3. Заполняем поля для создания тега

![Снимок экрана 2021-07-12 в 15.34.18.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-07-12%20%D0%B2%2015.34.18.png)

*Имя* — как тег будет отображаться в системе.  
*Системное имя* — как мы храним имя у себя в базе, подставится автоматически.  
*Описание* — можно скопировать имя или составить подробное описание.  
*Как используется* — можно поставит прочерк или указать место, где будете использовать тег.

4. Нажимаем на кнопку «Сохранить» и видим сообщение об успешном сохранении:

![Снимок экрана 2021-07-12 в 15.34.40.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-07-12%20%D0%B2%2015.34.40.png)
