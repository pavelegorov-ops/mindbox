# Как массово импортировать персонал по файлу

Чтобы импортировать персонал:

1. Перейдите в раздел **Настройки** → **Безопасность** → **Пользователи**:

![персонал.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%BF%D0%B5%D1%80%D1%81%D0%BE%D0%BD%D0%B0%D0%BB.png)

2. Выберите в меню «Импорт»:

![Снимок экрана 2022-11-06 в 01.06.18.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-11-06%20%D0%B2%2001.06.18.png)

3. Выберите операцию «Массовое добавление персонала»:

![Скриншот 21-03-2022 15.14.01.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BA%D1%80%D0%B8%D0%BD%D1%88%D0%BE%D1%82%2021-03-2022%2015.14.01.png)  
*Для скачивания доступен шаблон с примером. Также на странице появляются данные по всем возможным полям для загрузки: их название, описание и обязательность с примерами принимаемых форматов.*

4. Подготовьте файл для импорта.

В первой строке указываются названия полей, в которые нужно загрузить данные по персоналу.  
Формат — .csv  
Кодировка — по умолчанию utf-8.

Основные поля, которые можно передавать в файле:

- **UserName** (Логин) — заполняется латиницей; обязательное поле.
- **MobilePhone** (Мобильный номер) — необязательно. Но при [двухфакторной аутентификации](2-step-verification.md) по SMS без связанного номера не войти.
- **Email** — на этот адрес будет отправлено письмо со ссылкой, по которой новый пользователь сможет установить пароль; обязательное поле.
- **Comment** (Комментарий) — например, роль сотрудника; обязательное поле.
- **IsChargeable** (Тарифицируемый доступ к чату поддержки) — тарифицируется при наличии более пяти аккаунтов с доступом к [чату поддержки](%D0%BA%D0%B0%D0%BA-%D0%BF%D0%BE%D0%BB%D1%8C%D0%B7%D0%BE%D0%B2%D0%B0%D1%82%D1%8C%D1%81%D1%8F-mindbox-support.md).
- **FirstName** (Имя) — необязательно.
- **LastName** (Фамилия) — необязательно.
- **Groups** (Группы безопасности) — общая группа, включающая набор прав. Можно использовать [системные](system-staff-groups.md) или [создать свою](staff-group-create.md).  
  Чтобы назначить группу безопасности, нужно либо самому в ней находиться, либо иметь весь набор ее пермиссий. Исключение — группы безопасности сотрудников Mindbox, их нельзя выбрать из интерфейса.В файле в поле Groups указываем системное имя группы.![](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/Снимок%20экрана%202022-11-06%20в%2002.21.08.png)
- **Permissions** (Дополнительные права) — добавить [дополнительные права](permissions.md), помимо тех, что есть в выданной группе безопасности.  
  Дополнительные права можно выдавать те, которые есть в своем профиле.

*Пример заполненного файла:*

![Скриншот 21-03-2022 15.20.38.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BA%D1%80%D0%B8%D0%BD%D1%88%D0%BE%D1%82%2021-03-2022%2015.20.38.png)

5. Загрузите созданный файл и поставьте импорт нажатием кнопки «Добавить задачу».

- Появится ссылка на задачу:

![Снимок экрана 2021-11-07 в 14.46.08.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-11-07%20%D0%B2%2014.46.08.png)

- Персонал будет добавлен после успешного завершения задачи:

![Снимок экрана 2021-11-07 в 14.51.22.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-11-07%20%D0%B2%2014.51.22%281%29.png)

Созданным пользователям на почту придет письмо с ссылкой для установки пароля. После этого они смогут начать работу в системе.
