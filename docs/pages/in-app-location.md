# Как настроить отображение In-App’а в любом месте приложения

In-App можно показывать не только при старте приложения, но и на любом другом экране приложения, а также ответом на действия пользователя. Например, по нажатию на кнопку или при переходе на другой экран.

Опция доступна в версиях SDK 2.5.0 [iOS](https://github.com/mindbox-cloud/ios-sdk/releases/tag/2.5.0) и [Android](https://github.com/mindbox-cloud/android-sdk/releases/tag/2.5.0).

Для настройки показа In-App’а в любом месте в приложении:

1. Определите места в приложении, где нужно показывать In-App. При наличии приложений и на iOS, и на Android, желательно, чтобы это были одинаковые места.
2. Создайте [операцию](%D0%BE%D0%BF%D0%B5%D1%80%D0%B0%D1%86%D0%B8%D0%B8-v-%D0%BE%D1%81%D0%BD%D0%BE%D0%B2%D0%BD%D1%8B%D0%B5-%D1%81%D0%B2%D0%B5%D0%B4%D0%B5%D0%BD%D0%B8%D1%8F.md) в Mindbox.

В точках интеграции укажите нужные приложения.  
Шаг: «Клиент — Неавторизованный — Получить существующего» ищем по «устройству».

![Снимок экрана 2023-04-09 в 17.15.09.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-04-09%20%D0%B2%2017.15.09.png)

3. Настройте вызов операций в мобильном приложении по [инструкции](https://developers.mindbox.ru/docs/in-app-targeting-by-custom-operation).
4. [Создайте In-App](in-apps.md).

В блоке «Таргетинг» выберите операцию, при вызове которой будет показываться In-App.  
В списке отображаются только те операции, которые доступны для всех приложений, указанных в общих настройках in-app'а.

![Снимок экрана 2023-04-09 в 17.12.57.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-04-09%20%D0%B2%2017.12.57.png)

Нажмите кнопку «Добавить фильтр» и «Сохранить» в блоке. После этого можно запускать In-App. Он будет показан всем пользователям при старте мобильного приложения, но после показа экранов с онбордингом.
