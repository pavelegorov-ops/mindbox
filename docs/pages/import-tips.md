# Рекомендации по импорту клиентов

Подготовка файла к импорту позволит избежать ошибок и задержки при загрузке данных.

Файл должен подходить под следующие критерии:

- Количество колонок — до 20 включительно.
- Количество [дубликатов](%D0%BA%D0%B0%D0%BA-mindbox-%D1%81%D0%BE%D0%B7%D0%B4%D0%B0%D0%B5%D1%82-%D0%B5%D0%B4%D0%B8%D0%BD%D1%8B%D0%B9-%D0%BF%D1%80%D0%BE%D1%84%D0%B8%D0%BB%D1%8C-%D0%BA%D0%BB%D0%B8%D0%B5%D0%BD%D1%82%D0%B0.md) — менее 5%

### Ожидания по скорости

Если файлы импорта соответствует описанным выше требованиям, можно рассчитать примерную скорость выполнения задач в зависимости от количества клиентов на проекте.

|  |  |
| --- | --- |
| **Количество клиентов** | **Ожидаемая скорость** |
| 50 0​01 — 99 999 | 150 0​00 строк в час |
| 100 0​00 — 999 999 | 300 0​00 строк в час |
| Свыше 1 000 0​00 | 1 000 0​00 строк в час |

### Если скорость снижена

При низкой скорости импорта файла, соответствующего требованиям, Mindbox автоматически узнает о проблеме и приступает к ее исследованию.  
Если скорость остается сниженной на протяжении долгого времени, обратитесь в чат поддержки.
