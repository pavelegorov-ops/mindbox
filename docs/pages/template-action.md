# Шаблон действия для выдачи действия в операции или сценарии

Одним из возможных шагов в операции и сценарии является выдача [действия](action).  
Чтобы [созданный шаблон](template-create.md) был доступен, должны выполняться два условия:

1. Шаблон создан в той же кампании, что и операция/сценарий, или в её дочерней кампании;  
   2.Выбраны правильные категории шаблона.
