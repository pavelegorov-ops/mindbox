# Как выгрузить продукты

Чтобы выгрузить продукты:

1. Перейдите в раздел **Данные** → **Продукты**:

![Снимок экрана 2021-08-24 в 14.37.32.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-08-24%20%D0%B2%2014.37.32.png)

2. При необходимости постройте фильтр. Отметьте нужные продукты: можно выбрать все найденные или отобрать только часть из них с помощью чекбоксов:

![Снимок экрана 2023-03-06 в 20.14.00.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-03-06%20%D0%B2%2020.14.00.png)

Кнопка экспорта доступна только при выборе хотя бы одного продукта.

3. Нажмите «Экспорт» → «Продуктов»:

![Снимок экрана 2023-03-06 в 20.14.33.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-03-06%20%D0%B2%2020.14.33.png)

- Ставится задача:

![Снимок экрана 2023-03-06 в 20.14.45.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-03-06%20%D0%B2%2020.14.45.png)

- Файл доступен после завершения задачи. В описании — ссылки на фильтр, по которому была поставлена выгрузка, и на операцию экспорта:

![Снимок экрана 2023-03-06 в 20.26.41.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-03-06%20%D0%B2%2020.26.41.png)

В файле будут данные по всем полям выбранных продуктов в cvs-формате.

### Выгрузить продукты в JSON или XML

Чтобы получить выгрузку в других форматах, нужно создать для них отдельные операции.

Для этого:

1. В меню экспорта нажмите «Добавить экспорт»:

![Снимок экрана 2023-03-06 в 20.42.58.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-03-06%20%D0%B2%2020.42.58.png)

2. Заполните настройки операции:

![Снимок экрана 2023-03-06 в 20.44.41.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-03-06%20%D0%B2%2020.44.41.png)

В качестве точек интеграции доступны:

- «Административная панель Mindbox».  
  Операции с этой точкой добавляются на проект в выпадающий список экспортов. При выборе данной настройки указывать сегмент продуктов нельзя, так как нужные продукты выбираются непосредственно в разделе.
- Пользовательские точки интеграции.  
  Операции с остальными точками интеграции нельзя ставить из интерфейса проекта, но их можно вызывать по API по конкретному сегменту.

Экспорт появляется в списке:

![Снимок экрана 2023-03-06 в 20.45.13.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-03-06%20%D0%B2%2020.45.13.png)
