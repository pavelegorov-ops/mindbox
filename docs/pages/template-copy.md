# Как клонировать шаблон действия

Функция клонирования позволяет быстро создать новый шаблон действия из существующего.

1. Переходим в раздел **Настройки** → **Клиенты и действия** → **Шаблоны действий**:

![action-templates-interface.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/action-templates-interface.png)

2. Находим нужный шаблон, нажимаем на шестеренку → «Клонировать»:

![action-templates-copy.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/action-templates-copy.png)

3. Заполняем настройки:

![action-templates-copy-example.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/action-templates-copy-example.png)

4. Нажимаем «Сохранить».
