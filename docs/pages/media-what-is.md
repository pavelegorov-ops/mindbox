# Как настроить модуль Медиа

С помощью модуля Медиа можно в автоматическом режиме передавать сегменты (аудитории) из Mindbox в рекламные кабинеты:

- Яндекс.Аудитории
- Google AdWords
- VK Реклама
- ВКонтакте
- MyTarget
- Facebook*

Благодаря этому в рекламных кабинетах можно:

- настраивать персонализированную рекламу, основанную на личных данных и истории поведения пользователей;
- привлекать новых клиентов с помощью look-alike технологии;
- снизить частоту показа рекламы, исключив ненужные аудитории;
- реактивировать покупателей.

Также модуль позволяет наполнять Mindbox данными из лид-форм.

Для настройки модуля на стороне Mindbox нужно:

1. Создать рекламный кабинет (точку интеграции).
2. Подключиться к нему.
3. Создать связки для передачи сегментов через подключение.

### Создать рекламный кабинет

Достаточно одного рекламного кабинета на бренд. С его помощью можно настраивать подключение ко всем нужным сервисам.

1. Перейдите в раздел **Интеграции** и нажмите «Добавить интеграцию»:

2. Выберите «Рекламные кабинеты»:

![Снимок экрана 2022-07-15 в 18.14.56.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-07-15%20%D0%B2%2018.14.56.png)

3. Задайте название, выберите бренд (для многобрендовых проектов) и нажмите «Добавить интеграцию»:

![Снимок экрана 2022-07-15 в 18.24.441.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-07-15%20%D0%B2%2018.24.44%281%29%281%29.png)

### Подключиться к рекламным кабинетам

Подключение — это канал для передачи аудиторий (сегментов) между Mindbox и рекламным кабинетом.

Для отдельного сервиса достаточно добавить одно подключение и использовать его во всех связках кабинета.

Раздел «Медиа» доступен только после включения модуля.

Для этого обратитесь к менеджеру проекта или запросите подключение в разделе **[Подписка и оплата](billing-modules.md)**.

1. Перейдите в раздел **Интеграции** → **Медиа** и перейдите на вкладку «Подключения»:

![медиа — копия.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%BC%D0%B5%D0%B4%D0%B8%D0%B0%C2%A0%E2%80%94%20%D0%BA%D0%BE%D0%BF%D0%B8%D1%8F.png)

![Снимок экрана 2023-07-25 в 18.09.52.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-07-25%20%D0%B2%2018.09.52.png)

2. Нажмите «Добавить подключение»:

![Снимок экрана 2023-05-16 в 13.18.37.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-05-16%20%D0%B2%2013.18.37.png)

3. Выберите нужный сервис и нажмите «Добавить подключение»:

![Снимок экрана 2023-05-16 в 13.19.31.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-05-16%20%D0%B2%2013.19.31.png)

4. Задайте его название:

![Снимок экрана 2023-05-16 в 13.58.08.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-05-16%20%D0%B2%2013.58.08.png)

*Отозвать токены доступа, ранее выданные приложению при предоставлении доступа* — выбор опции заберет доступ у подключений, ранее созданных с выбранным аккаунтом.

5. Нажмите «**Предоставить доступ**»:

![Снимок экрана 2023-05-16 в 13.20.45.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-05-16%20%D0%B2%2013.20.45.png)

Далее откроется окно выбранного сервиса, где нужно будет дать доступ к аккаунту.

- Для сбора лидов настройте связку [по инструкции](media-leads.md).
