# Можно ли выключить дедубликацию?

Дедубликацию отключить нельзя. Контакты клиентов должны быть уникальны. Поэтому системе обязательно нужно принять решение кому из клиентов принадлежит номер телефона или email. И возможно ли их объединение.

[Собираем единый профиль клиента](https://mindbox.ru/academy/education/zachem-sobirat-edinyj-profil-klienta/) для точного таргетинга, улучшения пользовательского опыта, чистоты данных.
