# Сколько мобильных приложений можно интегрировать с Mindbox

Вы можете интегрировать несколько мобильных приложений с одним проектом Mindbox.  
Количество мобильных приложений не ограничено.

Для интеграции каждого нового мобильного приложения нужно создавать новые «точки интеграции»: для iOS-приложения и для Android.

[Работа с API без навыков программирования](https://mindbox.ru/academy/education/kak-rabotat-s-api/) - интегрируем друг с другом разные сервисы типа банкинга, телефонии и CRM-систем.
