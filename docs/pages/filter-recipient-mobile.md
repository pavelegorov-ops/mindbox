# Найти получателей мобильных пушей

Мобильные пуши можно отправлять клиентам, у которых есть подписка на канал и мобильное приложение с нужными разрешениями:

- Если рассылка по [тематике](%D0%BA%D0%B0%D0%BA-%D1%81%D0%BE%D0%B7%D0%B4%D0%B0%D1%82%D1%8C-%D1%82%D0%B5%D0%BC%D0%B0%D1%82%D0%B8%D0%BA%D1%83-%D1%80%D0%B0%D1%81%D1%81%D1%8B%D0%BB%D0%BA%D0%B8.md), подписка должна быть именно на эту тематику.

Фильтр из статьи подставляется в рассылку **автоматически**.  
Его не надо вводить в блок получателей рассылки.  
Инструкция для того, чтобы определить примерное количество клиентов, которым можно отправлять коммуникации

Переходим на вкладку **Данные** -> **Клиенты**:
