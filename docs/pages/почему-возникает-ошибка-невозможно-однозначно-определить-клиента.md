# Почему возникает ошибка “Невозможно однозначно определить клиента”?

Переданные при импорте или редактировании идентификаторы принадлежат разным клиентам. В этом случае система не может выбрать клиента с которым требуется произвести действия.

Часто один из идентификаторов находится в истории у клиента. Проверить это можно при анализе истории изменений в профиле клиента.

**Пример.**

Клиент1 c WebsiteID 111111

Клиент2 с CrmID 222222

В импорте приходит запись: WebsiteID 111111; CrmID 222222; Email [mail1@mail.ru](mailto:mail1@mail.ru)

Предполагается, что клиенту будет добавлен email. Но т.к. ID принадлежат разным клиентам, то нельзя определить кому из них записать email. Поэтому изменения данных не происходит и выдается ошибка.
