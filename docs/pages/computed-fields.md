# Вычисляемые поля

Вычисляемые поля позволяют автоматически обогащать профиль клиента данными, рассчитанными на основе его поведения. Например, система может определить:

- какой продукт или категорию клиент покупает чаще всего,
- какие товары он просматривает больше всего,
- какого бренда предпочитает продукцию.

После пересчёта полученное значение сохраняется в карточке клиента как отдельное поле, которое можно использовать:

- для сегментации аудиторий,
- в персонализированных рассылках и рекомендациях,
- в настройке сценариев по событию [«Предпочитаемый продукт изменился»](workflow-events.md#predpochitaemyj-produkt-izmenilsya).

## Создать вычисляемое поле

В демо-режиме возможно создание не более 2 полей. При [подключении модуля](billing-modules#vklyuchit-i-vyklyuchit-modul) «Вычисляемые поля» лимит увеличивается до 10. Модуль доступен начиная с [тарифа 7.3](https://mindbox.ru/documents/pricing/7-3/)

1. Перейдите на вкладку **Настройки** → **Системные** → **Дополнительные поля**:

![computed-field-menu.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/computed-field-menu.png)

2. Нажмите «Создать» → «Вычисляемое поле»:

![computed-field-create.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/computed-field-create.png)

3. Заполните настройки:

![computed-field-general-settings](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/computed-field-general-settings.png)

### **Общие настройки**

- Имя — как поле будет выводиться в фильтрах и кампаниях
- Бренд
- Системное имя — используется в интеграциях и параметрах шаблонизатора

### **Пересчет**

- Частота — вручную или каждый день
- Период — данные за какое время учитывать в подсчете

- **Первый расчет** после создания или редактирования поля может занять **от одного дня** в зависимости от объёма данных в проекте.
- Последующие пересчеты выполняются в ночное время.

## Вывод в рассылке

Параметры по вычисляемым полям находятся в списке `Recipient.CustomField`

Для вывода продукта по клиенту используется параметр вида `Recipient.CustomField.{Системное имя поля}`.

Важно

Вычисляемые поля не учитывают региональные данные продуктов. При выводе данных продукта в рассылку будут подставлены данные из *мастер-фида*.

Доступные параметры зависят от типа вычисляемого поля.

> Определяли продукт — доступны все параметры по продукту:

![Снимок экрана 2024-09-13 в 13.24.46.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202024-09-13%20%D0%B2%2013.24.46.png)

> Искали самое частое значение дополнительного поля — доступны параметры по выводу этого поля:  
> ![Снимок экрана 2024-11-22 в 15.09.16.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/aa/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202024-11-22%20%D0%B2%2015.09.16.png)
