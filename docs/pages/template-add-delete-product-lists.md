# Шаблоны действия для добавления/удаления продуктов из списка продуктов

Чаще всего изменения списков продуктов происходит через операции. При этом шаблоны действия для операций создаются автоматически. Но в некоторых случаях стоит задача [отредактировать списки через интерфейс](product-lists-edit.md).

Для создания шаблона воспользуемся [общей](template-create.md) инструкцией, поменяв лишь категории на нужные для нашей задачи.
