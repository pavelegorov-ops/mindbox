# Как обнулить баланс по файлу

Чтобы выдать или снять баллы:

1. В разделе **Данные** → **Клиенты** нажмите «Импорт» → «Изменить баланс»:

![Снимок экрана 2022-06-19 в 17.05.14.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-06-19%20%D0%B2%2017.05.14.png)

2. Выберите операцию «Обнуление балльных счетов». Для скачивания доступен шаблон с примером:

![Снимок экрана 2023-02-09 в 19.18.04.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-02-09%20%D0%B2%2019.18.04.png)

3. Заполните настройки:

- Комментарий к задаче — поможет найти задачу в списке; необязательно.
- Кодировка файла — по умолчанию utf-8.
- Файл для импорта — разберем в следующем пункте.

Дальнейшие поля можно либо заполнить едино для всех клиентов из задачи, либо не указывать их в настройках, а задать индивидуально для каждого в файле:

- Точка интеграции — источник данных.
- Точка контакта — где произошло обнуление баланса. По умолчанию определяться автоматически по точке интеграции. Можно заменить на любую другую.
- Провайдер идентификации — какой контакт или идентификатор будет указан в файле для определения клиента.
- Действие изменения баланса — с каким действием обнулить баллы. Можно использовать имеющийся на проекте шаблон или [создать](template-create.md) новый.
- Причина — необязательно.
- Балльный счет — какой счет нужно обнулить.

![Снимок экрана 2023-02-09 в 19.20.21.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-02-09%20%D0%B2%2019.20.21.png)

4. Заполните файл:

- *CustomerIdentity* — идентификатор клиента (тип выбирается в настройках импорта).

Пример заполненного файла:

![Снимок экрана 2023-02-09 в 19.21.10.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-02-09%20%D0%B2%2019.21.10.png)

5. Добавьте файл и запустите задачу:

![Снимок экрана 2023-02-09 в 19.25.11.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-02-09%20%D0%B2%2019.25.11.png)

- Появляется сообщение о добавлении задачи и ссылка на нее:

![Снимок экрана 2023-02-09 в 19.25.23.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-02-09%20%D0%B2%2019.25.23.png)
