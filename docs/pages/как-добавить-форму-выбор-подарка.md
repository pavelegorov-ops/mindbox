# Как добавить форму «Выбор подарка»

Для запуска этого попапа требуется интеграция:

нужно выполнить настройки по инструкции: [https://developers.mindbox.ru/page/рекомендации-на-сайт](https://developers.mindbox.ru/page/%D1%80%D0%B5%D0%BA%D0%BE%D0%BC%D0%B5%D0%BD%D0%B4%D0%B0%D1%86%D0%B8%D0%B8-%D0%BD%D0%B0-%D1%81%D0%B0%D0%B9%D1%82)

#### **Задача:**

Создать игровую форму с "Выбором подарка", которая будет предлагать выиграть один из подарков за подписку.  
Возможные подарки:

- скидка - 5%
- бонусные 500 рублей
- бонусные 200 рублей

#### Условия:

- Случайным образом выпадает один из вариантов, выбранный вариант передаём как дополнительное поле действия;
- Форму показывать всем, кто посещает сайт в первый раз после того, как они посмотрели две страницы на сайте;
- Исключить показ подписчикам;
- После закрытия к форме можно вернуться через кнопку.

[Инструкция по созданию попапа](%D0%BA%D0%B0%D0%BA-%D1%81%D0%BE%D0%B7%D0%B4%D0%B0%D1%82%D1%8C-%D0%BF%D0%BE%D0%BF-%D0%B0%D0%BF.md)

Вам нужно зайти в “**Кампании**” в меню слева, выбрать нужную кампанию из списка кампаний, затем нажать “**Попапы**” - “**Добавить**” - “**Попап**”.

## Определяемся с наполнением формы

Находим из предложенных вариантов нужную форму (можно воспользоваться фильтром "С игровой механикой"), нажимаем “**Выбрать**”.

## Определяем расположение формы на экране

По умолчанию форма показывается по центру экрана. Изменить расположение формы на экране можно с помощью кнопки в нижнем левом углу.

![Снимок экрана 2021-03-27 в 18.49.58.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-03-27%20%D0%B2%2018.49.58.png)

По умолчанию на мобильных устройствах и планшете применяются такие же условия, как и на десктопе. Но можно изменить эти настройки, особенно, если вы используете отступы на десктопе (чтобы на мобильных устройствах форма не улетела за края экрана из-за отступов).

Важно

Данная настройка работает на фронтенде и не является защищенной от «взлома» посетителями через код сайта. Не рекомендуем использовать её для розыгрышей дорогих и особо ценных подарков.

## Адаптируем шаблон под сайт

1. Все тексты - если в тексте нужен перенос строки используйте тег в поле ввода на месте переноса `<br>`;
2. Меняем картинки и иконки (фон в форме можно отключить);
3. Настраиваем подарки: меняем иконки подарков, их количество, текст или картинку после выбора подарка;
4. Добавляем ссылку на политику конфиденциальности - найдите на сайте клиента "Политику конфиденциальности" и скопируйте ссылку (эту настройку не рекомендуем отключать, потому как по законодательству России такая ссылка должна быть в формах сбора данных);
5. Отступы и размеры для мобильных устройств и десктопа - при корректировке размеров обращайте особое внимание на мобильную версию формы;
6. Подбираем шрифты для формы:

Здесь можно указать настройки для шрифта или использовать [свой шрифт](%D0%BA%D0%B0%D0%BA-%D0%B4%D0%BE%D0%B1%D0%B0%D0%B2%D0%B8%D1%82%D1%8C-%D1%81%D0%B2%D0%BE%D0%B8-%D1%88%D1%80%D0%B8%D1%84%D1%82-%D0%B2-%D0%BF%D0%BE%D0%BF-%D0%B0%D0%BF.md) с сайта.

Шрифт в форме будет подгружаться с сайта, но в превью может отображаться некорректно из-за того, что у нас в системе этого уникального шрифта может не быть.  
7. Выбираем цвета формы - рекомендуем для подбора цвета с формы использовать расширение для браузера [Eye Dropper](https://chrome.google.com/webstore/detail/eye-dropper/hmdcmlfkchdmnmnmheododdhjedfccka?hl=ru) или же использовать номер цвета с брендбука компании;  
8. Настраиваем кнопку формы - можно выбрать что произойдет после нажатия на кнопку - закроета форма или киент перейдет по ссылке.

Не забудьте проверить экран после подписки!

## Действия после заполнения формы клиентом

Для того, чтобы подарок был передан в mindbox, требуется настроить действия после заполнения формы. Потребуется создать "Дополнительное поле" с типом "**Перечисление**":  
переходим в **Настройки** → **Системные** → **Дополнительные поля** - "Добавить". Назвать поле можно "Подарок".

![дополн поля — копия.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%B4%D0%BE%D0%BF%D0%BE%D0%BB%D0%BD%20%D0%BF%D0%BE%D0%BB%D1%8F%C2%A0%E2%80%94%20%D0%BA%D0%BE%D0%BF%D0%B8%D1%8F.png)

![Снимок экрана 2024-03-21 в 13.48.49.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202024-03-21%20%D0%B2%2013.48.49.png)

Полная инструкция по созданию дополнительных полей есть по [ссылке](additional-data.md)

Затем нужно заполнить поля, которые должны быть переданы в профиль клиента из формы; также выдается действие, и номер подарка записывается в его дополнительное поле:

![Снимок экрана 2024-03-21 в 13.54.11.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202024-03-21%20%D0%B2%2013.54.11.png)

Выдать подарок клиенту и отправить ему об этом письмо можно разными способами:

1. Выдать промокод в сценарии и подставить его в письмо;
2. Отправить письмо с единым промокодом для каждого варианта выигрыша;
3. Добавить клиента в сегмент для применения акции, которая и будет предоставлять клиенту скидку или другой бенефит. Затем нужно отправлять рассылку с этим бенефитом.

Вы можете выбрать наиболее удобный для вас вариант.

На примере рассмотрим первый вариант.

## Отправить пользователям призы

1. Добавляем на проект [пулы промокод](%D0%BA%D0%B0%D0%BA-%D0%B4%D0%BE%D0%B1%D0%B0%D0%B2%D0%B8%D1%82%D1%8C-%D0%BF%D1%80%D0%BE%D0%BC%D0%BE%D0%BA%D0%BE%D0%B4%D1%8B-%D0%B2-%D0%BF%D1%80%D0%BE%D0%B5%D0%BA%D1%82.md) для каждого типа подарка.
2. Создаем [автоматическую рассылку](email-trigger.md), в которой проверяем полученный подарок. В зависимости от типа подарка выводим соответствующий текст и промокод.

Пример верстки:

```
Используйте промокод

@{if CustomerAction.CustomField.GiftPopup = "Промокод"}
    ${Recipient.LastReceivedPromoCode.WithTypeGiftPromo.Value} для получения скидки 5%

@{else if CustomerAction.CustomField.GiftPopup = "Бонус 500"}
    ${Recipient.LastReceivedPromoCode.WithTypeGift500.Value} для получения 500 бонусных баллов

@{else if CustomerAction.CustomField.GiftPopup = "Бонус 200"}
    ${Recipient.LastReceivedPromoCode.WithTypeGift200.Value} для получения 200 бонусных баллов

@{end if}

на следующую покупку.
```

Если клиент выиграл скидку, для него в рассылке подставится текст:

> Используйте промокод PROMO для получения скидки 5% на следующую покупку.

3. Затем нужно создать [сценарий](what-is-workflow.md), который будет срабатывать на заполнение попапа и отправлять выданные призы.

Запускающее событие — выдача приза. Выберите шаблон из попапа:

## Тестирование формы

В окне редактирования формы слева сверху есть кнопка "Проверить на сайте". С ее помощью вы сможете увидеть как будет работать форма на сайте. Необходимо:

- Нажать кнопку "Проверить на сайте";
- Подставитьссылку на свой сайт;
- Перейти по новой ссылке;
