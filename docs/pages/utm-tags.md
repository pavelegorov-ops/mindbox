# Как настроить UTM-метки в рассылках

## Зачем нужны UTM-метки

UTM-метки используются для отслеживания переходов клиентов на сайт. Это полезный инструмент для анализа поведения клиентов и определения наиболее эффективных каналов и кампаний.

Функционал стандартных UTM-меток автоматически подставляет их в рассылку. Это позволяет экономить время, если используется одинаковый набор меток для большинства коммуникаций.

## Как настроить стандартные UTM-метки

Чтобы настроить значения стандартных UTM-меток, перейдите в раздел **Настройки** → **Рассылки** → **Стандартные UTM-метки**:

![utm-tags-settings-standard.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/utm-tags-settings-standard.png)

Доступны настройки меток для каналов Email, SMS, Вебпуш и для каналов модуля «Уведомления и мессенджеры». На проектах с [мультибрендом](multibrand.md) настройки задаются отдельно для каждого бренда.

Есть пять типов UTM-меток, первые три из которых являются обязательными:

- **utm_source** — источник трафика (mindbox);
- **utm_medium** — канал кампании (email/sms/webpush);
- **utm_campaign** — название кампании. Для этой метки можно использовать параметр шаблонизатора `${Message.MailingUtmName}`, который выводит в ссылку транслитерированное название рассылки;
- **utm_content** — контент ссылки. Можно использовать, чтобы разграничить ссылки на разные элементы одной кампании (например, клиент может кликнуть на логотип или на текстовый блок с одинаковой ссылкой на главную страницу);
- **utm_term** — ключевое слово. Используется для анализа пользовательских запросов.

## Как добавить UTM-метки в рассылку

Чтобы использовать стандартные метки в рассылке, включите соответствующую настройку в блоке «UTM-метки»:

![utm-tags-settings-campaign.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/utm-tags-settings-campaign.png)

UTM-метки автоматически подставляются ко всем ссылкам с типом **«Отслеживаемый переход»**.

- **Если стандартные метки не подходят**, их можно редактировать в рамках конкретной кампании;
- **Если метки нужно заменить только для части ссылок**, то их можно прописать в ссылках вручную. По умолчанию их приоритет выше, поэтому они не будут перезаписаны метками из настроек.

При использовании UTM-меток длина ссылки существенно увеличивается. В SMS-канале, если не использовать [сокращение ссылок](shorten-url-sms), это может привести к увеличению количества оплачиваемых частей и общей стоимости отправки рассылки.
