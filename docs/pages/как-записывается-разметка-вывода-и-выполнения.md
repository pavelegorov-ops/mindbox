# Как записывается разметка вывода и выполнения

**Разметка бывает двух типов:**

- Разметка вывода (отображает текст), начинается со знака доллара:

```
${Recipient.FirstName}
```

Выдаст:

> Иван

```
${Recipient.FirstName & " " & Recipient.LastName}
```

Выдаст:  
Иван Петров

- Разметка выполнения (не может выводить текст), начинается со знака собачки:

```
@{for purchase in Recipient.PurchasesHistory.Purchases} 
… 
@{end for}
```
