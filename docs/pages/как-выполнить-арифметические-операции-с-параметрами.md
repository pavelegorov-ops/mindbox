# Как выполнить арифметические операции с параметрами

- Сложение

```
${Recipient.CustomField.Age + 5}
```

- Вычитание

```
${1000 - Recipient.CustomField.Age}
```

- Умножение

```
${RetailPosition.Cost * RetailPosition.Count}
```

- Деление

```
${Recipient.CustomField.OSum / Recipient.CustomField.OCount}
```
