# Как добавить простую форму подписки

По [ссылке](%D0%BA%D0%B0%D0%BA-%D1%81%D0%BE%D0%B7%D0%B4%D0%B0%D1%82%D1%8C-%D0%BF%D0%BE%D0%BF-%D0%B0%D0%BF.md) есть инструкция по созданию попапа - здесь описано как добавлять трекер на сайт, тестировать форму и как настраивать условия показа.

## Определяемся с наполнением формы

Для удобства в фильтре справа указываем цель попапа. В нашем случае попап нужен для того, чтобы клиент ввел емайл. Возьмем универсальный шаблон для емайл подписки.

Находим из предложенных вариантов нужную форму, нажимаем “**Выбрать**”.

![Снимок экрана 2021-01-25 в 21.36.591](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-01-25%20%D0%B2%2021.36.59%281%29.png)

После выбора шаблона укажите сайт:

![выбрать сайт.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%B2%D1%8B%D0%B1%D1%80%D0%B0%D1%82%D1%8C%20%D1%81%D0%B0%D0%B9%D1%82.png)

## Адаптируем шаблон под сайт

В разделе «Попап» нажмите «Изменить», затем — «Редактировать»:

![редактировать попап.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D1%80%D0%B5%D0%B4%D0%B0%D0%BA%D1%82%D0%B8%D1%80%D0%BE%D0%B2%D0%B0%D1%82%D1%8C%20%D0%BF%D0%BE%D0%BF%D0%B0%D0%BF.png)

Далее мы попадаем в “**Редактирование шаблона**”.

![Снимок экрана 2021-01-25 в 21.47.321](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-01-25%20%D0%B2%2021.47.32%281%29.png)

В этом меню можно пройтись по всем вкладкам справа.

1. Все тексты - если в тексте нужен перенос строки, используйте тег в поле ввода на месте переноса `<br>`;
2. Картинки и иконки;
3. Далее настраиваем “Отступы” для мобильных устройств и десктопа;
4. Политика конфиденциальности:  
   найдите на сайте клиента эту страницу и скопируйте на нее ссылку. Эту настройку не рекомендуем отключать, так как по законодательству России такая ссылка должна быть в формах сбора данных.
5. Поля ввода данных;
6. Далее настраиваем размеры для мобильных устройств, десктопа и размеры шрифтов;
7. Рамки и границы формы;
8. Скрытие элементов формы;
9. Цвета формы:  
   выберите подходящие цвета. Рекомендуем для подбора цвета использовать расширение для браузера [Eye Dropper](https://chrome.google.com/webstore/detail/eye-dropper/hmdcmlfkchdmnmnmheododdhjedfccka?hl=ru) или использовать номер цвета с брендбука компании.
10. Шрифты: общие настройки - здесь вы можете выбрать шрифт из предложенных или использовать свой с сайта - тут есть подробная инструкция [как добавить шрифт с сайта](%D0%BA%D0%B0%D0%BA-%D0%B4%D0%BE%D0%B1%D0%B0%D0%B2%D0%B8%D1%82%D1%8C-%D1%81%D0%B2%D0%BE%D0%B8-%D1%88%D1%80%D0%B8%D1%84%D1%82-%D0%B2-%D0%BF%D0%BE%D0%BF-%D0%B0%D0%BF.md). Шрифт формы из списка предложенных будет сразу отображаться в превью и на сайте.

## Настройка для мобильных устройств и планшета

![Снимок экрана 2021-01-25 в 22.07.22](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-01-25%20%D0%B2%2022.07.22.png)

По умолчанию на мобильных устройствах и планшете применяются такие же условия, как и на десктопе. Но можно изменить эти настройки, например, если вы используете отступы на десктопе (чтобы на мобильных устройствах форма не улетела за края экрана из-за отступов). Далее можно протестировать форму (для этого нужно нажать слева сверху "Проверить на сайте").

[Инструкция по созданию попапа](%D0%BA%D0%B0%D0%BA-%D1%81%D0%BE%D0%B7%D0%B4%D0%B0%D1%82%D1%8C-%D0%BF%D0%BE%D0%BF-%D0%B0%D0%BF.md).

## Таргетинг

Собирать емайлы нужно только у клиентов, которые адрес почты нам еще не предоставили. Для этого создаем сегмент клиентов с заполненными емайл и выбираем "**НЕ показывать форму**" по этому сегменту (создание сегмента описано по [ссылке](segment-client-filter-realtime.md)).

![Снимок экрана 2021-02-09 в 16.12.33.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-02-09%20%D0%B2%2016.12.33.png)

## Действия после заполнения формы пользователем

Далее нужно указать, что произойдет после заполнения формы.

Вы можете:

1. Создать нового клиента
2. Редактировать существующего

Для создания или редактирования клиента нужно указать тип данных (например, email) и заполнить "**Поле формы**".

При создании нового клиента можно подписать его на рассылки (нужно выбрать "**Канал**" и "**Тематику**").

![Снимок экрана 2021-04-07 в 20.51.41.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-04-07%20%D0%B2%2020.51.41.png)
