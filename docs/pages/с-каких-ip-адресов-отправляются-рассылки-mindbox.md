# С каких ip-адресов отправляются рассылки Mindbox

Ip-адреса - это своего рода "транспорт" с помощью которого отправляются email-сообщения. Ip-адреса помогают обмениваться данными между устройствами в сети, например, между Mindbox и компьютером вашего подписчика.

В зависимости от [оценки здоровья](%D0%BE%D1%82%D1%87%D0%B5%D1%82-%D0%B7%D0%B4%D0%BE%D1%80%D0%BE%D0%B2%D1%8C%D0%B5-email.md#ocenka-zdorovya-email-rassylok), для отправок сообщений используется один из трёх пулов ip-адресов. Это разделение призвано исключить влияние на доставляемость друг друга клиентов, по-разному следящих за гигиеной своей базы и активностью аудитории.

Пул ip-адресов для отправки определяется автоматически раз в сутки, после подсчёта [оценки здоровья](%D0%BE%D1%82%D1%87%D0%B5%D1%82-%D0%B7%D0%B4%D0%BE%D1%80%D0%BE%D0%B2%D1%8C%D0%B5-email.md#ocenka-zdorovya-email-rassylok).

Mindbox ежедневно автоматически тестирует доставляемость во всех группах с помощью небольшого количества отправок на тестовые адреса основных популярных почтовых сервисов: Gmail, Mail.ru, Yandex, Outlook, Icloud, Yahoo, AOL.

При снижении доставляемости у клиентов, команда email-рассылок в течение суток реагирует и предпринимает меры для ее повышения:

- Автоматически выводим из работы ip-адреса, попавшие в черные списки (например, Spamhaus и Proofpoint). Отправки при этом продолжаются с других ip-адресов, а по попавшим в чёрные списки ip-адресам делаются запросы на вывод из чёрного списка;
- Следим за корректностью настройки инфраструктуры отправки и соблюдением нужных протоколов;
- Генерируем и берём в работу другие гипотезы для устранения проблем.

Отправки идут с помощью общих ip-адресов, которые предоставляет Mindbox.

## Преимущества отправки рассылок с общих ip-адресов

- **Инфраструктура всегда готова к большому количеству отправок.** С общих ip-адресов поддерживается постоянный высокий объем отправок рассылок. Таким образом, нет необходимости в дополнительной подготовке инфраструктуры к праздникам или черной пятнице;
- **Разовые ошибочные отправки будут меньше влиять на доставляемость.** Случайные или ошибочные отправки по неактивным клиентам с меньшей вероятностью повлекут за собой попадание в спам и продолжительное падение репутации в почтовых сервисах. Общее высокое качество рассылок спасет репутацию в таком случае. Несмотря на это, увлекаться массовыми отправками по неактивным клиентам не рекомендуется;
- **Высокая скорость и надёжность.** Отправка с общих ip-адресов обеспечивает высокую скорость и надежность отправок. При временной блокировке части ip-адресов почтовыми сервисами у каждого клиента есть большой запас доступных для отправки ip-адресов. Также, при отказе части отправляющих серверов, обеспечивается быстрое переключение на другие, это позволяет не потерять в скорости отправки.
