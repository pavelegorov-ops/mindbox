# Логи вызовов операций

Для доступа к странице нужна пермиссия «Просмотр логов интеграций».

Чтобы открыть логи вызовов операций, перейдите в раздел **Интеграции** → **Логи интеграций**:

![image.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/image%28337%29.png)

В списке хранятся все вызовы за последние 14 суток.

Есть возможность фильтровать по дате, названию операции, статусу вызова, точке интеграции, наличию ошибок, идентификатору лога, URL, телу запроса и ответа.

![image.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/image%28336%29.png)

На странице всегда выводится количество найденных логов, однако пролистать можно только последние 500 записей. Если записей больше, чтобы посмотреть их все, нужно их [экспортировать](operation-logs.md#vygruzka-logov).

---

Раскройте строку, чтобы посмотреть детали конкретного вызова:

- время фактического выполнения операции. Может отсутствовать, если операция еще не выполнена.
- метод и URL запроса;
- заголовки и тело запроса;
- заголовки и тело ответа;
- идентификатор лога;
- наличие ошибок;
- ссылка на данный вызов (включая повторные попытки, если они были).

![image.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/image%28338%29.png)

Вызовы приоритетных операций имеет соответствующую отметку:

![Снимок экрана 2024-02-14 в 19.15.28.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202024-02-14%20%D0%B2%2019.15.28.png)

### Выгрузка логов

Экспорт из платформы доступен для персонала с пермиссией «Экспорт логов интеграций».

Чтобы выгрузить логи, выберите нужные вызовы и нажмите «Экспорт»:

![image.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/image%28339%29.png)

Создается задача:

![image.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/image%28340%29.png)

По ссылке после завершения задачи — CSV-файл с выгрузкой.

Также логи можно выгрузить по API, следуя [инструкции](https://developers.mindbox.ru/docs/%D1%8D%D0%BA%D1%81%D0%BF%D0%BE%D1%80%D1%82-%D0%BB%D0%BE%D0%B3%D0%BE%D0%B2-%D0%BE%D0%BF%D0%B5%D1%80%D0%B0%D1%86%D0%B8%D0%B9).
