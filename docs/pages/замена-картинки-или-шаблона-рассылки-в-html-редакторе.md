# Замена картинки или шаблона рассылки в HTML-редакторе

Данной инструкцией решаются задачи:

1. Замена картинки в шаблоне
2. Обновление шаблона письма

![37882031d77c7305d8ef0e0fb57d6f1bbt8juv3T8r.gif](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/37882031d77c7305d8ef0e0fb57d6f1bbt8juv3T8r.gif)

Задача сводится к тому, чтобы перезалить заново шаблон. Так делаем, потому что картинки мы выкладываем у себя и чтобы они обновились, их нужно перевыложить.

1. Заходим в **Кампании**

![378842526f8646e1b53faad7c35e8a571.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/378842526f8646e1b53faad7c35e8a571.png)

2. Находим нужную кампанию

![3788428116e5f70af8026009ad21ca182.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/3788428116e5f70af8026009ad21ca182.png)

3. Открываем рассылку для редактирования

![37884545876ff432bdac9f248d16499a3.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/37884545876ff432bdac9f248d16499a3.png)

4. Выбираем **Заменить шаблон**

![3788665363cb83e1822094449dea32f64.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/3788665363cb83e1822094449dea32f64.png)

5. Нажимаем на ZIP и выбираем архив с обновленным шаблоном

![37885941090c4b467a0895c07adf11ef5.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/37885941090c4b467a0895c07adf11ef5.png)

6. Нажимаем **Загрузить**

![378872217982191e42fda522564c20d96.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/378872217982191e42fda522564c20d96.png)

7. Сохраняем рассылку

![37888108c33a1fb3bffc1e39a9fdc3397.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/37888108c33a1fb3bffc1e39a9fdc3397.png)
