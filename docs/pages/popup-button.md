# Как настроить кнопку вызова попапа

## Что это такое

**Кнопка вызова формы** — небольшой статический элемент сбоку на сайте, который может вызывать любую всплывающую форму.

## Как попасть в раздел настройки кнопки

- На странице настройки попапа включаем показ кнопки:

![кнопка.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%BA%D0%BD%D0%BE%D0%BF%D0%BA%D0%B0%282%29.png)

## Настройка кнопки

1. Выбираем шаблон:

![Снимок экрана 2021-03-10в 17.40.54.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-03-10%20%D0%B2%2017.40.54.png)

2. Настраиваем внешний вид:

Можно:

- загрузить вашу иконку/картинку;
- выбрать размер кнопки;
- задать цвет;
- задать шрифты и размеры шрифтов и т.д.

![Снимок экрана 2021-03-10в 17.44.09.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-03-10%20%D0%B2%2017.44.09.png)

3. Выбираем расположение кнопки на экране:

![Снимок экрана 2021-03-10в 17.45.15.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-03-10%20%D0%B2%2017.45.15.png)

Можно задавать разное расположение кнопки для каждого из устройств. Для этого переключайте иконки превью:

![Снимок экрана 2021-03-10в 17.46.39.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-03-10%20%D0%B2%2017.46.39.png)

4. Задаем условия показа кнопки в «Настройках поведения»:

- Всегда — всем пользователям сайта на протяжении всей сессии;
- После показа и закрытия поп-апа — после закрытия этого попапа на этой же странице;
- При попадании в таргенинг — всем пользователям, подходящим под условия таргетинга.

![Снимок экрана 2021-03-10 в 17.44.09.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-03-10%20%D0%B2%2017.44.09%281%29.png)

5. Настраиваем показ попапа по клику.

Если хотите выводить попап только при нажатии на кнопку, выберите соответствующий пункт в настройке попапа в разделе **Условие всплывания**:

![Снимок экрана 2021-03-10в 17.59.38.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-03-10%20%D0%B2%2017.59.38.png)

6. Предпросмотр кнопки

- В настройках попапа выбираем **Проверить на сайте**:

![Снимок экрана 2021-03-10в 18.11.24.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-03-10%20%D0%B2%2018.11.24.png)

- Вводим адрес сайта и получаем ссылку просмотра:

![Снимок экрана 2021-03-10в 18.11.48.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-03-10%20%D0%B2%2018.11.48.png)

- Проверяем отображение:

![Снимок экрана 2021-03-10в 18.27.14.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-03-10%20%D0%B2%2018.27.14.png)

Проверка на сайте игнорирует таргетинг и условия всплывания, поэтому попап показывается сразу, даже если был выбран показ по нажатию кнопки
