# Какие настройки есть у дедубликации?

В настройках точки интеграции можно выбрать какие из контактов требуют подтверждения и дают доступ к аккаунту.

После включения флага все новые контакты будут требовать подтверждения / давать доступ к аккаунту. На клиентов в базе настройка не влияет. Если необходимо, чтобы все или часть существующих контактов получили доступ к аккаунту или статус “ожидает подтверждения”, то для этого нужно, например, отредактировать клиентов с использованием точки интеграции с нужными настройками.

В настройках дополнительного поля уникальный идентификатор можно запретить объединять клиентов с разными ID.
