# Как импортировать заказы по файлу

1. Переходим на вкладку **Данные** → **Действия** и нажимаем на «Импорт»:

![действия-импорт.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%B4%D0%B5%D0%B9%D1%81%D1%82%D0%B2%D0%B8%D1%8F-%D0%B8%D0%BC%D0%BF%D0%BE%D1%80%D1%82.png)

2. Выбираем операцию «Импорт заказов»:

![Снимок экрана 2022-10-18 в 11.13.46.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-10-18%20%D0%B2%2011.13.46.png)

В правой части экрана появится возможность посмотреть описание полей и скачать шаблон с примером. Обратите внимание, что **некоторые поля обязательны**:

- внешний идентификатор заказа (должно быть создано [дополнительное поле](additional-data.md) типа «Внешний идентификатор» сущности «Заказ»);
- дата и время создания/изменения заказа;
- хотя бы один идентификатор клиента;
- внешний идентификатор продукта (должна быть создана [внешняя система](%D0%BA%D0%B0%D0%BA-%D1%81%D0%BE%D0%B7%D0%B4%D0%B0%D1%82%D1%8C-%D0%B2%D0%BD%D0%B5%D1%88%D0%BD%D1%8E%D1%8E-%D1%81%D0%B8%D1%81%D1%82%D0%B5%D0%BC%D1%83.md));
- количество продукта;
- базовая цена продукта или цена за линию чека;
- статус позиции заказа.

3. Заполняем файл данными по заказам.  
   Пример:

![Снимок экрана 2022-10-18 в 11.20.09.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-10-18%20%D0%B2%2011.20.09.png)

Максимальный размер файла — 300 МБ.

4. Настраивам операцию:

![Снимок экрана 2022-10-18 в 11.21.30.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-10-18%20%D0%B2%2011.21.30.png)

- *Операция* — Импорт заказов.
- *Комментарий к задаче* — необязательно, но так будет проще найти в списке задач.
- *Кодировка файла* — по умолчанию utf-8.
- *Файл для импорта* — выбираем подготовленный файл.
- [*Точка интеграции*](как-создать-и-настроить-точку-интеграции)  — выбираем подходящую по задаче.
- [*Точка контакта*](point-of-contact-add)  — определяем автоматически по точке интеграции или указываем вручную / в файле.

Нажимаем «Добавить задачу».

- Появляется ссылка на задачу:

![Снимок экрана 2022-10-18 в 11.23.24.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-10-18%20%D0%B2%2011.23.24.png)

- Ждем выполнения задачи:

![Снимок экрана 2022-10-18 в 11.31.57.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-10-18%20%D0%B2%2011.31.57.png)
