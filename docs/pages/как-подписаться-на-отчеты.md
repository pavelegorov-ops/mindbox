# Как подписаться на отчеты

На проекте бывает необходимость снимать отчеты не разово, а с некоторой периодичностью. Для этого есть фунционал подписки на отчет:

![Снимок экрана 2022-01-12 в 21.51.38.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-01-12%20%D0%B2%2021.51.38.png)

В некоторых случаях необходимо указать обязательные условия отчета, который вы будете получать.  
Например, в отчете «Сравнение рассылок» необходимо сразу указать, по каким рассылкам и целевым действиям будет выводиться статистика.

![Снимок экрана 2022-01-12 в 21.51.21.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-01-12%20%D0%B2%2021.51.21.png)

После нажатия на «Оформить подписку» открывается окно с настройками самой подписки:

![Снимок экрана 2022-01-12 в 22.04.58.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-01-12%20%D0%B2%2022.04.58.png)

- В строке «Описание» укажите информацию, которая будет отображаться вместе с названием отчета в списке оформленных регулярных подписок. Можно оставлять заметки для удобства.
- Можно подписать на отчет других людей. В «Подписчиках» укажите email персонала, который будет дополнительно получать эти отчеты на почту. Для этого у персонала должна быть заполнена почта. Вы будете подписаны в любом случае.

Обращаем внимание, что вы можете подписать другой персонал на отчеты, но отписаться от них другой сотрудник сможет только сам через свой аккаунт

- Выберите «Период исполнения» – когда отчет будет приходить на почту:
  - Раз в сутки в определенный час по времени проекта.
  - По дням недели в указанный день и время.
  - По дням месяца, где вы можете выбрать конкретные числа либо повторяющиеся дни: первый понедельник, последний день месяца и другие.

Отчет формируется по настройкам, которые вы указали при оформлении подписки. То есть по определенным сегментам, механикам.

Отчет показывает диапазон дат с последнего построения до текущего. То есть, если вы поставили «Период исполнения» раз в неделю, то в отчете будет статистика за последние 7 дней

При выборе Сводного отчета по рассылкам с указанием конкретных дат в диапазоне, отчет будет приходить на почту раз в указанный период за то количество дней, которое было выбрано в диапазоне дат из настроек отчета. Диапазон дат будет сдвигаться каждый раз на интервал между формированием отчетов.  
То есть мы взяли диапазон в настройках отчета с 29.12 по 29.03 (это 91 день), период исполнения поставили каждый понедельник – отчет сдвинулся к первому дню получения отчета по подписке, то есть к первому понедельнику (например, 5.04) и будет сформирован за 91 день (с 4.01 по 5.04). Потом взяли следующий понедельник, 12 апреля, и за 91 день от 12 апреля формируется отчет и т. д.

- Нажмите «Оформить».

После сохранения настроек в своей системе в разделе «Уведомления» вы увидите список отчетов, на которые подписаны:
