### Поиск по группе рассылок (канал, тип, папка, тематика, теги)

В каждом фильтре по статусу есть [вложенное условие](%D0%BA%D0%B0%D0%BA-%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%B0%D0%B5%D1%82-%D0%B2%D0%BB%D0%BE%D0%B6%D0%B5%D0%BD%D0%BD%D0%BE%D1%81%D1%82%D1%8C-%D0%B2-%D1%84%D0%B8%D0%BB%D1%8C%D1%82%D1%80%D0%B0%D1%85.md) «Рассылки» — в нем можно указать, взаимодействие с каким видом рассылок нужно искать.  
Доступна фильтрация по [признакам](mailings.md):

- тип рассылки (автоматические, массовые, транзакционные)
- [тематики](%D0%BA%D0%B0%D0%BA-%D1%81%D0%BE%D0%B7%D0%B4%D0%B0%D1%82%D1%8C-%D1%82%D0%B5%D0%BC%D0%B0%D1%82%D0%B8%D0%BA%D1%83-%D1%80%D0%B0%D1%81%D1%81%D1%8B%D0%BB%D0%BA%D0%B8.md)
- [папки](folders.md)
- каналы (Email, SMS, MobilePush, WebPush, Viber)
- [теги](tag.md)
