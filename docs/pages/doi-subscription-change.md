# Как меняется подписка на Email на проектах с DOI

Double Opt-In (DOI) — двойное подтверждение подписки на Email-рассылки.

Подробнее о подключении можно почитать в [статье](doi-turn-on).

Статус подписки у клиента может быть:  
подписан, отписан, требует подтверждения, нет данных.

При этом то, как меняется подписка на email и тематики в рамках этого канала, зависит от способа передачи данных.

## Операции

### Зарегистрировать

![Снимок экрана 2021-07-11 в 18.34.44.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-07-11%20%D0%B2%2018.34.44.png)

Нельзя передать отписку, только бренд, канал и тематику в узле **/customer/subscriptions/subscription**, на которые подписывается клиент.

- всегда → требует подтверждения.

В операции регистрации всегда создаётся новый клиент.  
Если в базе уже есть клиент с переданным идентификатором, произойдёт объединение и у клиента подписка поставится по правилам, описанным в [статье](что-происходит-с-подписками-при-объединении-клиентов).

### Создать и подписать на рассылки

![Снимок экрана 2021-07-11 в 18.44.38.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-07-11%20%D0%B2%2018.44.38.png)

В операции подписки всегда создаётся новый клиент.  
Если в базе уже есть клиент с переданным идентификатором, произойдёт объединение и у клиента подписка поставится по правилам, описанным в [статье](что-происходит-с-подписками-при-объединении-клиентов).

При этом нельзя передать отписку, только бренд, канал и тематику в узле **/customer/subscriptions/subscription**, на которые подписывается клиент.

- всегда → требует подтверждения.

### Импортировать

![Снимок экрана 2021-07-11 в 18.56.19.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-07-11%20%D0%B2%2018.56.19.png)

Зависит от передачи данных в узле **/customer/subscriptions/subscription/isSubscribed**

- true → Подписан
- false → Отписан
- Если не передали блок с подпиской → Нет данных

### Клиент — Авторизованный — Редактировать

![Снимок экрана 2021-07-11 в 19.03.42.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-07-11%20%D0%B2%2019.03.42.png)

Зависит от статуса, переданного в узле **/customer/subscriptions/subscription/isSubscribed**

- true → подписан;
- false → отписан.

Операция отрабатывает только на имеющихся в базе клиентах.

### Клиент — Авторизованный — Дополнить

![Снимок экрана 2021-07-11 в 19.06.09.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-07-11%20%D0%B2%2019.06.09.png)

Нельзя передать отписку, только бренд, канал и тематику в узле **/customer/subscriptions/subscription**, на которые подписывается клиент.

- всегда → требует подтверждения.

## Импорт

### [Импорт клиентов](clients-import)

Если клиент новый, подписку можно добавить в любом статусе, в том числе не передавать её вообще (в таком случае по подписке не будет данных).

Если клиент уже есть в базе, можно поменять с любого статуса на следующие:

- подписан (true)
- отписан (false)
- требует подтверждения (WaitingForConfirmation)

На отсутствие данных не поменять.

### [Импорт редактирования данных](clients-import-edit)

Можно поменять клиенту с любого статуса на следующие:

- подписан (true)
- отписан (false)
- требует подтверждения (WaitingForConfirmation)

На отсутствие данных не поменять.

[Инструкция](clients-subscribe) как массово подписать/отписать клиентов.

## [Сценарии](what-is-workflow.md)

При редактировании клиенту выдается автоматически сгенерированное действие «Редактирование клиента в блоке сценария *’Название сценария’* - *’Описание шага’*».

Подписка на Email-канал недоступна в сценариях. Клиента можно отписать от канала или проставить статус «Требует подтверждения».

### Сценарий с требованием подтверждения

![Снимок экрана 2024-03-14 в 17.09.17.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202024-03-14%20%D0%B2%2017.09.17.png)

*Подписка до отработки сценария → подписка после отработки сценария:*

- Любой статус → Требует подтверждения

### Сценарий с отпиской

![Снимок экрана 2024-03-14 в 17.09.36.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202024-03-14%20%D0%B2%2017.09.36.png)

*Подписка до отработки сценария → подписка после отработки сценария:*

- Любой статус → Отписан

## Голосование

### Голосование с подпиской

![147005110951dc2b51f16716a11061b7bтриггер-подписка.jpg](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/147005110951dc2b51f16716a11061b7b%D1%82%D1%80%D0%B8%D0%B3%D0%B3%D0%B5%D1%80-%D0%BF%D0%BE%D0%B4%D0%BF%D0%B8%D1%81%D0%BA%D0%B0.jpg)

*Подписка до голосования → подписка после голосования:*

- Подписан → Подписан.
- Отписан → Требует подтверждения.
- Требует подтверждения → Требует подтверждения.
- Нет данных → Требует подтверждения

### Голосование с отпиской

![1470051849fa54977dec3fefa0d881b2eтриггер-отписка.jpg](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/1470051849fa54977dec3fefa0d881b2e%D1%82%D1%80%D0%B8%D0%B3%D0%B3%D0%B5%D1%80-%D0%BE%D1%82%D0%BF%D0%B8%D1%81%D0%BA%D0%B0.jpg)

*Подписка до голосования → подписка после голосования:*

- Любой статус → Отписан

## [Брендированная страница отписки](branded-unsubscribe-page.md)

- Клиент ставит галочку в блоке тематик и сохраняет выбор:
  - Любой статус → Подписан
- Клиент снимает галочку или отписывается от всего:
  - Любой статус → Отписан
