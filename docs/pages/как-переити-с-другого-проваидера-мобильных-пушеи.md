# Как перейти с другого провайдера мобильных пушей

Для корректной работы наших пушей в вашем приложении должно быть интегрировано наше SDK.  
Поэтому при переходе с другого провайдера мобильных пушей мы не можем просто импортировать токены.

Для перехода нужно выполнить следующие шаги:

1. [Интегрировать мобильный SDK](https://developers.mindbox.ru/docs/mindbox-sdk#).
2. Предусмотреть в процессе обработки пушей ветвление: пуши от Mindbox обрабатывать, например, методом от SDK, другие пуши — текущим способом.
3. Выпустить обновление приложения, начать собирать аудиторию в Mindbox.  
   Пользователи, которые установят обновления и запустят приложения, попадут к нам в систему.
4. Через 1-2 месяца активная аудитория перетечет к нам в систему и можно будет удалить из приложения интеграцию со старым провайдером.

Переход между провайдерами никогда не гарантирует перенос 100% пользователей

При переходе в Mindbox появится только активная аудитория — те, кто пользуются приложением. Клиенты, которые к моменту перехода удалили приложение или перестали им пользоваться, в Mindbox не попадут
