# Как импортировать значения дополнительного поля с типом “перечисление”

Дополнительное поле типа «перечисление» добавляет на проект поле с возможностью выбора варианта из списка.  
Такое решение подходит, когда надо, например, записать город клиента.

Заводить значения перечисления можно как вручную в режиме редактирования поля, так и импортом. Последнее особенно удобно при большом количестве значений.

По шагам:

1. Перейдите в раздел **Настройки** → **Системные** → **Дополнительные поля**:

![custom-field-menu.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/custom-field-menu.png)

2. Нажмите **Импорт**:

![custom-field-import.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/custom-field-import.png)

3. Подготовьте файл для импорта.

   3.1. Скачайте шаблон файла:

   ![Снимок экрана 2021-01-25в 20.14.59.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-01-25%20%D0%B2%2020.14.59.png)

   3.2. Заполните значения:  
   **ExternalId** — внешний идентификатор, который будет передаваться в импортах, операциях и т.д.  
   **Value** — значение, которое вы будете видеть на проекте.

   Пример заполненного файла:

   ![Снимок экрана 2021-01-25в 21.11.37.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-01-25%20%D0%B2%2021.11.37.png)
4. Заполните настройки:

![Снимок экрана 2021-01-25в 21.14.40.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-01-25%20%D0%B2%2021.14.40.png)

- *операция* — Импорт значений перечислений дополнительных полей
- *комментарий* — необязательно, но так будет проще найти импорт в списке задач
- *кодировка* — по умолчанию utf-8
- *файл для импорта* — подготовленный файл для импорта
- *дополнительные поля* — в какое поле импортируем значения

5. Нажмите "Добавить задачу" — появляется ссылка на задачу:

![Снимок экрана 2021-01-25в 21.17.06.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-01-25%20%D0%B2%2021.17.06.png)

После её успешного завершения значения добавлены на проект:

![Снимок экрана 2021-01-25в 21.19.51.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-01-25%20%D0%B2%2021.19.51.png)
