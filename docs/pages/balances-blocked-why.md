# Почему баллы по заказу у клиента неактивные

Есть несколько причин, по которым баллы на счете еще не доступны для использования и находятся в статусе **Неактивные**:

![Снимок экрана 2022-06-19 в 18.55.46.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-06-19%20%D0%B2%2018.55.46.png)

### Настройки промоакции

- В промоакции можно указать срок, после которого баллы становятся доступными:

![Снимок экрана 2022-06-20 в 13.52.04.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-06-20%20%D0%B2%2013.52.04.png)

- У заказа из акции будет отложенный доступ к баллам:

![Снимок экрана 2022-06-20 в 14.28.04.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-06-20%20%D0%B2%2014.28.04.png)

*Заказ совершен 20 июня. Баллы будут доступны 4 июля.*
