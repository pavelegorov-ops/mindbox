# Что такое чат-боты и как их подключить

Чат-бот — это программа, которая позволяет автоматизировать общение с пользователями через мессенджеры.

## Преимущества канала

- высокий процент открываемости;
- широкая аудитория;
- снижение расходов на SMS;
- доступность 24/7;
- интерактивное взаимодействие с пользователями.

## Области применения

Чат-боты можно использовать для широкого спектра задач:

- личный кабинет пользователя;
- просмотр каталога и оформление заказов;
- рекомендации для покупок;
- отправка массовых и автоматических рассылок;
- игровые механики;
- опросы;
- FAQ и т.д.

Поддерживаемые мессенджеры: Telegram, VK, Viber, Instagram*, Одноклассники, Facebook*, Max.

## Как настроить и использовать

Для создания чат-ботов используется конструктор сервиса [Fasttrack](https://fstrk.io/).

Для интеграции сервиса с Mindbox необходимо [подготовить проект](https://help.mindbox.ru/docs/chat-bots-integration).

Для настройки логики бота (экраны с кнопками, опросами, сообщениями; перемещение между экранами и т.д.) используйте [инструкции сервиса](https://docs.fstrk.io/knowledge_base/).
