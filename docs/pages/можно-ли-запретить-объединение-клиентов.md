# Можно ли запретить объединение клиентов?

Если вы присваиваете клиенту уникальный идентификатор, то можно запретить объединение клиентов с разными ID. Для этого в настройках уникального идентификатора клиента нужно установить флаг “Не объединять клиентов с разными ID”.

[Что такое CDP](https://mindbox.ru/academy/education/chto-takoe-cdp/) и когда пора начинать ее использовать
