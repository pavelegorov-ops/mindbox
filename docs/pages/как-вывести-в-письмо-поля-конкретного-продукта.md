# Как вывести в письмо поля конкретного продукта

Для вывода полей продукта используйте параметр вида  
**Products.SearchInIdentity("c1").GetByValue("123″)**, где

- c1 — внешняя система продуктов:
- 123 — внешний идентификатор продукта.

Дальше добавляете параметр для конкретного поля:

![Снимок экрана 2021-06-24 в 19.58.15.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-06-24%20%D0%B2%2019.58.15%281%29.png)

Например,

```
Название: ${Products.SearchInIdentity("c1").GetByValue("123").Name}
Цена: ${Products.SearchInIdentity("c1").GetByValue("123").Price}
```

Если стоит задача вывести поля продуктов из сегмента, воспользуйтесь [инструкцией](%D0%BA%D0%B0%D0%BA-%D0%B2%D1%8B%D0%B2%D0%B5%D1%81%D1%82%D0%B8-%D0%BF%D0%BE%D0%BB%D0%B5-%D1%82%D0%BE%D0%B2%D0%B0%D1%80%D0%B0-%D0%B8%D0%B7-%D1%81%D0%B5%D0%B3%D0%BC%D0%B5%D0%BD%D1%82%D0%B0.md).
