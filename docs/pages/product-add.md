# Как добавить продукт через интерфейс

Способ подходит для задач, когда надо вручную добавить один-два продукта на проект. Для загрузки большого количества продуктов лучше использовать [массовый импорт](products-import.md).

Добавляем продукт через интерфейс:

1. Переходим на вкладку **Данные** → **Продукты**:

![Снимок экрана 2021-08-24 в 14.37.32.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-08-24%20%D0%B2%2014.37.32.png)

2. Нажимаем на знак меню → «Добавить продукт»:

![Снимок экрана 2021-08-24 в 14.37.18.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-08-24%20%D0%B2%2014.37.18.png)

3. Заполняем данные по продукту и нажимаем «Сохранить»:

![Снимок экрана 2022-07-08 в 17.28.44.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-07-08%20%D0%B2%2017.28.44.png)

- Про внешнюю систему подробнее почитать в [статье](%D0%BA%D0%B0%D0%BA-%D1%81%D0%BE%D0%B7%D0%B4%D0%B0%D1%82%D1%8C-%D0%B2%D0%BD%D0%B5%D1%88%D0%BD%D1%8E%D1%8E-%D1%81%D0%B8%D1%81%D1%82%D0%B5%D0%BC%D1%83.md).
