# Как импортировать каналы

**Канал** — это средство объединения точек контакта в группы.  
Сами каналы также можно группировать.

Каналы можно добавить вручную по одному, следуя инструкции из [статьи](channel-add) , или импортировать группой с использованием файла csv.  
Вторым способом можно добавить только дочерние каналы.

Для импорта каналов выполните следующие шаги:

1. Откройте раздел **Настройки** → **Клиенты и действия** → **Каналы**:

![каналы.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%BA%D0%B0%D0%BD%D0%B0%D0%BB%D1%8B%282%29.png)

2. Нажмите «Импорт»:

![Снимок экрана 2021-07-13 в 18.36.47.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-07-13%20%D0%B2%2018.36.47.png)

3. Выберите операцию «Импорт каналов».  
   Для скачивания доступен шаблон файла с примером:

![Снимок экрана 2021-07-13 в 18.39.54.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-07-13%20%D0%B2%2018.39.54.png)

4. Подготовьте файл для импорта.

Рассмотрим поля в файле:

- *MindboxID* — для новых указывать не надо — генерируется автоматически; если указать MindboxID имеющегося канала, его данные будут отредактированы соответственно данным из файла.
- *ExternalID* — внешний идентификатор — для новых каналов указывать обязательно; если указать ExternalID имеющегося канала, его данные будут отредактированы соответственно данным из файла. По нему же автоматически генерируется системное имя (из латинских букв, цифр и дефисов).
- *Comment* — критерии объединения точек контакта в этот канал; необязательно.
- *Name* — название.
- *ParentChannelMindboxId* или *ParentChannelExternalId* — MindboxID или ExternalID родительского канала; один из идентификаторов обязательно должен быть.

**Как определить ParentChannelMindboxId или ParentChannelExternalId?**

Найдите родительский канал в блоке «Каналы»:

![Снимок экрана 2021-07-13 в 18.46.01.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-07-13%20%D0%B2%2018.46.01.png)

Пример заполненного файла:

![Снимок экрана 2021-07-13 в 18.49.10.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-07-13%20%D0%B2%2018.49.10.png)

5. Заполните настройки импорта:

![Снимок экрана 2021-07-13 в 18.49.38.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-07-13%20%D0%B2%2018.49.38.png)

*Операция:* Импорт каналов.  
*Комментарий к задаче:* необязательно, но так будет проще найти в списке задач.  
*Кодировка файла:* по умолчанию — utf-8.  
*Файл для импорта:* подготовленный файл для импорта.

6. Нажмите **Добавить задачу**.

- Появится сообщение о добавлении задачи с ссылкой на неё:

![Снимок экрана 2021-07-13 в 18.49.50.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-07-13%20%D0%B2%2018.49.50.png)

- Ждём выполнения задачи:

![Снимок экрана 2021-07-13 в 18.54.25.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-07-13%20%D0%B2%2018.54.25.png)

- После успешного выполнения задачи каналы появятся в разделе с данными, указанными в файле:

![Снимок экрана 2021-07-13 в 18.54.48.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-07-13%20%D0%B2%2018.54.48.png)
