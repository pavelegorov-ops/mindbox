# Передача лидов из рекламных кабинетов в Mindbox

Задача: настроить передачу данных из лид-форм, создавать и подписывать на их основе клиентов в Mindbox.

Перед добавлением связок на проекте уже должны быть [созданы](media-what-is.md) рекламный кабинет и подключение к нужному сервису.

### Создать связку

Рассмотрим настройку на примере VK Рекламы.

Для сбора лидов:

1. Перейдите в раздел **Интеграции** → **Медиа**:

![медиа — копия.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%BC%D0%B5%D0%B4%D0%B8%D0%B0%C2%A0%E2%80%94%20%D0%BA%D0%BE%D0%BF%D0%B8%D1%8F.png)

2. На вкладке **Мои связки** нажмите «Создать новую связку»

![Снимок экрана 2023-05-17 в 17.38.38.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-05-17%20%D0%B2%2017.38.38.png)

3. Можно задать название:

![Снимок экрана 2023-05-22 в 15.56.02.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-05-22%20%D0%B2%2015.56.02.png)

3. «Добавьте триггер, который будет запускать связку».

Задаем, из какого сервиса и каких форм данные передаются в Mindbox.

3.1. «Настройте триггер»:

- Сервис — VK Реклама.
- Событие — «Лиды с форм (все формы клиента)» или «Лиды с форм (из выбранной формы)» — по задаче.
- Аккаунт VK Реклама — созданное для сервиса подключение.
- Клиент — аккаунт в VK Рекламе.
- Форма — нужная форма. Опция доступна при выборе варианта «Лиды с форм (из выбранной формы)» в Событии.

![Снимок экрана 2023-05-22 в 16.09.07.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-05-22%20%D0%B2%2016.09.07.png)

Нажмите «Добавить триггер».

3.2 «Режим работы связки»:

Всегда — «В реальном времени (Сбор данных текущего периода)»

![Снимок экрана 2023-05-22 в 16.14.30.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-05-22%20%D0%B2%2016.14.30.png)

Нажмите «Сохранить».

4. «Добавьте действие, которое будет происходить после старта связки».

Задаем, что делать с полученными из форм данными в Mindbox.

При необходимости записи в [дополнительное поле](additional-data.md) клиента укажите его системное имя в подключении к рекламному кабинету Mindbox. Если полей несколько, перечислите их каждый с новой строки:

![Снимок экрана 2023-05-22 в 16.46.48.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-05-22%20%D0%B2%2016.46.48%282%29.png)

В подключении не работает валидация, поэтому убедитесь в правильности написания полей.

4.1. «Добавьте действие»:

- Сервис — Mindbox.
- Действие — «Создать и подписать на рассылки».
- Аккаунт Mindbox — точка интеграции для рекламных кабинетов.

![Снимок экрана 2023-05-22 в 16.16.15.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-05-22%20%D0%B2%2016.16.15.png)

Нажмите «Добавить действие».

4.2. Mindbox:

- Выберите, из какого поля формы вписывать данные в соответствующие поля Mindbox.
- «Источник лида» — обязательно к заполнению. По нему создается точка контакта для связки. Обычно ставится «ID формы» или «Имя формы».

![Снимок экрана 2023-05-22 в 17.12.09.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-05-22%20%D0%B2%2017.12.09%281%29.png)

Нажмите «Сохранить».

5. Запустите связку:

![Снимок экрана 2023-05-22 в 17.24.52.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-05-22%20%D0%B2%2017.24.52.png)

По умолчанию связка запускается раз в сутки.

### Найти клиентов из формы

Для связок по лидам автоматически создается операция 'media.LeadAdsSubscrition':

![Снимок экрана 2023-05-23 в 11.39.01.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-05-23%20%D0%B2%2011.39.01.png)

Как и для других операций с шагом [«Создать и подписать на рассылки»](steps-create-client.md#klient-sozdat-i-podpisat-na-rassylki) для операции генерируется шаблон по ее имени — «Подписка клиента в операции 'media.LeadAdsSubscrition'». С ним пользователи и попадают в базу.

Точка контакта при этом задается по идентификатору или названию формы (в зависимости от настройки связки). Все точки контакта форм попадают в канал «Нераспределённые».
