# Как импортировать и редактировать списки продуктов

## Импортировать продукты в список

1. Перейдите в раздел **Клиенты**:

![клиенты-тест2.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%BA%D0%BB%D0%B8%D0%B5%D0%BD%D1%82%D1%8B-%D1%82%D0%B5%D1%81%D1%822.png)

2. Нажмите «Импорт» → «Изменить список продуктов»:

![Снимок экрана 2022-07-08 в 17.56.53.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-07-08%20%D0%B2%2017.56.53.png)

3. Выберите операцию «Импорт персонального списка продуктов».

Для скачивания доступен шаблон с примером:

![Снимок экрана 2021-08-24 в 09.53.52.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-08-24%20%D0%B2%2009.53.52.png)

Особенность импорта — список продуктов **полностью обновляется**. Что есть в файле импорта, то и будет у клиента в списке, а остальное удалится.

Чтобы только **добавить** продукты из файла в список, выберите операцию «Дополнение персонального списка». Прочие настройки не отличаются.

4. Подготовьте файл:

![Снимок экрана 2021-08-24 в 10.13.19.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-08-24%20%D0%B2%2010.13.19.png)

Разрешено передавать либо цену за линию, либо цену за один продукт.

5. Заполните настройки импорта:

![Снимок экрана 2024-07-30 в 21.22.28.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202024-07-30%20%D0%B2%2021.22.28.png)

- *операция* — «Импорт персонального списка продуктов»;
- *файл* — подготовленный файл из пункта 4;
- *[точка интеграции](%D0%BA%D0%B0%D0%BA-%D1%81%D0%BE%D0%B7%D0%B4%D0%B0%D1%82%D1%8C-%D0%B8-%D0%BD%D0%B0%D1%81%D1%82%D1%80%D0%BE%D0%B8%D1%82%D1%8C-%D1%82%D0%BE%D1%87%D0%BA%D1%83-%D0%B8%D0%BD%D1%82%D0%B5%D0%B3%D1%80%D0%B0%D1%86%D0%B8%D0%B8.md) и [точка контакта](point-of-contact-add.md)* — по бизнес-задаче;
- *[персональный список продуктов](personal-list.md)* — куда добавляем продукты.

6. Нажмите «Добавить задачу».

Появляется ссылка на задачу — дождитесь её успешного завершения:

![Снимок экрана 2021-08-24 в 10.13.47.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-08-24%20%D0%B2%2010.13.47.png)

В карточке у клиента появляется **одно действие** — *«Установка списка продуктов в импорте»*, содержащее все изменения его списка:

![Снимок экрана 2024-07-30 в 21.33.52.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202024-07-30%20%D0%B2%2021.33.52.png)

## Добавить продукты в список

Вместо импорта поставьте задачу «Дополнение персонального списка»:

![Снимок экрана 2021-08-24 в 10.52.24.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-08-24%20%D0%B2%2010.52.24.png)

Принцип заполнения файла и настроек тот же.

## Удалить продукты из списка

Поставьте «Импорт персонального списка продуктов» и передайте в файле только те продукты, **которые должны остаться**. Прочие продукты будут удалены из списка.
