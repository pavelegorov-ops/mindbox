# Как посмотреть тепловую карту кликов email-рассылки

**Тепловая карта** — инструмент для визуализации статистики кликов на основе цветовой кодировки.

На карте показано количество переходов и их процент от всех кликов по каждой ссылке.  
Теплые тона (красный, оранжевый, желтый) обозначают участки с частыми кликами, а холодные (голубой, синий, фиолетовый) — с наименьшей активностью.

Чтобы посмотреть тепловую карту:

1. Откройте нужную рассылку:

## Как считаются клики

В тепловой карте отображается статистика уникальных переходов по каждой ссылке.

Это означает, что:

- если клиент перешел несколько раз **по одной и той же** ссылке, в отчете будет **только один клик**;
- если клиент перешел **по нескольким разным ссылкам**, в отчет попадет **по клику на каждую ссылку**.

Процент переходов по ссылке = (уникальные переходы по выбранной ссылке / общее количество переходов в карте) * 100%

### Ссылка отписки

Клики по ссылке отписки также включаются в данные карты.

Исключение: отписка через спам, так как клика как такового не происходит. В данном случае для отчета по рассылке выдается действие запроса отписки, но в данные тепловой карты они не входят. [Подробнее.](how-to-unsubscribe.md#otpiska-cherez-spam-i-iz-pochtovogo-klienta)

### Сброс данных

Редактирование ссылок в шаблоне сбрасывает показатели карты.

Посмотреть историю изменений рассылки можно по ссылке:

![Снимок экрана 2023-05-24 в 14.13.44.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-05-24%20%D0%B2%2014.13.44.png)

### При удалении данных

Удаление действий и клиентов, в том числе ручное, не влияет на тепловую карту, данные сохраняются.

### Отличия от других отчетов и фильтров

При сравнении данных из тепловой карты с отчетом по рассылке или с выборкой из фильтров могут быть различия в количественных показателях.

Дело в том, что принцип подсчета в таких случаях разный:

- тепловая карта — уникальные клики по каждой ссылке, в том числе по отписке;
- отчет по рассылке — письма, в которых есть хотя бы один клик по любой ссылке, кроме отписки:

![Снимок экрана 2023-05-24 в 10.26.46.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-05-24%20%D0%B2%2010.26.46%282%29.png)

- фильтр по [клиентам](filter-clients-mailing.md) — клиенты, кликнувшие хотя бы раз по любой ссылке, кроме отписки:

![Снимок экрана 2024-08-05 в 14.33.00.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202024-08-05%20%D0%B2%2014.33.00.png)

- фильтр по статусам — все клики по каждой ссылке, кроме отписки:

![Снимок экрана 2024-08-05 в 14.33.54.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202024-08-05%20%D0%B2%2014.33.54.png)

#### Кликов в карте больше

- При сравнении с отчетом по рассылке и количеством клиентов в фильтре показатели могут быть выше, так как:
  - в отчет попадает количество клиентов с кликом, а в карту — количество уникальных кликов по каждой ссылке.
  > Например, клиент переходит по трем разным ссылкам в рассылке: в отчет по рассылке попадет 1 клик, в карту — 3.

  - в отчете запрос отписки — отдельный от кликов критерий, а в карте ссылка отписки — такая же ссылка как и другие.
  > Например, клиент в рассылке только отписывается: в отчет по рассылке попадет 0 кликов и 1 отписка, а в карту — 1 клик.

#### Кликов в карте меньше

- Возможно, в шаблоне [редактировали ссылки](click-maps.md#sbros-dannyh).
- При сравнении с количеством статусов показатели могут быть ниже, так как действия выдаются по каждому клику, а в карту попадают только первые клики клиента по каждой ссылке.

> Например, клиент кликнул по одной и той же ссылке 5 раз: появится 5 действий клика, а в карте — только 1.

- При сравнении с отчетом по рассылке и количеством клиентов в фильтре показатели отписки могут быть ниже, так как в карту не попадают отписки через [спам](how-to-unsubscribe.md#otpiska-cherez-spam-i-iz-pochtovogo-klienta).
