# Как массово импортировать действия по файлу

1. Переходим на вкладку **Данные** → **Действия** и нажимаем на «Импорт»:

![действия-импорт.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%B4%D0%B5%D0%B9%D1%81%D1%82%D0%B2%D0%B8%D1%8F-%D0%B8%D0%BC%D0%BF%D0%BE%D1%80%D1%82.png)

2. Выбираем операцию «Импорт действий клиента»:

![Снимок экрана 2022-10-17 в 13.11.53.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-10-17%20%D0%B2%2013.11.53.png)  
Для скачивания доступен шаблон с примером.

3. Подготавливаем файл.

Минимум заполнения: одна колонка с идентификаторами.

Пример:

![Снимок экрана 2021-07-12 в 17.18.19.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-07-12%20%D0%B2%2017.18.19.png)

В нашем файле есть только колонка с email-адресами. Значит, точку контакта и время действия выбираем в настройках операции.

4. Заполняем настройки:

![Снимок экрана 2022-10-17 в 13.30.05.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-10-17%20%D0%B2%2013.30.05.png)

- *операция* — импорт действий клиента;
- *комментарий к задаче* — необязательно;
- *кодировка файла* — по умолчанию utf-8;
- [*точка интеграции*](%D0%BA%D0%B0%D0%BA-%D1%81%D0%BE%D0%B7%D0%B4%D0%B0%D1%82%D1%8C-%D0%B8-%D0%BD%D0%B0%D1%81%D1%82%D1%80%D0%BE%D0%B8%D1%82%D1%8C-%D1%82%D0%BE%D1%87%D0%BA%D1%83-%D0%B8%D0%BD%D1%82%D0%B5%D0%B3%D1%80%D0%B0%D1%86%D0%B8%D0%B8.md);
- [*точка контакта*](point-of-contact-add.md) — определяем по точке интеграции или указываем вручную/в файле;
- *действие* — выбираем шаблон. Если на проекте нет нужного, можно создать по [инструкции](template-create.md).

Нажимаем на «Добавить задачу».

- Появляется ссылка на задачу:

![Снимок экрана 2022-10-17 в 13.30.23.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-10-17%20%D0%B2%2013.30.23.png)

- Ждем её завершения:

![Снимок экрана 2022-10-17 в 15.43.55.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-10-17%20%D0%B2%2015.43.55.png)

- В карточке клиента появляется действие:

![Снимок экрана 2022-10-17 в 15.57.33.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-10-17%20%D0%B2%2015.57.33.png)
