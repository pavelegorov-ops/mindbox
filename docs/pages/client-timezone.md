# Как определяется часовой пояс клиента

Одним из базовых полей по клиенту является часовой пояс:

![client-timezone-client.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/client-timezone-client.png)

Его наличие позволяет персонализировать коммуникации — отправлять рассылки с учетом локального времени получателей.

**Как определяется часовой пояс.**

Источники, начиная с самого приоритетного:

1. явная передача в операции или импорте;
2. трекер мобильного приложения;
3. трекер JS (по системному времени устройства);
4. зона клиента, если для нее [прописан](areas-import.md) пояс;
5. код мобильного номера.

> Например, у клиента заполнен часовой пояс на основе данных о зоне. Он переходит на сайт, и время на устройстве отличается от указанного в профиле. Часовой пояс изменится, так как данные от кода отслеживания более приоритетны, чем зона.
