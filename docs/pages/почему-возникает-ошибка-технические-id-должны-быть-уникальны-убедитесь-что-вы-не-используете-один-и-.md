# Почему возникает ошибка “Технические ID должны быть уникальны. Убедитесь, что вы не используете один и тот же ID для разных клиентов.”?

Повторная регистрация клиента с уникальным идентификатором, который уже есть в системе, не допускается. Сообщение с ошибкой появится в результатах обработки файла или в логе выполненных операций (раздел Интеграции).

Попытка регистрации с дублирующим ID может возникнуть из-за повторной регистрации клиента или из-за использования не уникальных идентификаторов для разных клиентов.  
**Если ошибка появилась при импорте (через v3 операцию или в файловом импорте). Возможные причины:**

- Система не смогла точно определить какого клиента нужно отредактировать. При попытке создать нового возникла ошибка, т.к. клиент с таким ID уже существует.
- В v3-операции клиент с выбранным в настройках идентификатором не найден. Система создает нового клиента. При этом может возникнут ошибка, т.к. у нового клиента повторно используется уникальный идентификатор, который уже есть у существующего клиента.

Аналогичное поведение будет при попытке создать клиента с телефоном или email-адресов с флагом "Доступ к аккаунту", если клиента с такими контактами уже существуют в системе.

Повторная регистрация запрещена для уникальных идентификаторов и контактов с доступом к аккаунту. [Подробнее в статье про идентификаторы клиента в Mindbox.](идентификаторы-клиента-в-mindbox)
