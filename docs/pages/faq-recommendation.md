# Советы по использованию алгоритмов рекомендаций

## Какие рекомендации отправлять неактивным клиентам

Алгоритмы рекомендаций для клиента рассчитывают рекомендации только для клиентов, у которых есть личные действия за последние 90 дней.

В зависимости от типа алгоритма для клиентов без личных действий за последние 90 дней будут выведены ранее сгенерированные рекомендации или популярные продукты. Также рекомендации могут быть и вовсе не отображены.

**Алгоритмы, которые отобразят популярные продукты**:

- [Персональные рекомендации](recommendations-personal.md#personalnye-rekomendacii)
- [Популярные продукты](recommendations-bestsellers.md#populyarnye-produkty)
- [Событийные персональные рекомендации](recommendations-personal.md#sobytijnye-personalnye-rekomendacii)

**Алгоритмы, которые отобразят ранее сгенерированные или пустые рекомендации**:

- [Популярные продукты в просмотренных категориях в последней сессии](recommendations-bestsellers.md#populyarnye-produkty-v-prosmotrennyh-kategoriyah-v-poslednej-sessii)
- [Сопутствующие продукты к последнему заказу](recommendations-related.md#soputstvuyushie-produkty-k-poslednemu-zakazu)
- [Сопутствующие продукты к списку продуктов](recommendations-related.md#soputstvuyushie-produkty-k-spisku-produktov)
- [Похожие продукты на просмотренные в последней сессии](recommendations-similar.md#pohozhie-produkty-k-prosmotrennym-v-poslednej-sessii)
- [Похожие продукты к списку продуктов](recommendations-similar.md#pohozhie-produkty-k-spisku-produktov)
- [Ручное соответствие категорий к последнему заказу](recommendations-custom.md#ruchnoe-sootvetstvie-kategorij-k-poslednemu-zakazu)
- [Последние просмотренные продукты](recommendation-algorithms.md#poslednie-prosmotrennye-produkty)

Для реактивации клиентов используйте алгоритмы «Персональные рекомендации», «Событийные персональные рекомендации» или «Популярные продукты». При использовании других алгоритмов клиент может получить письмо с пустыми или уже неподходящими рекомендациями.

## Как избежать повторений продуктов, если несколько алгоритмов используются в одном месте

Рассмотрим наиболее частые ситуации использования алгоритмов в одном месте.

### В одном виджете рекомендаций

В одном виджете к выводу доступны рекомендации из нескольких алгоритмов. При использовании [виджета рекомендаций](recommendation-widget-create.md) Mindbox продукты фильтруются автоматически и не дублируются.

Если вы получаете рекомендации через [запрос по API](%D0%BA%D0%B0%D0%BA-%D1%81%D0%BE%D0%B7%D0%B4%D0%B0%D1%82%D1%8C-%D0%BE%D0%BF%D0%B5%D1%80%D0%B0%D1%86%D0%B8%D1%8E-%D0%B4%D0%BB%D1%8F-%D0%BF%D0%B5%D1%80%D0%B5%D0%B4%D0%B0%D1%87%D0%B8-%D1%80%D0%B5%D0%BA%D0%BE%D0%BC%D0%B5%D0%BD%D0%B4%D0%B0%D1%86%D0%B8%D0%B9-%D0%BD%D0%B0-%D1%81%D0%B0%D0%B9%D1%82.md) и подставляете их в собственный виджет, фильтрацию повторяющихся продуктов необходимо настроить на стороне фронтенда вашего сайта по их идентификатору.

### На одной странице установлено несколько виджетов

При использовании [виджетов рекомендаций](recommendation-widget-create.md) Mindbox: перейдите в общие настройки виджета и в разделе «Основные настройки рекомендаций» отметьте чекбокс «Фильтровать по другим рекомендациям на странице».

![reco-filters.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/reco-filters.png)

Если вы получаете рекомендации через [запрос по API](%D0%BA%D0%B0%D0%BA-%D1%81%D0%BE%D0%B7%D0%B4%D0%B0%D1%82%D1%8C-%D0%BE%D0%BF%D0%B5%D1%80%D0%B0%D1%86%D0%B8%D1%8E-%D0%B4%D0%BB%D1%8F-%D0%BF%D0%B5%D1%80%D0%B5%D0%B4%D0%B0%D1%87%D0%B8-%D1%80%D0%B5%D0%BA%D0%BE%D0%BC%D0%B5%D0%BD%D0%B4%D0%B0%D1%86%D0%B8%D0%B9-%D0%BD%D0%B0-%D1%81%D0%B0%D0%B9%D1%82.md) и подставляете их в собственный виджет, фильтрацию повторяющихся продуктов необходимо настроить на стороне фронтенда вашего сайта по их идентификатору.

### Несколько алгоритмов рекомендаций используются в одной рассылке

При использовании нескольких алгоритмов в одной рассылке невозможно автоматически исключить одинаковые товары. Рекомендуем использовать непересекающиеся сегменты продуктов в алгоритмах рекомендаций одной рассылки.

## Что делать, если алгоритм останавливается через 20 дней без использования

Система автоматически останавливает пересчет алгоритма, если он не используется в течение 20 дней. Алгоритм остается доступен для выбора в рассылках, однако качество выдачи рекомендаций постепенно ухудшается:

- Рекомендации становятся неактуальными. Рекомендуются только те продукты, которые были в наличии на момент последнего пересчета алгоритма.
- Рекомендации не формируются для новых клиентов, которые были добавлены в базу после остановки пересчета.

Если алгоритм используется раз в месяц или реже, например, при отправке ежемесячных дайджестов с подборкой товаров — рекомендуем воспользоваться одним из способов для предотвращения ухудшения качества рекомендаций:

1. Создать [сценарий](what-is-workflow.md), в котором раз в несколько недель будут отправляться тестовые письма с рекомендациями из нужного алгоритма на служебный адрес.
2. Создать [операцию](%D0%BE%D0%BF%D0%B5%D1%80%D0%B0%D1%86%D0%B8%D0%B8-v-%D0%BD%D0%B0%D1%81%D1%82%D1%80%D0%BE%D0%B9%D0%BA%D0%B0-%D1%88%D0%B0%D0%B3%D0%BE%D0%B2.md), которая будет получать рекомендации из нужного алгоритма и вызывать операцию раз в несколько недель.
