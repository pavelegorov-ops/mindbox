# Как подключить Viber-рассылки

Mindbox — управляющая маркетинговая система, а провайдер является транспортом для доставки SMS- и Viber-сообщений пользователям через шлюз.  
Отправка Viber по SMPP — это не стандартная интеграция, поэтому мы не можем работать со всеми провайдерами. Нам подходят только те провайдеры, которые могут принимать от нас данные через SMPP и на своей стороне переводить их в формат отправки в Viber.

Мы работаем со следующими провайдерами Viber-рассылок:

|  |  |  |
| --- | --- | --- |
| - ADV Media Group - Devino Telecom Viber SMPP - Easy Sms Viber - edna Viber (бывший MFMS Viber) - Generic Uploader Viber SMPP - Generic Viber SMPP - Green SMS Viber SMPP | - i-Digital Viber SMPP - Imobis Viber - Infobip Viber - Messaggio - Rapporto Viber SMPP - SevenTech Viber | - SMS-Центр Viber - Sms-Traffic Viber - Stream Telecom Viber - StreamTelecom, VK через Viber - Svyaznoy Viber - Webcom Mobi Viber - Terasms |

### Шаг 1. Подключите SMPP-соединение.

Если у вас уже подключено Viber SMPP-соединение с провайдером из списка, переходите к шагу 2.  
1. Выберите шлюз для отправки сообщений.

**Если вашего провайдера нет в списке, обратитесь к менеджеру Mindbox.**

### Шаг 2. Добавьте SMPP-соединение в Mindbox.

2.1. Запросите у провайдера следующие данные:

- host
- port
- логин (или systemId)
- пароль
- имя отправителя

#### IP адреса в Mindbox

Провайдер может потребовать IP-адреса, с которых к ним будут подключаться, чтобы добавить их в список разрешенных:

95.131.31.24  
130.193.65.100  
130.193.65.114  
178.57.72.88  
178.57.72.107  
95.131.24.140

Внести в список нужно все адреса. Актуальный список — на странице добавления соединения.

2.2. Перейдите на страницу добавления соединения: **Настройки** → **Рассылки** → **Соединения** → **Viber** → **Все соединения**:

![viber-smpp-1.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/viber-smpp-1.png)

Выберите бренд. Если у вас один бренд, то он будет выбран автоматически. Нажмите на «Добавить соединение» и введите данные, полученные от провайдера.

![viber-smpp-2.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/viber-smpp-2.png)

**Обратите внимание:** после введения имени отправителя надо нажать Enter.

![Screenshot 2022-10-05 at 14-15-53 Aag Viber SMPP-соединения.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/Screenshot%202022-10-05%20at%2014-15-53%20Aag%20Viber%20SMPP-%D1%81%D0%BE%D0%B5%D0%B4%D0%B8%D0%BD%D0%B5%D0%BD%D0%B8%D1%8F%281%29.png)

Имена отправителя нельзя удалить после сохранения соединения.

### Шаг 3. Включите модуль Viber-рассылок.

В демо-режиме можно отправлять [тестовые сообщения](mailings-test-mode.md), но запуск Viber-рассылок не доступен.

Для этого запросите подключение модуля Viber-рассылок у менеджера вашего проекта.

**На этапе запуска рассылок,убедитесь, что на стороне провайдера нет каскада Viber -» SMS.**

Важно, чтобы у оператора были отключены каскадные рассылки из Viber в SMS. В противном случае SMS будут слаться двумя системами параллельно: Mindbox и провайдером.

Конечную стоимость за услуги отправок Viber рассылок, вы можете уточнить у провайдера.
