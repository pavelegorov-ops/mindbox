# Как добавить статус позиции заказа

Для того, чтоб добавить новый статус позиции заказа, выполним следующие шаги:

1. Заходим в **Настройки** → **Продукты и заказы** → **Статусы позиции заказа** и нажимаем «Добавить»:

![статусы.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D1%81%D1%82%D0%B0%D1%82%D1%83%D1%81%D1%8B.png)

2. Заполняем поля:

![Снимок экрана 2021-08-05 в 08.46.17.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-08-05%20%D0%B2%2008.46.17.png)

*Название* — название статуса покупки.  
*Внешний идентификатор* — идентификатор позиции заказа во внешней системе. То, как прописывается позиция заказа в интеграциях.  
*Категория* — группа статусов, к которой будет относиться статус.

Статусы позиции заказа каждая компания задает самостоятельно, исходя из своих бизнес-процессов. Однако категории для каждого статуса выбираются из пяти стандартных: Доставлена, Отменена, Возврат, Оформлена, Оплачена.

Категории влияют на автоматический расчет стоимости заказа. Предположим, мы импортируем заказ без стоимости и в нем три позиции: две позиции категории «Доставлена» и одна позиция категории «Возврат». Мы автоматически посчитаем сумму заказа, просуммировав *только доставленные позиции.*

Также простановка логичной категории важна в событийных сценариях. Например, сценарий по событию «Продукт в заказе доставлен» будет срабатывать после того, как позиция заказа перешла в любой статус категории «Доставлена».

3. Нажимаем «Добавить».
