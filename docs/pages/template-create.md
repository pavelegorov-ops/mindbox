# Как создать шаблон действия

## Описание

Шаблон действия — это название события, которое происходит с клиентом.

Например: вход на сайт, открытие письма, импорт клиента в базу, пометка клиента для рассылки и т.д

Ситуации, когда нужен шаблон действия:

- Сделать пометку при импорте клиентов. Для использования в фильтрах, чтобы отделить одних клиентов от других.
- Зафиксировать действие в результате выполнения операции на сайте. Например, просмотр товара
- Настроить сценарий.

## Создание шаблона действия:

1. Переходим в раздел **Настройки** → **Клиенты и действия** → **Шаблоны действий**:

![action-templates-interface.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/action-templates-interface.png)

2. Выбираем «Добавить» → «Шаблон действия»:

![action-templates-add.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/action-templates-add.png)

3. Заполняем поля

Пример заполнения:

![action-templates-example.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/action-templates-example.png)

*Название* — имя действия. Будет записываться клиентам в системе.  
*Тип* — тип действия. Чаще всего нужен будет «Стандартный».  
*Системное имя* — имя, с которым шаблон действия записывается в нашей базе. Используется в интеграциях. Проставляется автоматически.  
*Кампания* — кампания, в которой будет использоваться действие.  
*Допустимые бренды* — бренд, в котором можно выдавать данный шаблон, если на проекте есть бренды.

*Категории* заполняются в зависимости от цели, для которой создается шаблон действия. Примеры заполнения можно посмотреть в связанных статьях.

*Категория I уровня* — глобальная категория:

- Личные действия клиента — действия, которые клиент совершил сам
- Действия в отношении клиента — инициатором действия выступаем мы

*Категория II уровня* — выбирается по смыслу в зависимости от того, что выбрано в первой категории  
*Категория III уровня* — выбирается по смыслу в зависимости от того, что выбрано во второй категории

*В каком случае выдается и Как используется* — необязательно.

*Теги* — можно указать для группировки шаблонов

4. Сохраняем шаблон.
