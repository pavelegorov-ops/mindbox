# Начислить баллы за заказ (или каждые n рублей в заказе)

## По шагам

#### 1. Создаем балльную промоакцию по [инструкции](how-to-creare-bonus-points-promo)

Не запускаем ее, настраиваем все, кроме бенефитов, в соответствии с бизнес-целью.

#### 2. Настраиваем бенефиты в блоке «Состав заказа»

Выбираем заказы, на которые будет действовать скидка.  
Можно выбрать: все заказы, заказы в сегментации, заказы не в сегментации.
