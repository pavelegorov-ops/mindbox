# Как перевести проект на opt-in (подтверждение подписки)

Функция Opt-in — это подтверждение подписки. Для перевода проекта на opt-in выполним следующие шаги:

1. Заходим в **Настройки → Рассылки → Настройки email**:

![настройки емейл.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%BD%D0%B0%D1%81%D1%82%D1%80%D0%BE%D0%B9%D0%BA%D0%B8%20%D0%B5%D0%BC%D0%B5%D0%B9%D0%BB.png)

2. Ставим галочку в поле **Подтверждение подписки** и сохраняем:

![Снимок экрана 2021-07-11 в 17.54.54.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-07-11%20%D0%B2%2017.54.54.png)

3. Создаем **[рассылку для сценария](email-trigger)**.

В настройках рассылки должна стоять галочка «Подтверждение подписки».

Отмечаем нужную ссылку как подтверждение подписки на канал/тематику.  
Подробнее в инструкции: [Как поставить в рассылке ссылку подтверждения подписки на канал или тематику](как-поставить-в-рассылке-ссылку-подтверждения-подписки-на-канал-или-тематику).

---

Есть второй способ, который подходит, если стоит задача также подтвердить контакт. В таком случае в шаблоне рассылки добавляем тикет подтверждения email-адреса к нужной ссылке:

```
?direct-crm-ticket=${Ticket.EmailConfirmationLinkTicket}
```

Тикет подпишет только тех клиентов, у кого был статус подписки "Требует подтверждения".  
Если клиент был отписан, клик по ссылке с тикетом не изменит его подписки.

4. Создаем [сценарий](what-is-workflow.md).

Запуск — по [появлянию статуса](workflow-events.md#izmenilsya-status-podpiski) «Требует подтверждения» в канале:

![Снимок экрана 2023-02-09 в 16.11.12.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-02-09%20%D0%B2%2016.11.12.png)

Тематику указываем, только если хотим подтверждения по конкретной тематике. Для подтверждения по каналу email оставляем «без тематики».

В блоке **Шаги** выбираем «Отправить email» и добавляем рассылку, созданную в пункте 4:

![Снимок экрана 2023-02-09 в 16.14.00.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-02-09%20%D0%B2%2016.14.00.png)

5. На стороне сайта нужно реализовать отдельную страницу с установленным основным кодом трекера. Обычно такая страница содержит информацию об успешном подтверждении e-mail и кнопку возврата на сайт. На эту страницу клиенты будут переходить по ссылке из полученного по сценарию письма.

Переход на Double opt-in не влияет на статус подписки уже существующих клиентов.
