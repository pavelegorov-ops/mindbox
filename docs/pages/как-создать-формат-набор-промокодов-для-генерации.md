# Как создать формат (набор) промокодов для генерации

Прежде, чем генерировать промокоды для пула, нужно создать формат промокодов. По этому формату будут генерироваться коды единого вида.

## Создание формата промокодов

В настройке пула выберите способ добавления **Сгенерировать промокоды**. Дальше нажмите на **Создать** у «Формата».

#### Настройки формата

![Снимок экрана 2021-05-09 в 18.02.01.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-05-09%20%D0%B2%2018.02.01.png)

**Название** - то, как формат будет показан в меню выбора формата.  
**Алфавит** - то, какие символы будут использованы при генерации кодов. По умолчанию выбраны все. Клик по символу исключит его из генерации. В строке под таблицей — список всех используемых символов.

**Маркер** — символы, единые для всех промокодов набора. Ставятся в одном и том же месте каждого промокода. Помогают визуально определить, к какому набору относится код. Необязательно.  
Если устанавливаете, укажите место в промокоде.

**Длина промокода** — длина кода в символах, включая маркер (если он есть). Максимум — 20 символов.

**Максимально допустимое количество промокодов** — то, сколько кодов можно сгенерировать в этом наборе.
