# Технические ограничения в пушах

### Какие есть ограничения на количество символов в мобильных пушах?

Представленные значения актуальны для делегата Mindbox (методы библиотеки Mindbox SDK для отрисовки пуша). При использовании кастомной отрисовки ограничения в тексте могут отличаться.

- **заголовок и текст**:
  - **iOS** — ограничены количеством символов:
    - заголовок — 1000, текст — 256 (вне зависимости от наличия картинки)
  - **Android** — ограничены строками или символами в зависимости от наличия картинки. Количество символов, которое умещается в строку/текст, зависит от параметров устройства пользователя (разрешение экрана, производитель и т.д.).
    - без картинки: заголовок — 1-2 строки (25-80 символов), текст — 440-560 символов
    - с картинкой:
      - до Android 12: заголовок — 1 строка (25-50 символов), текст — 1-2 строки (38-80 символов)
      - Android 12 и выше — 2 строки (около 70 символов), текст — 1-2 строки (38-80 символов)
- **текст кнопки без параметров** — 20 символов
- **текст кнопки с параметрами** — 1000 символов
- **ссылки (клики/картинка)** — 2000 символов

Максимальный размер всего пуша для текущих версий iOS и Android — 4 Кб.

### Какова скорость отправки мобильных пушей?

Средняя скорость — 1,5 млн пушей в час на проект в сумме по обеим платформам.  
Одновременные отправки рассылок по другими каналами снижают скорость отправки.

### Какие есть ограничения по картинкам?

Ограничения по картинкам зависят от версии SDK. Уточните версию SDK у разработчиков мобильного приложения.

#### Для версии SDK 2.11.0 и выше

**iOS**

- пуши поддерживают картинки форматов JPG и PNG;
- рекомендуем использовать файл размером не больше 5 Мб, иначе вместо картинки будет отображаться белая заглушка.

Не используйте сильно вытянутые вертикальные картинки. В них появляется скролл: чтобы увидеть нижнюю часть картинки нужно пролистать вниз. Например, изображения форматов 2:1 / 16:9 / 4:3 / 1:1 отобразятся целиком, а с 1:2 / 9:16 / 2:3 / 5:7 уже появится скролл.

| Изображение формата 1:2 | Изображение формата 1:2 |
| --- | --- |
| 00_ios_12 | 01_ios_12 |

**Android**

- пуши поддерживают картинки форматов JPG, PNG, WEBP;
- рекомендуем использовать размер файла не больше 5 Мб;
- масштаб картинки рассчитывается автоматически в зависимости от ширины устройства.

Рекомендуем использовать горизонтальные изображения, например, 2:1, чтобы ширина картинки соответствовала ширине текста. Если использовать вертикальные изображения — они будут выравниваться по центру и их ширина будет меньше ширины текста.

| Изображение формата 4:1 | Изображение формата 2:3 |
| --- | --- |
| 02_android_41 | 03_android_23 |

#### Для версии SDK ниже 2.11.0

**iOS**

- рекомендуем использовать размер файла не больше 5 Мб;
- рекомендуем использовать изображение с соотношением сторон 5:4

iOS автоматически масштабирует изображения. Если его размер превышает допустимые значения, то оно может быть обрезано по бокам или сверху/снизу в зависимости от размера экрана устройства.

**Android**

- рекомендуем использовать размер файла не больше 5 Мб;
- длина сторон рассчитывается автоматически;
- рекомендуемое соотношение 2:1.
