# Ошибки при интеграции мобильного приложения

Часто ошибки при интеграции связаны с неправильной передачей какого-либо метода или неточной реализацией инструкции на [developers.mindbox.ru](https://developers.mindbox.ru/).

Основные проблемы при интеграции и способы их решения описаны [здесь](https://developers.mindbox.ru/docs/%D1%87%D0%B5%D0%BA%D0%BB%D0%B8%D1%81%D1%82-%D0%BF%D1%80%D0%BE%D0%B2%D0%B5%D1%80%D0%BA%D0%B8-%D0%B8%D0%BD%D1%82%D0%B5%D0%B3%D1%80%D0%B0%D1%86%D0%B8%D0%B8-sdk-1).

[Интеграция сайта с платформой Mindbox](https://mindbox.ru/academy/education/5-ehtapov-integracii-mindbox/): получение данных с сайта, из мобильного приложения, лендингов, программы лояльности, офлайн-точек, CRM-систем.
