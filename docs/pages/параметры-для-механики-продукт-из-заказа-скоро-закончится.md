# Параметры для механики «Продукт из заказа скоро закончится»

[Заказ](what-is-an-order.md) состоит из позиций. Позиция включает в себя продукт со статусом, ценой и [дополнительными полями](additional-data.md).

В сценариях по событию «Продукт в заказе доставлен» можно использовать [параметр](%D1%87%D1%82%D0%BE-%D1%82%D0%B0%D0%BA%D0%BE%D0%B5-%D1%88%D0%B0%D0%B1%D0%BB%D0%BE%D0%BD%D0%B8%D0%B7%D0%B0%D1%82%D0%BE%D1%80.md) OrderItem, который обращается именно к позиции:

![Снимок экрана 2021-10-21 в 16.47.59.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-10-21%20%D0%B2%2016.47.59.png)

Пример верстки:

```
Название: ${OrderItem.Product.Name}
Цена: ${OrderItem.Price * OrderItem.Count}
```
