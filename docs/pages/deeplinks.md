# Что такое Deeplinks (диплинки)

**Deeplinks**, они же **диплинки** — это ссылки, ведущие в мобильное приложение.

Технология позволяет создать индивидуальный путь пользователя: если у него уже скачано приложение, то он перейдет в конкретный раздел, указанный в ссылке, если нет — ссылка приведет его в нужных магазин приложений.

Диплинки используются:

- При переходе из email-рассылки в приложение.
- При переходе из push-уведомления в приложение или на сайт.

При этом в диплинк-ссылках можно передать параметры, чтобы затем их использовать в приложении. Например, промокод для подстановки в корзину или ID отслеживаемого заказа.

Для диплинк-ссылок не проставляются UTM-метки, указанные в рассылке, а также **не отслеживаются клики**.

Для бесшовного перехода в мобильное приложение с **сохранением статистики кликов** используйте функционал [Уникальных ссылок](unique-links.md).

Рассмотрим подробнее каждый вариант использования.

## При переходе из email-рассылки в приложение

При разработке шаблона письма нужно выбрать для ссылки один из видов действия:

- Отслеживаемый переход
- Переход без отслеживания

Переход по отслеживаемой ссылке пересобирает ее таким образом, чтобы она вела на домен e.mindbox.ru, но это ломает работу диплинков. Чтобы этого избежать, для них нужно выбрать режим «Переход без отслеживания».

## При переходе из push-уведомления в приложение

При создании push-рассылки, диплинк нужно указать в поле «Ссылка перехода по пушу». При этом ссылка может вести как в приложение, так и на сайт.
