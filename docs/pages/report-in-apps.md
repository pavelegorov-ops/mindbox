# Отчет по In-app’ам

Отчет по In-App’ам позволяет отслеживать выручку, которую приносят все запущенные информационные формы в приложении, а также оценивать влияние форм на подписку на прирост количества клиентов, разрешивших получение мобильных пушей.

Отчет расположен в разделе **Аналитика → In-App**:

![reports-in-app.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/reports-in-app.png)

Все данные в отчетах актуальны на предыдущий день, так как они пересчитываются один раз в сутки ночью.

## Информационные формы

![reports-in-app-information-forms.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/reports-in-app-information-forms.png)

### Настройка отчета

По умолчанию отчет открывается за последний месяц с разбивкой по дням и целью «Заказы».

- Период укажите вручную или воспользуйтесь пресетами дат, которые автоматически отберут период за последнюю неделю, месяц или полгода. Правая дата задается включительно.

![report-inapp-period-choose.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/report-inapp-period-choose.png)

- Выберите интересующие In-App'ы: можно указать нужные вручную или отфильтровать по статусам, папкам, мобильным приложениям.

![report-inapp-chooseform.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/report-inapp-chooseform.png)

- Выберите цель — выручку по каким категориям и статусам заказов нужно вывести. Цель по умолчанию «Заказы» включает позиции в статусах «Оформлена», «Оплачена», «Доставлена».

![report-in-apps-goals.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/report-in-apps-goals.png)

### Динамика форм

Отчет поможет увидеть, какие показатели растут или падают по сравнению с предыдущими периодами. В шапке отчета даны [показатели](report-in-apps.md#metriki-otcheta) по выбранным In-App’ам за период.

#### Графики

Для настройки графика:

- Кликните по нужной метрике в шапке отчета.
- Выберите группировку показателей: по дням, неделям или месяцам.

Абсолютные значения даны в виде столбчатой диаграммы и представлены по правой оси, процентные — в виде линейного графика и расположены по левой оси. При наведении на отрезок выводятся показатели за данный интервал:

![report-inapps-charts.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/report-inapps-charts.png)

Под графиком приведена таблица с разбивкой всех метрик по выбранному шагу. При раскрытии метрики выводятся показатели по конкретным формам. Для группировки In-App’ов по папкам, кликните на соответствующий переключатель:

![report-inapps-table.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/report-inapps-table.png)

### Сводные показатели

При переключении на сводные показатели выводятся суммарные данные по выбранным формам за указанный период. В этом отчете приведены те же [показатели](report-in-apps.md#metriki-otcheta), что и в динамике форм.

![report-inapps-summary.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/report-inapps-summary.png)

В отчете по сводным показателям не будут отображены формы, в которых значения всех метрик равны нулю. При этом они отобразятся в отчете динамики форм, если в фильтре выбран хотя бы один In-App, по которому есть данные.

### Метрики отчета

- **Выручка** — суммарная выручка по совершенным за указанный период заказам, атрибутированным к кликам по всем формам.
  - Количество заказов за указанный период.
- **Средний чек** — средний чек по совершенным за указанный период заказам, атрибутированным к кликам по всем формам.
- **Попаданий в таргетинг** — количество неуникальных пользователей, попавших под условия таргетинга за выбранный период.
- **Доля показов** — отношение количества показов к количеству попаданий в таргетинг за выбранный период.
  - Количество неуникальных показов формы за выбранный период.
- **CTR** — отношение количества кликов к количеству показов за выбранный период.
  - Количество неуникальных кликов за выбранный период.
- **Конверсия в заказ** — отношение количества заказов, атрибутированных к форме, к количеству просмотров за указанный период.
  - Количество заказов, атрибутированных к кликам за выбранный период.
- **Выручка из конверсий** — суммарная выручка по всем заказам, атрибутированным к совершенным за указанный период кликам по всем формам.
  - Средний чек по заказам из конверсий.

Обратите внимание:

- Отмененные и возвращенные позиции не входят в выручку.
- Анонимные показы In-App’ов и клики по ним учитываются в отчете, даже если анонимные клиенты не передаются в Mindbox.

Для настройки графика:

График доступен по каждому показателю. При наведении на отрезок выводятся показатели за данный интервал:

![report-in-apps-table-subscriptionforms.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/report-in-apps-table-subscriptionforms.png)

### Сводные показатели

При переключении на сводные показатели выводятся суммарные данные по выбранным формам за указанный период. В этом отчете приведены те же [показатели](report-in-apps.md#metriki-otcheta1), что и в динамике форм.

![report-inapps-summury-subscriptionforms.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/report-inapps-summury-subscriptionforms.png)

В отчете по сводным показателям не будут отображены формы, в которых значения всех метрик равны нулю. При этом они отобразятся в отчете динамики форм, если в фильтре выбран хотя бы один In-App, по которому есть данные.

### Метрики отчета

- **Разрешили пуши** — количество неуникальных разрешений на мобильные пуши, атрибутированных к кликам по форме в установленное на проекте окно [атрибуции](attribution.md). Считается по выданному [действию разрешения](template-permission-mobilepush.md) и атрибутируется к клику по точке контакта.
- **Попаданий в таргетинг** — количество неуникальных пользователей, попавших под условия таргетинга за указанный период.
- **Доля показов** — отношение количества показов к количеству попаданий в таргетинг за указанный период.
  - Количество неуникальных показов формы за выбранный период.
- **CTR** — отношение количества кликов к количеству показов формы за указанный период.
  - Количество неуникальных кликов за выбранный период.
- **Доля разрешивших пуши** — отношение количества неуникальных разрешений на мобильные пуши к количеству кликов по форме за указанный период.
  - Количество неуникальных разрешений на мобильные пуши, атрибутированных к кликам по форме в установленное на проекте окно атрибуции.

#### Особенности метрик

- Анонимные показы In-App’ов и клики по ним учитываются в отчете, даже если анонимные клиенты не передаются в Mindbox.
- Разрешения анонимных клиентов не учитываются в метрике «Разрешили пуши».
- Разрешение для одного приложения не будет атрибутировано к клику в In-app в другом приложении, если для приложений используются разные точки контакта. Пример: пользователь кликнул в форме в приложении для Android, но не разрешил получение уведомлений. Далее он дал разрешение в приложении для IOS. Разрешение для iOS не будет атрибутировано к клику на Android, так как действия приходят из разных точек контакта.
- Метрика «Разрешили пуши» фиксирует факт предоставления разрешения на уведомления пользователем, даже если позже он отозвал его. Учитывается именно действие разрешения, а не текущее состояние.

## Как удаление данных отражается на отчетах

- Автоматическое и ручное удаление действий и клиентов не влияет на отчет, данные сохраняются.
- Удаление In-App’ов также не влияет на отчет: они остаются в отчете и помечаются как удаленные.

Важно

После удаления клиентов или их действий, результаты фильтров по действиям кликов или показов могут не сходиться с данными, предоставленными в отчете.

## Экспорт отчетов

Выберите нужный тип отчета, период, формы и цель. Нажмите на «Экспорт в .csv»:

![report-inapps-export.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/report-inapps-export.png)

В CSV-файл будут выгружены поля:

- date — начальная дата отрезка (только при выгрузке динамики форм).
- campaignName — название формы.
- campaignLink — ссылка на форму.
- revenue — выручка.
- orders — количество заказов.
- targeting — попаданий в таргетинг.
- showsRate — доля показов.
- CTR — отношение к количеству кликов к количеству показов формы за указанный период.
- orderConversion — конверсия в заказ.
- shows — количество показов.
- clicks — количество кликов.
- conversionOrders — количество заказов, атрибутированных к кликам за выбранный период.
- conversionRevenue — выручка из конверсий.
- averageOrderValue — средний чек.
- conversionAverageOrderValue — средний чек из конверсий.
- pushSubscriptions — количество неуникальных разрешений на мобильные пуши, атрибутированных к кликам по форме (только при выгрузке отчета «Формы подписки на пуши»).
- pushSubscriptionsRate — доля разрешивших пуши (только при выгрузке отчета «Формы подписки на пуши»).
- startDate — дата старта.
- endDate — дата окончания.
- category — тип формы.
  - Modal Standard — модальное окно.
  - Snackbar Standard — снекбар.
  - Snackbar Subscribe to push — снекбар на подписку.
  - Modal Subscribe to push — модальное окно на подписку.
- status — статус.
  - Active — запущена.
  - Draft — черновик.
  - Stopped — остановлена.
  - Deleted — удалена.
- applications — приложение.
- folder — папка.
- campaignID — идентификатор формы.

Экспорт отчетов по In-App’ам недоступен по API.
