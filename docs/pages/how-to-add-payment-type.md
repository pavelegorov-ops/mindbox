# Как добавить способ оплаты заказа

Заказ можно оплачивать разными способами: наличными, кредитной или дебетовой картой и т.д.  
Эти способы можно записать в Mindbox и передавать по ним данные в заказах.  
Для добавления способа оплаты выполним следующие действия:

1. Заходим в **Настройки** → **Продукты и заказы** → **Способы оплаты** и нажимаем «Добавить»:

![способы.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D1%81%D0%BF%D0%BE%D1%81%D0%BE%D0%B1%D1%8B.png)

2. Заполняем поля в форме:

![Снимок экрана 2021-08-05 в 09.00.03.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-08-05%20%D0%B2%2009.00.03.png)

*Название -* название способа оплаты, которое будет отображаться в списке.  
*Внешний идентификатор* — идентификатор способа оплаты во внешней системе. Это то, как прописывается способ оплаты в интеграциях.

3. Нажимаем «Добавить».
