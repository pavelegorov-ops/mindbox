# Как добавить In-App «Скидка на подборку товаров»

**Цель механики** — увеличить конверсию в заказ среди пользователей, которые уже зашли в приложение и сами начали просматривать товары, чтобы с большей вероятностью довести их до покупки.

## Как это работает

1. Пользователь заходит в приложение, открывает карточку товара (например, свитер).
2. Показывается In-App с промокодом на категорию или сегмент с просматриваемым товаром (например, нового бренда одежды со свитшотами).
3. Клиент выбирает предложенные товары, добавляет их в корзину и применяет полученный промокод при оформлении заказа.

## Шаги настройки

Некоторые настройки на этой странице требуют обновления SDK приложения до версии 2.14.0. Для обновления SDK версии обратитесь к вашим разработчикам.

### 1. Создайте операцию просмотра продукта / категории продуктов

Чтобы показать In-App с промокодом тем, кто открыл карточку товара, нужно настроить операцию просмотра продукта или просмотра категории продуктов.

Если такой операции ещё нет, настройте операцию [по инструкции](%D0%BA%D0%B0%D0%BA-%D0%BD%D0%B0%D1%81%D1%82%D1%80%D0%BE%D0%B8%D1%82%D1%8C-%D1%82%D0%B0%D1%80%D0%B3%D0%B5%D1%82%D0%B8%D0%BD%D0%B3-in-app-%D0%BF%D0%BE-%D0%BF%D1%80%D0%BE%D0%B4%D1%83%D0%BA%D1%82%D1%83-%D0%B8%D0%BB%D0%B8-%D0%BA%D0%B0%D1%82%D0%B5%D0%B3%D0%BE%D1%80%D0%B8%D0%B8-%D0%BF%D1%80%D0%BE%D0%B4%D1%83%D0%BA%D1%82%D0%BE%D0%B2.md). Разработчики должны настроить вызов операции в приложении и выпустить новый релиз приложения.

### 2. Настройте промоакцию

Если акция должна обрабатываться и выдавать скидку по промокоду на стороне Mindbox, [создайте новый пул](%D0%BA%D0%B0%D0%BA-%D0%B4%D0%BE%D0%B1%D0%B0%D0%B2%D0%B8%D1%82%D1%8C-%D0%BF%D1%80%D0%BE%D0%BC%D0%BE%D0%BA%D0%BE%D0%B4%D1%8B-%D0%B2-%D0%BF%D1%80%D0%BE%D0%B5%D0%BA%D1%82.md) с многоразовым промокодом и [настройте промоакцию](how-to-create-a-discount-promo.md).

### 3. Создайте In-App с промокодом

Создайте In-App по [инструкции](in-apps.md).

#### Внешний вид формы

- Выберите и отредактируйте один из предлагаемых [шаблонов Figma](https://www.figma.com/file/QoJ0yKREcTsP3CPNUUZ8LG/%D0%93%D0%B0%D0%BB%D0%B5%D1%80%D0%B5%D1%8F-%D1%88%D0%B0%D0%B1%D0%BB%D0%BE%D0%BD%D0%BE%D0%B2-In-App?type=design&node-id=0%3A1&mode=design&t=COtICWsqaoJBMAJO-1) либо используйте свой дизайн.

С техническими рекомендациями к размеру и формату картинки для In-app можно ознакомиться [здесь](in-apps.md#shablon-modalnoe-okno).

- В поле Payload вставьте промокод, который пользователь должен скопировать по клику в In-App, например, `PROMOCODE`

![in-app-selected-products-form.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/in-app-selected-products-form.png)

#### Общие настройки

- Выберите приложения, в которых будет отображаться форма, и даты показа.
- Укажите частоту всплывания **«Всего один раз»**, особенно если промокод действует на выбранные товары ограниченное время.

![in-app-selected-products-general.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/in-app-selected-products-general.png)

#### Условия всплывания

Выберите **«Спустя время после попадания в таргетинг»** и поставьте задержку в 2-3 секунды секунды. Такой In-App покажется после того, как пользователь откроет товар, но у него будет несколько секунд, чтобы ознакомиться с продуктом, и он будет готов к акционному предложению.

![in-app-selected-products-frequency.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/in-app-selected-products-frequency.png)

#### Таргетинг

Добавьте в таргетинг условие **«Экран продукта»** и выберите сегмент продуктов, на который распространяется акция.

![in-app-selected-products-targeting.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/in-app-selected-products-targeting.png)

Если акция действует на категорию товаров, выберите **«Экран категории»** и укажите нужную категорию.

![in-app-selected-products-targeting2.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/in-app-selected-products-targeting2.png)

При первом входе в приложение клиент получает несколько системных окон для настройки приложения и онбординга. Чтобы не перегружать пользователя уведомлениям, добавьте условие **«Количество входов в приложение больше или равно 2»**. Так In-App покажется только после второго входа в приложение.

### 4. Протестируйте In-App

Чтобы понять, правильно ли отображается In-App, добавьте сегмент с тестовым клиентом в таргетинг In-App. Подробнее в [статье](in-apps.md#kak-protestirovat-in-app).

### 5. Запустите In-App

Когда форма готова и протестирована, запустите ее:

![in-app-selected-products-start.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/in-app-selected-products-start.png)

## Отслеживайте данные по механике

Отслеживайте метрики по запущенному In-App с помощью [отчета по In-App](report-in-apps.md).

![reports-in-app.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/reports-in-app.png)

Чтобы понять, сколько пользователей сделали заказ с промокодом из In-App, постройте фильтр по клиентам, у которых:

- Было действие показа In-App с промокодом
- Было действие заказа с применением промокода.

![in-app-selected-products-check.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/in-app-selected-products-check.png)

## Рекомендации для АБ-тестов с механикой

Чтобы увеличить конверсию в покупку, необходимо тестировать различные подходы и инструменты, которые подходят именно вашей аудитории.

Ниже несколько идей для проведения АБ-тестов, которые помогут вам в этом.

Базовые шаги по созданию и настройке АБ-теста по In-App’ам описаны [здесь](ab-test-app.md).

1. Сравните In-App с промокодом против контрольной группы по метрике «Конверсия в заказ», чтобы понять, помогает ли выдача промокода внутри приложения лучше конвертировать пользователя в покупку
2. Сравните разные предложения в In-App с промокодом по метрике ARPU (средней выручке на одного пользователя). Например, скидка 300 рублей при заказе от 3000 и скидка 500 рублей при заказе от 5000.
3. Сравните разное время всплывания In-App с промокодом по метрике «Конверсия в заказ», чтобы понять, когда лучше показывать предложение: сразу после того, как пользователь откроет карточку товара или через 3 / 5 / 10 секунд.
