# Выделенный поддомен (Return Path)

По умолчанию Mindbox использует общий технический домен для отправки писем на всех проектах. Это означает, что на репутацию отправителя может влиять отправки других компаний.

**Выделенный поддомен** позволяет использовать отдельный адрес отправителя, что дает:

- Больший контроль над репутацией отправителя
- Улучшение доставляемости писем, в том числе на корпоративные адреса

**Перед настройкой**

Выделенный поддомен не является отправителем рассылки. Если на проекте еще нет ни одного отправителя, перейдите к [инструкции](https://help.mindbox.ru/docs/%D0%BA%D0%B0%D0%BA-%D0%BD%D0%B0%D1%81%D1%82%D1%80%D0%BE%D0%B8%D1%82%D1%8C-%D0%B4%D0%BE%D0%B1%D0%B0%D0%B2%D0%B8%D1%82%D1%8C-%D0%B8%D0%B7%D0%BC%D0%B5%D0%BD%D0%B8%D1%82%D1%8C-%D0%BE%D1%82%D0%BF%D1%80%D0%B0%D0%B2%D0%B8%D1%82%D0%B5%D0%BB%D1%8F-%D0%B2-email-%D1%80%D0%B0%D1%81%D1%81%D1%8B%D0%BB%D0%BA%D0%B5).

## Настройка выделенного поддомена

### Проверка доступности поддомена

Перед настройкой убедитесь, что выбранный поддомен:

- Не используется для сайта или других сервисов;
- Не имеет существующих SPF-записей, или есть возможность объединить записи;
- Не имеет MX-записей, или есть возможность сделать запись Mindbox наиболее приоритетной;

Попросите выполнить проверку IT-специалиста или проверьте самостоятельно через сервис MxToolbox.

**Как проверить поддомен через MxToolbox:**

1. Перейдите на сайт [mxtoolbox.com](https://mxtoolbox.com/);
2. Выберите тип проверки «MX Lookup»;
3. Введите ваш предполагаемый поддомен, например: info.company.ru;
4. Нажмите «MX Lookup», чтобы проверить наличие MX-записей:

   ![return-path-mx-check.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/return-path-mx-check.png)

   *Пример проверки поддомена с одной MX-записью*
5. Повторите проверку с помощью инструмента «TXT Look up»:

   ![return-path-spf-check.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/return-path-spf-check.png)

   *Пример проверки поддомена без SPF-записей*

### Добавьте поддомен в Mindbox

1. Перейдите в **Настройки → Рассылки → Настройки Email:**

   ![return-path-path.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/return-path-path.png)
2. Выберите бренд и найдите нужный домен в списке. Настройка выделенного поддомена находится под DKIM-записью домена. Нажмите «Настроить поддомен»:

   ![return-path-button.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/return-path-button.png)
3. Выберите имя по [инструкции](return-path.md#proverka-dostupnosti-poddomena) и нажмите "Продолжить".
4. Укажите имя поддомена:

   ![return-path-setting.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/return-path-setting.png)
5. Нажмите «Создать поддомен». Система сгенерирует записи MX и SPF, которые необходимо перенести в настройки DNS.

   ![return-path-dns.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/return-path-dns.png)

**Обратите внимание**

Для одного домена отправителя можно добавить только один выделенный поддомен.

### Настройте DNS-записи

Скопируйте сгенерированные записи и передайте их IT-специалисту или добавьте самостоятельно в панели управления доменом.

При добавлении сгенерированных записей в поле **«Имя записи»** укажите имя поддомена, которое вы указали в настройках Mindbox.

**Пример имен записи:**

- example.mindbox.ru → example
- info.example.mindbox.ru → info.example

Обратите внимание

Для одного поддомена может быть:

- одна SPF-запись;
- несколько MX-записей. В этом случае убедитесь, что MX-запись для Mindbox имеет наивысший приоритет (наименьшее числовое значение) среди всех записей.

**Пример записей DNS поддомена `test.mindbox.ru`:**

| **Имя записи** | **Тип записи** | **Приоритет** | **Значение** |
| --- | --- | --- | --- |
| test | MX | 1 | bounce.mindbox.ru |
| test | TXT | — | v=spf1 a mx include:spf.mindbox.ru ?all |

После добавления настроек, выделенный поддомен будет готов в течение 48 часов.

### Подтвердите готовность домена

По готовности домена на почту пользователя, который добавил поддомен, придет письмо с уведомлением.

1. Вернитесь в **Настройки → Рассылки → Настройки Email**
2. Проверьте, что статус записей подтвержден
3. Ознакомьтесь с рекомендациями в шаге 4 и нажмите «Продолжить»:

   ![return-path-pre-on.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/return-path-pre-on.png)
4. Нажмите кнопку подтверждения готовности домена

   ![return-path-on.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/return-path-on.png)

## Прогрев домена

Перед началом полноценной отправки необходимо **прогреть новый поддомен**.

Почтовые сервисы (Gmail, Mail.ru и др.) воспринимают новые домены как потенциально ненадежные. Резкий старт с большими объемами отправок может привести к блокировкам и попаданию в спам.

С рекомендациями для прогрева можно ознакомиться в [журнале Mindbox](https://mindbox.ru/journal/education/progrev-domena-otpravitelya/).

Для прогрева используйте аудиторию [активных клиентов](https://help.mindbox.ru/docs/%D0%B0%D0%BA%D1%82%D0%B8%D0%B2%D0%BD%D1%8B%D0%B5-%D0%BF%D0%BE%D0%B4%D0%BF%D0%B8%D1%81%D1%87%D0%B8%D0%BA%D0%B8).

## Что делать, если DNS-записи удалены

Mindbox проверяет наличие DNS-записей для выделенного поддомена каждые 10 минут.

Если записи перестают обнаруживаться:

- Отправка писем **не останавливается**
- Все письма начнут отправляться с техническим доменом Mindbox
- Если клиент отпишется от письма, которое ушло с выделенным поддоменом, **отписка в Mindbox выдана не будет**
- На всех письмах и в настройках появляется ошибка
- На проекте открывается проблема

Перейдите по ссылке в проблеме или ошибке, чтобы узнать ее подробности:

![return-path-error.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/return-path-error.png)

Для возобновления отправки восстановите DNS-записи в настройках выделенного поддомена. Как проверить корректность записей, рассказываем в [статье](return-path-verification.md).

![return-path-error-description.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/return-path-error-description.png)

## Проверка выделенного поддомена

Для проверки работы выделенного поддомена, отправьте тестовое письмо в любой почтовик. По его данным можно проверить, через какой домен была отправка.

Перейдите в оригинал (свойства) письма:

![](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-10-28%20%D0%B2%2017.13.36.png)

*Как перейти к оригиналу письма в интерфейсе Gmail*

Поддомен будет находится в свойстве `Return-Path`:

![return-path-check2](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/return-path-check2.png)

В Gmail можно раскрыть подробности об отправке не переходя в оригинал письма. Выделенный поддомен будет находится в параметре «Отправлено через»:

![return-path-check](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/return-path-check.png)
