# Как продлить срок действия/выдачи промокодов в пуле

**Задача**: у добавленных промокодов увеличить время выдачи и использования на две недели:

![Снимок экрана 2021-05-11 в 21.17.55.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-05-11%20%D0%B2%2021.17.55.png)

Для этого нужно загрузить в пул тот же список промокодов, но уже с новыми датами.

Данный способ актуален только для пулов со способом пополнения пула «Загрузить промокоды по файлу».

#### 1. Скачиваем список промокодов из пула

Для этого кликаем на задачу загрузки в блоке «Промокоды»:

![76249248497099fb4602fe62413cf3af1536858784684.jpg](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/76249248497099fb4602fe62413cf3af1536858784684.jpg)

И скачиваем исходный файл:

![Снимок экрана 2021-05-11 в 21.12.15.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-05-11%20%D0%B2%2021.12.15.png)

Колонки в файле:

- IssueStartDateTimeUtc — дата начала выдачи;
- IssueEndDateTimeUtc — дата конца выдачи;
- AvailableFromDateTimeUtc — начало срока действия;
- AvailableTillDateTimeUtc — конец срока действия.

#### 2. Исправляем даты в файле на актуальные

Мы продлеваем сроки выдачи и использования, поэтому нам нужно поправить колонки `IssueEndDateTimeUtc` и `AvailableTillDateTimeUtc`. Но остальные колонки в файле не удаляем.

Исправляем:

![promocode-edit-example.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/promocode-edit-example.png)

#### 3. Загружаем файл

Пункт 2.2. [инструкции](как-добавить-промокоды-в-проект) поможет освежить знания.  
Появляется новая задача загрузки промокодов в файл.

Ожидаем статуса "все успешно"и переходим на страницу просмотра промокодов:

![Снимок экрана 2021-05-11 в 21.34.53.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-05-11%20%D0%B2%2021.34.53.png)

Проверяем, что все получилось:

![Снимок экрана 2021-05-11 в 21.36.54.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-05-11%20%D0%B2%2021.36.54%281%29.png)

[Чем полезны промокоды](https://mindbox.ru/academy/education/kak-primenyat-promokody/): собирают и обогащают клиентскую базу, стимулируют совершить целевое действие, персонализируют скидки.
