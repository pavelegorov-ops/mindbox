# Как создать статический сегмент по точкам контакта

Сначала создаём сегментацию, потом сегмент(ы) в ней.  
По шагам:

1. Переходим в раздел **Данные** → **Сегментации**:

![Снимок экрана 2023-01-15 в 19.20.03.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-01-15%20%D0%B2%2019.20.03.png)

2. Нажимаем «Добавить» → «Статическую по точкам контакта»:

![Снимок экрана 2023-01-15 в 19.20.42.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-01-15%20%D0%B2%2019.20.42.png)

2. Заполняем название и описание.  
   Также можно поменять автоматически сгенерированные системное имя и внешний идентификатор сегментации (могут понадобиться в механиках):

![image](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-06-25%20%D0%B2%2015.15.57.png)

3. Добавляем сегмент(ы).  
   Заполняем название. Системное имя проставляется автоматически при клике по строке, внешний идентификатор генерируется при сохранении сегмента:

![image](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-06-25%20%D0%B2%2015.20.45.png)

Для удаления лишнего сегмента кликаем на красный крестик в правом верхнем углу.

4. Чтобы сегментация появилась в фильтрах и её можно было использовать в механиках, нужно её активировать.  
   Для этого нажимаем «Запустить в работу »:

![image](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-06-25%20%D0%B2%2015.22.01.png)

Статус сегментации меняется:

![image](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-06-25%20%D0%B2%2015.22.59.png)

В активной сегментации можно редактировать только названия имеющихся сегментов и добавлять новые; удалять их уже нельзя.  
***Готово!***
