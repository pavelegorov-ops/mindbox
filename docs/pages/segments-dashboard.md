# Отчет по сегментам

Отчет по сегментам помогает анализировать метрики в разрезе клиентских сегментов и каналов коммуникации.

С помощью отчета можно:

- Сравнивать эффективность разных клиентских сегментов
- Отслеживать рост или падение метрик во времени
- Анализировать вклад рассылок и каналов в выручку
- Находить точки роста и сегменты с наибольшим потенциалом

Отчет находится в разделе Аналитика:

![segments-dashboard-path.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/segments-dashboard-path.png)

## Когда обновляются данные

- Данные за последние 3 месяца обновляются ежедневно
- Данные за последние 2 года - еженедельно в воскресенье. Пересчитанные данные доступны с понедельника
- При добавлении нового сегмента в отчет, изменения окна атрибуции или же настройки нового целевого действия — данные за 2 года пересчитываются на следующий день.

## Режимы работы отчета

Отчет работает в двух режимах:

|  |  |  |
| --- | --- | --- |
| **Режим** | **Назначение** | Когда использовать |
| **Сравнение** | Сравнение сегментов по списку метрик с прошлым годом и анализ по каналам коммуникаций | - Определить, какие сегменты растут, а какие падают - Выделить [точки роста](https://help.mindbox.ru/docs/report-business-metrics#shag-5-analiziruem-segment-novichkov) - Оценить вклад каналов коммуникации |
| **Динамика** | Тренды изменения сегментов по месяцам в рамках одной выбранной метрики | Определить сезонность или влияние долгосрочных изменений |

### Режим «Сравнение»

Позволяет сравнивать метрики по сегментам относительно прошлого года, а также определять их эффективность в разрезе каналов коммуникации.

Чтобы увидеть детализацию по каналам (Email, Mobile Push, SMS, Viber, Web Push и др.), кликните по строке сегмента. Список каналов зависит от настроек проекта.

![segments-dashboard-comparison.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/segments-dashboard-comparison.png)

### Режим «Динамика»

Показывает, как сегменты менялись в рамках выбранной метрики **по месяцам**.

![segments-dashboard-dynamic.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/segments-dashboard-dynamic.png)

## Настройка отчета

В верхней части отчета доступны базовые настройки:

- **Период** — диапазон месяцев для анализа
- **Бренд** — доступно для проектов с [мультибрендом](multibrand.md)
- **Целевое действие** — по умолчанию «Заказы». Подробнее про целевые действия, их создание и настройку в [документации](goals.md).

![segments-dashboard-general-settings.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/segments-dashboard-general-settings.png)

## Метрики

1. Нажмите кнопку «Метрики»:

   ![segments-dashboard-metrics.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/segments-dashboard-metrics.png)
2. Выберите метрики из списка:

   - В режиме «Сравнение» — можно выбрать несколько метрик
   - В режиме «Динамика» — одну метрику

   ![segments-dashboard-metrics-choose.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/segments-dashboard-metrics-choose.png)
3. При необходимости добавьте дополнительные метрики с фильтрами по кнопке «Добавить метрику». Например, выручка только из попапов:

   ![segments-dashboard-metrics-add.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/segments-dashboard-metrics-add.png)

## Сегменты

В отчете доступны данные по [сегментам жизненного цикла](https://help.mindbox.ru/docs/customer-lifecycle). Дополнительно в отчет можно добавить любые сегменты по клиентам – [пересчитываемые](https://help.mindbox.ru/docs/segment-client-filter-recalculate), [статические](https://help.mindbox.ru/docs/segment-client-static) и [RFM-сегменты](https://help.mindbox.ru/docs/%D0%BA%D0%B0%D0%BA-%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%B0%D0%B5%D1%82-rfm-%D1%81%D0%B5%D0%B3%D0%BC%D0%B5%D0%BD%D1%82%D0%B8%D1%80%D0%BE%D0%B2%D0%B0%D0%BD%D0%B8%D0%B5).

1. Нажмите на знак `+` рядом с блоком «Сегменты».
2. Выберите до **30 сегментов**.
3. Сохраните выбор.

Сегменты появятся в таблице отчета после следующего пересчета.

![segments-dashboard-segments.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/segments-dashboard-segments.png)

[**Как считаются метрики по добавленным сегментам**](segments-dashboard.md#segments-recalculation)

- В отчет попадают только те события, которые произошли в период, когда клиент находился в выбранном сегменте.
- Момент попадания в сегмент для расчета метрик сдвигается **на 00:00 предыдущего календарного дня**.

Такой подход позволяет сохранить логику анализа в отчете при учете задержки попадания в сегменты (например, из-за пересчета сегмента по расписанию или ожидания импорта в статический сегмент).

**Пример 1. Первый заказ клиента.**

Клиент сделал первый заказ 03.12 в 16:00, а в сегмент «Клиенты с заказами» попал только во время следующего пересчета 04.12 в 08:00. Отчет учитывает его данные в рамках сегмента «Клиенты с заказами», начиная с 03.12 00:00.

**Пример 2. [Реактивация клиентов по заказам](workflow-reactivate.md).**

На проекте вручную созданы и добавлены в отчет два пересчитываемых сегмента: «Отток» и «Активные клиенты».

**Как происходит реактивация клиента:**

- 09.12 00:00 — клиент находится в пересчитываемом сегменте «Отток».
- 10.12 12:00 — клиенту была отправлена реактивационная рассылка.
- 15.12 10:00 — клиент переходит на сайт через письмо и оформляет заказ.
- 16.12 03:00 — происходит пересчет сегментов: клиент выходит из «Оттока» и переходит в пересчитываемый сегмент «Активные клиенты».

**Как это отобразится в отчетах:**

- **«Влияние сегментов»**: в итоге пересчета метрик попадание клиента в сегмент «Активные клиенты» сдвинется на 15.12 00:00, поэтому выручка от заказа попадет в сегмент «Активные клиенты».
- «[**Эффективные кампании**](report-business-metrics.md#6-effektivnye-kampanii)»: сдвиг при пересчете сегментов также применится. В данном случае метрики рассчитываются **от даты отправки рассылки**. Поэтому выручка от заказа клиента [атрибутируется](attribution.md) к тому сегменту, в котором клиент был на момент 09.12 в 00:00 — к сегменту «Отток».

При оценке эффективности реактивации учитывайте особенности пересчета сегментов в разных отчетах и ориентируйтесь на отчет по рассылкам.

[**Описание колонок выгрузки**](segments-dashboard.md#export-comparison)

- `PeriodStart` - начало выбранного периода сравнения;
- `PeriodEnd` - конец выбранного периода сравнения;

- `SegmentName` - название сегмента;
- `Channel` - канал рассылок;
- `MailingType` - тип рассылки (автоматическая, транзакционная, массовая);
- `FormType` - тип формы (попап, встроенный блок, виджет рекомендаций);
- `TotalRevenue` - метрика «Выручка»;
- `Orders` - метрика «Заказы»;
- `AverageOrderValue` - метрика «Средний чек»;
- `AverageOrdersPerCustomerPerMonth` - метрика «Заказов на покупателя в месяц»;
