# Вывод заказа (новый конструктор)

[Новый конструктор](email-editor.md) email-рассылок позволяет настроить динамический вывод позиций заказа без использования кода и [параметров](%D0%BF%D0%B0%D1%80%D0%B0%D0%BC%D0%B5%D1%82%D1%80%D1%8B-%D0%B4%D0%BB%D1%8F-%D1%80%D0%B0%D1%81%D1%81%D1%8B%D0%BB%D0%BA%D0%B8-%D0%B7%D0%B0%D0%BA%D0%B0%D0%B7-%D0%BE%D1%84%D0%BE%D1%80%D0%BC%D0%BB%D0%B5%D0%BD.md).

Чтобы вывести заказ:

1. Выберите блок по продуктам с динамическим заполнением:

![Снимок экрана 2024-07-13 в 15.17.04.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202024-07-13%20%D0%B2%2015.17.04.png)  
2. В настройках блока:

- **Заполнение контента** — «Динамическое»
- **Какие продукты отображать** — «Заказ»
- Правила вывода продуктов
- **Количество строк**, либо выводить строки со всеми позициями.

  ![Снимок экрана 2024-07-14 в 12.30.43.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202024-07-14%20%D0%B2%2012.30.43.png)

3. Настройте карточку позиции:

   ![Снимок экрана 2024-07-13 в 15.19.55.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202024-07-13%20%D0%B2%2015.19.55.png)
4. Данные по заказу введите по кнопке "Добавить переменную":

   - Идентификатор заказа:

   ![Снимок экрана 2024-07-13 в 15.20.41.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202024-07-13%20%D0%B2%2015.20.41.png)

   ![Снимок экрана 2024-10-08 в 18.20.52.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202024-10-08%20%D0%B2%2018.20.52%281%29.png)

   ![Снимок экрана 2024-10-08 в 18.22.16.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202024-10-08%20%D0%B2%2018.22.16.png)

   - Полная стоимость заказа:

   ![Снимок экрана 2024-07-13 в 15.24.41.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202024-07-13%20%D0%B2%2015.24.41.png)

   ![Снимок экрана 2024-10-08 в 18.34.47.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202024-10-08%20%D0%B2%2018.34.47.png)

   ![Снимок экрана 2024-10-08 в 18.36.39.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202024-10-08%20%D0%B2%2018.36.39.png)

   ![Снимок экрана 2024-10-08 в 18.38.00.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202024-10-08%20%D0%B2%2018.38.00.png)
5. Сохраните изменения в шаблоне.
