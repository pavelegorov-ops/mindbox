# Необходимые интеграции для подключения виджета рекомендаций на сайт

Необходимые интеграции с Mindbox, чтобы использовать виджет рекомендаций на сайте:

1. [Трекер](https://developers.mindbox.ru/docs/javascript-1) Mindbox стоит на каждой странице сайта, где предполагается устанавливать виджет рекомендаций;
2. В Mindbox регулярно загружается актуальная  [информация о продуктах](products-import):
   - наличие
   - цена
   - категория
   - внешний id продукта совпадает с id на сайте
   - ссылка на продукт
   - ссылка на картинку
   - дополнительные поля, описывающие продукт (цвет, характеристики, производитель, пол, возраст и т.д.);
3. В случае, если необходимо отображать разные цены и разную доступность для разных регионов, необходима интеграция региональных [фидов](yml-import) и [передача признаков “зоны” для клиента](regional-yml-import)
4. Передаются просмотры продуктов, добавления в корзину/избранное и т.д., заказы с сайта в реальном времени [настройка операций](операции-v-настройка-шагов)
5. Установлены коды [персонализации сайта](https://developers.mindbox.ru/page/%D1%80%D0%B5%D0%BA%D0%BE%D0%BC%D0%B5%D0%BD%D0%B4%D0%B0%D1%86%D0%B8%D0%B8-%D0%BD%D0%B0-%D1%81%D0%B0%D0%B9%D1%82)
6. Установлены коды [div-блоков виджетов](https://developers.mindbox.ru/page/%D1%80%D0%B5%D0%BA%D0%BE%D0%BC%D0%B5%D0%BD%D0%B4%D0%B0%D1%86%D0%B8%D0%B8-%D0%BD%D0%B0-%D1%81%D0%B0%D0%B9%D1%82)
