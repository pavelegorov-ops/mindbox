# Найти клиентов, у которых нет заказов

Для поиска клиентов без [заказов](what-is-an-order.md) переходим на вкладку **Данные** -> **Клиенты**:

![Снимок экрана 2021-03-30в 20.26.00.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-03-30%20%D0%B2%2020.26.00.png)

Принцип построения такой же, как для [наличия заказа](filter-order-users.md).  
Отличие: вместо «заказ — есть такие» выбираем «заказ — нет таких»:

![Снимок экрана 2021-04-07в 19.37.16.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-04-07%20%D0%B2%2019.37.16%281%29.png)

Если нужны клиенты без заказов в **любом** [статусе](filter-orders-status.md), эту часть фильтра можно опустить:

![Снимок экрана 2021-04-07в 19.37.30.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-04-07%20%D0%B2%2019.37.30.png)
