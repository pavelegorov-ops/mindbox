# Как добавить In-App «Авторизуйтесь и получите промокод на заказ»

**Цель механики** — увеличить количество авторизованных пользователей. Если клиент авторизован, то мы можем узнать о нем больше. Это позволит отправлять таким клиентам персонализированные коммуникации, что увеличит шанс на покупку.

## Как это работает

1. Пользователь заходит в приложение и видит In-App с предложением войти в существующий аккаунт или зарегистрироваться в приложении.
2. Пользователь авторизуется либо регистрируется.
3. После авторизации пользователю показывается второй In-App с промокодом.

## Шаги настройки

Некоторые настройки на этой странице требуют обновления SDK приложения до версии 2.14.0. Для обновления SDK версии обратитесь к вашим разработчикам.

### 1. Создайте сегмент неавторизованных клиентов

Создайте [пересчитываемый сегмент клиентов](segment-client-filter-realtime.md) для тех, кто не авторизован в приложении. Фильтр необходимо построить в зависимости от способа авторизации в вашем приложении.

Например, если клиенты авторизаются в приложении либо по телефону, либо по почте, то у неавторизованных клиентов не будет этих данных:  
![in-app-log-in-segment.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/in-app-log-in-segment.png)

### 2. Настройка In-App с просьбой авторизоваться

Создайте In-App по [инструкции](in-apps.md).

#### Внешний вид формы

Выберите и отредактируйте один из предлагаемых [шаблонов Figma](https://www.figma.com/file/QoJ0yKREcTsP3CPNUUZ8LG/%D0%93%D0%B0%D0%BB%D0%B5%D1%80%D0%B5%D1%8F-%D1%88%D0%B0%D0%B1%D0%BB%D0%BE%D0%BD%D0%BE%D0%B2-In-App?type=design&node-id=0%3A1&mode=design&t=COtICWsqaoJBMAJO-1) либо используйте свой дизайн.

С техническими рекомендациями к размеру и формату картинки для In-app можно ознакомиться [здесь](in-apps.md#shablon-modalnoe-okno).

Чтобы клиент мог сразу перейти в окно авторизации, добавьте ссылку перехода. Рекомендуемый формат диплинка: `https://link`.

![in-app-log-in-form.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/in-app-log-in-form.png)

#### Общие настройки

- Выберите приложения, в которых будет отображаться форма, и даты показа.
- Укажите частоту всплывания. Например, **«Не чаще одного раза в указанный период»** один раз в 5 или 7 дней.
- Если эта механика должна быть с более высоким приоритетом, чем другие формы, и игнорировать лимиты показов, включите настройку **«Приоритетный In-App»**.

![in-app-log-in-general.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/in-app-log-in-general.png)

#### Условия всплывания

Так как по умолчанию In-App отображается сразу после входа в приложение, укажите в настройке всплывания **«Спустя время после попадания в таргетинг»**, например, через 5 секунд. Так форма не будет всплывать в ту же секунду после входа в приложения.

![in-app-log-in-frequency.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/in-app-log-in-frequency.png)

#### Таргетинг

- Добавьте ранее созданный сегмент неавторизованных пользователей.
- При первом входе в приложение клиент получает несколько системных окон для настройки приложения и онбординга. Чтобы не перегружать клиента уведомлениями, добавьте условие **«Количество входов в приложение больше или равно 2»**. Так In-App покажется только после второго входа в приложение.

![in-app-log-in-targeting.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/in-app-log-in-targeting.png)

Первый In-App готов

In-App покажется неавторизованным пользователям спустя 5 секунд после входа в приложение и не чаще, чем 1 раз в 5 дней, даже если пользователь уже достиг лимитов по In-App, которые выставлены на проекте.

### 3. Создайте операцию авторизации

Для показа второго In-App с промокодом тем, кто авторизовался в приложении, необходимо настроить таргет In-App на вызов операции авторизации. Так мы узнаем, что клиент авторизовался.

Если такой операции ещё нет:

- Cоздайте новый [шаблон действия](template-create.md):

![in-app-log-in-action.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/in-app-log-in-action.png)

- Настройте операцию авторизации пользователя [по инструкции](https://help.mindbox.ru/docs/in-app-location):

![in-app-log-in-operation.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/in-app-log-in-operation.png)

Разработчики должны настроить вызов операции в приложении и выпустить новый релиз приложения.

### 4. Настройте промоакцию

Если акция должна обрабатываться и выдавать скидку по промокоду на стороне Mindbox, [создайте новый пул](%D0%BA%D0%B0%D0%BA-%D0%B4%D0%BE%D0%B1%D0%B0%D0%B2%D0%B8%D1%82%D1%8C-%D0%BF%D1%80%D0%BE%D0%BC%D0%BE%D0%BA%D0%BE%D0%B4%D1%8B-%D0%B2-%D0%BF%D1%80%D0%BE%D0%B5%D0%BA%D1%82.md) с многоразовым промокодом и [настройте промоакцию](how-to-create-a-discount-promo.md).

### 5. Создайте In-App с промокодом

Создайте In-App по [инструкции](in-apps.md).

#### Внешний вид формы

- Выберите и отредактируйте один из предлагаемых [шаблонов Figma](https://www.figma.com/file/QoJ0yKREcTsP3CPNUUZ8LG/%D0%93%D0%B0%D0%BB%D0%B5%D1%80%D0%B5%D1%8F-%D1%88%D0%B0%D0%B1%D0%BB%D0%BE%D0%BD%D0%BE%D0%B2-In-App?type=design&node-id=0%3A1&mode=design&t=COtICWsqaoJBMAJO-1) либо используйте свой дизайн.
- В поле Payload укажите промокод. При клике на In-App промокод будет автоматически копироваться. В примере на скриншоте — `NEW10`

![in-app-log-in-promo.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/in-app-log-in-promo.png)

#### Общие настройки

- Выберите приложения, в которых будет отображаться форма, и даты показа.
- Чтобы пользователь увидел In-App только один раз при первой авторизации, укажите частоту всплывания **«Всего один раз»**.
- Если эта механика должна быть с более высоким приоритетом, чем другие формы, и игнорировать лимиты показов, включите настройку **«Приоритетный In-App»**.

![in-app-log-in-promo-general.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/in-app-log-in-promo-general.png)

#### Условия всплывания

- Выберите **«Сразу после попадания пользователя в таргетинг»**, чтобы пользователь получил подарок сразу после авторизации.

![in-app-log-in-promo-frequency.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/in-app-log-in-promo-frequency.png)

#### Таргетинг

- Укажите таргетинг по операции авторизации пользователя.
- Задайте условие **«Количество входов в приложение»** больше или равно 2, чтобы не показывать In-App с промокодом тем, кто только что установил приложение и авторизовался.

![in-app-log-in-promo-targeting.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/in-app-log-in-promo-targeting.png)

Второй In-App готов

Он покажется только один раз только что авторизовавшимся пользователям (если это не их первый вход в приложение), даже если пользователь уже достиг лимитов по In-App, которые выставлены на проекте.

### 6. Протестируйте формы

Чтобы понять, правильно ли отображается In-App, добавьте сегмент с тестовым клиентом в таргетинг In-App. Подробнее в [статье](in-apps.md#kak-protestirovat-in-app).

### 7. Запустите формы

Когда обе формы готовы и протестированы, запустите их:

![in-app-log-in-start.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/in-app-log-in-start.png)

Отслеживайте метрики по запущенному In-App с помощью [отчета по In-App](report-in-apps.md).

Чтобы понять, сколько пользователей увидели первый In-App, авторизовались в приложении и увидели In-App с промокодом, постройте фильтр:
