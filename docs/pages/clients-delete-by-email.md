# Как массово удалить клиентов по списку email

Иногда мы не можем [удалить клиента по фильтру](clients-delete). Например, когда у нас есть список email-адресов клиентов и мы не хотим строить фильтр для каждого.  
[Удалить по списку Mindbox ID](clients-delete-by-id) просто. По списку email ненамного сложнее.

Чтобы удалить клиентов по списку email, нужно:

1. Создать [действие-пометку](template-delete-client).
2. Выдать действие по файлу по [инструкции](как-массово-импортировать-действия-по-файлу).
3. Отфильтровать по выданному действию.
4. Удалить найденных клиентов [по инструкции](clients-delete).

---

По шагам:

1. Проверяем наличие на проекте действия-пометки для удаления.

   Если действия еще нет, создаем его по [инструкции](действие-пометка-при-удалении-клиента-из-базы).
2. Выдаем клиентам действие.  
   Подготавливаем файл со списком Email: название единственной колонки — Email, формат — .csv

   Импортируем по [инструкции](как-массово-импортировать-действия-по-файлу) операцией «Импорт действий клиентов с идентификацией по Email».
3. Строим фильтр вида:

![Снимок экрана 2022-06-08 в 21.12.26.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-06-08%20%D0%B2%2021.12.26.png)  
В нашем случае шаблон действия из п.1 называется «Пометка для удаления».

4. Удаляем всех найденных клиентов [по инструкции](clients-delete).
