# Как создать автоматическую SMS-рассылку

Автоматические рассылки — это кампании, которые отправляется клиенту из сценария или операции с наступлением определенного события.

В механиках можно использовать только автоматические рассылки в статусе «Готова к использованию», которые находятся в той же папке, что и создаваемая кампания, или в её дочерней папке.

## Добавление рассылки

Чтобы создать автоматическую SMS-рассылку:

1. Перейдите в раздел **Кампании**

![список.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D1%81%D0%BF%D0%B8%D1%81%D0%BE%D0%BA%281%29.png)

2. Нажмите «Создать кампанию» → «Автоматизация» → «Автоматическая рассылка»:

![trigger-email-create1.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/trigger-email-create1.png)

3. Выберите канал «SMS», [папку](folders.md) и нажмите «Создать»:

![Снимок экрана 2023-01-23 в 00.08.35.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-01-23%20%D0%B2%2000.08.35%281%29.png)

### Имя рассылки

![trigger-sms-name.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/trigger-sms-name.png)

Название нужно для поиска рассылки среди кампаний и в фильтрах на проекте.

### SMS-сообщение

![trigger-sms-message.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/trigger-sms-message.png)

- **Отправитель** — имя [отправителя](%D0%BA%D0%B0%D0%BA-%D0%BF%D0%BE%D0%B4%D0%BA%D0%BB%D1%8E%D1%87%D0%B8%D1%82%D1%8C-sms-%D1%80%D0%B0%D1%81%D1%81%D1%8B%D0%BB%D0%BA%D0%B8.md), от которого будет послана SMS.
- **Сообщение** — текст SMS. Можно использовать [параметры шаблонизатора](%D1%87%D1%82%D0%BE-%D1%82%D0%B0%D0%BA%D0%BE%D0%B5-%D1%88%D0%B0%D0%B1%D0%BB%D0%BE%D0%BD%D0%B8%D0%B7%D0%B0%D1%82%D0%BE%D1%80.md) и эмоджи.

- В одном SMS на русском языке — 70 символов, в двойном — 134;
- Если в сообщении есть хотя бы один кириллический символ, то все сообщение считается кириллическим;
- Пробелы и знаки препинания считаются за отдельные символы.

![image](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/b_56d456b75cf55.jpeg)

#### Тестовая отправка

После заполнения раздела «SMS-сообщение» можно посмотреть пример сформированной рассылки для пользователя.

**Исключение:** рассылки [с событийными параметрами](%D0%BA%D0%B0%D0%BA%D0%B8%D0%B5-%D0%B1%D1%8B%D0%B2%D0%B0%D1%8E%D1%82-%D0%BF%D0%B0%D1%80%D0%B0%D0%BC%D0%B5%D1%82%D1%80%D1%8B-%D0%BF%D0%BE-%D0%B4%D0%BE%D1%81%D1%82%D1%83%D0%BF%D0%BD%D0%BE%D1%81%D1%82%D0%B8.md#sobytijnye-parametry). Проверить их можно с помощью [тестового режима рассылки](mailings-test-mode.md).

При тестовой отправке выбранный клиент **получает сообщение на мобильный телефон**.

Поэтому отправлять тесты можно **только на контакты, имеющиеся на проекте**. Для создания карточки клиента воспользуйтесь [инструкцией](client-add.md).

Кликните по кнопке «Тестовая отправка», отметьте пользователей из списка или добавьте новых и нажмите «Отправить выбранным»:

![trigger-sms-test.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/trigger-sms-test.png)

Тестовые отправки никак не фиксируются в карточке клиента. Их статусы можно посмотреть списком по ссылке.

Сформированное сообщение можно посмотреть **без отправки клиенту на телефон** — для этого кликните по «Предпросмотру».

### Общие настройки

![trigger-sms-general.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/trigger-sms-general.png)

- **Бренд** — актуально для [мультибрендовых](multibrand.md) проектов;
- **Тематика** — разделение на [тематики](%D0%BA%D0%B0%D0%BA-%D1%81%D0%BE%D0%B7%D0%B4%D0%B0%D1%82%D1%8C-%D1%82%D0%B5%D0%BC%D0%B0%D1%82%D0%B8%D0%BA%D1%83-%D1%80%D0%B0%D1%81%D1%81%D1%8B%D0%BB%D0%BA%D0%B8.md) позволяет пользователям настроить гибкую подписку, чтобы получать коммуникации только по интересующим темам;
- **Теги** — с помощью [тегов действий](tag.md) можно объединять рассылки по дополнительному признаку, если не хватает разделения по каналам, тематикам и папкам. Это позволит группировать рассылки в фильтрах и отчетах;
- **Профиль** — тип рассылки и ограничения по получателям, которые должны применяться или игнорироваться в зависимости от него:
  - Стандартная — для маркетинговых кампаний. Применяются базовые проверки по получателям:
    - есть валидный мобильный номер;
    - есть подписка на SMS (или тематику в SMS, если она указана в рассылке);
    - не входит в [глобальную контрольную группу](%D1%87%D1%82%D0%BE-%D1%82%D0%B0%D0%BA%D0%BE%D0%B5-%D0%B3%D0%BB%D0%BE%D0%B1%D0%B0%D0%BB%D1%8C%D0%BD%D0%B0%D1%8F-%D0%BA%D0%BE%D0%BD%D1%82%D1%80%D0%BE%D0%BB%D1%8C%D0%BD%D0%B0%D1%8F-%D0%B3%D1%80%D1%83%D0%BF%D0%BF%D0%B0.md) (если включена функция) — не путать [с контрольной группой рассылки](%D0%BA%D0%B0%D0%BA-%D1%81%D0%BE%D0%B7%D0%B4%D0%B0%D1%82%D1%8C-sms-%D1%80%D0%B0%D1%81%D1%81%D1%8B%D0%BB%D0%BA%D1%83.md#ab-test-i-kontrolnaya-gruppa-rassylki);
    - не превышен лимит по [коммуникациям за день](frequency-policy.md) (если включена функция).  
        
      Эти проверки можно отключить в рамках рассылки, используя соответствующие переключатели в профиле.
  - Opt-in — для [подтверждения подписки](doi-turn-on.md). Применяются проверки:
    - есть валидный мобильный номер;
    - подписка SMS (или тематику в SMS, если она указана в рассылке) в статусе «Ожидает подтверждения»;
    - не превышен лимит по коммуникациям за день (если включена функция).  
        
      Можно отключить проверку по частоте коммуникаций.
  - Транзакционная — рассылка, которую клиент сам запрашивает и ожидает получить как можно быстрее. Проверки не применяются.

### Ограничения отправки

![trigger-sms-time.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/trigger-sms-time.png)

- **Часы отправки** — можно ограничить по [часовому поясу клиента](client-timezone.md) или [проекта](project-settings.md);
- **Актуальность** — время, в течение которого имеет смысл отправлять рассылку. Можно ограничить по времени отправки сообщения или задать дату вручную.

### Аналитика

![mass-sms-shorten.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/mass-sms-shorten.png)

**Отслеживание кликов** позволяет [сократить ссылку](shorten-url-sms.md) и собирать статистику по переходам.

В результате ссылка в сообщении принимает вид `yourdomain.com/s?s={15-ти символьный код}`

Для использования требуется доработка на целевом сайте.

Можно настроить [атрибуцию](attribution.md) в SMS-канале по доставкам.  
В таком случае получение кликов будет не обязательно для сбора конверсий.

### UTM-метки

![mass-sms-utm.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/mass-sms-utm.png)

Метки позволяют определить [источник перехода](%D0%BA%D0%B0%D0%BA-%D0%BE%D0%BF%D1%80%D0%B5%D0%B4%D0%B5%D0%BB%D1%8F%D0%B5%D1%82%D1%81%D1%8F-%D0%B8%D1%81%D1%82%D0%BE%D1%87%D0%BD%D0%B8%D0%BA-%D0%BF%D0%B5%D1%80%D0%B5%D1%85%D0%BE%D0%B4%D0%B0-%D0%BD%D0%B0-%D1%81%D0%B0%D0%B8%D1%82.md) на сайт и тем самым атрибутировать трафик к конкретной кампании и каналу.

Можно создать стандартные метки и переиспользовать их в SMS-рассылках или ввести пользовательские метки для конкретной рассылки.

## После заполнения настроек

### Готовность к отправке

В разделе автоматически проверяется наличие всех обязательных полей. Кликом по пункту можно перейти к нужному разделу.

Если всё заполнено, рассылка переходит из статуса «Черновик» в «Готова к отправке»:

![trigger-sms-ready.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/trigger-sms-ready.png)

Чтобы рассылку можно было выбирать в сценариях и операциях, нужно перевести ее в статус «Готова к использованию». Для этого кликните по кнопке «Закончить редактирование».

После завершения редактирования нельзя будет менять бренд, профиль (кроме приоритета) и настройки АБ-тестирования рассылки.

Рассылка готова:

![trigger-sms-is-ready.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/trigger-sms-is-ready.png)

## АБ-тест и контрольная группа рассылки

- **АБ-тесты** позволяют сравнивать разные варианты рассылок по влиянию на открытия, клики, выручку.
- **Контрольная группа (КГ)** определяет эффективность кампании, сравнивая поведение пользователей, получивших письмо, и клиентов без рассылки.  
  ![trigger-sms-ab-test.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/trigger-sms-ab-test.png)

В SMS доступны критерии оценки:

- **Показатель кликов** — процент клиентов, сделавших хотя бы один клик в рассылке за время тестирования (только без сравнения с контрольной группой);
- **Целевое действие** — личное действие, совершенное клиентом за время тестирования.

![trigger-sms-ab-test-settings.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/trigger-sms-ab-test-settings.png)
