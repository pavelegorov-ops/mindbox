# Как начать строить фильтры

**Фильтры** — основа комфортной работы в Mindbox. Правильный фильтр помогает настроить отправку рассылок нужному сегменту клиентов, настроить промоакцию, найти данные для аналитики и решить многие другие задачи.

---

Для примера построим фильтр по клиентам.

Зайдем в раздел **Клиенты**.  
Поле для построения фильтра содержит варианты **Добавить фильтр** и **Добавить группы ИЛИ**, в правой части — общий размер базы.

![Снимок экрана 2021-03-29в 18.04.48.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-03-29%20%D0%B2%2018.04.48.png)

## Добавить фильтр

Щелкнем по полю **Добавить фильтр**. В выпадающем меню увидим список признаков клиента, по которым можно строить фильтр. Сверху — стандартные личные данные, дальше — группы свойств:

![Снимок экрана 2021-03-29в 18.05.46.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-03-29%20%D0%B2%2018.05.46.png)

Кликнув на название группы, раскрываем дополнительные признаки:

![Снимок экрана 2021-03-29в 18.18.52.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-03-29%20%D0%B2%2018.18.52.png)

Выбрав условие, заполняем дополнительные настройки, если они есть.

Например, в фильтре по подписке можно выбрать бренд, канал и тематику подписки:

![Снимок экрана 2021-03-29в 21.48.47.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-03-29%20%D0%B2%2021.48.47.png)

Когда условие готово, нажимаем **Добавить фильтр**:

![Снимок экрана 2021-03-29в 19.36.55.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-03-29%20%D0%B2%2019.36.55.png)

Применяем фильтр и получаем нужных клиентов и их количество:

![Снимок экрана 2021-03-29в 19.37.51.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-03-29%20%D0%B2%2019.37.51.png)

## Добавить группу ИЛИ

Выбираем эту функцию, когда выполняем задачу «должно выполниться хотя бы одно условие».

Например, хотим отобрать клиентов, у которых есть валидный email или мобильный телефон.

Ход действий следующий:

1. Нажимаем «Добавить группу ИЛИ».
2. В группе выбираем «Добавить фильтр» -> «email заполнен и валидный» — > «Добавить фильтр».
3. Ниже в той же группе выбираем «Добавить фильтр» -> «мобильный телефон заполнен и валидный» -> «Добавить фильтр».
4. Нажимаем «Применить фильтр»:

![Запись_экрана_2021-03-29_в_19.06.45.gif](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%97%D0%B0%D0%BF%D0%B8%D1%81%D1%8C_%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0_2021-03-29_%D0%B2_19.06.45.gif)

Подробнее об условии ИЛИ — в [статье](filters-or.md).

## Добавляем вложенное условие

У поля могут быть дополнительные условия.  
Основное и уточняющее условия соединены синей линией.

Например, хотим найти клиентов не просто с заказом, а с заказом стоимостью от 2000 и оплаченными покупками:

![Снимок экрана 2021-03-30в 01.00.32.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-03-30%20%D0%B2%2001.00.32%281%29.png)

Чтобы ввести дополнительные условия, кликаем на знак «плюс» около нужного фильтра.  
Чтобы добавить новое вложенное условие, кликаем по линии «соседних» условий.

Например, хотим добавить уточнение по позиции, помимо статуса. Это можно сделать одним из двух способов:

![Снимок экрана 2021-03-30в 01.10.22.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-03-30%20%D0%B2%2001.10.22.png)

## Поиск

Можно искать поле по названию:

![Снимок экрана 2021-03-29в 18.22.30.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-03-29%20%D0%B2%2018.22.30.png)

### Сквозной поиск

Позволяет искать поле среди вложенных условий.

Например, хотим выбрать поле «Шаблон действия». Оно вложено в поле «Действие клиента».

Можно сначала выбрать поле «Действие клиента» и внутри него найти «Шаблон действия»:

![Снимок экрана 2021-03-29в 18.27.44.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-03-29%20%D0%B2%2018.27.44.png)

С использованием сквозного поиска, то же можно сделать в один шаг: в фильтре начать вводить название нужного поля и сразу выбрать его:

![Снимок экрана 2021-03-29в 18.28.00.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-03-29%20%D0%B2%2018.28.00.png)

Сквозной поиск доступен для полей, вложенных до второго уровня

Например, странице клиентов сквозным поиском можно добраться до шаблона действия, но не до категории или кампании шаблона.
