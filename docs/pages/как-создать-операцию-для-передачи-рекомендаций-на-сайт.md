# Как создать операцию для передачи рекомендаций

Для создания операции необходимо выполнить следующие шаги:  
**1.** Заходим в кампанию, где будут лежать операции по рекомендациям, и нажимаем на **Добавить - Операцию**:

**2.** На странице редактирования операции вводим необходимые параметры:

![Снимок экрана 2021-02-16 в 15.06.30.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-02-16%20%D0%B2%2015.06.30%283%29.png)

- *имя* - название операции;
- *системное имя* - системное имя; либо оставляем сгенерированное, либо меняем на то, которое нужно;
- *для сервиса* - Операция V3;
- *для точек интеграции* - выбираем нужную [точку интеграции](%D0%BA%D0%B0%D0%BA-%D1%81%D0%BE%D0%B7%D0%B4%D0%B0%D1%82%D1%8C-%D0%B8-%D0%BD%D0%B0%D1%81%D1%82%D1%80%D0%BE%D0%B8%D1%82%D1%8C-%D1%82%D0%BE%D1%87%D0%BA%D1%83-%D0%B8%D0%BD%D1%82%D0%B5%D0%B3%D1%80%D0%B0%D1%86%D0%B8%D0%B8.md);
- ставим чек-бокс рядом с ***Операция требует передачи deviceUUID**.*

**3.** Переходим к настройке шагов, где определяем клиента, которому будут показаны рекомендации, и тип рекомендаций:

![Снимок экрана 2021-02-18 в 15.14.10.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-02-18%20%D0%B2%2015.14.10.png)

Шаг первый:  
**Клиент** - **Неавторизованный** - Получить существующего ищем по **Устройству**.

Шаг второй:  
**Рекомендации** - Получить персональные рекомендации по алгоритму - Персональные рекомендации.

**Получать дополнительные поля** - отмечаем, если выводим дополнительные поля рекомендуемых товаров.

#### Для реализации другого алгоритма необходимо выбрать другой тип рекомендаций, а именно:

![Снимок экрана 2021-02-18 в 15.16.14.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-02-18%20%D0%B2%2015.16.14.png)

**Получить персональные рекомендации** выдаёт алгоритмы - Персональные рекомендации, Событийные персональные рекомендации, Похожие продукты к списку продуктов, Похожие продукты на просмотренные в последней сессии, Сопутствующие продукты к списку продуктов, Сопутствующие продукты к последнему заказу, Популярные продукты, Популярные продукты в просмотренных категориях в последней сессии, Ручное соответствие категорий к последнему заказу, Последние просмотренные продукты.

**Получить популярные по категориям** - Популярные продукты по категориям.

**Получить рекомендации к продуктам** - Ручное соответствие категорий, Похожие продукты, Сопутствующие продукты.

Система сама выдаст те алгоритмы, которые доступны для данных рекомендаций

4. После того, как заполнили все поля, нажимаем **Добавить:**

![Снимок экрана 2021-02-16 в 15.21.59.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-02-16%20%D0%B2%2015.21.59%281%29.png)

**Готово!**
