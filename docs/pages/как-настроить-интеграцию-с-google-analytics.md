# Как настроить интеграцию форм с Google Аналитика 4

Важно

При сборе данных через Google Analytics происходит трансграничная передача персональных данных.  
В таких случаях перед использованием иностранных сервисов нужно предпринять обязательные шаги, в том числе уведомить Роскомнадзор о соответствующем намерении. При необходимости проконсультируйтесь с юристами или специалистами по защите данных.

## Для попапов и встроенных блоков

**Интеграция с Google Analytics позволяет отправлять события при:**

- показе формы;
- закрытии формы;
- заполнении формы или клику по главной кнопке формы.

Для одного события можно задать не более 25 специальных параметров. Каждое значение параметра может содержать не более 100 символов.

В значениях параметров можно передавать данные из [базовых полей](%D0%BA%D0%B0%D0%BA-%D0%BF%D0%B5%D1%80%D0%B5%D0%B4%D0%B0%D1%82%D1%8C-%D0%B4%D0%B0%D0%BD%D0%BD%D1%8B%D0%B5-%D0%B8%D0%B7-%D1%84%D0%BE%D1%80%D0%BC%D1%8B-%D0%BD%D0%B0-%D0%BF%D1%80%D0%BE%D0%B5%D0%BA%D1%82.md#bazovye-polya) или [дополнительных полей шаблона форм](%D0%BA%D0%B0%D0%BA-%D0%BF%D0%B5%D1%80%D0%B5%D0%B4%D0%B0%D1%82%D1%8C-%D0%B4%D0%B0%D0%BD%D0%BD%D1%8B%D0%B5-%D0%B8%D0%B7-%D1%84%D0%BE%D1%80%D0%BC%D1%8B-%D0%BD%D0%B0-%D0%BF%D1%80%D0%BE%D0%B5%D0%BA%D1%82.md#dopolnitelnye-polya-shablona).

Включите настройку в разделе **Действия после заполнения формы клиентом** и настройте передачу событий в Google Аналитика 4:

- **Ресурс Google Analytics для отправки событий**

Выберете "Передавать события в Google Аналитика 4".

![Снимок экрана 2024-03-07 в 12.55.58.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202024-03-07%20%D0%B2%2012.55.58.png)

- **Название события**

Название событий позволяют группировать схожие типы событий в аналитике. Одно и то же значение можно использовать для названия однотипных событий из всех форм, чтобы сгруппировать их.

Структура передаваемого события может отличаться

Вы можете настраивать события и набор дополнительных параметров согласно требованиям вашего бизнеса для отслеживания аналитики. В статье приведен лишь один из возможных примеров.

Структуру события и набор переменных необходимо определить и также создать с помощью менеджера тегов в Google Аналитике 4. За помощью вы можете обратиться к своему аналитику.

Затем полученную структуру событий можно передавать из поп-апов и встроенных блоков Mindbox.  
Ниже инструкции от Google, которые помогут настроить события в Google Аналитике 4.

[Как настроить события Google Аналитики 4 с помощью Менеджера тегов](https://support.google.com/tagmanager/answer/13034206)

Специальные параметры на уровне события позволяют включать в отчеты данные, полученные с помощью специальных параметров событий, которые передают подробные сведения о действиях пользователей вместе с событием. Вы можете добавить специальный параметр события для рекомендованного или специального события, чтобы идентифицировать, например, нажатые ссылки или взаимодействия с видео. Это позволит глубже анализировать данные.

[Как создать специальный параметр на уровне события](https://support.google.com/analytics/answer/14239696)

- **Событие на открытие формы**

Какое действие отправлять в момент показа формы на сайте

Название такого события, например, может быть со значением open.

Набор других параметров для события будет зависеть от требований бизнеса для аналитики.

- **Событие на успешное заполнение формы**

Какое действие отправлять в момент выполнения целевого действия.  
Если это форма подписки, то целевым действием является успешная отправка контактов.  
Если это форма-уведомление с кнопкой-ссылкой, то целевым действием будет клик по главной кнопке.  
Главной кнопкой считается та, у которой в верстке задан атрибут data-popmechanic-submit  
Если такой кнопки нет в форме, то событие отправляться не будет.

Название такого события, например, может быть со значением lead.

Набор других параметров для события будет зависеть от требований бизнеса для аналитики.

- **Событие на закрытие формы без действия**

Какое действие отправлять в момент закрытия формы, если не было выполнено целевое действие.

Название такого события, например, может быть со значением close.

Набор других параметров для события будет зависеть от требований бизнеса для аналитики.

- **ID потока данных (MeasurementID)**

![Снимок экрана 2024-03-07 в 12.56.45.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202024-03-07%20%D0%B2%2012.56.45.png)

Если скрипт Google Analytics установлен на сайт напрямую без использования каких-либо контейнеризаторов (Google Tag Manager — GTM, SegmentStream, OWOX или любые другие), то этот шаг можно пропустить и оставить поле пустым.  
Если же для загрузки скрипта используется контейнеризатор, то заполнить ID необходимо для корректной работы интеграции.  
Рекомендуем заполнять поле идентификатора в любом случае.

ID потока данных представляет собой конструкцию вида — G-123456789.

ID потока данных можно найти в личном кабинете GA4 или на сайте, если уже настроена интеграция через GTM, с помощью [инструкции](https://support.google.com/analytics/answer/12270356?hl=ru).

## Для виджетов рекомендаций

В разделе **Общие настройки** включите настройку и настройте передач данных в список событий Google Аналитика 4:

![Снимок экрана 2024-03-07 в 13.24.55.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202024-03-07%20%D0%B2%2013.24.55.png)

**Как узнать имя трекера и ID потока**

1. Перейдите на ваш сайт.
2. Нажмите правой кнопкой мыши → Просмотреть код
3. Зайдите на вкладку Console:

![Снимок экрана 2021-03-24 в 18.38.57.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-03-24%20%D0%B2%2018.38.57.png)

[Инструкция по открытию Консоли для всех браузеров.](browser-console.md)

4. Введите код, который дан ниже, в поле ввода, и нажмите Enter:

```
ga.getAll().map(pc => pc.model.data.ea[':name'])
```

5. Имя трекера будет указано в ответе:

![Снимок экрана 2021-03-24 в 18.42.09.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-03-24%20%D0%B2%2018.42.09.png)

ID потока данных можно найти в личном кабинете GA4 или на сайте, если уже настроена интеграция через GTM, с помощью [инструкции](https://support.google.com/analytics/answer/12270356?hl=ru).

**Название списка в GA**

Название списка нужно, если вы используете отчеты по монетизации и хотите группировать данные по названию списка в отчете по совершенным покупкам.

Название списка задается произвольно и нужно для того, чтобы идентифицировать события, которые приходят из каждого виджета.  
Например, если есть задача различать, из какого виджета пришел просмотр продукта, у виджетов должны быть разные названия списков. В таком случае в GA данные по ним будут храниться раздельно.  
Если конкретика по виджетам не важна, можно во всех виджетах передавать одно название “Mindbox” — действия из них всех будут собираться в один список “Mindbox” в GA.

Виджеты Mindbox передают просмотры и клики по продуктам.  
Чтобы в отчете отобразились данные по добавленным в корзину и купленным товарам, нужно у событий “добавление в корзину” и “покупка” на сайте [добавить](https://support.google.com/analytics/answer/12200568?hl=ru#zippy=) название списка, которое используется в настройках форм Mindbox.

В течение суток после настройки интеграции в Mindbox, в Google Analytics, в разделе «Монетизация — Совершенные покупки", появится список товаров и данные по нему — от количества просмотров за период времени до дохода от продуктов в списке.

## Как проверить корректность интеграции

1. Вызовите показ формы или заполните её на своем сайте по тестовой ссылке
2. Сразу зайдите в ваш Google Analytics, который установлен на сайте. Раздел **Отчет в реальном времени** → **События**
3. Если вы всё настроили корректно, то увидите события открытия и заполнения формы:

![Снимок экрана 2023-11-09 в 13.57.58.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-11-09%20%D0%B2%2013.57.58.png)

Также для отслеживания событий можно воспользоваться [режимом отладки](https://support.google.com/analytics/answer/7201382?sjid=2058631579948368666-EU#zippy=).

  
**При необходимости, вы можете настроить цель на данное событие.**

Это иногда используется для удобства отслеживания подписок.  
Следуйте [инструкции для настройки](https://support.google.com/analytics/answer/1032415?hl=ru).
