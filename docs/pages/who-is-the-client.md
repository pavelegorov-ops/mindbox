# Кто такой «Клиент»

Клиент — это потребитель, которого можно каким-либо образом идентифицировать.  
У каждого клиента при попадании на проект должен быть хотя бы один уникальный **контакт/идентификатор**:

- email;
- мобильный номер;
- номер дисконтной карты;
- внешний идентификатор (идентификатор из вашей системы; на проекте для его обозначения создаётся [дополнительное поле](additional-data.md) типа ’Уникальный идентификатор’ или ’Идентификатор’ по сущности «Клиент»);
- мобильное приложение;
- устройство для мобильных пушей.

После добавления клиента на проект ему также автоматически присваивается идентификатор в нашей системе — MindboxID.

Для каждого клиента создаётся карточка.  
Все карточки клиентов собраны на странице **Данные — Клиенты**:

## Какую информацию содержит карточка клиента

![клиентка.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%BA%D0%BB%D0%B8%D0%B5%D0%BD%D1%82%D0%BA%D0%B0.png)

В центре находится основная информация по клиенту. Сверху отображается мобильный телефон, электронная почта, дата рождения, пол, зона и часовой пояс. Ниже указаны идентификаторы клиента, дисконтные карты, а также тикет для авторизации — клик на него копирует в буфер обмена значение тикета авторизации клиента. Рядом находится история идентификаторов, где можно посмотреть все прошлые идентификаторы клиента, если они менялись.

Также в этой области находится информация по дате регистрации и данные покупок. При клике на дату регистрации в ленте активности клиента отобразится действие регистрации. Если проект [мультибрендовый](multibrand.md) — указывается первая дата регистрации и название бренда.

В правой области экрана отображаются устройства клиента.

### Данные покупок

Нижеперечисленные показатели считаются по заказам в категориях статусов «Оформлена», «Оплачена», «Доставлена» и не учитывают удаленные заказы. При раскрытии выпадающего списка отобразится:

![who-is-the-client-purchase-data](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/who-is-the-client-purchase-data.png)

- Количество заказов, совершенных клиентом;
- Средний чек. Рассчитывается от общей суммы заказов в статусах «Оформлена», «Оплачена», «Доставлена», разделенных на количество заказов в этих статусах;
- Сумма покупок. Если на проекте настроена [RFM-сегментация](%D0%BA%D0%B0%D0%BA-%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%B0%D0%B5%D1%82-rfm-%D1%81%D0%B5%D0%B3%D0%BC%D0%B5%D0%BD%D1%82%D0%B8%D1%80%D0%BE%D0%B2%D0%B0%D0%BD%D0%B8%D0%B5.md), то рядом с суммой покупок будет указан сегмент, в котором состоит клиент.

Средний чек и сумма покупок рассчитываются по стоимости заказов после применения скидок.

При нажатии на «Скопировать», значения будут скопированы в буфер обмена. При отсутствии пермиссии «Просмотр и редактирование персональных данных» — данные скопируются в маскированном виде.

На данный момент информация по данным покупок и дате регистрации не выгружается в экспорте клиентов.
