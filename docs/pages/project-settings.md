# Как выбрать формат дат и чисел в системе

Чтобы установить форматы, перейдите в раздел **Настройки** → **Системные** → **Параметры платформы**:

![пар платф.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%BF%D0%B0%D1%80%20%D0%BF%D0%BB%D0%B0%D1%82%D1%84.png)

- Часовой пояс — по какому поясу выводится время в интерфейсе (фильтры, промоакции, время пересчета, журнал событий и т.д.).

> Пример.  
> Коллега из Москвы (UTC +03:00) строит фильтр по продуктам «Начало вебинара — от 12:00». Раньше коллега из Екатеринбурга (UTC +05:00) увидел бы тот же фильтр со временем 14:00, потому что его локальное время отличается от московского. Теперь оба увидят одинаковое время — 12:00 (UTC +03:00).

![Снимок экрана 2023-02-02 в 10.20.54.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-02-02%20%D0%B2%2010.20.54.png)

- Формат чисел в экспортах — десятичные числа с разделителем точкой или запятой.
- Валюта — отображение символа (рубль / доллар / евро / фунт стерлингов).
