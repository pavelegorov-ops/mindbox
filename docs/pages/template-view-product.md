# Шаблон действия для просмотра продукта/категории

В операциях просмотра продукта и категории автоматически создаются шаблоны действий.  
При этом для некоторых задач, например, импорте просмотров, шаблоны нужно добавить на проект самостоятельно.

Общую инструкцию по созданию шаблонов действия можно посмотреть [здесь](template-create.md).

Для нашей задачи важно выбрать правильные категории шаблона:

**Категория 1:** Личные действия клиента  
**Категория 2:** Потребление контента и просмотр продуктов  
**Категория 3:** Взаимодействие с разделами сайта или мобильного приложения
