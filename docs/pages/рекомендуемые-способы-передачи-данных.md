# Рекомендуемые способы передачи данных

Есть несколько вариантов, как можно передать персональные данные на платформу Mindbox или вашему менеджеру, и в этой статье описаны рекомендуемые способы. Они помогут сохранить данные в безопасности во время импорта или отправки файлов с информацией о пользователях.

### Как импортировать данные в Mindbox?

1. **Импорт через интерфейс.** Для этого нужно подготовить файл с данными и загрузить его через внутренний импорт Mindbox. Подробнее — [здесь](clients-import.md).
2. **Импорт через API.** Выполняется с помощью POST-запроса. Подробнее — [здесь](https://developers.mindbox.ru/docs/customers-import-v3).
3. **Импорт с FTP.** Осуществляется с помощью интеграции Mindbox и внешней системы с данными. Подробнее — [здесь](%D0%BA%D0%B0%D0%BA-%D0%BD%D0%B0%D1%81%D1%82%D1%80%D0%BE%D0%B8%D1%82%D1%8C-%D0%B8%D0%BC%D0%BF%D0%BE%D1%80%D1%82-%D1%81-ftp.md).

### Как передать файл с данными менеджеру Mindbox?

Если вам нужно передать выгрузку менеджеру Mindbox, то необходимо создать архив с паролем и добавить файл с данными в него. После этого можно отправить его любым удобным способом (email, мессенджер, Bitrix24).

Пароль от такого архива нужно передать **отдельно** любым другим удобным способом.

Не используйте один и тот же канал для передачи и архива, и пароля от него.

### Как создать архив с паролем?

#### Windows:

Понадобится архиватор 7-Zip.

1. Кликните правой кнопкой мыши по нужному файлу → 7-Zip → «Добавить к архиву».
2. Установите пароль к архиву в правом нижнем углу открывшегося окна.
3. Зашифрованный архив создан. Пожалуйста, отправьте архив и пароль от него с помощью **двух разных каналов** (email, мессенджер, Bitrix24).

[](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/windows.mov)

#### MacOS:

Понадобится архиватор Keka.

1. Кликните на файл и откройте архиватор Keka.
2. Установите пароль к архиву в открывшемся окне и перетащите в это окно нужный файл.
3. Добавьте файл в нужную папку и нажмите «Сжать».
4. Зашифрованный архив создан. Пожалуйста, отправьте архив и пароль от него с помощью **двух разных каналов** (email, мессенджер, Bitrix24).
