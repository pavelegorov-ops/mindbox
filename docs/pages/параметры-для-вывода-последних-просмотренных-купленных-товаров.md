# Вывод последних купленных товаров

Для вывода последних купленных товаров без [привязки к заказу](%D0%BF%D0%B0%D1%80%D0%B0%D0%BC%D0%B5%D1%82%D1%80%D1%8B-%D0%B4%D0%BB%D1%8F-%D1%80%D0%B0%D1%81%D1%81%D1%8B%D0%BB%D0%BA%D0%B8-%D0%B7%D0%B0%D0%BA%D0%B0%D0%B7-%D0%BE%D1%84%D0%BE%D1%80%D0%BC%D0%BB%D0%B5%D0%BD.md) используем [параметр](что-такое-шаблонизатор) `**Recipient.RecentlyBoughtProducts.Take(N)`. Параметр не выводит отмененные или возвращенные позиции.

Параметры являются коллекциями и доступны во всех письмах.

- Для обращения к каждому товару в коллекции используем цикл [for...end for](%D0%BA%D0%B0%D0%BA-%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%B0%D1%82%D1%8C-%D1%81-%D1%8D%D0%BB%D0%B5%D0%BC%D0%B5%D0%BD%D1%82%D0%B0%D0%BC%D0%B8-%D0%BA%D0%BE%D0%BB%D0%BB%D0%B5%D0%BA%D1%86%D0%B8%D0%B8-%D1%81-%D0%BF%D0%BE%D0%BC%D0%BE%D1%89%D1%8C%D1%8E-%D1%86%D0%B8%D0%BA%D0%BB%D0%B0-for-end-for-%D0%B8-set.md):

```
@{for item in Recipient.RecentlyBoughtProducts.Take(3)}
    Цена продукта: ${item.Price}
    Название: ${item.Name}
@{end for}
```

- Для вывода через товарную сетку воспользуйтесь [инструкцией](how-to-display-data-as-a-table).
- Для вывода товаров только из выбранного сегмента используем функцию FilterBySegment().

Например, хотим выводить только продукты из сегмента "В наличии" (VNalichii).  
Параметр в таком случае будет: `Recipient.RecentlyBoughtProducts.FilterBySegment("VNalichii").Take(10)`
