# Как импортировать подарочные карты

Перед добавлением [подарочных карт](gift-cards-what-is.md) на проекте нужно завести [пулы](gift-card-pools-import.md) для их хранения.

Чтобы импортировать подарочные карты:

1. Из раздела **Кампании** → **Лояльность** → **Пулы подарочных карт** перейдите по ссылке к списку подарочных карт:

   ![Снимок экрана 2024-01-16 в 18.21.37.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202024-01-16%20%D0%B2%2018.21.37.png)
2. Нажмите «Импорт»:

   ![Снимок экрана 2024-01-16 в 18.20.59.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202024-01-16%20%D0%B2%2018.20.59.png)
3. Выберите операцию «Импорт подарочных карт» и подготовьте файл. На странице доступен шаблон с примером:

   ![Снимок экрана 2023-12-18 в 13.04.34.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-12-18%20%D0%B2%2013.04.34%281%29.png)

Поля для заполнения:

- **Number** — номер карты.
- **PoolSystemName** — системное имя пула, к которому принадлежит карта.
- **Cvv** — CVV подарочной карты. Обязательно только в пулах, которые требуют передачи CVV.
- **Amount** — стоимость карты. Обязательно, даже если у пула задан фиксированный номинал.
- **PurchasePointOfContact** — внешний идентификатор точки контакта. Необязательное поле. Можно использовать, если нужно зафиксировать место выдачи карты в прошлом; в таком случае нужно также передать дату выдачи (PurchaseDateTimeUtc) и активный статус карты (CanBeUsed).
- **PurchaseDateTimeUtc** — дата покупки карты в часовом поясе UTC+0. Необязательное поле. Можно использовать, если нужно зафиксировать время выдачи карты в прошлом; в таком случае нужно также передать точку контакта выдачи (PurchasePointOfContact) и активный статус карты (CanBeUsed), а пул подарочных карт должен быть с фиксированным сроком действия. Для подсчета срока действия карты к дате покупки карты прибавляется срок действия пула.
- **Status** — статус подарочной карты. Необязательное поле. Если его не заполнять, по умолчанию будет проставлено значение «Не активирована».  
  Допустимые статусы:
  - **CanBeUsed** — Активирована. Можно использовать для оплаты заказа. Продавать такие карты нельзя.
  - **Inactive** — Не активирована. Можно продавать. После этого карта станет активированной, и ее можно будет использовать для оплаты заказа.
  - **Blocked** — Заблокирована. Продавать и использовать в заказах такие карты нельзя.
