# Каскадная скидка

Рассмотрим пример, как настраивать промоакцию со следующими условиями: на первый товар скидка 5%, на второй — скидка 10%, на третий — 15% и т.д. с максимальной скидкой 30%.

Скидка настраивается в блоке «Состав заказа» скидочной промоакции.

Инструкция:

1. Создайте скидочную промоакцию по [инструкции](https://goo.gl/vEUdZD).
2. Перейдите в блок **Состав заказа** для настройки.
3. Выберите заказы, на которые будет действовать скидка.

Можно выбрать:

- все заказы
- заказы в сегментации
- заказы не в сегментации

Для создания сегмента заказы можно фильтровать по:

- количеству продуктов в линиях чека (Линии чека — Суммарное количество продуктов (товаров) в линии);
- по наличию в линии чека (позиции заказа) продукта из определённого сегмента (Линии чека — Сегмент продукта);
- по сумме линий чека (Линии чека — сумма по базовым/текущим ценам)
  - Базовая цена — цена за продукт до скидок
  - Текущая цена — цена за продукт после скидок
- по способу оплаты (Платежи — Способ оплаты);
- по дополнительному полю позиции заказа (Линии чека — Дополнительные поля)
- по данным из дополнительных полей по заказу.

4. Выберите бенефит — **Каскадная скидка** и настраиваем его для акции с указанными выше условиями:

![Снимок экрана 2021-05-04 в 09.28.32.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-05-04%20%D0%B2%2009.28.32.png)

При применении скидки продукты сортируются по убыванию цены, т.е. на продукт с наибольшей ценой применится минимальная скидка.

При сохранении блока расписываются скидки на каждый продукт:

![Снимок экрана 2021-05-04 в 09.30.20.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-05-04%20%D0%B2%2009.30.20.png)

5. Нажмите **Сохранить и выйти**, или **Запустить** для запуска промоакции.
