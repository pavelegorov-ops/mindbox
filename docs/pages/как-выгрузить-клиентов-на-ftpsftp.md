# Как экспортировать данные на FTP/SFTP

#### Экспортировать данные на FTP/SFTP можно двумя способами:

1. Указав данные подключения к серверу в запросе на постановку задачи. Подробнее на [Developers.](https://developers.mindbox.ru/docs/%D1%8D%D0%BA%D1%81%D0%BF%D0%BE%D1%80%D1%82-%D0%BD%D0%B0-ftpsftp)
2. Создав задачу на внешнюю интеграцию в интерфейсе административной панели  
   2.1. В меню выбираем раздел «Интеграции» → «FTP/SFTP импорт и экспорт данных»

![Снимок экрана 2022-06-19 в 16.32.34.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-06-19%20%D0%B2%2016.32.34.png)  
2.2. Нажимаем «Добавить»

![Снимок экрана 2020-10-27 в 21.48.37.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202020-10-27%20%D0%B2%2021.48.37.png)  
2.3. Выбираем систему для интеграции «Экспорт»

![Снимок экрана 2020-10-27 в 21.49.59.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202020-10-27%20%D0%B2%2021.49.59.png)  
2.4. Настройки для FTP:

"Первоначальная дата для старта выгрузок" - дата с которой начинается экспорт. Далее изменения загружаются с момента последней выгрузки до текущей даты. Данные экспортируются с помощью периодических задач.

Частота экспорта:

- Если выбран режим "Раз в N часов", то заданный период отсчитывается от момента **окончания** прошлой задачи. То есть постановка задачи будет сдвигаться в зависимости от длительности выполнения экспорта.
- Если выбран режим "Раз в сутки", то каждая задача будет начинаться в указаное в настройках конфигурации время.

![Снимок экрана 2020-10-27 в 22.03.17.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202020-10-27%20%D0%B2%2022.03.17.png)

2.5. Настройки для SFTP:

![Снимок экрана 2020-10-29 в 13.09.33.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202020-10-29%20%D0%B2%2013.09.33.png)

2.6. Нажать «Сохранить». При сохранении задачи произойдет тестовое подключение, которое проверит правильность данных для подключения.

Если операция экспорта вызывалась последние 7 дней от 5 раз ежедневно, а потом перестала - мы уведомим об этом.
