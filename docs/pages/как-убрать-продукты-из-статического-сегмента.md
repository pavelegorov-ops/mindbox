# Как убрать продукты из статического сегмента

1. Переходим в раздел **Данные** → **Сегментации**:

![Снимок экрана 2023-01-15 в 19.20.03.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-01-15%20%D0%B2%2019.20.03.png)

2. Нажимаем «Импорт»:

![Снимок экрана 2023-01-15 в 19.32.41.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-01-15%20%D0%B2%2019.32.41.png)

3. Подготавливаем файл

Можно скачать шаблон с примером:

![Снимок экрана 2021-03-17 в 14.39.11.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-03-17%20%D0%B2%2014.39.11.png)  
Под ссылкой на скачивание шаблона перечислены доступные названия полей.

Заполняем таблицу идентификаторами тех продуктов в нужной [внешней системе](%D0%BA%D0%B0%D0%BA-%D1%81%D0%BE%D0%B7%D0%B4%D0%B0%D1%82%D1%8C-%D0%B2%D0%BD%D0%B5%D1%88%D0%BD%D1%8E%D1%8E-%D1%81%D0%B8%D1%81%D1%82%D0%B5%D0%BC%D1%83.md), которые убираем из сегмента. Например:

![Снимок экрана 2021-03-17 в 14.42.21.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-03-17%20%D0%B2%2014.42.21.png)

4. Настраиваем операцию:

Операция: *импорт статических сегментов продуктов;*  
Кодировка: *по умолчанию utf-8;*  
Файл: *подготовленный файл из пункта 3;*  
Настройки операции: ***сегментация**, из которой убираем продукты.*

![Снимок экрана 2021-03-16 в 18.15.42.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-03-16%20%D0%B2%2018.15.42%282%29.png)

Важно выбрать **только** сегментацию без указания сегмента

5. Ставим задачу:

![Снимок экрана 2021-03-16 в 18.15.421.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-03-16%20%D0%B2%2018.15.42%281%29%281%29.png)

6. Переходим по ссылке на задачу:

![Снимок экрана 2021-03-16 в 18.16.30.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-03-16%20%D0%B2%2018.16.30%281%29.png)

Также её можно увидеть, перейдя в раздел **Настройки** → **Системные** → **Задачи**:

![задачи.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%B7%D0%B0%D0%B4%D0%B0%D1%87%D0%B8%281%29.png)

Тип задачи — импорт статических сегментов продуктов:

![Снимок экрана 2021-03-16 в 18.17.05.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-03-16%20%D0%B2%2018.17.05%281%29.png)

7. После успешного завершения задачи проверяем — продукты больше не в сегменте:

![Снимок экрана 2021-03-16 в 18.17.19.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-03-16%20%D0%B2%2018.17.19%281%29.png)
