# Как создать встроенный блок

## Создание встроенного блока на проекте

Для работы с данными из корзины и посещенных страниц требуется полная интеграция по [инструкции](https://developers.mindbox.ru/page/%D1%80%D0%B5%D0%BA%D0%BE%D0%BC%D0%B5%D0%BD%D0%B4%D0%B0%D1%86%D0%B8%D0%B8-%D0%BD%D0%B0-%D1%81%D0%B0%D0%B9%D1%82).

1. Перейдите в раздел **Кампании**:

   ![список.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D1%81%D0%BF%D0%B8%D1%81%D0%BE%D0%BA%281%29.png)
2. Нажмите на «Создать кампанию» → «Персонализация» → «Встроенный блок»:

   ![создать-встр.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D1%81%D0%BE%D0%B7%D0%B4%D0%B0%D1%82%D1%8C-%D0%B2%D1%81%D1%82%D1%80.png)
3. Выберите папку и нажмите «Создать»:

   ![Снимок экрана 2023-01-23 в 01.21.12.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-01-23%20%D0%B2%2001.21.12.png)
4. Выберите шаблон:

   ![Снимок экрана 2021-03-25 в 18.12.42.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-03-25%20%D0%B2%2018.12.42.png)
5. Укажите сайт:

   ![Снимок экрана 2023-01-23 в 03.42.10.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-01-23%20%D0%B2%2003.42.10.png)

**6. Задайте название:**

![Снимок экрана 2021-03-25 в 18.20.53.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-03-25%20%D0%B2%2018.20.53.png)

#### Новые шаблоны

Используйте новые шаблоны встроенных блоков для более гибкой настройки.

- Выберите шаблон с лейблом «Новинка»:

![inline-new-templates-label](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/inline-new-templates-label.png)

- Добавляйте нужные элементы на экраны с помощью кнопки «Добавить элементы», меняйте их порядок и убирайте лишние:

![inline-new-templates-screen](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/inline-new-templates-screen.png)

- Для перехода в редактирование элемента, кликните по нему в списке экрана или на превью:

![inline-new-templates-element](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/inline-new-templates-element.png)

В новых шаблонах можно задать разные настройки для каждого текстового элемента на разных экранах (начертание, размер и цвет шрифта, а также расположение текста).

- **Дизайн для устройств**

По умолчанию дизайн большинства элементов автоматически синхронизируется и подстраивается под мобильную версию. Отключите синхронизацию, чтобы указать уникальные настройки:

![inline-new-templates-devices](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/inline-new-templates-devices.png)

- Перейдите в **«Общие настройки»**, чтобы изменить:

  - Общий дизайн формы (шрифт, ширина и высота, кнопка закрытия и др.)
  - Место расположения на сайте
  - Настройки передачи данных (формат телефона, автодополнение, сохранение данных пользователей)

![inline-new-templates-general-settings](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/inline-new-templates-general-settings.png)

В настройках новых шаблонов можно указать единую высоту формы для всех экранов. Это будет полезно в тех случаях, когда экраны состоят из разного контента, из-за чего высота может отличаться при переключении между экранами.

В шаблонах с несколькими основными экранами можно настроить **сохранение введенных данных** при закрытии второго экрана.  
В таком случае все поля на втором экране становятся необязательными.

Для этого откройте **Общие настройки** → **Передача данных** → **Данные пользователей** и включите опцию:

![inline-new-templates-save-first-screen](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/inline-new-templates-save-first-screen.png)

Рекомендуем использовать эту настройку, только если на первом экране есть **обязательная политика конфиденциальности**, чтобы пользователь мог явно выразить согласие на передачу данных и получение коммуникаций.

#### Как выбрать селектор

**CSS-селектор** - это элемент, к которому мы собираемся применить определенные свойства CSS.

1. Установите расширение [Selector Gadget](https://chrome.google.com/webstore/detail/selectorgadget/mhjhnkcfbdhnjickkkdbjoemdmbfginb) для Google Chrome. Оно значительно облегчит поиск нужного селектора.
2. Перейдите на сайт, куда вы хотите поставить форму, выберите место на странице, где она должна располагаться.
3. Активируйте Selector Gadget, поднесите курсор мыши к этому месту и скопируйте его селектор.

Существуют селекторы:

- .someClass — соответствует любому элементу с классом "someClass";
- #someid — соответствует элементу с идентификатором "someid".

Детально о поиске нужного селектора в [статье](targeting.md#kak-najti-nuzhnyj-selektor,-chtoby-vstavit-formu).

Если для одной формы необходимо задать разные селекторы для ПК и мобильных устройств, то в поле выбора селектора нужно использовать:

```
.popmechanic-desktop [selector_for_desktop], .popmechanic-mobile [selector_for_mobile]
```

где вместо значений [selector_for_desktop] и [selector_for_mobile] нужно вставить соответствующие селекторы.
