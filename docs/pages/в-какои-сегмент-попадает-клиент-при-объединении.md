# В какой сегмент попадает клиент при объединении

## Статический сегмент

Если только один из клиентов находится в статическом сегменте, объединённый профиль будет в том же сегменте.

Если клиенты принадлежат к разным сегментам одной сегментации, объединённый профиль будет в том сегменте, дата попадания в который более поздняя, то есть более актуальная.

## Пересчитываемый сегмент

Клиент будет во всех пересчитываемых сегментах, в которых были начальные клиенты.  
Если после объединения клиент больше не подходит под условия сегмента, он из него выпадет после следующего пересчета.
