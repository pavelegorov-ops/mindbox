# Как создать алгоритм «Популярные продукты»

Можно создать три алгоритма популярных продуктов:

- Популярные продукты
- Популярные продукты по категориям
- Популярные продукты в просмотренных категориях в последней сессии

Для заведения рекомендации переходим в раздел **Контент** → **Продуктовые рекомендации** → нажимаем **Добавить механику**:

![recommendations-path.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/recommendations-path.png)

**Выбираем необходимый алгоритм**:

![Снимок экрана 2022-09-20 в 17.57.20.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-09-20%20%D0%B2%2017.57.20.png)

## Популярные продукты

Алгоритм рассчитывает популярные продукты за выбранный период времени. Популярность рассчитывается сначала по количеству заказов каждого продукта из категории, затем дополнительно сортируется по количеству просмотров продукта.

Тип алгоритма: *персональные рекомендации*  
Для клиентов: *идентифицированных и анонимных*  
Способы вызова: *API (виджет рекомендаций), email*  
Частота пересчета: *раз в сутки*

Автоматически проверяет, что:

- Продукт в наличии в зоне клиента
- Бренд продукта совпадает с брендом клиента (для многобрендовых проектов)
- Исключает из рекомендаций уже купленные клиентом продукты

Рекомендуется к использованию:

- В массовых рассылках
- На главной странице сайта

Ограничение:

- 40 алгоритмов на проект

**Настройка:**

1. Выбираем алгоритм - *Популярные продукты*

![Снимок экрана 2022-08-27 в 18.13.40.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-08-27%20%D0%B2%2018.13.40.png)  
2. Задаем название и нажимаем **Продолжить**

![Снимок экрана 2022-08-27 в 18.20.20.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-08-27%20%D0%B2%2018.20.20.png)  
3. Задаем **Общие настройки** :  
Рекомендовать из - *можно ограничить пересчитываемым сегментом, из которого рекомендуем товары (необязательно)*  
Учитывать действия с товарами - *будет учитываться статистика по заказам за период от 1 до 180*

![Снимок экрана 2022-08-27 в 18.21.59.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-08-27%20%D0%B2%2018.21.59.png)

Популярность рассчитывается сначала по количеству заказов каждого продукта из категории, затем дополнительно сортируется по количеству просмотров продукта.

Тип алгоритма: *рекомендации к категории*  
Для клиентов: *идентифицированных и анонимных*

## Популярные продукты в просмотренных категориях в последней сессии

Алгоритм рассчитывает популярные продукты в каждой товарной категории, и формирует рекомендации равномерно для каждой категории, просмотренной клиентом в последней сессии. Пересчитывается в реальном времени в зависимости от действий клиента с категориями.

Популярность рассчитывается сначала по количеству заказов каждого продукта из категории, затем дополнительно сортируется по количеству просмотров продукта.

На [мультибрендовых](multibrand.md) проектах алгоритм работает по [общей логике](recommendation.md#kak-opredelyaetsya,-kakoj-brend-budet-ispolzovatsya-v-mehanike): формирует рекомендации в рамках одного бренда к последней сессии в бренде.

Пример

Клиент посетил сайт бренда А и посмотрел категории А1, А2 и А3, затем перешел на сайт бренда Б и посмотрел категории Б1, Б2 и Б3. Будут сформированы рекомендации в бренде А — популярные продукты из категорий А1, А2 и А3 и в бренде Б — популярные продукты из категорий Б1, Б2 и Б3.

Настроить алгоритм рекомендаций для всех брендов можно, убрав ограничение по сегменту продуктов в настройках алгоритма или указав сегмент, в котором состоят продукты всех брендов. В случаях, когда логика настроек сходства для брендов разная, необходимо настроить несколько алгоритмов.

В механиках одного бренда нельзя рекомендовать продукты из другого.

Тип алгоритма: *персональные рекомендации*  
Для клиентов: *идентифицированных*  
Способы вызова: *API (виджет рекомендаций), email*  
Частота пересчета: *в реальном времени*

Автоматически проверяет, что:

- Продукт в наличии в зоне клиента
- Бренд продукта совпадает с брендом клиента (для многобрендовых проектов)
- Исключает из рекомендаций уже купленные клиентом товары
- Рекомендуется к использованию в механике “Брошенный просмотр категории”.

Ограничение:

- 1 алгоритм на проект

**Настройка:**

1. Выбираем алгоритм - *Популярные продукты в просмотренных категориях в последней сессии*
