# Как устроена подписка клиента

В системе подписок есть следующие понятия:

- канал (точка контакта) коммуникации — канал, по которому возможна коммуникация с клиентом, например, email, sms, viber, mobile push, webpush;
- тематика рассылки;
- подтверждение подписки (opt-in) — возможность отправлять ознакомительные письма тем, кто явно не выразил желание получать рассылки.

У каждого клиента хранятся как глобальные состояния подписок (на бренд в целом, на каналы коммуникации в бренде), так и состояния подписок на конкретные тематики рассылок по конкретным каналам, что позволяет эффективнее коммуницировать с клиентами.  
Клиент может быть подписан на канал, но иметь отписку в части его тематик. Тогда он будет получать рассылки только по актуальным тематикам.

### Состояния подписки клиента

- подписан — клиент выразил согласие на получение информационных рассылок;
- отписан — клиент отписался от рассылок;
- требует подтверждения — статус подписки клиента неясен, ему можно отправить opt-in рассылку для уточнения (появляется при включенной настройке Подтверждение подписки);
- нет данных — нет данных о состоянии подписки.

### Явная и неявная подписки

Если подписка пришла непосредственно по каналу/тематике, она считается явной.

Если подписка автоматически вычислена на основе подписки более «высокого» уровня, она считается неявной. В интерфейсе при этом будет соответствующая приписка.

От типа подписки зависит то, как она будет меняться при [изменении статуса](direct-subscription.md).

### Фильтр по подписке клиента

Чтобы отбирать клиентов по состоянию подписки, используйте соответствующий фильтр.

Настройки фильтра дублируют дерево подписок: можно уточнить канал, тематику и бренд на многобрендовых проектах.

### Как это работает в рассылках

В стандартных рассылках у получателей обязательно должна быть подписка на канал рассылки и на тематику, если она выбрана:

![Снимок экрана 2022-12-26 в 16.34.25.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-12-26%20%D0%B2%2016.34.25.png)*Рассылка отправится только клиентам, подписанным на дайджесты в канале Email.*

Особенности:

- транзакционные автоматические рассылки игнорируют статус подписки (данный профиль используется для писем, которые клиент обязательно должен получить — например о доставке заказа в пункт самовывоза; не для рекламых кампаний);
- рассылки для подтверждения подписки отправляются клиентам со статусом подписки «требует подтверждения».
