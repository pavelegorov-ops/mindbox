# Как создать сегмент по действиям

Для регулярно используемых фильтров по действию можно завести сегмент.

1. Перейдите в раздел **Данные** → **Действия**:

   ![страница действий.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D1%81%D1%82%D1%80%D0%B0%D0%BD%D0%B8%D1%86%D0%B0%20%D0%B4%D0%B5%D0%B9%D1%81%D1%82%D0%B2%D0%B8%D0%B9(1).png)
2. Постройте примените фильтр:

   ![Снимок экрана 2022-10-19 в 02.41.59.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-10-19%20%D0%B2%2002.41.59.png)
3. Нажмите «Создать сегмент»:

   ![Снимок экрана 2022-10-19 в 02.41.59 — копия.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-10-19%20%D0%B2%2002.41.59%C2%A0%E2%80%94%20%D0%BA%D0%BE%D0%BF%D0%B8%D1%8F.png)
4. Заполните название сегмента. Системное имя заполнится и внешний идентификатор генерируются автоматически.

   ![Снимок экрана 2022-10-19 в 02.42.31.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-10-19%20%D0%B2%2002.42.31.png)

   По действиям нельзя создать пересчитываемый по расписанию сегмент, только реалтаймовый.
5. Нажимите «Создать».

[Сегментация клиентов](https://mindbox.ru/academy/education/kak-segmentirovat-klientov/) — клиентская база на основе каких-либо признаков: гендера, количества покупок, суммы потраченных денег.
