# Как удалить сегменты

Периодическое удаление сегментов полезно, так как:

1. Сохраняется порядок на проекте, легче найти действительно нужные сегменты;
2. Можно снизить стоимость подписки.

Последнее актуально для проектов, на которых превышен лимит хранения переходов в пересчитываемых и статических сегментах. Уточнить по своему проекту можно в [детализации](billing-modules.md).  
Также в этом случае может помочь [автоудаление](%D0%BA%D0%B0%D0%BA-%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%B0%D0%B5%D1%82-%D0%B0%D0%B2%D1%82%D0%BE%D1%83%D0%B4%D0%B0%D0%BB%D0%B5%D0%BD%D0%B8%D0%B5.md) старых переходов с сохранением сегментов.

## Как удалить сегменты

1. Перейдите в раздел **Данные** → **Сегментации**:

   ![Снимок экрана 2023-01-15 в 19.20.03.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-01-15%20%D0%B2%2019.20.03%281%29.png)
2. Отберите сегментации для удаления по кнопке «Фильтры». Например, все реалтаймовые сегментации, которые нигде не используются:

   ![Снимок экрана 2023-01-15 в 20.08.09.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-01-15%20%D0%B2%2020.08.09.png)
3. Выделите нужный сегмент(ы) с помощью чекбоксов или селектора и нажмите «Удалить сегментации»:

   ![Снимок экрана 2023-01-15 в 20.09.02.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-01-15%20%D0%B2%2020.09.02.png)
4. Подтвердите действие:

   ![Снимок экрана 2023-01-15 в 20.09.17.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-01-15%20%D0%B2%2020.09.17.png)

   - Появляется ссылка на задачу:

   ![Снимок экрана 2023-01-15 в 20.09.35.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-01-15%20%D0%B2%2020.09.35.png)

   - Ждем ее успешного завершения:

   ![Снимок экрана 2022-09-11 в 14.50.11.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-09-11%20%D0%B2%2014.50.11.png)

## Почему нельзя удалить сегмент

### Сегмент используется в механике

![segment-delete-error.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/segment-delete-error.png)

Чтобы найти механики, нажмите на «Да» в колонке «Использование»:

![Снимок экрана 2023-01-15 в 20.18.52.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-01-15%20%D0%B2%2020.18.52.png)

Выберите «Блокируют удаление», чтобы просмотреть список механик, в которых используется сегмент:

![Снимок экрана 2023-01-15 в 20.19.05.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-01-15%20%D0%B2%2020.19.05.png)

Нужно убрать сегмент из всех механик, в которых он используется. После этого удаление не будет блокироваться.

### Сегмент системный

Такие сегменты нужны для отчетности и работы механик (глобальная контрольная группа). Их удаление невозможно.

[Сегментация клиентов](https://mindbox.ru/academy/education/kak-segmentirovat-klientov/) — клиентская база на основе каких-либо признаков: гендера, количества покупок, суммы потраченных денег.
