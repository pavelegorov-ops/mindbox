# Черный список контактов

## Что такое черный список и зачем он нужен

При регистрации, подписке или оформлении заказа пользователи могут указывать некорректные контакты. Например: 79777777777, not@real.ru. Клиенты с подобными данными массово объединяются, реальные телефоны и email-адреса смешиваются с несуществующими.

Для таких случаев создан «черный список» (ЧС), который защищает от попадания в базу некорректных контактов. В список уже внесены самые частые некорректные идентификаторы. При необходимости его можно редактировать.

В списке могут быть:

- email-адреса;
- мобильные номера;
- внешние идентификаторы клиента;
- идентификаторы устройства;
- номера дисконтной карты.

Обратите внимание:

- Попадание и наличие контакта в списке не отображается в карточке клиента. Для проверки можно воспользоваться [выгрузкой списка](blocklist-export-contacts.md).
- Добавление контакта в чёрный список не удаляет его с проекта автоматически, но предотвращает создание новых карточек с некорректным контактом в будущем. Если нужно удалить клиентов с контактами из списка, сначала [удалите клиентов](clients-delete.md), а затем внесите контакты в чёрный список.
- Добавление контактов в черный список [не влияет на отправку рассылок](blocklist.md#budut-li-otpravlyatsya-rassylki-na-kontakty-iz-chs). Они не исключаются из списка получателей.

## Причины попадания в ЧС

- Наличие [в базовом списке](blocklist.md#bazovyj-spisok-nekorrektnyh-kontaktov) самых частых некорректных контактов;
- [Импорт](blocklist-import-contacts.md) контактов в список;
- Автоматическое добавление контакта в список при превышении лимита редактирований или объединений. При этом на проекте открывается [«Предупреждение»](issues.md). Примеры проблем можно посмотреть [по ссылке](issues-types.md#kontakty).

## После попадания в ЧС

### Попытки добавить на проект контакт из ЧС

Попытки загрузить запрещенные контакты будут падать с ошибками:

- импорт — ошибка *«{контакт} cодержится в черном списке c {дата}. Причина:...»*; если это единственный переданный контакт, клиент загружен не будет:  
  ![blocklist-error-import](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/blocklist-error-import.png)
- операции:
  - без обязательной валидации (синхронные и асинхронные вызовы) — ошибка *«{контакт} cодержится в черном списке c {дата}. Причина:...»*; если это единственный переданный контакт, клиент загружен не будет:  
    ![blocklist-error-log](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/blocklist-error-log.png)
  - операции с флагом «Операция возвращает валидационные ошибки» — вызов не выполнится, даже если переданы другие, корректные, контакты.

Исключение

При добавлении контакта **[вручную](client-add.md)** валидации на наличие в ЧС нет.

### Будут ли отправляться рассылки на контакты из ЧС?

Важно

Добавление контактов в ЧС **не влияет на отправку рассылок**, то есть они **не исключаются из рассылок**.

Чтобы исключить загруженные контакты из всех будущих кампаний, после добавления в список, **нужно затереть** их у клиентов или **удалить клиентов** с ними из базы. Как следствие, пользователям не будут записываться некорректные контакты и в список получателей рассылок они не попадут.
