# Какие нужны пермиссии для разных задач

Для всех действий на проекте нужны определенные права — пермиссии.

В данной статье собраны все разделы административного сайта с указанием нужных пермиссий на любую заданную задачу: просто открыть раздел, редактировать сущность, добавить новую и так далее.

**Как подобрать нужные пермиссии**

---

1. Найдите нужный раздел проекта в оглавлении статьи или при помощи поиска и выдайте доступ(ы) на его просмотр.
2. Если нужны дополнительные права — редактирование, добавление, удаление — они также описаны в разделе.

### Мои задачи

![Снимок экрана 2023-08-30 в 13.12.42.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-08-30%20%D0%B2%2013.12.42.png)

Открывает раздел [Задачи](permissions.md#zadachi) с фильтром по персоналу.

#### Открыть раздел

- *«Просмотр только своих задач»* — показывать только несистемные задачи, поставленные с аккаунта залогиненного персонала.

Для расширения доступных к просмотру задач:

- *«Просмотр всех несистемных задач»* — показывать пользовательские задачи (автоудаление, ручное удаление, импорт сегментов, постановка отчета или экспорта).
- *«Просмотр всех системных задач»** — показывать технические задачи (пересчет сегментов, отправка рассылок).

*Пермиссия доступна только техническому персоналу Mindbox.

Для доступа к **исходным файлам импорта**:

- для просмотра файлов в собственных задачах достаточно пермиссии *«Просмотр только своих задач»*;
- *«Просмотр исходных файлов импортов»* — для скачивания файлов из любых задач.

Для доступа к файлам **экспорта** нужны отдельные пермиссии:

- *«Экспорт клиентов»* — для выгрузки клиентов, списков продуктов, дисконтных карт клиентов, контактов черного списка, изменения сегментов для клиентов;
- *«Экспорт действий»* — для выгрузки действий клиента, заказов и позиций заказов истории изменения баланса;
- *«Экспорт продуктов»* — для выгрузки продуктов, категорий продуктов, изменения сегментов для продуктов;
- *«Экспорт зон»* — для выгрузки зон;
- *«Экспорт рассылок»* — для выгрузки рассылок;
- *«Экспорт статусов рассылок»* — для выгрузки статусов рассылок;
- *«Экспорт сценариев»* — для выгрузки сценариев;
- *«Экспорт клиентов из отчета прохождений сценария»* — для выгрузки клиентов из прохождений блоков сценария;
- *«Экспорт логов интеграций»* — для выгрузки логов операций и вебхуков;
- *«Экспорт отчетов»* — для выгрузки сводного и динамического отчетов по рассылкам;
- *«Экспорт промоакций»* — для выгрузки промоакций.
