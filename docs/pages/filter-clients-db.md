# Найти клиентов с первым действием за указанный период

Трекер Mindbox сохраняет действия клиента в течение сессии и подтягивает их в карточку при [регистрации](filter-clients-register.md). Поэтому иногда у клиента первым действием может быть, например, переход на сайт. Научимся находить клиентов по дате таких действий.

---

Переходим на вкладку **Данные** → **Клиенты**:

![Снимок экрана 2021-03-30 в 20.26.00.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-03-30%20%D0%B2%2020.26.00.png)

«Первое взаимодействие» — один из возможных фильтров действия клиента.

Рассмотрим разные задачи и способы их решения.

**Задача 2.**
