# Как создать статический сегмент по зонам

Сначала создаём сегментацию, потом сегмент(ы) в ней.

По шагам:

1. Переходим в раздел **Данные** → **Сегментации**:

![Снимок экрана 2023-01-15 в 19.20.03.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-01-15%20%D0%B2%2019.20.03.png)

2. Нажимаем «Добавить» → «Статическую по зонам»:

![Снимок экрана 2023-01-15 в 19.20.52.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-01-15%20%D0%B2%2019.20.52.png)

3. Добавляем сегмент(ы).  
   Заполняем название. Системное имя проставляется автоматически при клике по строке, внешний идентификатор генерируется при сохранении сегмента:

![image](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-06-25%20%D0%B2%2017.31.16.png)

Для удаления лишнего сегмента кликаем на красный крестик в правом верхнем углу.

4. Чтобы сегментация появилась в фильтрах и её можно было использовать в механиках, нужно её активировать.  
   Для этого нажимаем «Запустить в работу »:

![image](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-06-25%20%D0%B2%2017.32.17.png)

Статус сегментации меняется:

![image](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-06-25%20%D0%B2%2017.33.03.png)

В активной сегментации можно редактировать только названия имеющихся сегментов и добавлять новые; удалять их уже нельзя.  
***Готово!***
