# Как удалить пулы подарочных карт

Удаление возможно только для тех пулов подарочных карт, по которым **нет карт**. [Как удалить подарочные карты](https://help.mindbox.ru/docs/gift-cards-deletion).

1. Перейдите в раздел **Кампании → Лояльность → Пул подарочных карт**:

   ![gift-cards-pools-deletion-path.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/gift-cards-pools-deletion-path.png)
2. Найдите нужный пул и откройте меню дополнительный действий как на скриншоте ниже. Нажмите «Удалить»:

   ![gift-cards-pools-deletion.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/gift-cards-pools-deletion.png)

По завершении удаления появится уведомление

![gift-cards-pools-deletion-result.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/gift-cards-pools-deletion-result.png)
