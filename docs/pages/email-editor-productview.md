# Вывод измененного просмотренного продукта (новый конструктор)

[Новый конструктор](email-editor.md) email-рассылок позволяет настроить вывод измененного просмотренного продукта без использования кода и [параметров](parameters-productview-price.md).

Чтобы вывести измененный товар:

1. Выберите блок по продуктам с динамическим заполнением:

![Снимок экрана 2023-12-05 в 00.12.59.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-12-05%20%D0%B2%2000.12.59.png)  
2. Настройте блок:

- **Заполнение контента** — «Динамическое»
  - **Какие продукты отображать** — «Изменение просмотренного продукта»

![email-editor-productview.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/email-editor-productview.png)

3. Настройте карточку продукта:

![email-editor-productlistitem-product.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/email-editor-productlistitem-product.png)

4. Сохраните изменения в шаблоне.
