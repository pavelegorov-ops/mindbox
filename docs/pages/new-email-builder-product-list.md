# Вывод списка продуктов (новый конструктор)

[Новый конструктор](email-editor.md) email-рассылок позволяет настроить динамический вывод продуктов из [списка](personal-list.md) без использования кода и [параметров](%D0%BF%D0%B0%D1%80%D0%B0%D0%BC%D0%B5%D1%82%D1%80%D1%8B-%D0%B4%D0%BB%D1%8F-%D0%B2%D1%8B%D0%B2%D0%BE%D0%B4%D0%B0-%D1%82%D0%BE%D0%B2%D0%B0%D1%80%D0%BE%D0%B2-%D0%B8%D0%B7-%D1%81%D0%BF%D0%B8%D1%81%D0%BA%D0%B0-%D0%BF%D1%80%D0%BE%D0%B4%D1%83%D0%BA%D1%82%D0%BE%D0%B2.md).

Чтобы вывести продукты из списка:

1. Выберите блок для списка продуктов с динамическим заполнением:

![Снимок экрана 2024-10-05 в 13.08.01.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202024-10-05%20%D0%B2%2013.08.01.png)

2. Настройте блок:

- **Заполнение контента** — «Динамическое»
  - **Какие продукты отображать** — «Список продуктов»
  - **Список продуктов** — выберите нужный.
  - Можно ограничить выборку сегментом продуктов ([пересчитываемый](%D0%BA%D0%B0%D0%BA-%D1%81%D0%BE%D0%B7%D0%B4%D0%B0%D1%82%D1%8C-%D0%BF%D0%B5%D1%80%D0%B5%D1%81%D1%87%D0%B8%D1%82%D1%8B%D0%B2%D0%B0%D0%B5%D0%BC%D1%8B%D0%B8-%D1%81%D0%B5%D0%B3%D0%BC%D0%B5%D0%BD%D1%82-%D0%BF%D0%BE-%D0%BF%D1%80%D0%BE%D0%B4%D1%83%D0%BA%D1%82%D0%B0%D0%BC.md) или [статический](%D0%BA%D0%B0%D0%BA-%D1%81%D0%BE%D0%B7%D0%B4%D0%B0%D1%82%D1%8C-%D1%81%D1%82%D0%B0%D1%82%D0%B8%D1%87%D0%B5%D1%81%D0%BA%D0%B8%D0%B9-%D1%81%D0%B5%D0%B3%D0%BC%D0%B5%D0%BD%D1%82-%D0%BF%D0%BE-%D0%BF%D1%80%D0%BE%D0%B4%D1%83%D0%BA%D1%82%D0%B0%D0%BC.md)) и зоной клиента.
- Правила вывода продуктов
  - **Строки** — сколько продуктов выводить.
  - **Если нет продуктов для отображения, то** — не отображать блок или не отправлять письмо.

![email-editor-product-list.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/email-editor-product-list.png)

3. Настройте карточку продукта.  
   Изменения в одной карточке автоматически дублируются на остальные.

![Снимок экрана 2024-10-05 в 13.54.01.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202024-10-05%20%D0%B2%2013.54.01.png)

4. Сохраните изменения в шаблоне.
