# Как добавить кнопку вызова попапа для механики «Сообщить о поступлении товара в наличие»

**Для добавления кнопки «Сообщить о поступлении» потребуется:**

1. Установить [трекер](https://developers.mindbox.ru/docs/%D1%82%D1%80%D0%B5%D0%BA%D0%B5%D1%80) Mindbox на сайт и включить модуль «Персонализация сайта»;
2. Создать список [WishList](personal-list.md) без использования цены и добавить [операцию](%D0%BE%D0%BF%D0%B5%D1%80%D0%B0%D1%86%D0%B8%D0%B8-v-%D0%BE%D1%81%D0%BD%D0%BE%D0%B2%D0%BD%D1%8B%D0%B5-%D1%81%D0%B2%D0%B5%D0%B4%D0%B5%D0%BD%D0%B8%D1%8F.md) по добавлению продукта в список;
3. Создать [папку](folders.md) для механики;
4. Настроить попап с добавлением товара с список «WishList»;
5. Настроить встроенный блок;
6. Создать автоматическую [Email-рассылку](email-trigger.md) и [сценарий](workflow-product-available.md);

## Создание операции

Для создания операции нужно зайти в кампанию, далее выбрать «Добавить» → «Операцию».

Шаги операции:

- Получить клиента;
- Добавить продукт в список.

## Настройка попапа

1. Выберите любой шаблон для сбора контактов с полем Email:

   ![Снимок экрана 2022-03-01 в 13.37.04.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-03-01%20%D0%B2%2013.37.04.png)
2. После выбора шаблона укажите сайт:

   ![выбрать сайт.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%B2%D1%8B%D0%B1%D1%80%D0%B0%D1%82%D1%8C%20%D1%81%D0%B0%D0%B9%D1%82.png)
3. При создании формы ей присваивается ID — он нам потребуется для настройки встроенного блока. Так же этот ID записывается в URL попапа.

   ![Снимок экрана 2022-03-01 в 13.44.06.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-03-01%20%D0%B2%2013.44.06.png)
4. Для добавления клиента в базу нужно в действиях после заполнения формы выбрать «Создать нового клиента или редактировать существующего»:

   ![Снимок экрана 2022-03-01 в 18.03.43.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-03-01%20%D0%B2%2018.03.43.png)
5. Для добавления в список WishList продукта, нужно **вызвать пользовательский JS код:**

![Снимок экрана 2023-07-19 в 13.19.59.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-07-19%20%D0%B2%2013.19.59.png)

```
var productIds = %product_id%;

if (productIds) {
    mindbox ("async", {
      operation: "Website.AddToAvailabilityList",
      data: {
        addProductToList: {
          product: { ids: productIds }
        }
      }
    });
}
```

## Тестирование механики

Тестовый просмотр формы не поддерживает открытие попапа из встроенного блока. Для тестирования механики, воспользуйтесь инструкцией ниже.

1. Создайте [пересчитываемый сегмент](https://help.mindbox.ru/docs/segment-client-filter-recalculate), в котором будет только ваш клиент. Рекомендуем строить фильтр по **UUID устройства** на странице вашего сайта. [Как определить UUID устройства](https://help.mindbox.ru/docs/deviceuuid#kak-najti-v-brauzere)

   ![popup-notify-about-product-test-segmentation](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/popup-notify-about-product-test-segmentation.png)
2. Добавьте в таргетинг попапа и встроенного блока условие показа по сегменту из п.1:

   ![popup-notify-about-product-test-targeting](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/popup-notify-about-product-test-targeting.png)
3. Запустите в работу обе формы и сценарий.
4. Перейдите на сайт в карточку продукта, которого нет в наличии, и протестируйте механику.
