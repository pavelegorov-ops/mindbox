# Как использовать HTML-редактор для создания шаблона рассылок

## 1. Возможности редактора

  

HTML редактор позволяет:

- составить свою верстку с нуля;
- вставить готовую верстку из html файла;
- отредактировать верстку, загруженную через ZIP архив;
- отредактировать верстку, созданную в визуальном редакторе (**ВАЖНО**: *верстку в визуальном редакторе нельзя будет больше править после сохранения письма в HTML-редакторе* ).

## 2. Редактирование и предпросмотр

Рассмотрим общие моменты по возможностям редактора.

2.1. Нажмите на блок «HTML», чтобы начать редактирование:

![html-editor-choose.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/html-editor-choose.png)

2.2. В левой части экрана область с версткой письма:

![html-editor-left.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/html-editor-left.png)

2.3. В правой части экрана область предпросмотра письма:

![html-editor-right.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/html-editor-right.png)

2.4. Клик на значок со стрелочкой позволит продолжить редактирование рассылки, не сохраняя шаблон письма:

![html-editor-back.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/html-editor-back.png)

2.5. «Скрыть превью» скроет область предпросмотра:

![preview-hide.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/preview-hide.png)

2.6. «Открыть превью» откроет область предпросмотра:

![preview-open.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/preview-open.png)

2.7. По верстке можно осуществить поиск. Для этого кликните по окну верстки и используйте команду Ctrl+F:

![html-editor-search.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/html-editor-search.png)

2.8. Если в шаблоне присутствуют ошибки, их количество отобразится возле времени сохранения рассылки. При клике на предупреждение раскроется окно с описанием ошибки:

![html-editor-mistake.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/html-editor-mistake.png)

2.9. Кнопка «Сохранить» сохранит изменения в шаблоне и закроет режим редактора:

![html-editor-save.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/html-editor-save.png)

2.10. По кнопке «Загрузить картинку» можно загрузить картинку на наш сервер и получить ссылку на неё:

![html-editor-picture.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/html-editor-picture.png)

2.11. По кнопке «Тестовая отправка» можно отправить [тестовое письмо](%D0%BA%D0%B0%D0%BA-%D0%BF%D1%80%D0%BE%D1%82%D0%B5%D1%81%D1%82%D0%B8%D1%80%D0%BE%D0%B2%D0%B0%D1%82%D1%8C-%D1%80%D0%B0%D1%81%D1%81%D1%8B%D0%BB%D0%BA%D1%83.md):

![html-editor-test.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/html-editor-test.png)
