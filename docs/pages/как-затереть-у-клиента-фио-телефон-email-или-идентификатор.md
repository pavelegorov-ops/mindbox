# Как затереть у клиента ФИО, телефон, email или идентификатор?

В операции или файловом импорте нужно передать %CLEAR%

Важно

Параметр CLEAR — регистрозависимый. Передавать его нужно полностью заглавными буквами.

Например, нужно затереть значение уникального идентификатора websiteID через операцию редактирования. Для этого в значении этого ID нужно передать:

```
"ids": {
    "websiteID": "%CLEAR%"
}
```

После выполнения операции идентификатор будет удален.

Аналогично в файле импорта в колонке с websiteID у нужного клиента указать %CLEAR%.

[Мир без персональных данных](https://mindbox.ru/academy/education/aleksandr-gornik-rusbase/) — как тренд на приватность повлияет на рыночную стратегию.
