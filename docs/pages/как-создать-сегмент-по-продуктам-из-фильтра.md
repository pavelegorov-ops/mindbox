# Как создать сегмент по продуктам из фильтра

Один из возможных [сегментов по продукту](segments-products.md) — по фильтру, считающийся в реальном времени.

1. Перейдите в раздел **Данные** → **Продукты**:

   ![Снимок экрана 2021-08-31 в 13.10.58.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-08-31%20%D0%B2%2013.10.58.png)
2. Постройте фильтр и нажмите кнопку «Применить»:

   ![Снимок экрана 2021-08-31 в 13.12.55.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-08-31%20%D0%B2%2013.12.55.png)
3. Нажмите «Создать сегмент»:

   ![Снимок экрана 2021-08-31 в 13.14.12.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-08-31%20%D0%B2%2013.14.12.png)
4. Заполните данные:

   - Название сегментации.
   - Системное имя генерируется автоматически. Можно задать собственное значение.
   - Тип — **реалтаймовая**.
     - Дополнительно (необязательны для заполнения):
     - Описание сегмента.
     - Внешний идентификатор. Генерируется автоматически с возможностью задать собственное значение.
5. Нажмите «Создать»:

   ![Снимок экрана 2021-08-31 в 13.15.18.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-08-31%20%D0%B2%2013.15.18.png)

---

Сегмент создан. Теперь по нему можно построить фильтр:

![Снимок экрана 2021-08-31 в 13.15.50.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-08-31%20%D0%B2%2013.15.50.png)

[Сегментация клиентов](https://mindbox.ru/academy/education/kak-segmentirovat-klientov/) — клиентская база на основе каких-либо признаков: гендера, количества покупок, суммы потраченных денег.
