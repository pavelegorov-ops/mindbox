# Как работает фильтр по статусам заказов

[Заказ](what-is-an-order.md) состоит из позиций.  
У позиции может быть один из [статусов](how-to-add-the-status-of-an-order-item.md): оформлен, доставлен, оплачен, отменен или возвращен.  
При этом в заказе могут быть позиции с **разными** статусами.  
Например, три позиции доставлены, одна отменена.

## По какому статусу идет поиск

Статус позиции смотрится по **последнему** состоянию

#### Что это значит.

Например, заказ был оформлен, оплачен, а потом доставлен:

![Снимок экрана 2021-04-07в 16.21.57.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-04-07%20%D0%B2%2016.21.57.png)

Фильтр будет работать только при поиске заказов с **доставленной** позицией.  
Оформление и оплата — это **исторические** состояния, по которым поиска нет.

Заказ из примера выдаст поиск по статусу «доставлено»:

![Снимок экрана 2021-04-07в 16.24.49.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-04-07%20%D0%B2%2016.24.49.png)

## Какие статусы использовать в фильтре

Исходим из бизнес-задачи. Обычно берем «положительные» статусы: оформление, оплату и доставку, указанные через [условие -ИЛИ-](filters-or.md):

![Снимок экрана 2021-04-07в 16.28.26.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-04-07%20%D0%B2%2016.28.26.png)

**Задача 1:** отобрать клиентов с оплаченными заказами:

![Снимок экрана 2021-04-07в 16.31.03.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-04-07%20%D0%B2%2016.31.03.png)

**Задача 2:** отобрать клиентов с заказами, в которых **все** позиции оплачены:

![Снимок экрана 2021-04-07в 16.31.18.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-04-07%20%D0%B2%2016.31.18.png)

В чем отличие фильтров: в первом случае будут считаться заказы с частичной отменой или доставкой, во втором — нет.
