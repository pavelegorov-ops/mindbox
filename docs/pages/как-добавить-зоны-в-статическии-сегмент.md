# Как добавить зоны в статический сегмент

Сначала создаём статический сегмент по зонам, следуя инструкции [Как создать статический сегмент по зонам](%D0%BA%D0%B0%D0%BA-%D1%81%D0%BE%D0%B7%D0%B4%D0%B0%D1%82%D1%8C-%D1%81%D1%82%D0%B0%D1%82%D0%B8%D1%87%D0%B5%D1%81%D0%BA%D0%B8%D0%B8-%D1%81%D0%B5%D0%B3%D0%BC%D0%B5%D0%BD%D1%82-%D0%BF%D0%BE-%D0%B7%D0%BE%D0%BD%D0%B0%D0%BC.md).

Теперь можно добавить в него зоны.

1. Переходим в раздел **Данные** → **Сегментации**:

![Снимок экрана 2023-01-15 в 19.20.03.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-01-15%20%D0%B2%2019.20.03.png)

2. Нажимаем «Импорт»:

![Снимок экрана 2023-01-15 в 19.32.41.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-01-15%20%D0%B2%2019.32.41.png)

3. Выбираем операцию Импорт статических сегментов зон.  
   Появляются названия колонок с описанием для файла импорта и ссылка на скачивание шаблона с примером:

![image](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-06-25%20%D0%B2%2017.50.30.png)

4. Сегмент можно указать в настройках операции или прописать в файле.  
   Второй вариант сложнее, но удобен для импорта зон в разные сегменты одной сегментации.

Рассмотрим оба способа.

Первый способ — указываем сегмент в настройках операции.  
В файле оставляем колонку с внешними идентификаторами (ExternalId) зоны в системе.  
Подготовьте файл с идентификаторами зон, которые вы хотите удалить. Пример есть в шаблоне.  
Идентификатор зон можно найти, [выгрузив зоны](%D0%BA%D0%B0%D0%BA-%D0%B2%D1%8B%D0%B3%D1%80%D1%83%D0%B7%D0%B8%D1%82%D1%8C-%D0%B7%D0%BE%D0%BD%D1%8B.md).

Пример заполненного файла для импорта в сегмент:

![image](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-06-25%20%D0%B2%2018.00.40.png)

В настройках выбираем сегментацию и сегмент, загружаем файл в выбранной в настройке кодировке:

![image](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-06-25%20%D0%B2%2018.01.53.png)

Второй способ — указываем сегмент и сегментацию в файле импорта.  
В файле должны быть колонки:

- ExternalId (внешний идентификатор зон в системе).
- SegmentationExternalId (внешний идентификатор сегментации).
- SegmentExternalId (внешний идентификатор сегмента).

Внешние идентификаторы сегментов смотрим на странице сегментации:

![Снимок экрана 2021-08-25 в 19.29.45.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-08-25%20%D0%B2%2019.29.45.png)

Пример заполненного файла:

![image](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-06-25%20%D0%B2%2018.08.51.png)

В настройках ничего не выбираем, только загружаем файл в нужной кодировке:

![image](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-06-25%20%D0%B2%2018.09.39.png)

5. Добавляем задачу:

![image](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-06-25%20%D0%B2%2018.11.22.png)

Появляется ссылка на неё:

![image](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-06-25%20%D0%B2%2018.12.24.png)

После того, как задача будет выполнена, сегмент с зонами можно использовать при настройке акций:

![image](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-06-25%20%D0%B2%2018.16.21.png)
