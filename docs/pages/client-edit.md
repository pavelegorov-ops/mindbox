# Как редактировать данные клиента в карточке

1. Открываем карточку клиента кликом на ФИО:

![Снимок экрана 2022-06-08 в 19.11.52.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-06-08%20%D0%B2%2019.11.52.png)

2. Нажимаем «Редактировать»:

![Снимок экрана 2022-06-08 в 19.12.23.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-06-08%20%D0%B2%2019.12.23.png)

3. Вносим изменения в данные клиента. Например, меняем email:

![Снимок экрана 2022-06-08 в 19.14.46.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-06-08%20%D0%B2%2019.14.46.png)

4. Нажимаем кнопку «Сохранить»:

![Снимок экрана 2022-06-08 в 19.15.20.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-06-08%20%D0%B2%2019.15.20.png)
