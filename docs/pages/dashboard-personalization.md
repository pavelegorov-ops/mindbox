# Отчет «Персонализация сайта»

Отчет «Персонализация сайта» позволяет отслеживать выручку, которую приносят все запущенные формы на сайте, а также оценивать влияние персонализации на прирост базы контактов.

Отчет расположен в разделе **Аналитика** → **Персонализация сайта**:

![отчет перс.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%BE%D1%82%D1%87%D0%B5%D1%82%20%D0%BF%D0%B5%D1%80%D1%81.png)

## Информационные формы

![Снимок экрана 2023-08-09 в 14.38.43.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-08-09%20%D0%B2%2014.38.43.png)

### Настройка отчета

По умолчанию отчет открывается за последний месяц с разбивкой по дням.

- Интересующий интервал укажите вручную или воспользуйтесь пресетами дат, которые автоматически отберут период за последнюю неделю, месяц или полгода:

![Снимок экрана 2023-08-09 в 13.04.23.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-08-09%20%D0%B2%2013.04.23.png)

Правая дата задается включительно.

- Можно отфильтровать по нужным формам: выбрать только попапы, встроенные формы или виджеты рекомендаций; отобрать формы из конкретной папки или показы на конкретном сайте:

![Снимок экрана 2023-08-09 в 13.15.08.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-08-09%20%D0%B2%2013.15.08.png)

### Показатели

![Снимок экрана 2023-08-09 в 13.12.34.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-08-09%20%D0%B2%2013.12.34.png)

- Выручка — суммарная выручка за выбранный период, атрибутированная к формам.
  - Количество заказов за выбранный период.
- Средний чек — средний чек заказов за выбранный период, атрибутированных к формам.
- Попаданий в таргетинг — количество неуникальных пользователей, попавших под условия таргетинга за выбранный период.
- Доля показов — отношение количества показов к количеству попаданий в таргетинг за выбранный период.
  - Количество неуникальных показов формы за выбранный период.
- CTR — отношение количества кликов к количеству показов за выбранный период.
  - Количество неуникальных кликов за выбранный период.
- Конверсия в заказ — отношение количества заказов, атрибутированных к кликам за выбранный период, к количеству кликов за период.
  - Количество заказов, атрибутированных к кликам за выбранный период.
- Выручка из конверсий — суммарная выручка по заказам, атрибутированным к кликам за выбранный период.
  - Средний чек по заказам из конверсий.

Отмененные и возвращенные позиции не входят в выручку.

## Выгрузить отчет

Нажмите на «Экспорт»:

![Снимок экрана 2023-08-09 в 15.17.56.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-08-09%20%D0%B2%2015.17.56.png)

В CSV-файл будут выгружены поля:

- **date** — начальная дата отрезка (только при выгрузке динамики форм)
- **campaignName** — название формы
- **campaignLink** — ссылка на форму
- **revenue** — выручка
- **orders** — количество заказов
- **targetedVisitors** — попаданий в таргетинг
- **impressionsRate** — доля показов
- **CTR** — доля кликов
- **conversionRate** — конверсия в заказ
- **leadConversionRate** — доля оставивших контакты
- **impressions** — количество показов
- **clicks** — количество кликов
- **conversionOrders** — заказов из конверсий
- **conversionRevenue** — выручка из конверсий
- **averageOrderValue** — средний чек
- **conversionAverageOrderValue** — средний чек из конверсий
- **leads** — оставили контакты
- **startDate** — дата старта
- **endDate** — дата окончания
- **campaignType** — тип механики
  - Pop-up — попап
  - Embedded form — встроенная форма
  - Recommendations widget — виджет рекомендаций
- **category** — тип формы
  - Notification — информационная
  - Lead generation — сбор контактов
- **status** — статус
  - Active — запущена
  - Draft — черновик
  - Disabled — остановлена
  - Deleted — удалена
- **website** — сайт
- **folder** — папка
- **campaignID** — идентификатор формы
