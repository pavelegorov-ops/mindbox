# Как массово удалить клиентов по списку ID

Задача: удалить клиентов из базы по списку Mindbox ID.

1. Переходим в раздел **Данные** → **Клиенты**:

![страница клиентов.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D1%81%D1%82%D1%80%D0%B0%D0%BD%D0%B8%D1%86%D0%B0%20%D0%BA%D0%BB%D0%B8%D0%B5%D0%BD%D1%82%D0%BE%D0%B2.png)

2. В меню справа выбираем «Удалить по файлу»:

![Снимок экрана 2022-06-08 в 20.50.40.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-06-08%20%D0%B2%2020.50.40.png)

3. Выбираем операцию «Полное удаление клиентов из базы» и скачиваем пример шаблона:

![Снимок экрана 2022-06-08 в 21.00.30.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-06-08%20%D0%B2%2021.00.30.png)

4. Заполняем его списком MindboxId удаляемых клиентов:

![Снимок экрана 2021-07-07 в 14.45.52.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-07-07%20%D0%B2%2014.45.52.png)

Подгружаем готовый файл в операцию.

5. Нажимаем «Добавить задачу», чтобы запустить удаление:

![Снимок экрана 2021-07-07 в 14.47.37.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-07-07%20%D0%B2%2014.47.37%282%29.png)

Задача успешно добавлена, посмотрим ее по ссылке:

![Снимок экрана 2021-07-07 в 14.47.53.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-07-07%20%D0%B2%2014.47.53.png)

Дожидаемся выполнения:

![Снимок экрана 2021-07-07 в 14.51.08.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-07-07%20%D0%B2%2014.51.08%281%29.png)
