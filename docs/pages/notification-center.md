# Центр уведомлений в мобильном приложении

**Центр уведомлений (ЦУ)** позволяет пользователям мобильного приложения просматривать отправленные им ранее пуши. Благодаря этому не теряется важная информация, которая может в них быть: промокоды, данные по заказу, сроки акции и т.д.

Чтобы отправленные из Mindbox пуши могли попадать в ЦУ, выполните шаги, описанные [в инструкции](https://developers.mindbox.ru/docs/%D1%86%D0%B5%D0%BD%D1%82%D1%80-%D1%83%D0%B2%D0%B5%D0%B4%D0%BE%D0%BC%D0%BB%D0%B5%D0%BD%D0%B8%D0%B9).

Если основная задача — вывод промокодов, ее можно решить запросом на [доступные для клиента промоакции](https://developers.mindbox.ru/docs/get-promotions-for-customer). Это позволит выводить актуальные на данный момент промокоды **без привязки к ранее полученным коммуникациям**. В таком случае сохранение пушей в ЦУ не понадобится.

## Как выглядит взаимодействие клиента с ЦУ

Можно настроить выдачу клиентам действий при открытии ЦУ и пушей в нем.

Для передачи этих событий в Mindbox нужно создать [операции](https://developers.mindbox.ru/docs/%D1%86%D0%B5%D0%BD%D1%82%D1%80-%D1%83%D0%B2%D0%B5%D0%B4%D0%BE%D0%BC%D0%BB%D0%B5%D0%BD%D0%B8%D0%B9#4-%D0%BF%D0%B5%D1%80%D0%B5%D0%B4%D0%B0%D1%82%D1%8C-%D1%81%D0%BE%D0%B1%D1%8B%D1%82%D0%B8%D1%8F-%D0%B2-mindbox) и настроить их вызов в приложении.

## Как оценить эффективность ЦУ

### Click Rate

Открытие пушей из ЦУ **не попадает в статистику и отчеты Mindbox**. Но, отобрав их с помощью фильтров по действиям, можно вручную рассчитать Click Rate и оценить, как сохранение пушей в ЦУ повлияло на показатель кликабельности рассылки.

- **Click Rate из ЦУ** = (клики по пушу из ЦУ / доставленные сообщения) * 100%
- **Общий Click Rate** = (клики из отчета + клики из ЦУ / доставленные сообщения) * 100%

> Посчитаем на примере рассылки:
>
> ![Снимок экрана 2024-07-31 в 19.01.06.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202024-07-31%20%D0%B2%2019.01.06.png)
>
> Клики по ней из ЦУ:
>
> ![Снимок экрана 2024-07-31 в 19.04.16.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202024-07-31%20%D0%B2%2019.04.16.png)
>
> - Click Rate из ЦУ = (36 / 2160) * 100% = 1.7% — показатель кликабельности для пушей, сохраненных в ЦУ;
> - Общий Click Rate = ((115 + 36) / 2160) * 100% = 7% — показатель кликабельности для рассылки с учетом ЦУ.

По тому же принципу можно рассчитать изменение Click Rate для всего канала без привязки к конкретной рассылке, и оценить пользу от сохранения пушей в ЦУ.

### Конверсия

Чтобы оценить конверсию в целевое действие (заказ / транзакцию и т.д.) для пушей из ЦУ, обратитесь к менеджеру проекта или в поддержку.

Пришлите в запросе:

- Фильтр, отбирающий открытия нужного пуша из ЦУ;
- Интересующий статус целевого действия (например, считаем конверсию только для оформленных заказов).
