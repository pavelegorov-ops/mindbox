# Скидка на продукт по дисконтной карте

Рассмотрим пример, как настраивать промоакцию со следующими условиями:  
при покупке по карте лояльности выделенного ассортимента продуктов на эти позиции можно получить скидку Х%.

Для этого выполним следующие действия:

1. Заходим на страницу редактирования промоакции.

*Подробнее о создании промоакции можно прочитать [здесь](how-to-create-a-discount-promo.md)*.

2. В блоке **Продукты** выбираем сегмент с продуктами, на которые будет действовать скидка.  
   Если сегмент создан, то выбираем его.  
   Если сегмента по продуктам еще нет, то нажимаем на **Создать**:

![Снимок экрана 2021-05-04 в 09.11.32.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-05-04%20%D0%B2%2009.11.32.png)

3. В пункте **применить бенефиты** выбираем **Выдать скидку**, вводим необходимое значение скидки и нажимаем **Сохранить**:

![Снимок экрана 2021-05-04 в 09.16.26.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-05-04%20%D0%B2%2009.16.26.png)

4. Настраиваем остальные условия акции.
5. Нажимаем **Сохранить и выйти** или **Запустить**, для запуска промоакции.

[Арбитраж промоакций](https://mindbox.ru/academy/education/arbitrazh-promoakczij/) — важная функция программы лояльности
