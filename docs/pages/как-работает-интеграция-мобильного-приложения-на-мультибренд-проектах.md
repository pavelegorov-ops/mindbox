# Как работает интеграция мобильного приложения на мультибренд проектах

Интеграция мобильного приложения привязывается к точке интеграции. Точка интеграции привязана к бренду.

Поэтому интеграция на проектах с мультибрендом ничем не отличается от интеграции на обычных проектах.

Если в конфигурации мобильного SDK стоит флаг «подписывать анонимов» ([базовый путь интеграции](%D0%B1%D0%B0%D0%B7%D0%BE%D0%B2%D1%8B%D0%B8-%D0%B8-%D0%BF%D1%80%D0%BE%D0%B4%D0%B2%D0%B8%D0%BD%D1%83%D1%82%D1%8B%D0%B8-%D0%BF%D1%83%D1%82%D0%B8-%D0%B8%D0%BD%D1%82%D0%B5%D0%B3%D1%80%D0%B0%D1%86%D0%B8%D0%B8.md)), то они будут подписаны на канал в том бренде, которому принадлежит точка интеграции

[Интеграция сайта с платформой Mindbox](https://mindbox.ru/academy/education/5-ehtapov-integracii-mindbox/): получение данных с сайта, из мобильного приложения, лендингов, программы лояльности, офлайн-точек, CRM-систем.
