# Как добавить QR-код в рассылку

В рассылку можно добавить QR-код, который шифрует промокод или любые другие данные, ссылку.

**Ситуации, когда может быть полезно:**

- Клиент на кассе показывает промокод в виде QR-кода вместо того, чтобы диктовать
- Клиент открывает письмо на компьютере и по QR-коду переходит на свой заказ с телефона
- Клиент делится промокодом с другом, друг считывает промокод с телефона

### Как создать QR-код

Для генерации QR-кода испольуется [QR Code Generator.](http://goqr.me/api/)

Так выглядит промокод, сгенерированный с его помощью. Попробуйте считать его камерой телефона.

![Снимок экрана 2021-02-03 в 11.21.09.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-02-03%20%D0%B2%2011.21.09.png)

Можете заменить "PROMOCODE1" на любое значение и открыть в браузере ссылку:  
<https://api.qrserver.com/v1/create-qr-code/?size=150x150&data=PROMOCODE1>

### Как добавить QR-код в рассылку

1. Редактируем текст письма в режиме "HTML"

![Снимок экрана 2021-02-03 в 10.45.42.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-02-03%20%D0%B2%2010.45.42%281%29.png)

2. В шаблон письма вставляем картинку, используя блок:

```
<img src="">
```

Источником картинки указываем ссылку на генератор QR-кодов:  
https://api.qrserver.com/v1/create-qr-code/?**size**=150x150&**data**=Текст для кодирования

Указываем параметры в ссылке:

- **size** - размер картинки
- **data** - текст, который кодируем
- дополнительные параметры (цвет qr-кода, цвет фона, отступы) в [документации](http://goqr.me/api/doc/create-qr-code/)

3. Для того, чтобы QR-код формировался динамически, разный под каждого клиента, в **data** записываем параметр из шаблонизатора в виде `${Recipient.LastReceivedPromoCode.WithTypePromoGad.Value}`

```
<img src="https://api.qrserver.com/v1/create-qr-code/?size=150x150&data=${Recipient.LastReceivedPromoCode.WithTypePromoGad.Value}">
```

4. Отправляем тестовое письмо для проверки. Проверяем, как считывается промокод телефоном и кассой, при необходимости.  
   [Пример](https://api.qrserver.com/v1/create-qr-code/?size=150x150&data=PROMOCODE1) сформированного промокода.

**5. Важно: важно дублировать значение QR-кода текстом на маловероятный случай, если промокод не сгенерируется.**

Как считать QR-код

Большинство телефонов автоматически считывают QR-код, если включить камеру и направить на картинку. Для некоторых телефонов требуется установка специального приложения.
