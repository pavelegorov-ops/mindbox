# Что происходит с подписками при объединении клиентов?

Подписки клиентов объединятся. Если в данных о клиентах есть противоречие в подписках, то подписки объединятся на основе приоритетов:

- подписан;
- подписка ожидает подтверждения;
- отписан.

Примеры.  
При объединении у клиентов разный статус подписки на рассылки по email:

- Клиент1 отписан. Клиент2 подписан. Итоговый: подписан.
- Клиент1 подписан. Клиент2 подписка ожидает подтверждения. Итоговый: подписан.
- Клиент 1 отписан. Клиент2 подписка ожидает подтверждения. Итоговый: подписка ожидает подтверждения.
