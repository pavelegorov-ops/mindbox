# Как импортировать точки контакта

**Точка контакта** — это способ связи с клиентом (иногда: место действия), с помощью которого происходит действие.  
Примерами могут быть сайт, магазин, социальная сеть.

Точки контакта могут объединяться в группы (классифицироваться) при помощи каналов. Подробнее о них в статьях по [добавлению](channel-add) и [импорту](channel-import)  каналов.

Точки контакта можно добавить вручную по одному, следуя инструкции из [статьи](point-of-contact-add), или импортировать группой с использованием файла csv.

Для импорта выполните следующие шаги:

1. Откройте раздел **Настройки** → **Клиенты и действия** → **Точки контакта**:

![точки.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D1%82%D0%BE%D1%87%D0%BA%D0%B8.png)

2. Нажмите «Импорт»:

![Снимок экрана 2021-07-13 в 19.15.52.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-07-13%20%D0%B2%2019.15.52.png)

3. Выберите операцию «Импорт точек контакта». После этого для скачивания доступен шаблон с примером:

![Снимок экрана 2021-07-13 в 19.16.59.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-07-13%20%D0%B2%2019.16.59.png)

Рассмотрим поля в файле:

- MindboxID — **для новых указывать не надо — генерируется автоматически**; если указать MindboxID имеющейся точки, его данные будут отредактированы соответственно данным из файла.
- ExternalID — внешний идентификатор — для новых точек указывать обязательно; если указать ExternalID имеющейся точки, её данные будут отредактированы соответственно данным из файла. По нему же автоматически генерируется системное имя (с использованием латинских букв, цифр и дефисов).
- Name — название.
- Comment — справочная информация для вас, чтобы было понятно, для чего точка заводилась; необязательно.
- ParentChannelMindboxId или ParentChannelExternalId — MindboxID или ExternalID родительского канала; один из идентификаторов обязательно должен быть.

**Как определить ParentChannelMindboxId или ParentChannelExternalId?**

Найдите родительский канал в блоке Каналы:

![Снимок экрана 2021-07-13 в 19.30.11.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-07-13%20%D0%B2%2019.30.11.png)

Пример заполненного файла:

![Снимок экрана 2021-07-13 в 19.45.17.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-07-13%20%D0%B2%2019.45.17.png)

4. Заполните настройки импорта:

![Снимок экрана 2021-07-13 в 19.46.13.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-07-13%20%D0%B2%2019.46.13.png)

*Операция:* Импорт точек контакта.  
*Комментарий к задаче:* необязательно, но так будет проще найти в списке задач.  
*Кодировка файла:* по умолчанию — utf-8.  
*Файл для импорта:* подготовленный файл для импорта.

5. Нажмите «Добавить задачу».

Появится сообщение о добавлении задачи с ссылкой на неё:

![Снимок экрана 2021-07-13 в 19.46.25.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-07-13%20%D0%B2%2019.46.25.png)

6. Ждём выполнения:

![Снимок экрана 2021-07-13 в 19.52.34.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-07-13%20%D0%B2%2019.52.34.png)

- После успешного выполнения задачи точки контакта появятся в разделе с данными, указанными в файле:

![Снимок экрана 2021-07-13 в 19.53.07.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-07-13%20%D0%B2%2019.53.07.png)

[Что такое омниканальность](https://mindbox.ru/academy/education/chto-takoe-omnikanalnost/) и для чего нужно объединение разрозненных каналов общения с клиентом в одну систему.
