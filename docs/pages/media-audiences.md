# Как создать связку в Медиа

Задача: настроить передачу сегментов (аудиторий) из Mindbox в рекламные кабинеты.

Перед добавлением связок на проекте уже должны быть [созданы](media-what-is.md) рекламный кабинет и подключение к нужному сервису.

Для передачи сегмента:

1. Перейдите в раздел **Интеграции** → **Медиа**:

   ![медиа — копия.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%BC%D0%B5%D0%B4%D0%B8%D0%B0%C2%A0%E2%80%94%20%D0%BA%D0%BE%D0%BF%D0%B8%D1%8F.png)
2. На вкладке **Мои связки** нажмите «Создать новую связку»

   ![Снимок экрана 2023-05-17 в 17.38.38.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-05-17%20%D0%B2%2017.38.38.png)
3. Можно задать название:

   ![Снимок экрана 2023-05-17 в 18.08.29.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-05-17%20%D0%B2%2018.08.29.png)
4. «Добавьте триггер, который будет запускать связку».

   Задаем, какой сегмент и в каком виде отправляется из Mindbox.

4.1. «Настройте триггер»:

- Сервис — Mindbox.
- Событие — «Выгрузка аудитории».
- Аккаунт Mindbox — точка интеграции для рекламных кабинетов.

![Снимок экрана 2023-05-17 в 17.41.22.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-05-17%20%D0%B2%2017.41.22.png)

Нажмите «Добавить триггер».

4.2 «Режим работы связки».

Всегда — «В реальном времени (Сбор данных текущего периода)»:

![Снимок экрана 2023-05-17 в 17.41.46.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-05-17%20%D0%B2%2017.41.46.png)

Нажмите «Сохранить».

4.3. «Настройте поля»:

- Шифрование данных — в зависимости от выбранного сервиса:
  - VK Реклама, ВКонтакте, MyTarget — MD5;
  - Яндекс Аудитории (MD5 перестанет поддерживаться с января 2025 года), Google AdWords, Facebook* — SHA256;
- Сегменты — выберите, какую аудиторию хотите выгрузить. Доступны [пересчитываемые и статические сегменты](segments-clients.md) по клиентам.

Требования к сегментам Mindbox

- **Максимальный размер аудитории** — один миллион пользователей. Если аудитория больше, ее нужно разделить на несколько сегментов и передавать через отдельные связки.
- **Яндекс.Аудитории.** Минимальный размер сегмента — 100 пользователей.

![Снимок экрана 2023-05-17 в 18.46.44.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-05-17%20%D0%B2%2018.46.44.png)

Нажмите «Сохранить».

Если сегмент не появляется в списке

Сегменты подгружаются в Медиа раз в сутки.  
Чтобы ускорить процесс, можно вручную обновить подключение к рекламному кабинету Mindbox:

![Снимок экрана 2023-05-22 в 13.15.53.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-05-22%20%D0%B2%2013.15.53.png)

Настройка действия варьируется между платформами.

## VK Реклама

1. «Добавьте действие, которое будет происходить после старта связки»:

   ![Снимок экрана 2023-05-22 в 14.15.37.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-05-22%20%D0%B2%2014.15.37.png)

   Задаем, куда и какие данные из сегмента Mindbox передаются в сервис.

5.1. «Добавьте действие»:

- Сервис — VK Реклама.
- Действие — «Изменить данные пользовательской аудитории».
- Аккаунт VK Реклама — созданное для сервиса подключение.
- ID пользовательской аудитории — созданная в VK Рекламе аудитория.
- Операция — «Добавить пользователей».

![Снимок экрана 2023-05-22 в 13.34.10.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-05-22%20%D0%B2%2013.34.10.png)

Если нужна новая аудитория, создайте ее в VK Рекламе:

- В разделе **Аудитории** → **Списки пользователей** нажмите «Загрузить список»:

![Снимок экрана 2023-05-22 в 13.51.31.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-05-22%20%D0%B2%2013.51.31.png)

- На вкладке «Создать новый»:

  - Задайте **название аудитории**.
  - Выберите **тип списка** — можно создать список по мобильным номерам, почтовым адресам или единый. Если выбрать «Единый список», пополнять его можно будет любыми контактами.
  - **Файл списка** — обязательное поле. Необходимо загрузить минимум 100 контактов клиентов. Их можно указывать в открытом виде, при загрузке VK Реклама зашифрует данные автоматически.

  Подробнее о требованиях к списку [в документации VK Реклама](https://ads.vk.com/help/features/audiences_lists/user_lists).

  - Создать аудиторию из списка — отметьте чекбокс.

![Снимок экрана 2023-05-22 в 13.56.07.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-05-22%20%D0%B2%2013.56.07.png)  
* Нажмите «Сохранить».

- Обновите список на странице связки, чтобы аудитория подгрузилась:

![Снимок экрана 2023-05-22 в 14.29.49.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-05-22%20%D0%B2%2014.29.49.png)

5.2. VK Реклама:

- Нужно ли хэшировать данные — да.
- Данные пользовательской аудитории — те, по которым создана аудитория:
  - Телефон — Покупатель-Мобильный телефон
  - Email — Покупатель-Email

![Снимок экрана 2023-05-23 в 10.21.58.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-05-23%20%D0%B2%2010.21.58.png)

Нажмите «Сохранить».

6. Запустите связку:

![Снимок экрана 2023-05-22 в 14.40.26.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-05-22%20%D0%B2%2014.40.26.png)

По умолчанию связка запускается раз в сутки.

## Яндекс.Аудитории

5. «Добавьте действие, которое будет происходить после старта связки»:

![Снимок экрана 2023-05-22 в 14.55.23.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-05-22%20%D0%B2%2014.55.23.png)

Задаем, куда и какие данные из сегмента Mindbox передаются в сервис.

5.1. «Добавьте действие»:

- Сервис — Яндекс.Аудитории.
- Действие — «Изменить данные сегмента».
- Аккаунт Яндекс.Аудитории — выберите созданное для сервиса подключение;
- ID сегмента — созданный в Яндекс.Аудитории сегмент.

![Снимок экрана 2023-05-17 в 20.17.28.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-05-17%20%D0%B2%2020.17.28.png)

Если нужен новый сегмент, создайте его в Яндекс.Аудитории:

- В разделе **Сегменты** нажмите «Создать сегмент» → На основе загружаемых данных — «Данные CRM»:

![Снимок экрана 2023-05-22 в 15.05.08.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-05-22%20%D0%B2%2015.05.08.png)

- В открывшемся окне:
  - Задайте название сегмента.
  - «Хэшированные данные» — отметьте чекбокс.
  - Формат хеширования — MD5 или SHA256
  - Файл — обязательное поле. [Пример файла MD5.](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/YandexMedia.csv) [Пример файла SHA256.](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%9F%D1%80%D0%B8%D0%BC%D0%B5%D1%80%20SHA265.csv)  
    ![яндекс.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D1%8F%D0%BD%D0%B4%D0%B5%D0%BA%D1%81.png)
  - Нажмите «Создать сегмент».

Начиная с января 2025 года загрузка хешей MD5 в Яндекс Аудитории перестанет поддерживаться. Используйте SHA256.

- Обновите список на странице связки, чтобы сегмент подгрузился:

![Снимок экрана 2023-05-22 в 15.18.37.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-05-22%20%D0%B2%2015.18.37.png)

Время обработки сегмента на стороне Яндекс.Аудитории может занять до двух часов — актуальный статус можно увидеть в самом сервисе.  
При этом сегмент можно использовать сразу для создания связки с Mindbox.

5.2. Яндекс.Аудитории:

- Нужно ли хэшировать данные — да.
- Данные пользовательской аудитории — те, по которым создана аудитория:
  - Телефон — Покупатель-Мобильный телефон
  - Email — Покупатель-Email

![Снимок экрана 2023-05-17 в 20.21.53.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-05-17%20%D0%B2%2020.21.53.png)

Нажмите «Сохранить».

6. Запустите связку:

![Снимок экрана 2023-05-22 в 15.29.37.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-05-22%20%D0%B2%2015.29.37.png)

По умолчанию связка запускается раз в сутки.
