# Как создать собственный шаблон формы

Когда не хватает функционала имеющихся шаблонов форм или нужен типовой шаблон в одном стиле, можно создать собственный шаблон и затем переиспользовать его:

![Untitled 2.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/Untitled%20%282%29.png)

### Какие формы можно добавить

Для создания доступны формы информационная и сбор контактов.  
Также формы могут быть [многоэкранными](popup-markdown-screens.md).

#### Форма для сбора контактов

- передает вводимые клиентами данные в mindbox;
- в форме должен быть как минимум 1 экран с полями ввода и кнопкой отправки данных;
- поддерживает экран благодарности;
- отчет показывает, сколько клиентов оставили контакты в форме. Эти данные не атрибутируются к заказам.

[Инструкция](popup-markdown-contacts.md)

#### Информационная форма

- не имеют строгих правил по верстке - нет обязательных элементов;
- не передает вводимые клиентами данные в mindbox;
- отчеты подстраиваются под содержимое верстки:
  - если на форме нет кнопок, то отчет будет показывать только показы этой формы клиентам
  - если в форме есть кнопка с параметром data-popmechanic-submit, то отчет будет содержать данные по кликам. Если на проекте настроена атрибуция к заказам, то отчет может содержать данные по конверсиям в заказ.

[Инструкция](popup-markdown-inform.md)
