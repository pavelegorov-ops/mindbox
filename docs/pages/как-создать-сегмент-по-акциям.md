# Как создать сегмент по акциям

Создать сегмент по промоакции можно через операцию.

По шагам:

1. Перейдите [в создание операции](%D0%BE%D0%BF%D0%B5%D1%80%D0%B0%D1%86%D0%B8%D0%B8-v-%D0%BE%D1%81%D0%BD%D0%BE%D0%B2%D0%BD%D1%8B%D0%B5-%D1%81%D0%B2%D0%B5%D0%B4%D0%B5%D0%BD%D0%B8%D1%8F.md#sozdanie-operacii-v3).
2. Выберите шаг «Экспорт — Выгрузить промоакции» или «Клиент — Получить доступные акции» и при выборе сегмента нажмите на «Создать».

   ![Снимок экрана 2021-11-06 в 00.32.38 — копия.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-11-06%20%D0%B2%2000.32.38%C2%A0%E2%80%94%20%D0%BA%D0%BE%D0%BF%D0%B8%D1%8F.png)
3. Укажите фильтр и характеристики сегмента и нажмите «Сохранить»:

   ![Снимок экрана 2021-11-06 в 00.33.18.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-11-06%20%D0%B2%2000.33.18.png)
4. Редактировать и посмотреть данные по сегменту можно в разделе **Сегментации**. Найти сегменты по акциям можно с помощью фильтра **Сущность** — **Промоакция**:

   ![Снимок экрана 2023-01-15 в 20.03.30.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-01-15%20%D0%B2%2020.03.30.png)

[Ценовые и неценовые промо в ритейле](https://mindbox.ru/academy/education/retail-loyalty-medvedev/), чем плохи массовые скидки и почему персональные промоакции более полезны для бизнеса.
