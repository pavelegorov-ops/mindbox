# Как настроить группировку продуктов в виджете

Задача:  
На главной странице выводить рекомендации с группировкой по основной категории продукта внутри виджета.

![image.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/image%28275%29.png)

1. Создаем виджет рекомендаций из шаблона. Подробнее о создании и настройке виджета рекомендаций в статье [Как создать виджет рекомендаций](recommendation-widget-create.md)
2. Открываем настройки внешнего вида → Группировка рекомендаций

![image.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/image%28269%29.png)

3. Указываем категорию в настройке “Атрибут продукта для группировки” как category

![image.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/image%28270%29.png)

Эта настройка поддерживает следующие поля:

- name - название продукта
- price - цена продукта
- manufacturer.name - поизводитель продукта
- discount - скидка на продукт
- category - основная категория продукта
- customFields.[name], где [name] — системное имя дополнительного поля - любое дополнительное поле продукта, системное имя которого можно посмотреть на странице Интеграции → дополнительные поля

![image.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/image%28272%29.png)

4. Можем указать категории, по которым нужно группировать через запятую. Это поле не чувствительно к регистру. Если не найдется ни одного товара в одной из указанных категорий, то таба просто не отрисуется. Если все товары не подходят ни под одну из указанных категорий, то на сайте будут представлены все категории из указанного атрибута. Например, если есть товары производителей А, Б, В, Г, а в настройке вы указали Д и Е, но на сайте будут присутствовать табы А, Б, В, Г, чтобы виджет не был пустым.

![image.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/image%28271%29.png)

5. Если нужно выводить в отдельных табах только несколько категорий, а остальных показать в общем списке, то можно включить настройку Показать группу Прочее. В нее попадут все продукты, которые не попали в категории, указанные в настройке “По каким значениям группировать". Этой категории можно задать любое имя через настройку "Название группы Прочее".

![image.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/image%28273%29.png)

6. Далее, с помощью настроек отображения можно подобрать стили таб под ваш сайт. Стили, связанные с размерами таб и шрифтов можно настроить отдельно для мобильного вида и ПК переключаясь между видами.
7. Сохраняем изменения внешнего вида и возвращаемся к настройкам виджета

![image.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/image%28274%29.png)

8. Указываем сайт и внешнюю систему продуктов
9. Указываем алгоритм
10. Указываем место, куда хотим поместить виджет
11. Проверяем по тестовой ссылке, что виджет отображается корректно
