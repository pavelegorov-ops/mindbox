# Как подставить баннер с именем в рассылку

Рассылку по клиентам можно персонализировать не только подставлением имени в теме письма или приветствии, но и добавив в письмо красочный баннер, на котором будет личная информация по каждому получателю (имя, количество баллов, данные из дополнительных полей).

Баннер может выглядеть, например, так:

![image](https://lh6.googleusercontent.com/-3aWsxLvs9UjMzFrTLhhcSRN56nkaw6Uvdm9L-2pRl66mpCfZ5R25_GU3rjK5j8s81lo8EAWb9h-PdtOfQm2DxyhHjmsQx0il15WGZ7FS03fFAs62tgD-uLNv2NryrzIUNQecgQU)

## Как сделать?

  

- Зарегистироваться на сайте <https://ux.niftyimages.com/> (бесплатно).

![image](https://lh5.googleusercontent.com/W4Y0FNiCllmrDIZVgwvDM8FlA96_6mnmG_nODErKO01mp99E93kFn1rE4KNOiTcGE2sMJ81xz43Ixu95WQpPx7Q-Pr-L8g3c6T8AwTJB19hgf0jRlIeBDPCTHnU0Z5W98S5kVqo6)

  
* Выбрать первый блок Personalized Image.

![image](https://lh3.googleusercontent.com/miDyCGIvIz7k8p2erkxfO3fcJyGqBeY0nupWqrUevJSLzLtZ-RZ25iN-Sk9bppMkxGaRXhGykGXuhBOhNWzEQcroUGbU9d--Xtup_ABfSSwC79uP6oTOrumuWHzDdfk6F-L8xOWr)

  
* В окно загрузить свой баннер либо выбрать из представленных ниже шаблонов.

![image](https://lh5.googleusercontent.com/ogbKXTc36fbBmubxYfC52sTjhEAlXCJxfuEdVympIQWKDZQfsXfdywdkIs0wGVLR-TSqQlvyQv342ceGNhDqkLTUgPtVQI3FoEyPrP-chNxDXbINTIClb7o0xKBWaFrM5bcsNYeT)

  
* На выбранном баннере можно изменить текст, который будет отображаться на картинке; размер и расположение текстового блока; размер, цвет и расположение самого текста:

![Пример изменения баннера](https://lh4.googleusercontent.com/We13CEaiLKr3_qH-CfN9gcRmWKj3AcTT4i-VXY_cQxNwg6t_FAvWu4uzX7quiMjYBxErgEseb3yJP-fQ8PjGe6BIbuApmwcQ9TfjAI47Ee79hHMGdQ6yMAlmiI4fHYrPF8oisfpq)  
**Пример изменения баннера**  
  
  
Указанный параметр FIRSTNAME здесь не меняем, мы сделаем это далее. В строке Default FIRSTNAME указывается значение, если параметр подстановки данных из системы окажется пустым.

> Например, мы подставляем имя клиента из системы параметром `${Recipient.FirstName}`, но у клиента не заполнено имя, тогда ему будет выведено то обращение, которое будет указано в строке Default FIRSTNAME.

  
* После того, как шаблон с обращением к клиенту готов, нажать кнопку Save и задать имя баннеру.

![image](https://lh4.googleusercontent.com/RHSOXLnCHJyu3_tRHka5VqCBCa6jrtRKJcSFfX1M4QvIWdfUzwgoMf5aXx5RLbuZFdKP_IMIXWn9RsYlLAfYud70XJx8JR20gb_vfl0RRSaS8EGD2jXvjFQ7NU7uS7u6ygyAvSu3)

  
Далее система выведет ссылку на баннер вида:

```
<img src="https://img1.niftyimages.com/aew/f-fo/cxxd?txt=FIRSTNAME"/>
```

![image](https://lh6.googleusercontent.com/TE5ClrEDZR9gKL3VpULmjMTuAG4yEt_S-56yzSpjJDzsvU4beIEFDBQKqwyZs0XPSYD2MVQ-YJd46oHtK7GbHHWAvLOWjG-EkT2h1mV64IZE7SjAQjUr-pBts8B_jel_21WchmDU)

  

- Теперь эту ссылку нужно вставить в конструктор или в HTML-код рассылки и значение FIRSTNAME заменить на необходимый параметр, например, имя клиента `${Recipient.FirstName}`. Получится ссылка такого вида:

```
<img src="https://img1.niftyimages.com/aew/p-fo/4xxd?txt=${Recipient.FirstName}">
```

В этом параметре можно отображать не только имя клиента, но и любые данные, которые можно вывести через Recipient из Шаблонизатора.

![image](https://lh3.googleusercontent.com/cyPitbC5MBKc_3L6ScseaIxa7y4Rh4gmtUn-Tcdls2VlLBCaNjDhWF0XvxI0iVKaSfrdt8j0AnsXwYvYlZ6hhHmED7BmkUhkKQyY4Ya8qw1zokgACQ1Wz8B0gqubw_uu4PiRN2t0)
