# Как выгрузить изменения баланса

Экспорт действий может быть стандартным или пользовательским.  
Стандартный создаётся автоматически и не настраивается.  
В пользовательском экспорте можно выбрать поля и создать свою выгрузку изменений баланса.

---

## Как сделать стандартную выгрузку изменений баланса

1. Выбираем нужные действия на вкладке списка действий:

![Снимок экрана 2022-10-23 в 15.06.33.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-10-23%20%D0%B2%2015.06.33.png)

2. Нажимаем Экспорт → Изменений баланса:

![Снимок экрана 2022-10-23 в 15.06.48.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-10-23%20%D0%B2%2015.06.48.png)

3. Создается задача на экспорт:

![Снимок экрана 2022-10-23 в 15.07.14.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-10-23%20%D0%B2%2015.07.14.png)

4. По ссылке файл и ссылка на операцию экспорта:

![Снимок экрана 2022-10-23 в 15.12.14.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-10-23%20%D0%B2%2015.12.14.png)

#### Какие поля выгружаются при экспорте «Изменений баланса»

- Изменения баланса (балльный счёт, сумма изменения баланса, количество потраченных баллов, комментарий к изменению баланса, дата доступности баланса, дата сгорания баллов, вид изменения баланса, дата совершения действия в UTC);
- валидность контактов и mindbox id клиентов;
- email и телефон в открытом виде;
- идентификаторы клиентов.

![Снимок экрана 2021-02-24 в 19.48.10.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-02-24%20%D0%B2%2019.48.10.png)

## Как создать свою выгрузку действий

Создаём операцию:

1. На вкладке действий нажимаем Экспорт → Добавить экспорт:

![Снимок экрана 2022-10-23 в 15.07.41.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-10-23%20%D0%B2%2015.07.41.png)

2. Настраиваем операцию:

![Снимок экрана 2022-10-23 в 15.20.44.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-10-23%20%D0%B2%2015.20.44.png)

- точка интеграции — Административная панель Mindbox
- шаг **Экспорт** — **Выгрузить историю изменений баллов**
- выбираем данные для экспорта

3. После создания операции и обновления страницы экспорт отразится в интерфейсе Mindbox:

![Снимок экрана 2022-10-23 в 15.22.45.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-10-23%20%D0%B2%2015.22.45.png)

4. Описание колонок файла можно увидеть, если редактировать операцию и нажать «Посмотреть описание»:

![Снимок экрана 2022-10-23 в 15.23.01.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-10-23%20%D0%B2%2015.23.01.png)

#### Детальная настройка данных для выгрузки

1. Доступные форматы:

- CSV
- Json
- Xml

2. Доступные поля:

- персонал;
- данные клиентов:
  - базовая информация (ID в Mindbox, ФИО, дата рождения, пол, дата последнего редактирования, таймзона, подтверждение контактов, валидность контактов, зона)
  - Email и телефон
  - внешние идентификаторы клиентов
  - последняя активированная карта
  - дополнительные поля
