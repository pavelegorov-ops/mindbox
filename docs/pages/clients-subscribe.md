# Как массово подписать/отписать клиентов

Задача: массово подписать или отписать клиентов.

1. На вкладке **Клиенты** нажмите «Импорт» → «Импорт клиентов»:

![Снимок экрана 2022-06-08 в 19.26.45.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-06-08%20%D0%B2%2019.26.45.png)

2. Выберите операцию **Редактирование клиентов**:

![Снимок экрана 2022-09-08 в 22.14.40.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-09-08%20%D0%B2%2022.14.40.png)*Для скачивания доступен шаблон с примером. Также на странице появляются данные по всем возможным полям для загрузки: их название, описание и обязательность с примерами принимаемых форматов.*

3. Подготовьте файл.

Из всех колонок в файле оставьте:

- Колонку с идентификатором. Это может быть Email, MobilePhone, уникальный внешний идентификатор или MindboxID.
- Колонки с подписками, в которые нужно внести изменения. Чтобы подписать ставьте значение **true**, чтобы отписать — **false** .

Например, чтобы подписать клиентов на канал Email, на канал Email в тематике News и на канал SMS, файл нужно оформить следующим образом:

![Снимок экрана 2021-07-11 в 17.28.10.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-07-11%20%D0%B2%2017.28.10.png)

4. Если не нужны [расширенные настройки](clients-subscribe.md#rasshirennye-nastrojki), загрузите файл и поставьте задачу:

![Снимок экрана 2022-09-08 в 22.18.32.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-09-08%20%D0%B2%2022.18.32.png)

- Появится ссылка на неё:

![Снимок экрана 2021-07-11 в 17.33.00.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-07-11%20%D0%B2%2017.33.00.png)

- Дождитесь завершения задачи:

![Снимок экрана 2021-07-11 в 17.39.40.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-07-11%20%D0%B2%2017.39.40.png)

- Если подписки были отредактированы, изменение зафиксируется на вкладке «История изменений»; также клиенту будет выдано действие:

![Снимок экрана 2024-04-09 в 23.44.37.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202024-04-09%20%D0%B2%2023.44.37.png)

![Снимок экрана 2024-04-09 в 23.45.27.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202024-04-09%20%D0%B2%2023.45.27.png)

Инструкция подходит и для подписки клиентов по фильтру.  
Чтобы получить их идентификаторы для файла, постройте фильтр и сделайте выгрузку по [инструкции](standard-export-clients.md).

## Расширенные настройки

Подходит для случаев, когда нужно редактировать клиентов с собственным действием, точкой контакта или временем.

Их можно указать в настройках (сработает для всех в файле) или в файле (значение для каждого клиента будет браться из данных в его строке).

Расширенные настройки:

![Снимок экрана 2023-06-26 в 11.26.17.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-06-26%20%D0%B2%2011.26.17.png)

- Точка интеграции — источник данных. По умолчанию — Административная панель Mindbox.
- Точка контакта. По умолчанию определяться автоматически по точке интеграции. Можно заменить на любую другую.
- Сегментация — статический сегмент, в который будут добавлены все клиенты из файла. Можно выбрать существующий или создать новый.

### Использовать другой шаблон действия

Действие редактирования можно задать только в файле и только с шаблоном категории «Личное действие».  
В остальных случаях изменения клиента сохраняются без записи действия.

Если нужного шаблона ещё нет на проекте, [создайте](template-create.md) его заранее или перейдя по ссылке со страницы импорта.

Указываем в файле с помощью колонки LastUpdateActionTemplate. Вписываются системные имена шаблонов:

![Снимок экрана 2022-09-08 в 22.53.35.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-09-08%20%D0%B2%2022.53.35.png)

### Использовать другую точку контакта

Если нужной точки ещё нет на проекте, [создайте](point-of-contact-add.md) её заранее или перейдя по ссылке со страницы импорта.

**У всех в файле одинаковая точка контакта**  
Выбираем в настройках точку интеграции с нужной точкой или указываем ее явно:

![Снимок экрана 2023-06-26 в 11.37.43.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-06-26%20%D0%B2%2011.37.43.png)

**У клиентов в файле разные точки контакта**  
Указываем в файле с помощью колонки LastUpdatePointOfContact. Вписываются внешние идентификаторы точек:

![Снимок экрана 2022-09-08 в 22.55.37.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-09-08%20%D0%B2%2022.55.37.png)

В настройках снимаем метку «Определять автоматически по точке интеграции» отмечаем пункт «Брать значение из файла»:

![Снимок экрана 2023-06-26 в 11.38.37.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-06-26%20%D0%B2%2011.38.37.png)

### Использовать другое время

Отдельной настройки по времени нет, поэтому можно указать только с помощью колонки LastUpdateDateTime:

![Снимок экрана 2022-09-08 в 22.57.03.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-09-08%20%D0%B2%2022.57.03.png)

Если не включать в файл данный столбец, действия запишутся по времени выполнения задачи редактирования.
