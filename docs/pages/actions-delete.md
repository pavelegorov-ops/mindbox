# Как удалить действия

Для удаления [действий](action) выполним следующие шаги:

1. Переходим в раздел **Действий**:

![страница действий.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D1%81%D1%82%D1%80%D0%B0%D0%BD%D0%B8%D1%86%D0%B0%20%D0%B4%D0%B5%D0%B9%D1%81%D1%82%D0%B2%D0%B8%D0%B9(1).png)

2. Строим фильтр, по которому хотим удалить действия.  
   Например:

![Снимок экрана 2022-10-17 в 16.42.53.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-10-17%20%D0%B2%2016.42.53.png)

3. Выделяем:

![Снимок экрана 2022-10-17 в 16.43.08.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-10-17%20%D0%B2%2016.43.08.png)

4. Кликаем «Удалить»:

![Снимок экрана 2022-10-17 в 16.43.08 — копия.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-10-17%20%D0%B2%2016.43.08%C2%A0%E2%80%94%20%D0%BA%D0%BE%D0%BF%D0%B8%D1%8F.png)

5. Подтверждаем:

![Снимок экрана 2022-10-17 в 16.43.25.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-10-17%20%D0%B2%2016.43.25.png)

6. Появляется ссылка на поставленную задачу:

![Снимок экрана 2022-10-17 в 16.43.35.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-10-17%20%D0%B2%2016.43.35.png)
