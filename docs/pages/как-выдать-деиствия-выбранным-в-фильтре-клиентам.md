# Как выдать действия выбранным в фильтре клиентам

Способ подходит для выдачи действий большому количеству клиентов.  
Чтобы выдать действие одному клиенту, можно воспользоваться [инструкцией](%D0%BA%D0%B0%D0%BA-%D0%B2%D1%8B%D0%B4%D0%B0%D1%82%D1%8C-%D0%B4%D0%B5%D0%B9%D1%81%D1%82%D0%B2%D0%B8%D0%B5-%D0%B2-%D0%BA%D0%B0%D1%80%D1%82%D0%BE%D1%87%D0%BA%D0%B5-%D0%BA%D0%BB%D0%B8%D0%B5%D0%BD%D1%82%D0%B0.md).

Для выдачи доступны действия категории I уровня **«Личные действия клиента»**.

---

1. На вкладке **Клиенты** находим нужных клиентов. Можно построить фильтр:

![Снимок экрана 2022-06-19 в 15.33.37.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-06-19%20%D0%B2%2015.33.37.png)

2. Выбираем клиентов:

![Снимок экрана 2022-06-19 в 15.33.59.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-06-19%20%D0%B2%2015.33.59.png)

Если нужно выбрать случайных клиентов, нажимаем «Случайный выбор» и указываем количество или процент от найденных клиентов.

3. Нажимаем в меню «Выдать действия»:

![Снимок экрана 2022-06-19 в 15.34.24.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-06-19%20%D0%B2%2015.34.24.png)

4. Выбираем шаблон действия (и бренд на многобрендовых проектах) и нажимаем «Добавить»:

![Снимок экрана 2022-06-19 в 15.34.59.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-06-19%20%D0%B2%2015.34.59.png)

Появляется ссылка на задачу:

![Снимок экрана 2022-06-19 в 15.35.09.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-06-19%20%D0%B2%2015.35.09.png)

5. Ждем её завершения:

![Снимок экрана 2022-06-19 в 15.40.44.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-06-19%20%D0%B2%2015.40.44.png)

Действие появляется в карточке клиента на соответствующей вкладке:

![Снимок экрана 2022-06-19 в 15.41.01.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-06-19%20%D0%B2%2015.41.01.png)
