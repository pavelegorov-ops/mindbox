# Тематики рассылок

## Создать тематику

1. Переходим в **Настройки** → **Рассылки** → **Тематики**:

![тематики.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D1%82%D0%B5%D0%BC%D0%B0%D1%82%D0%B8%D0%BA%D0%B8%282%29.png)

2. Нажимаем «Добавить»:

![Снимок экрана 2021-09-22 в 16.55.50.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-09-22%20%D0%B2%2016.55.50.png)

3. Создаем:

![Снимок экрана 2021-09-22 в 16.56.14.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-09-22%20%D0%B2%2016.56.14.png)

- Название — как тематика выглядит в фильтрах, рассылках, операциях.
- Внешний идентификатор — как тематику передавать в интеграциях.

Готово:

![Снимок экрана 2021-09-22 в 16.56.25.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-09-22%20%D0%B2%2016.56.25.png)

При редактировании тематики можно сменить только название тематики

## Удалить тематику

Можно удалить тематики, которые не используются в механиках и не передаются в явном виде по API и в импортах.  
Тематики из завершенных массовых рассылок удалять можно.

1. Уберите [явную](direct-subscription.md) передачу тематики из всех [вызовов по API](operation-logs.md) и импортов.

> Тематика явно используется в импорте → нужно убрать:  
> ![Снимок экрана 2024-08-06 в 10.13.12.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202024-08-06%20%D0%B2%2010.13.12.png)
>
> Тематика неявно используется в импорте → ничего делать не нужно:  
> ![Снимок экрана 2024-08-06 в 10.14.03.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202024-08-06%20%D0%B2%2010.14.03.png)
>
> Тематика явно используется в вызове → нужно убрать:  
> ![Снимок экрана 2024-08-06 в 10.22.39.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202024-08-06%20%D0%B2%2010.22.39.png)
>
> Тематика неявно используется в вызове → ничего делать не нужно:  
> ![Снимок экрана 2024-08-06 в 10.23.58.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202024-08-06%20%D0%B2%2010.23.58.png)

2. В разделе **Настройки** → **Рассылки** → **Тематики** выделите нужные тематики и нажмите «Удалить»:

![Снимок экрана 2024-08-06 в 10.29.14.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202024-08-06%20%D0%B2%2010.29.14.png)

- При отсутствии блокеров удаления появится сообщение:

![Снимок экрана 2024-08-06 в 10.30.30.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202024-08-06%20%D0%B2%2010.30.30.png)

- Если тематика связана с механиками, появится валидация и список кампаний, из которых ее нужно убрать:

![Снимок экрана 2024-08-06 в 10.29.52.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202024-08-06%20%D0%B2%2010.29.52.png)

После удаления:

- Клиенты автоматически отписываются от тематики, а сама она скрывается из дерева подписок и отчётов;
- В истории изменений и завершённых рассылках название тематики останется + добавится пометка «(удалено)»:

![Снимок экрана 2024-08-06 в 10.53.10.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202024-08-06%20%D0%B2%2010.53.10.png)

- При копировании рассылки с удалённой тематикой отредактировать её не получится.
