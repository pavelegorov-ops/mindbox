# Как добавить клиента через интерфейс

Задача: добавить на проект одного клиента вручную.

1. Заходим в раздел **Данные → Клиенты**:

![кл1.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%BA%D0%BB1%281%29.png)

2. Нажимаем «Добавить» в меню справа:

![кл2.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%BA%D0%BB2.png)

3. Заполняем поля:

   - **Идентификаторы** — как минимум один надо указать:

![ид.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%B8%D0%B4.png)

- **Персональные данные** — необязательно:

![перс.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%BF%D0%B5%D1%80%D1%81.png)

- **Подписки** — по умолчанию у клиента нет данных о подписке. Можно выбрать статус подписки в выпадающем списке:

![подп.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%BF%D0%BE%D0%B4%D0%BF.png)

- **[Дополнительные поля](additional-data.md)** — необязательно:

![доп.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%B4%D0%BE%D0%BF.png)

4. Нажимаем «Создать»:

![создать.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D1%81%D0%BE%D0%B7%D0%B4%D0%B0%D1%82%D1%8C.png)

Готово:

![готово.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%B3%D0%BE%D1%82%D0%BE%D0%B2%D0%BE.png)
