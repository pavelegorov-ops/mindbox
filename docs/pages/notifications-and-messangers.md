# Уведомления и мессенджеры

Модуль **«Уведомления и мессенджеры»** позволяет настраивать и отправлять сообщения клиентам в дополнительных каналах: мессенджерах и сервисах (например, «Кошелёк»). Всё это можно делать прямо из интерфейса Mindbox.

Чтобы начать работу, [подключите модуль](billing-modules.md#vklyuchit-i-vyklyuchit-modul) в разделе «Подписка и оплата».

## Преимущества

- **Без кода.** Настраивайте отправку сообщений в удобном интерфейсе.
- **Аналитика.** Собирайте клики из кампаний для отслеживания эффективности.
- **Гибкость.** Отправляйте уведомления даже в каналы, которые не требуют подписки (например, личный кабинет)

## Доступные каналы

- [Кошелёк](https://koshelek.app/)
- [OSMICards](https://osmicards.com/)
- WhatsApp (через стронних провайдеров)
- Telegram (через стронних провайдеров)

Следите за новостями — список каналов будет расширяться.

## Как начать пользоваться

У каждого канала и провайдера есть свои особенности. Подробные инструкции:

- [Как отправить рассылку в Telegram через Fasttrack](https://help.mindbox.ru/docs/telegram)
- [Как отправить рассылку в WhatsApp через Fasttrack](https://help.mindbox.ru/docs/whatsapp)
- [Как отправить рассылку в WhatsApp через Wazzup24](https://help.mindbox.ru/docs/wazzup)

## Аналитика

Чтобы оценивать эффективность рассылок, отслеживайте клики с помощью [сокращателя ссылок](shorten-url-sms.md) и [настраивайте UTM-метки](utm-tags.md).
