# Статусы отправки рассылок

Каждый этап взаимодействия клиента с рассылкой фиксируется в виде соответствующего статуса.

У рассылки могут быть следующие статусы, идущие друг за другом:

- **Участие в рассылке** — *Письмо сформировано. Не означает отправку.*
  - **Неотправка** — *Письмо не смогло отправиться из Mindbox.*
  - **Отправка** — *Письмо отправлено из Mindbox на почтовый сервер.*
    - **Не доставлено** — Письмо отправлено, но не принято почтовым сервером.
    - **Открытие** — *Письмо открыто.*
      - **Клик** — *Клиент кликнул по ссылке в письме.*
      - **Запрос отписки** — *Клиент кликнул по ссылке [отписки](how-to-unsubscribe.md) в письме.*

![Снимок экрана 2024-08-06 в 17.12.49.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202024-08-06%20%D0%B2%2017.12.49.png)

Особенности каналов

- **Открытия** приходят только в email и WebPush
- **Запрос отписки** — только в email

> Клиент, который кликнул в email-рассылке, будет иметь статусы по этой рассылке: участие, отправка, открытие, клик:  
> ![Снимок экрана 2024-08-06 в 18.59.53.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202024-08-06%20%D0%B2%2018.59.53.png)  
> У клиента, которому не удалось доставить мобильный пуш, будут статусы по этой рассылке: участие, отправка, недоставка:

![Снимок экрана 2024-08-06 в 19.05.14.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202024-08-06%20%D0%B2%2019.05.14.png)

Все статусы по всем рассылкам хранятся на вкладке **Данные** → **Статусы рассылок**:

![Снимок экрана 2024-08-06 в 19.15.18.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202024-08-06%20%D0%B2%2019.15.18.png)

Клиентов можно найти по любому из имеющихся статусов в истории:

- [Найти клиентов, которые взаимодействовали с рассылкой](filter-clients-mailing.md)
- [Найти клиентов, которые взаимодействовали с рассылками](filter-clients-mailings-open.md)
