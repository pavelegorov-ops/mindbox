# Как выгрузить заказы

Экспорт заказов может быть стандартным или пользовательским.  
Стандартный создаётся автоматически и не настраивается.  
В пользовательском экспорте можно выбрать поля и создать свою выгрузку заказов.

---

## Как сделать стандартную выгрузку заказов

1. Выбираем нужные действия на вкладке списка действий:

![Снимок экрана 2022-10-19 в 02.23.51.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-10-19%20%D0%B2%2002.23.51.png)

2. Нажимаем **Экспорт** → **Заказов**:

![Снимок экрана 2022-10-19 в 02.24.06.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-10-19%20%D0%B2%2002.24.06.png)

3. Ставится задача на экспорт:

![Снимок экрана 2022-10-19 в 02.24.39.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-10-19%20%D0%B2%2002.24.39.png)

4. По ссылке получаем задачу с файлом:

![Снимок экрана 2022-10-19 в 02.37.01.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-10-19%20%D0%B2%2002.37.01.png)

#### Какие поля выгружаются при экспорте «Заказов»

- базовая информация (ID в Mindbox, первое действие, зона, стоимость доставки, стоимость заказа с учетом скидок);
- дополнительные поля заказа;
- дополнительные поля позиции заказа;
- валидность контактов;
- email и телефон;
- идентификаторы клиента.

![Снимок экрана 2023-03-17 в 07.17.33.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-03-17%20%D0%B2%2007.17.33.png)

## Как создать свою выгрузку заказов

Создаём операцию:

1. На вкладке действий нажимаем Экспорт → Добавить экспорт:

![Снимок экрана 2022-10-19 в 02.24.55.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-10-19%20%D0%B2%2002.24.55.png)

2. Настраиваем операцию:

![Снимок экрана 2022-10-19 в 02.33.19.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-10-19%20%D0%B2%2002.33.19.png)

- точка интеграции — Административная панель Mindbox
- шаг **Экспорт** — **Выгрузить заказы и позиции заказов**
- выбираем данные для экспорта

3. После создания операции, экспорт отразится в интерфейсе Mindbox:

![Снимок экрана 2022-10-19 в 02.26.41.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-10-19%20%D0%B2%2002.26.41.png)

4. Описание колонок файла можно увидеть, если редактировать операцию и нажать «Посмотреть описание»:

![Снимок экрана 2022-10-19 в 02.26.15.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-10-19%20%D0%B2%2002.26.15.png)

#### Детальная настройка данных для выгрузки

1. Доступные форматы:

- csv
- JSON
- XML

2. Доступные поля:

- базовая информация (ID в Mindbox, первое действие, зона, стоимость доставки, стоимость заказа с учетом скидок);
- дополнительные поля заказа
- дополнительные поля позиции заказа
- рассылка, к которой атрибутирован заказ:
  - id кампании (ID в Mindbox)
  - Тип кампании (пока доступен только тип Mailing)
  - Имя кампании (название кампании в Mindbox)
  - Тип действия (действие, к которому происходит атрибуция - пока только тип Click)
- данные клиентов:
  - базовая информация (ID в Mindbox, ФИО, дата рождения, пол, дата последнего редактирования, таймзона, подтверждение контактов, валидность контактов, зона)
  - Email и телефон
  - внешние идентификаторы клиентов
  - последняя активированная карта
  - дополнительные поля
