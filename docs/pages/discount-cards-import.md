# Как массово импортировать дисконтные карты

Для импорта дисконтных карт выполните следующие шаги:

1. Перейдите в **Настройки** → **Клиенты и действия** → **Дисконтные карты**:

![диск карты.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%B4%D0%B8%D1%81%D0%BA%20%D0%BA%D0%B0%D1%80%D1%82%D1%8B.png)

2. Нажмите **Импорт, открепление и удаление**:

![Снимок экрана 2021-04-30 в 10.17.32 — копия.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-04-30%20%D0%B2%2010.17.32%C2%A0%E2%80%94%20%D0%BA%D0%BE%D0%BF%D0%B8%D1%8F.png)

3. Скачайте шаблон файла с примером:

![Снимок экрана 2021-04-30 в 10.19.44.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-04-30%20%D0%B2%2010.19.44%281%29.png)

4. Заполните файл:

![Снимок экрана 2021-04-30 в 10.23.36.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-04-30%20%D0%B2%2010.23.36.png)

- *номер (Number) — обязательно;*
- *[тип](discount-card-types.md) (Type) — необязательно.*

5. В форме заполните все поля, загрузите файл и добавьте задачу:

![Снимок экрана 2021-04-30 в 10.24.16.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-04-30%20%D0%B2%2010.24.16.png)

6. Появится ссылка на задачу:

![Снимок экрана 2021-04-30 в 10.24.38.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-04-30%20%D0%B2%2010.24.38.png)

7. После завершения задачи карты добавлены на проект:

![Снимок экрана 2021-04-30 в 10.25.09.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-04-30%20%D0%B2%2010.25.09.png)
