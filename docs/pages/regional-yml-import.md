# Как настроить импорт регионального продуктового фида

С августа 2025 года в системе перестанут создаваться задачи на импорт продуктов.

**Как было раньше**: после добавления фида на проект, а также раз в указанный интервал — в системе запускалась задача по импорту продуктов из фида, если в нем было изменение данных после предыдущего импорта. В задачах к скачиванию были доступны: исходный файл и файл с результатом работы.

**Как будет работать сейчас**: задачи на импорт данных из фида не создаются. Логика обновления данных осталась прежней. История обновления фида доступна на его странице. [Подробнее](yml-import.md#istoriya-obnovleniya-fida).

Для начала на проект должны быть добавлены [зоны](areas-import.md).

## Добавление регионального фида

1. Переходим на вкладку **Интеграции**. Нажимаем «Добавить интеграцию»:

![feed-newintegrations.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/feed-newintegrations.png)

Выбираем пресет «Продуктовые фиды»:

![feed-integration-choose-preset.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/feed-integration-choose-preset.png)

Альтернативный способ поиска

На вкладке **Продукты** нажимаем «Импорт» → «Добавить продуктовый фид».

![feed-add-products.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/feed-add-products.png)

2. Заполняем поля на странице:

![regional-feed-fields.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/regional-feed-fields.png)

Задаем название. При необходимости можно переименовать фид и после его добавления.

**Обязательные для заполнения поля:**

- **Тип фида** — YML/Google. По умолчанию выбран YML ([Yandex Market Language](https://yandex.ru/support/marketplace/ru/assortment/auto/yml)), поскольку он чаще всего используется в странах СНГ.
- **Внешняя система** — система, из которой к нам поступают данные.
- **Бренд** — актуально для [мультибрендовых](multibrand.md) проектов. Выберите бренд, для которого нужно загрузить информацию по продуктам.
- **URL** — адрес файла.
- **Обновлять каждые n часов** — интервал, с которым система скачивает файл с информацией из фида и при необходимости обновляет данные по продуктам по информации из файла. После добавления фида загрузка данных начнется сразу, далее — с выбранной периодичностью. [Подробнее про алгоритм обновления](yml-import.md#kak-proishodit-obnovlenie-dannyh-po-produktam).

Если указать число, кратное 12, появится возможность указать конкретное время, в которое необходимо обновлять данные.

**Необязательные поля:**

- **Региональная зона** — выберите зону, по которой нужно загрузить фид. Технически поле является необязательным, но если вы настраиваете импорт регионального фида, нужно выбрать зону. Иначе фид не будет считаться региональным.
- **Начать обновление** — при необходимости укажите определенное время, когда необходимо обновлять данные. После добавления фида загрузка данных начнется сразу, далее обновление будет происходить в выбранное время.
- **Данные авторизации** — заполняется, если загружаемый файл находится под паролем. Для добавления фидов, находящихся под паролем, необходима [пермиссия]((/docs/permissions)) «Управление секретными данными».

3. Нажимаем «Добавить». После этого фид отобразится на странице **Интеграции во вкладке** «Продуктовые фиды»:

![regional-feed-integration.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/regional-feed-integration.png)

4. Проверяем состояние загрузки фида на странице **Мониторинг интеграций → Продуктовые фиды**.

![monitoring-product-regional-feed.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/monitoring-product-regional-feed.png)

## Особенности региональных фидов

- В региональных фидах не обрабатываются поля: vendorCode (артикул), shelfLife (срок годности в днях), categories (внешние идентификаторы категорий продукта), groupId (идентификатор группы продуктов).
- Для клиентов с заполненной зоной система в первую очередь ориентируется на региональные данные о продукте в зоне клиента: при формировании рекомендаций, выводе информации по продукту параметрами шаблонизатора, запуске сценариев с событиями по изменению продукта. Если у клиента не указана зона или региональные данные по продукту в зоне клиента отсутствуют — система использует данные из *мастер-фида*.
- Если продукт указан и в мастер-фиде, и в региональном, система дополнит карточку продукта региональными данными. Но в случаях, когда продукт указан только в региональном фиде, будет создана новая карточка продукта на основе региональных данных. При этом на странице продукта не будет выпадающего списка с выбором зоны. Когда информация по продукту появится в *мастер-фиде*, региональные данные перейдут на страницу продукта в нужной зоне.
  > *Информация по продукту содержится только в региональном фиде:*  
  > ![regionalfeed-productcard.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/regionalfeed-productcard.png)  
  > *Информация по продукту есть и в мастер-фиде, и в региональном:*  
  > ![regionalfeed-productcard-2.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/regionalfeed-productcard-2.png)

Мастер-фид — фид без зоны
