# Список IP Mindbox

Чтобы письма Mindbox, отправленные на корпоративные адреса, проходили через спам-фильтры и доставлялись получателям, нужно ввести IP-адреса Mindbox в список разрешенных IP почтового сервера.

Для просмотра актуального списка:

1. Перейдите на сайт [https://mxtoolbox.com](https://mxtoolbox.com/SuperTool.aspx?action=mx:&run=toolpage)
2. Выберите режим **SPF Record Lookup**
3. Вставьте в поле ввода **spf.mindbox.ru**
4. Нажмите Enter.
