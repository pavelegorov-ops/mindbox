# Как удалить дополнительное поле

Чтобы удалить дополнительное поле:

1. Перейдите в раздел **Настройки** → **Системные** → **Дополнительные поля**:

![custom-field-menu.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/custom-field-menu.png)

2. Проверьте, используется ли удаляемое поле в кампаниях:

![custom-field-use.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/custom-field-use.png)  
![custom-field-uses.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/custom-field-uses.png)

Нужно убрать поле из связанных механик.

3. Нажмите «Удалить»:

![custom-field-delete.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/custom-field-delete.png)

Если поле осталось в механиках, появляется валидация:

![custom-field-val.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/custom-field-val.png)

Если валидация успешно пройдена, поле удаляется:

![custom-field-no-val.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/custom-field-no-val.png)
