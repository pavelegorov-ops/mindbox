# Как создать точку контакта

**Точка контакта** — это способ связи с потребителем (иногда: место действия), с помощью которого происходит действие.  
Примерами могут быть сайт, магазин, социальная сеть.

Точки контакта могут объединяться в группы (классифицироваться) при помощи каналов. Подробнее о них в статьях по [добавлению](channel-add) и [импорту](channel-import) каналов.

Точки контакта можно добавить вручную по одному, следуя данной инструкции, или импортировать группой с использованием файла csv по [инструкции](point-of-contact-import).

Для добавления точки контакта через интерфейс выполняем следующие шаги:

1. Открываем страницу **Настройки** → **Клиенты и действия** → **Точки контакта**:

![точки.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D1%82%D0%BE%D1%87%D0%BA%D0%B8.png)

2. Нажимаем на «Добавить»:

![Снимок экрана 2021-07-13 в 19.15.52 — копия.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-07-13%20%D0%B2%2019.15.52%C2%A0%E2%80%94%20%D0%BA%D0%BE%D0%BF%D0%B8%D1%8F.png)

3. Заполняем поля:

![Снимок экрана 2021-07-13 в 19.57.38.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-07-13%20%D0%B2%2019.57.38.png)

- Внешний идентификатор — то, как будет передаваться точка контакта при вызове операций, импорте, сервисах.
- Название — имя, по которому точку контакта можно найти в фильтрах.
- Системное имя — как точка контакта записывается в базе проекта.
- Системная точка контакта — точку контакта нельзя будет удалить.
- В каком случае будет использоваться — справочная информация для вас, чтобы было понятно, для чего точка заводилась.
- Канал — важно для поиска и отчетов, важно выбрать в соответствии с требованиями.

4. Нажимаем на кнопку «Добавить» и видим сообщение об успешно добавленной точке контакта:

![Снимок экрана 2021-07-13 в 19.57.59.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-07-13%20%D0%B2%2019.57.59.png)

[Что такое омниканальность](https://mindbox.ru/academy/education/chto-takoe-omnikanalnost/) и для чего нужно объединение разрозненных каналов общения с клиентом в одну систему.
