# Параметры для механики «Брошенная корзина»

В данной статье разберём вывод продуктов, добавленных в последней сессии. Для вывода товаров из списка клиента без привязки к сессии смотрите [статью](параметры-для-вывода-товаров-из-списка-продуктов).

## Каким параметром обратиться к добавленным в сессии продуктам

#### Session.GetAddedToListProducts("Korzina").Take(N)

Korzina - системное имя вашего списка

![Снимок экрана 2021-04-30 в 13.49.25.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-04-30%20%D0%B2%2013.49.25.png)

- Такой [параметр](что-такое-шаблонизатор) является коллекцией и доступен только в определённых автоматических письмах. Подходящие события сценариев перечислены в разделе "Доступность" (см. скрин выше).
- Для обращения к каждому элементу (продукту в списке) используйте цикл [for...end for](как-работать-с-элементами-коллекции-с-помощью-цикла-for-end-for-и-set):

```
@{for item in Session.GetAddedToListProducts("Korzina").Take(5)}
    Цена продукта: ${item.Price}
    Название: ${item.Name}
@{end for}
```

- При использовании вывода через [товарную сетку](how-to-display-data-as-a-table):

```
@{for row in tableRows (Session.GetAddedToListProducts("Korzina").Take(6), 2)}
    @{for cell in row.Cells}
        @{if cell.Value != null}
            Цена продукта: ${cell.Value.Price}
            Название: ${cell.Value.Name}
        @{end if}
    @{end for}
@{end for}
```

- Чтобы отобрать продукты только из определенного сегмента, добавьте функцию FilterBySegment, например: **Session.GetAddedToListProducts("Korzina").FilterBySegment("VNalichii").Take(N)**

В новом конструкторе можно настроить вывод корзины без использования параметров и кода — [инструкция](email-editor-added-products-in-session.md).
