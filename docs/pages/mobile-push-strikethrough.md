# Как добавить зачеркнутый текст в мобильный пуш

**Задача**: вывести в мобильном пуше зачеркнутый текст.

**Решение**: воспользуйтесь сервисами [https://yaytext.com](https://yaytext.com/) или [https://saijogeorge.com](https://saijogeorge.com/strikethrough-text-generator/) для генерации текста и вставьте его в пуш:

![Снимок экрана 2021-05-17 в 15.16.22.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-05-17%20%D0%B2%2015.16.22.png)

Вывести зачернутым значение параметра нельзя

То есть $̶{̶P̶r̶o̶d̶u̶c̶t̶.̶O̶l̶d̶P̶r̶i̶c̶e̶}̶ выведет именно этот текст, а не зачеркнутую старую цену.
