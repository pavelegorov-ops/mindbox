# Как выгрузить действия

Экспорт действий может быть стандартным или пользовательским.  
Стандартный создаётся автоматически и не настраивается.  
В пользовательском экспорте можно выбрать поля и создать свою выгрузку.

---

## Как сделать стандартную выгрузку действий

1. Выбираем нужные действия на вкладке списка действий:

![Снимок экрана 2022-10-18 в 11.51.07.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-10-18%20%D0%B2%2011.51.07.png)

2. Нажимаем **Экспорт** → **Действий**:

![Снимок экрана 2022-10-18 в 11.51.26.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-10-18%20%D0%B2%2011.51.26.png)

3. Создается задача на экспорт:

![Снимок экрана 2022-10-18 в 11.52.25.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-10-18%20%D0%B2%2011.52.25.png)

4. По ссылке файл с данными и информация об экспорте:

- ссылка на операцию экспорта;
- фильтр, по которому был поставлен экспорт:

![Снимок экрана 2022-10-18 в 11.52.45.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-10-18%20%D0%B2%2011.52.45.png)

#### Какие поля выгружаются в экспорте «Действий»

- Базовая информация (Id в Mindbox, Шаблон действия, Дата и время, дата и время создания в системе, бренд, точка контакта);
- все дополнительные поля действий;
- id клиента в mindbox;
- внешние идентификаторы клиента.

![export-actions-operation.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/export-actions-operation.png)

## Как создать свою выгрузку действий

Создаём операцию:

1. На вкладке действий нажимаем **Экспорт** → **Добавить экспорт**:

![свой экспорт.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D1%81%D0%B2%D0%BE%D0%B9%20%D1%8D%D0%BA%D1%81%D0%BF%D0%BE%D1%80%D1%82.png)

2. Настраиваем операцию:

![Снимок экрана 2022-10-18 в 12.18.47.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-10-18%20%D0%B2%2012.18.47.png)

- точка интеграции — Административная панель Mindbox
- шаг **Экспорт** — Выгрузить действия клиентов
- выбираем данные для экспорта

3. После создания операции, экспорт отразится в интерфейсе Mindbox:

![Снимок экрана 2022-10-18 в 12.19.55.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-10-18%20%D0%B2%2012.19.55.png)

4. Описание колонок файла можно увидеть, если редактировать операцию и нажать «Посмотреть описание»:

![Снимок экрана 2022-10-18 в 12.19.11.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-10-18%20%D0%B2%2012.19.11.png)

#### Детальная настройка данных для выгрузки

1. Доступные форматы:

- CSV
- Json
- Xml

2. Доступные поля:

- базовая информация (Id в Mindbox, Шаблон действия, Дата и время, дата и время создания в системе, бренд, точка контакта);
- связанные продукты и категории продуктов;
- дополнительные поля действий;
- состояние заказа:
  - базовая информация (ID в Mindbox, первое действие, зона, идентификатор транзакции, стоимость доставки, стоимость заказа с учетом скидок);
  - дополнительные поля заказа
  - дополнительные поля позиции заказа
- связанное объединение клиентов;
- статус дисконтной карты;
- персонал;
- связанные клиенты;
- данные клиентов:
  - базовая информация (ID в Mindbox, ФИО, дата рождения, пол, дата последнего редактирования, таймзона, подтверждение контактов, валидность контактов, зона)
  - Email и телефон
  - внешние идентификаторы клиентов
  - последняя активированная карта
  - дополнительные поля
