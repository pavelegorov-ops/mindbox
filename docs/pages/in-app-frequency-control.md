# Как ограничить частоту показа In-App для клиентов

Показ нескольких In-App доступен только для пользователей с приложением с версией SDK 2.14.0 и выше. Если версия SDK ниже, то клиент по умолчанию может увидеть лишь одну форму за сессию.

Узнать версию SDK в приложении вы можете у своей команды мобильной разработки.

Показ чрезмерного количества уведомлений может перегружать пользователя и вызывать негативное мнение о приложении и компании. Если на вашем проекте используется версия SDK выше 2.14.0 и вы активно иcпользуете In-App, рекомендуем настроить «Контроль частоты In-App».

## Как включить настройку

Перейдите в раздел **Настройки** → **Оптимизация коммуникаций → Контроль частоты In-App**:

![in-app-frequency-control-path.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/in-app-frequency-control-path.png)

Контроль частоты применяется для каждого пользователя в соответствии с указанными настройками. Чтобы изменить показатели, включите настройку.

Доступные следующие ограничения на пользователя:

- Максимальное количество In-App в [сессию](%D0%BF%D1%80%D0%BE-%D1%81%D0%B5%D1%81%D1%81%D0%B8%D1%8E-%D0%BF%D0%BE%D1%87%D0%B5%D0%BC%D1%83-%D1%83-%D0%BA%D0%BB%D0%B8%D0%B5%D0%BD%D1%82%D0%B0-%D0%B5%D1%81%D1%82%D1%8C-%D0%B4%D0%B5%D0%B9%D1%81%D1%82%D0%B2%D0%B8%D1%8F-%D0%BA%D0%BE%D1%82%D0%BE%D1%80%D1%8B%D0%B9-%D1%81%D0%BB%D1%83%D1%87%D0%B8%D0%BB%D0%B8%D1%81%D1%8C-%D0%B4%D0%BE-%D0%B5%D0%B3%D0%BE-%D0%BF%D0%BE%D1%8F%D0%B2%D0%BB%D0%B5%D0%BD%D0%B8%D1%8F-%D0%B2-%D0%B1%D0%B0%D0%B7%D0%B5.md).
- Максимальное количество In-App в сутки.
- Минимальный интервал между In-App (в секундах, минутах, часах или днях). Интервал считается с момента, когда пользователь закрыл показанную форму до всплывания следующей.

Если In-App не успел показаться из-за настроек интервала, то он покажется только тогда, когда клиент снова попадет под его условия и таргетинг.

Когда настройки готовы, нажмите на кнопку **«Сохранить»**:

![in-app-frequency-control-save.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/in-app-frequency-control-save.png)

Если конкретный In-App должен отобразиться, несмотря на настройки контроля частоты (например для проведения важной акции), отметьте его приоритетным в «Общих настройках» In-App.

![in-app-frequency-control-priority.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/in-app-frequency-control-priority.png)
