# Как сгенерировать промокоды для пула

При создании пула промокодов можно выбрать способ его пополнения. Заливка промокодов и ручное добавление описаны [в статье](как-добавить-промокоды-в-проект) про создание пула.

Рассмотрим другой способ добавления промокодов — генерирование.

- Создайте пул по инструкции выше. Разница — в блоке «Промокоды».
- Выберите способ пополнения пула — *сгенерировать промокоды*.
- Система предложит выбрать формат промокодов. Можно выбрать существующий или создать новый:

![Снимок экрана 2021-05-09 в 18.10.34.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-05-09%20%D0%B2%2018.10.34.png)

- Создать формат кодов можно [по инструкции](как-создать-формат-набор-промокодов-для-генерации). А пока — выберите уже созданный формат и количество промокодов.

**Количество** - столько промокодов будет сгенерировано текущей задачей.  
**Доступное количество кодов для генерации** - столько кодов доступно для генерации из выбранного набора.

Можно поставить галочку *«Догенерировать промокоды, если они закончились»* , если это нужно по бизнес-цели. Тогда после выдачи последнего кода из пула произойдет автоматическая генерирация.

- Нажмите *«Сохранить и сгенерировать»* .

Появляется новая задача загрузки промокодов в пул. Сначала в статусе «ожидает выполнения», потом — с результатом выполнения:

![Снимок экрана 2021-05-09 в 18.15.59.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-05-09%20%D0%B2%2018.15.59.png)

Готово. Сохраните блок «Промокоды».

[Чем полезны промокоды](https://mindbox.ru/academy/education/kak-primenyat-promokody/): собирают и обогащают клиентскую базу, стимулируют совершить целевое действие, персонализируют скидки.
