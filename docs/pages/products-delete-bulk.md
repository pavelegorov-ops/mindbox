# Как удалить продукты по файлу

Ограничения

Нельзя удалить продукты со связанными заказами или действиями.

Поэтому перед постановкой задачи может понадобиться их [удалить](actions-delete.md).

---

Чтобы удалить продукты:

1. Перейдите в раздел **Данные** → **Продукты**:

![Снимок экрана 2021-08-24 в 14.37.32.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-08-24%20%D0%B2%2014.37.32.png)

2. В меню страницы нажмите «Удалить продукты»:

![Снимок экрана 2023-03-06 в 23.12.03.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-03-06%20%D0%B2%2023.12.03.png)

3. Выберите операцию «Удаление продуктов». Для скачивания доступен шаблон файла с примером:

![Снимок экрана 2023-03-07 в 06.07.31.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-03-07%20%D0%B2%2006.07.31.png)

4. Заполните файл.

В файл нужно добавить столбец со списком удаляемых продуктов. Для идентификации можно использовать как MindboxId, так и идентификаторы во внешних системах.

Пример:

![Снимок экрана 2023-03-07 в 06.16.22.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-03-07%20%D0%B2%2006.16.22.png)

Подгрузите файл в операцию.

5. Нажимите «Добавить задачу»:

![Снимок экрана 2023-03-07 в 06.16.57.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-03-07%20%D0%B2%2006.16.57.png)

- Появляется ссылка на нее:

![Снимок экрана 2023-03-07 в 06.17.09.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-03-07%20%D0%B2%2006.17.09.png)

- После успешного завершения задачи продукты удалены:

![Снимок экрана 2023-03-07 в 06.21.19.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-03-07%20%D0%B2%2006.21.19.png)
