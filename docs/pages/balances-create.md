# Как создать балльный счет

Балльные счета содержат набор правил хранения и обработки бонусных баллов.  
В системе поддерживается ведение множества балльных счетов, что позволяет реализовать различные настройки хранения и обработки бонусных баллов. Например, если у вас мультибрендовая система и для разных брендов нужно настроить свои правила округления и время активации баллов, то можно создать отдельные балльные счета для каждого бренда.

Для добавления балльного счета выполните следующие шаги:

1.На вкладке **Настройки** → **Лояльность** → **Балльные счета** нажмите «Создать»:

![Снимок экрана 2024-09-11 в 23.27.34.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202024-09-11%20%D0%B2%2023.27.34.png)

2. Заполните поля для нового балльного счета:

![158523313f48eb16159391cac0644350aБальныисчет.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/158523313f48eb16159391cac0644350a%D0%91%D0%B0%D0%BB%D1%8C%D0%BD%D1%8B%D0%B8%D1%81%D1%87%D0%B5%D1%82.png)

- Имя — имя, по которому балльный счет можно найти в фильтрах.
- Системное имя — имя, которое используется для передачи в сервисы Mindbox, должно состоять из английских букв и цифр.
- Описание — краткое описание назначения балльного счета.
- Дробный — данный параметр определяет, будут ли храниться дробные значения баланса клиентов. Если балльный счет не дробный, то при начислении баллов они будут округляться.
- Не возвращать баллы при возврате заказа — позволяет определить, в каких статусах при возврате покупки баллы, потраченные на оплату заказа, не будут возвращены клиенту.
- Баллы, начисленные за заказ, будут доступны — это правило определяет, в какой момент баллы станут доступны.
- Объединение баллов при дедубликации клиентов — по этому правилу определяется поведение балльных счетов при дедубликации клиентов.
- Правило округления баллов — по этому правилу определяется, в какую сторону при необходимости округляются баллы. Если включен параметр «Дробный», то округляются только копейки.

3. Нажмите «Добавить».
