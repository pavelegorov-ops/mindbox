# Отчет по акциям

Отчет расположен в разделе **Аналитика** → **Отчет по акциям**.

![report-discount-promo.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/report-discount-promo.png)

Страница включает в себя два отчета, с помощью которых можно:

**«Динамика акции»**

- Оценить результаты акции в динамике и сравнить с целевыми показателями бизнеса.
- Проанализировать изменения метрик по дням, неделям, месяцам или годам.
- Выявить точки продаж (точки контакта) или каналы, где акция сработала хуже или лучше ожидаемого, и оперативно принять меры по улучшению показателей.

**«Сравнение акций»**

- Выявить наиболее успешные акции за выбранный период.
- Оценить влияние акций на показатели бизнеса по сравнению с предыдущими периодами.
- Определить, какие акции больше подходят конкретному региону, сравнивая их показатели метрик по точкам контакта.

Все данные в отчетах актуальны на предыдущий день, так как они пересчитываются один раз в сутки ночью.

## Динамика акции

Позволит увидеть метрики эффективности выбранной скидочной акции.

![choose-report.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/choose-report.png)

### Настройка отчета

По умолчанию отчет строится по последней запущенной промоакции, а в периоде отчета указывается время ее активной работы. Если промоакция до сих пор запущена, в правой границе даты указывается вчерашний день.

- Выберите интересующую вас промоакцию. Акции, которые не применялись к заказам, недоступны для выбора и не отобразятся в выпадающем списке.  
  ![choose-discount-promo.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/choose-discount-promo.png)
- Период укажите вручную или воспользуйтесь пресетами дат, которые автоматически отберут период за время действия выбранной акции, последнюю неделю или месяц. Правая дата задается включительно и в ней нельзя выбрать текущий день, так как данные отчета актуальны на вчерашний.  
  ![discount-promo-report-period.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/discount-promo-report-period.png)
- В местах отображаются только те точки контакта, где были продажи по акции. По умолчанию выбраны все, при необходимости выберите интересующие.  
  ![discount-promo-point-of-contact.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/discount-promo-point-of-contact.png)
- По кнопке «Еще фильтры» укажите, какие заказы должны учитываться в отчете. Доступна фильтрация по категориям статусов и анонимным заказам.  
  ![additional-filters-order.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/additional-filters-order.png)
- В дополнительных фильтрах также можно выбрать, какие показатели будут отображены в отчете. Для удаления метрики из отчета, уберите галочку напротив нее. Эта настройка будет полезна, если при анализе чаще всего используется определенный набор данных. Самые важные настройки можно перенести выше, а ненужные — скрыть. Для изменения порядка метрик перетяните строчку в нужную позицию. Настройка отображения сохраняется для всех пользователей на проекте.  
  ![additionals-filters-metrics.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/additionals-filters-metrics.png)

Настройка метрик и фильтрация по заказам влияет на экспорт. В полученном файле будут только выбранные показатели.

- Добавьте период для сравнения, если нужно оценить динамику промоакции: можно указать произвольный период или воспользоваться пресетами дат.  
  ![discount-promo-period-of-comparison.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/discount-promo-period-of-comparison.png)

### Метрики отчета

Описание метрик

- **Выручка**

  - По акции — итоговая стоимость всех товаров, к которым применилась акция за выбранный период.
  - Общая — итоговая стоимость всех товаров, проданных за выбранный период в местах, где были продажи по акции.
- **Выручка чеков**

  - По акции — итоговая стоимость всех заказов, к которым применилась акция за выбранный период. Учитываются как акционные, так и не акционные товары.
  - Общая — итоговая стоимость всех товаров, проданных за выбранный период в местах, где были продажи по акции.
- **Товары**

  - По акции — количество проданных товаров, к которым применилась акция за выбранный период.
  - Общая — количество товаров, проданных за выбранный период в местах, где были продажи по акции.
- **Чеки**

  - По акции — количество заказов, к которым применилась акция за выбранный период.
  - Общая — количество заказов за выбранный период в местах, где были продажи по акции.
- **Средний чек**

  - По акции — средний чек по заказам, к которым применилась акция, за выбранный период. Считается как: «Выручка чеков по акции» / «Чеки по акции».
  - Общая — средний чек по всем заказам за выбранный период. Считается как: «Выручка общая» / «Чеки общие».
- **Скидка по акции** — сумма скидки по выбранной акции за выбранный период.
- **Средний процент скидки по акции** — считается как: «Скидка по акции» / «Стоимость заказов по акции до применения скидок» * 100%.
- **Средняя скидка по акции** — считается как: «Скидка по акции» / «Чеки по акции».

### Диаграммы

По каждой метрике доступны столбчатые диаграммы с разбивкой на календарные дни, недели, месяцы или года. Для настройки диаграммы:

- Кликните по нужной метрике в шапке отчета.
- Выберите группировку показателей: по дням, неделям, месяцам или годам. Список возможных группировок может отличаться в зависимости от выбранного периода.

При наведении на определенный отрезок видны данные за выделенный период:  
![discount-promo-chart.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/discount-promo-chart.png)

Если в настройках отчета указан период для сравнения, будут приведены два столбца с разбивкой показателей по текущему и сравнительному периодам.

С помощью общих метрик (выручка, выручка чеков, товары, чеки, средний чек) вы можете оценить, как акция отработала относительно периода сравнения. При наведении на столбец сравнительного периода — в общих метриках отобразятся показатели, рассчитанные по точкам контакта (местам), которые выбраны в настройках отчета.

![discount-promo-chart-comparison-period.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/discount-promo-chart-comparison-period.png)

Если в период сравнения акция не была запущена, то в столбцах отобразятся значения только по общим метрикам.

![report-discount-promotion-common-metrics.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/report-discount-promotion-common-metrics.png)

### Таблица отчета

Под диаграммой приведена таблица, позволяющая детально анализировать результаты акции по точкам контакта. Поможет быстро определить точки контакта с низкой эффективностью акции для дальнейшего анализа и внедрения улучшений. При клике на канал отобразятся точки контакта, относящиеся к нему.

В таблице под временным диапазоном отображается значение метрики за указанный период, под ней — прирост по сравнению с прошлым периодом, выражающийся в абсолютном и процентном изменении.

![discount-promo-table.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/discount-promo-table.png)

## Сравнение акций

Поможет сравнить эффективность выбранных скидочных акций.

![choose-second-report.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/choose-second-report.png)

### Настройка отчета

По умолчанию отчет строится по 5 последним запущенным акциям за последний месяц. Настройка отчета происходит по таким же шагам, как и в [отчете «Динамика акции»](report-discount-promotions.md#nastrojka-otcheta). Акции, которые не применялись к заказам, недоступны для выбора и не отобразятся в выпадающем списке.

### Метрики отчета

Описание метрик

- **Средняя дневная выручка по товарам по акции** — считается как: «Выручка по акции» / «Дни пересечений». Учитываются дни, которые попали в выбранный период.
- **Среднее дневное количество чеков по акции** — считается как: «Чеки по акции» / «Дни пересечений». Учитываются дни, которые попали в выбранный период.
- **Среднее дневное количество товаров по акции** — считается как: «Товары по акции» / «Дни пересечений». Учитываются дни, которые попали в выбранный период.

Важно

Рекомендуем сравнивать акции, запущенные разное количество дней в выбранном периоде отчета, с помощью показателей средних дневных метрик.

- **Выручка по акции** — итоговая стоимость всех товаров, к которым применилась акция за выбранный период.
- **Товары по акции** — количество проданных товаров, к которым применилась акция за выбранный период.
- **Чеки по акции** — количество чеков, к которым применилась акция за выбранный период.
- **Средний чек по акции** — средний чек по заказам, к которым применилась акция, за выбранный период. Считается как: «Выручка чеков по акции» / «Чеки по акции».
- **Товары в чеках по акции** — количество проданных товаров в чеках, где есть хотя бы один акционный товар, за выбранный период.
- **Выручка чеков по акции** — итоговая стоимость всех чеков, к которым применилась акция за выбранный период. Учитываются как акционные, так и не акционные товары.
- **Охват акции по выручке** — считается как: «Выручка по акции» / «Выручка общая за выбранный период в дни пересечений».
- **Охват акции по чекам** — считается как: «Чеки по акции» / «Чеки общие в дни пересечений».
- **Охват акции по выручке чеков** — считается как: «Выручка чеков по акции» / «Выручка чеков общая за выбранный период в дни пересечений».
- **Охват акции по товарам** — считается как: «Товары по акции» / «Товары общие за выбранный период в дни пересечений».
- **Скидка по акции** — сумма скидки по акции за выбранный период.
- **Средний процент скидки по акции** — считается как: «Скидка по акции» / «Стоимость заказов по акции в дни пересечений до применения скидок» * 100%.
- **Средняя скидка по акции** — считается как: «Скидка по акции» / «Чеки по акции».

Если выбран период для сравнения, в отчете становятся доступны метрики роста:

- **Рост выручки** — изменение выручки за выбранный период относительно периода сравнения. Учитываются точки контакта, где были продажи по акции. Считается как: «Выручка по акции» - «Выручка по акции за сравнительный период»
- **Рост чеков** — изменение чеков за выбранный период относительно периода сравнения. Учитываются точки контакта, где были продажи по акции. Считается как: «Чеки по акции» - «Чеки по акции за сравнительный период».
- **Рост среднего чека** — изменение среднего чека за выбранный период относительно периода сравнения. Учитываются точки контакта, где были продажи по акции. Считается как: «Средний чек по акции» - «Средний чек по акции за сравнительный период».
- **Рост проданных товаров** — изменение проданных товаров за выбранный период относительно периода сравнения. Учитываются точки контакта, где были продажи по акции. Считается как: «Товары по акции» - «Товары по акции за сравнительный период».

### Таблица отчета

Под настройками отчета приведена таблица с разбивкой всех метрик по выбранным промоакциям. Также в ней указаны статусы промоакций, приведены дни пересечения и период промоакций.

- **Дни пересечений** — количество дней, в течение которых акция находилась в статусе «Запущена» в выбранном периоде отчета.
- **Период акции** — период между первым запуском акции и последней датой, когда акция была в статусе «Запущена» до ее завершения или постановки на паузу. Если в текущий момент акция еще запущена — крайняя граница даты не будет отображаться.

![discount-promo-comparison-chart.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/discount-promo-comparison-chart.png)

## Фильтры

С помощью данных фильтров можно найти заказы, по которым считаются показатели метрик. Также вы можете [экспортировать](export-orders.md) их, чтобы сверить показатели остальных метрик.

**«Чеки общие»:**

- Укажите дату, которая будет соответствовать выбранному в отчете периоду.
- В статусах позиции заказа выберите категории заказов, которые учитываются в дополнительных фильтрах отчета.
- Выберите те точки контакта, чекбоксы которых активированы в отчете.

![discount-promo-filters-one.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/discount-promo-filters-one.png)

**«Чеки по акции»:**

- Укажите такие же условия, как и в фильтре для поиска заказов из общих чеков, но также добавьте, что к заказам должна быть применена выбранная в отчете промоакция:

![discount-promo-filters-two.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/discount-promo-filters-two.png)

Если данные не сходятся, проверьте, что:

- В фильтре указан тот же период, что и в отчете. Обратите внимание, что данные в отчете актуальны на предыдущий день и в нем нельзя выбрать текущий.
- В фильтре и в отчете выбраны одинаковые категории статусов заказов.
- В настройках отчета вы выбрали, что анонимные заказы не учитываются. Если они учитываются, то расхождения допустимы, так как анонимные заказы не добавляются на проект.
- В этот день не было удалений заказов или клиентов с заказами. После удаления отчет обновляется не сразу, а после ночного пересчета.

## Как удаление данных отражается на отчетах

Изменение и удаление заказов за три последних месяца, а также удаление клиентов с заказами за этот период — влияет на отчет, данные по метрикам уменьшаются соответствующим образом. Изменения отразятся в отчете на следующий день после ночного пересчета. Удаление или изменение заказов старше трех месяцев не влияет на данные отчета.

## Экспорт отчетов

Выберите нужный тип отчета, задайте необходимые настройки. Содержимое и структура файла зависят от выбранных настроек отчета. Если в экспорте не нужны определенные метрики — деактивируйте их чекбоксы в настройках отчета. Нажмите на «Экспорт .csv»:

![report-discount-promotions-export.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/report-discount-promotions-export.png)

Экспорт отчетов по акциям недоступен по API.

### Экспорт отчета «Динамика акции»

Если период для сравнения не указан в настройках отчета, показатели метрик отобразятся в файле с разбивкой по дням.

При выбранном периоде для сравнения — показатели метрик отобразятся в разбивке по выбранным точкам контакта, а также будут представлены показатели метрик за период сравнения.

Описание колонок

*Если в настройках отчета выбраны все метрики, в CSV-файл будут выгружены поля:*

- **promotionName** — название акции.
- **promotionId** — идентификатор промоакции.
- **channelName** — канал.
- **pointOfContactName** — название точки контакта.
- **pointOfContactID** — внешний идентификатор точки контакта.
- **startReportDate** — начало периода отчета.
- **endReportDate** — конец периода отчета.
- **date** — дата. Колонка присутствует, если не выбран период для сравнения.
- **promoItemsRevenue** — выручка по акции.
- **promoReceiptsRevenue** — суммарная выручка по чекам, участвующим в акции.
- **totalRevenueForSelectedPeriod** — выручка общая.
- **promoItemsSold** — количество товаров по акции.
- **totalItemsSoldForSelectedPeriod** — общее количество товаров.
- **promoReceipts** — чеки по акции.
- **totalReceiptsForSelectedPeriod** — чеки общие.
- **averagePromoReceipt** — средний чек по акции.
- **averageReceipt** — средний чек общий.
- **promotionDiscountAmount** — скидка по акции.
- **averagePromoDiscountPercentage** — средний процент скидки по акции.
- **averagePromoDiscountAmount** — средняя скидка по акции.
- **promoRevenueCoverage** — охват акции по выручке. Считается как: «Выручка по акции» / «Выручка общая» * 100%.
- **promoReceiptsCoverage** — охват акции по чекам. Считается как: «Чеки по акции» / «Чеки общие» * 100%
- **promoReceiptsRevenueCoverage** — охват акции по выручке чеков. Считается как «Выручка чеков по акции» / «Выручка общая» * 100%.
