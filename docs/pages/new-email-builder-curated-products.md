# Ручная подборка продуктов в новом конструкторе

Собирайте витрину продуктов в новом конструкторе вручную: выберите продукты из базы и настройте, как они будут выглядеть в рассылке.

## Когда использовать ручную подборку

- Нужно показать конкретные продукты (рассказать о новинках, акциях, тематических подборках).
- Важен определенный порядок продуктов в письме.
- Необходимо отправить продукты с актуальной информацией.

Для отправки персонализированной подборки, используйте [динамическую подборку с рекомендациями](new-email-builder-recommendations.md).

## Настройка ручной подборки

### 1. Добавьте блок

Выберите блок из категории «Продукты» и добавьте его в рабочую область:

![curated-products-add-block.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/curated-products-add-block.png)

### 2. Добавьте продукты

Укажите выбор продуктов через заполнение вручную и перейдите к добавлению продуктов.

![curated-products-block-settings.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/curated-products-block-settings.png)

Найдите нужные продукты по:

- названию,
- идентификатору,
- артикулу.

Важно

Если наличие продукта **неизвестно**, он не попадет в результат поиска.

Поиск находит продукты по частичному совпадению без учета регистра.

![curated-products-product-search.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/curated-products-product-search.png)

Перейдите в общие настройки блока, чтобы:

- изменить порядок продуктов перетаскиванием,
- заменить продукт,
- удалить лишние продукты.

![curated-products-product-order.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/curated-products-product-order.png)

### 3. Настройте дизайн карточек

Перейдите в настройки элементов карточки. Здесь задаются отступы, цвета, шрифты и другие параметры отображения.

![curated-products-product-settings.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/curated-products-product-settings.png)

По умолчанию оформление применяется ко всем карточкам. Отключите «Применить дизайн ко всем карточкам», если нужно оформить конкретную карточку иначе (например, выделить акционный продукт).

![curated-products-product-toogle.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/curated-products-product-toogle.png)

### 4. Добавьте ссылку перехода

Ссылка перехода автоматически проставляется во всех элементах карточки. Укажите ссылку вручную либо через переменную:  
![curated-products-product-link.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/curated-products-product-link.png)

### 5. Протестируйте рассылку

Проверьте формирование письма на примере конкретного пользователя с помощью [тестовой отправки](%D0%BA%D0%B0%D0%BA-%D0%BF%D1%80%D0%BE%D1%82%D0%B5%D1%81%D1%82%D0%B8%D1%80%D0%BE%D0%B2%D0%B0%D1%82%D1%8C-%D1%80%D0%B0%D1%81%D1%81%D1%8B%D0%BB%D0%BA%D1%83.md): через предпросмотр или отправку на почту.

Письмо готово:

![curated-products-done.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/curated-products-done.png)
