# Почему у клиента пропало значение дополнительного поля?

Возможные варианты:

- Для дополнительного поля передано значение %CLEAR% – данные в дополнительном поле затираются.

В настройках дополнительного поля стоит настройка “Затирать, если передано пустое значение”. Передается пустое значение и значение поля затирается.
