# Как импортировать пулы подарочных карт

[Подарочные карты](gift-cards-what-is.md) обязательно должны принадлежать какому-либо пулу.

Пулы позволяют:

- задавать номинал карт;
- указывать возможность частичного гашения карт;
- группировать карты по маркетинговым кампаниям;
- отбирать заказы, связанные с картами из определенного пула.

---

Чтобы импортировать пул:

1. В разделе **Кампании** нажмите «Создать кампанию» → «Лояльность» → «Пул подарочных карт»:

![Снимок экрана 2023-12-18 в 12.17.24.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-12-18%20%D0%B2%2012.17.24.png)

2. Появляется уведомление с остатком по лимиту.

Учтите, что удаление пулов пока невозможно.

Подтвердите создание:

![пул внимание.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%BF%D1%83%D0%BB%20%D0%B2%D0%BD%D0%B8%D0%BC%D0%B0%D0%BD%D0%B8%D0%B5.png)

3. Выберите операцию «Импорт пулов подарочных карт» и подготовьте файл. На странице доступен шаблон с примером:

![Снимок экрана 2023-12-18 в 12.55.15.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-12-18%20%D0%B2%2012.55.15.png)

Поля для заполнения:

- **PoolName** — название пула.
- **PoolSystemName** — системное имя пула.
- **ProductExternalId** — внешний идентификатор технического продукта, который будет создан для пула.
- **ExternalSystem** — внешняя система технического продукта, который будет создан для пула.
- **Brand** — бренд технического продукта, который будет создан для пула.
- **IsCvvRequired** — обязательно ли указывать CVV у карт в пуле.
- **Amount** — номинал карт в пуле. Если пул поддерживает произвольную стоимость, поле не должно быть заполнено.
- **IsCustomAmount** — поддерживает ли пул произвольную стоимость карт. Если не заполнять поле, по умолчанию будет проставлено значение «Нет».
- **IsPartialUse** — поддерживает ли пул частичное гашение карт. Если не заполнять поле, по умолчанию будет проставлено значение «Нет».
- **ExpirationType** — тип срока действия карт в пуле. Возможные значения: **NoExpiration** — «Без срока действия»; **Year** — «Год N». Если не заполнять поле, по умолчанию будет проставлено значение «Без срока действия».
- **Expiration** — срок действия карт в пуле. Принимаемые значения: целые числа от 1 до 10 включительно. Работает при указании в поле **ExpirationType** значения **Year**.

Пример заполненного файла:

![импорт пула файл.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%B8%D0%BC%D0%BF%D0%BE%D1%80%D1%82%20%D0%BF%D1%83%D0%BB%D0%B0%20%D1%84%D0%B0%D0%B9%D0%BB(1).png)

4. Загрузите подготовленный файл и запустите задачу:

![Снимок экрана 2023-12-27 в 13.56.34.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-12-27%20%D0%B2%2013.56.34.png)

5. Убедитесь, что задача завершилась без ошибок:

![Снимок экрана 2023-12-27 в 14.02.31.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-12-27%20%D0%B2%2014.02.31.png)

![Снимок экрана 2023-12-27 в 14.04.52.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-12-27%20%D0%B2%2014.04.52.png)

После этого появляется пул и автоматически создается его технический продукт:

![Снимок экрана 2024-04-07 в 16.23.41.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202024-04-07%20%D0%B2%2016.23.41.png)

![Снимок экрана 2023-12-20 в 00.15.36.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-12-20%20%D0%B2%2000.15.36.png)

Далее можно загрузить в него подарочные карты по [инструкции](gift-cards-import.md).
