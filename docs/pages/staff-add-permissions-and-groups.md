# Как расширить права персонала

Иногда доступов в выданной группе безопасности может не хватать для выполнения нужных задач. В таком случае встает задача расширения прав персонала.

### Какие права выдать

Для начала:

1. Найдите [пермиссии](permissions.md), которые нужны для задачи;
2. [Проверьте](own-permissions-and-groups.md), действительно ли они отсутствуют у сотрудника.

При расширении прав есть возможность не просто выдать дополнительные права, а целиком сменить группу безопасности. Это удобно, когда не хватает большого количества пермиссий.

Подберите подходящую [системную группу](system-staff-groups.md) или [создайте новую](staff-group-create.md).

Добавлять группы стоит, когда есть несколько людей с нестандартным набором прав. Для разового расширения доступа сотрудника лучше ограничиться дополнительными правами.

### Кто может расширить права

Для расширения прав важны два фактора:

- доступ к редактированию персонала;
- наличие достаточных пермиссий.

#### Доступ к редактированию персонала

Править персонал могут пользователи с пермиссиями:

- *Просмотр и экспорт списка персонала*
- *Просмотр персонала*
- *Редактирование персонала*

Такие права есть у системной группы «Владельцы».

#### Наличие достаточных пермиссий

Можно выдать те дополнительные права, которые есть в своем профиле.

Чтобы назначить группу безопасности, нужно либо самому в ней находиться, либо иметь весь набор ее пермиссий.

Обычно права выдают «Владельцы», так как у них максимальный доступ на проекте. Если страница персонала доступна, подходящих коллег можно найти с помощью фильтра:

### Как выдать дополнительные права

Чтобы настроить дополнительные права для сотрудника:

1. Перейдите в раздел **Настройки** → **Безопасность** → **Пользователи**:

![персонал.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%BF%D0%B5%D1%80%D1%81%D0%BE%D0%BD%D0%B0%D0%BB.png)

2. Найдите нужного пользователя и перейдите в его карточку:

![Снимок экрана 2022-11-06 в 21.33.12.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-11-06%20%D0%B2%2021.33.12.png)

3. Добавьте нужные права из выпадающего списка:

![Снимок экрана 2023-10-30 в 20.31.58.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-10-30%20%D0%B2%2020.31.58%281%29.png)

4. Нажмите «Сохранить».
