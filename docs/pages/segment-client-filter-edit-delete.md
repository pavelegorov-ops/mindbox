# Как отредактировать сегмент клиентов по фильтру

1. Найдите в фильтре нужный сегмент нажмите на знак редактирования:

   ![Снимок экрана 2024-08-05 в 12.21.05](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202024-08-05%20%D0%B2%2012.21.05.png)
2. **Скорректируйте условия** и нажмите «Сохранить» (для пересчитываемых сегментов — «Сохранить и пересчитать»):

   ![Снимок экрана 2024-08-05 в 12.21.24 — копия](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202024-08-05%20%D0%B2%2012.21.24%C2%A0%E2%80%94%20%D0%BA%D0%BE%D0%BF%D0%B8%D1%8F.png)

Как удалить сегментацию, читайте в [статье](segment-delete.md).

[Сегментация клиентов](https://mindbox.ru/academy/education/kak-segmentirovat-klientov/) — клиентская база на основе каких-либо признаков: гендера, количества покупок, суммы потраченных денег.
