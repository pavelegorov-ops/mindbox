# Что такое транзакционный сценарий

Транзакционые сценарии — это сценарии, которые имеют приоритет в обработке событий относительно других сценариев.

### Как создать транзакционный сценарий

Сценарий не обязательно должен быть полностью транзакционным — приоритетом может обладать только его часть или одна из цепочек каскада.

Обязательные условия для транзакционных цепочек:

1. Событие — [«Новый заказ»](workflow-events.md#novyj-zakaz), [«Данные заказа изменены»](workflow-events.md#dannye-zakaza-izmeneny), [«Статус заказа изменен»](workflow-events.md#status-zakaza-izmenen), [«Клиент запросил код авторизации»](workflow-events.md#klient-zaprosil-kod-avtorizacii), [«Клиент зарегистрировался»](workflow-events.md#klient-zaregistrirovalsya), [«Статус подписки изменен»](workflow-events.md#status-podpiski-izmenen), [«Номер телефона подтвержден»](workflow-events.md#nomer-telefona-podtverzhden) или [«Значение дополнительного поля клиента изменено»](workflow-events.md#znachenie-dopolnitelnogo-polya-klienta-izmeneno).
2. Событие должно приходить из операции с типом [«Приоритетная»](%D0%BE%D0%BF%D0%B5%D1%80%D0%B0%D1%86%D0%B8%D0%B8-v-%D0%BE%D1%81%D0%BD%D0%BE%D0%B2%D0%BD%D1%8B%D0%B5-%D1%81%D0%B2%D0%B5%D0%B4%D0%B5%D0%BD%D0%B8%D1%8F.md#:~:text=%D0%9F%D1%80%D0%B8%D0%BE%D1%80%D0%B8%D1%82%D0%B5%D1%82%D0%BD%D0%B0%D1%8F) и c включенной настройкой «Запускает транзакционный сценарий». *(События из операций c типом «Стандартная» также попадут в сценарий, но будут обработаны в обычном порядке.)*
3. Ожидание — допустимы только [временной интервал](workflow-delay.md#vremennoj-interval) и [фиксированное](workflow-delay.md#fiksirovannoe) ожидание до 5 минут включительно.  
   Заложенная задержка не входит в гарантированную скорость.
4. Группа шагов — отправка транзакционной рассылки в канале email, SMS или MobilePush, или шаги «Изменить баланс балльного счёта», «Сгенерировать код авторизации».
5. Цепочки — можно использовать до трех последовательных транзакционных групп шагов.  
   Для каждой части цепочки время срабатывания считается отдельно.
6. Нет блока «Разделение».

Пример:

Пример частично транзакционного сценария:

![Снимок экрана 2023-12-28 в 01.09.45.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-12-28%20%D0%B2%2001.09.45.png)*Первая цепочка обладает приоритетом, остальная часть из-за нетранзакционной группы шагов работает как обычный сценарий.*

Наведение курсора на знак молнии подскажет, из-за каких блоков сценарий всё ещё не транзакционный.
