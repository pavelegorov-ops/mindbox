# Каналы уведомлений на Android

Канал — это совокупность настроек отображения уведомления, которую Google ввел в Android 8.0 (API level 26).

Все уведомления на Android телефоне должны принадлежать к какому-либо «каналу», чтобы пользователь мог настраивать то, как хочет видеть уведомления конкретного типа от вашего приложения.

Если вы используете готовый метод для отображения уведомлений `Mindbox.handleRemoteMessage`, все уведомления будут отображаться в рамках одного канала, который создается в рамках этого метода.  
Для канала, который мы создадим нужно заполнить следующие данные:  
— идентификатор канала  
— название  
— описание

Название и описание пользователь увидит в настройках телефона:

![Screenshot_20220321_125320.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/Screenshot_20220321_125320.png)

Если вы не используете наш метод для отрисовки, каналы настраиваются самостоятельно. Обсудите это с разработчиками приложения.
