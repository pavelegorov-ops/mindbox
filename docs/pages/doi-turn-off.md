# Как отключить подтверждение подписки

Подтверждение подписки означает, что клиенты не будут получать рассылки, пока явно не подтвердят подписку в соответствующем письме.  
До этого момента их подписка находится в статусе «требует подтверждения».  
Подробнее о статусах подписки на проектах с DOI в [статье](doi-subscription-change.md).

В данной инструкции рассмотрим, как отключить подтверждение подписки.

### 1. Убираем рассылки с подтверждением

Для отключения DOI нужно, чтобы на проекте не было рассылок с профилем «opt-in». Такие рассылки редактируем или удаляем.

Для их поиска можно использовать фильтр в [журнале событий](event-log.md):

![Снимок экрана 2024-09-11 в 11.55.42.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202024-09-11%20%D0%B2%2011.55.42.png)

![Снимок экрана 2024-09-11 в 11.58.12.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202024-09-11%20%D0%B2%2011.58.12.png)

Профиль надо заменить на любой без пункта «Слать только ожидающим подтверждения подписки». Например, на «Стандартный». При невозможности редактирования рассылку нужно удалить.

Для [мультибрендовых](multibrand.md) проектов: надо убрать рассылки только в том бренде, в котором собираетесь отключать подтверждение.

### 2. Отключаем подтверждение

Переходим в **Настройки → Рассылки → Настройки email**:

![настройки емейл — копия 2.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%BD%D0%B0%D1%81%D1%82%D1%80%D0%BE%D0%B9%D0%BA%D0%B8%20%D0%B5%D0%BC%D0%B5%D0%B9%D0%BB%C2%A0%E2%80%94%20%D0%BA%D0%BE%D0%BF%D0%B8%D1%8F%202.png)

Важно

Клиенты, которые раньше попадали в базу со статусом «требует подтверждения», теперь будут появляться сразу подписанными и будут получать соответствующую коммуникацию.

### 3. Подписываем при необходимости

После отключения подтверждения клиенты, которые уже были в базе со статусом подписки «требует подтверждения», не будут автоматически подписаны. Для этого их надо будет редактировать по [инструкции](clients-subscribe.md).
