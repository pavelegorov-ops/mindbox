# Как добавить баннеры на сайт

Задача: добавить на главную страницу сайта форму «Баннер».

![qXymAmu8U0.gif](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/qXymAmu8U0.gif)

## Варианты использования

- рассказать о персональных скидках и акциях на главной странице сайта;
- на каждой странице категории товара показывать баннер без дополнительной интеграции;

---

## Что нужно для размещения формы на сайте

1. Установить код [трекера](https://developers.mindbox.ru/docs/%D1%82%D1%80%D0%B5%D0%BA%D0%B5%D1%80) на ваш сайт.
2. Подключить модуль [«Персонализация сайта»](https://mindbox.ru/products/personalization/).
3. Создать [встроенную форму](inline-block.md) «Баннер» в админке Mindbox.

## Создание баннера в Mindbox

Добавьте в папку **встроенный блок**:

![создать-встр.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D1%81%D0%BE%D0%B7%D0%B4%D0%B0%D1%82%D1%8C-%D0%B2%D1%81%D1%82%D1%80.png)

Выберите шаблон «**Карусель баннеров**»:

![Снимок экрана 2022-06-30 в 21.09.11.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-06-30%20%D0%B2%2021.09.11%281%29.png)

Укажите сайт:

![Снимок экрана 2023-01-23 в 03.58.25.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-01-23%20%D0%B2%2003.58.25.png)

Чтобы добавить баннеры в карусель, перейдите в настройку «**Баннеры**» и нажмите «**Добавить баннер**»:

Для каждого изображения вы можете настроить отдельные настройки таргетинга, например, показывать:

- первый баннер — только новым клиентам;
- второй баннер — клиентам с корзиной более 3000 рублей и из определенного города;
- третий баннер — клиентам, которые посетили определенные страницы продуктов.

Сначала будет проверяться таргетинг, заданный в настройках самого встроенного блока, а затем — таргетинг каждого слайда.

![Снимок экрана 2022-06-30 в 21.14.03.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-06-30%20%D0%B2%2021.14.03%281%29.png)

После этого у вас откроется окно редактирования первого изображения для баннера. Здесь вы можете настроить внешний вид формы, как часто он должен быть показан и какому сегменту клиентов.

![Снимок экрана 2022-06-30 в 21.16.11.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-06-30%20%D0%B2%2021.16.11%281%29.png)

Когда первое изображение добавлено, возвращаемся в основную форму и добавляем остальные баннеры. Здесь же вы можете поменять порядок отображения баннеров с помощью перетаскивания баннеров за кнопку:

![banners-order-gif.gif](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/banners-order-gif.gif)

## Установка блока на сайт

Есть 2 варианта установки встроенного блока на сайт: встроить блок **в селектор** или поместить блок в нужное место **самостоятельно**.

![Снимок экрана 2022-04-21 в 20.57.12.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-04-21%20%D0%B2%2020.57.12.png)

Подробнее можно прочитать [в статье](inline-block.md#kak-dobavit-blok-na-sajt) по настройке встроенных блоков.

## Запуск формы

Далее нужно нажать «Запустить».

![Снимок экрана 2022-06-30 в 21.19.49.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-06-30%20%D0%B2%2021.19.49.png)

При запуске встроенного блока не запускается вся механика!

После запуска встроенного блока нужно перейти к запуску его элементов — отдельных изображений.

![Снимок экрана 2022-06-30 в 21.20.46.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-06-30%20%D0%B2%2021.20.46.png)

## Тестирование формы

Механику «Баннер» нельзя проверить по тестовой ссылке. Для тестирования необходимо:

1. В таргетинге указать **URL содержит mb-test**.
2. Запустить форму.
3. Добавить ?mb-test к адресу страницы сайта, куда встроена форма. Получится адрес вида: mysite.ru?mb-test.
4. Ввести получившийся URL в адресную строку браузера и перейти на него.
5. Проверить отображение формы.

![Снимок экрана 2022-06-30 в 21.24.52.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-06-30%20%D0%B2%2021.24.52.png)
