# Как создать группу безопасности

Этот функционал может быть недоступен на вашем проекте. Уточните условия у менеджера вашего проекта или в службе поддержки.

Чтобы добавить группу безопасности:

1. Перейдите в раздел **Настройки** → **Безопасность** → **Группы безопасности**:

   ![группы.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%B3%D1%80%D1%83%D0%BF%D0%BF%D1%8B.png)
2. Нажмите кнопку «Создать»:

   ![Снимок экрана 2022-11-06 в 20.19.25.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-11-06%20%D0%B2%2020.19.25.png)
3. Заполните настройки:

   ![all-permissions1.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/all-permissions1.png)

   ![all-permissions2.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/all-permissions2.png)

   - *Название* — название, которое будет отображаться в списке;
   - *Системное имя* — используется при [импорте персонала](staff-import.md);
   - *Описание* — для какой роли создается группа;
   - *Пермиссии* - какие [доступны](permissions.md) будут у группы.
4. Нажмите «Добавить».
