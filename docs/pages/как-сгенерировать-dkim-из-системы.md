# Как сгенерировать DKIM из системы

Для генерирования DKIM из системы выполним следующие шаги:

1. Переходим в **Настройки → Рассылки → Настройки email**:

![настройки емейл.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%BD%D0%B0%D1%81%D1%82%D1%80%D0%BE%D0%B9%D0%BA%D0%B8%20%D0%B5%D0%BC%D0%B5%D0%B9%D0%BB.png)

2. Добавляем имя и адрес [отправителя](%D0%BA%D0%B0%D0%BA-%D0%BD%D0%B0%D1%81%D1%82%D1%80%D0%BE%D0%B8%D1%82%D1%8C-%D0%B4%D0%BE%D0%B1%D0%B0%D0%B2%D0%B8%D1%82%D1%8C-%D0%B8%D0%B7%D0%BC%D0%B5%D0%BD%D0%B8%D1%82%D1%8C-%D0%BE%D1%82%D0%BF%D1%80%D0%B0%D0%B2%D0%B8%D1%82%D0%B5%D0%BB%D1%8F-%D0%B2-email-%D1%80%D0%B0%D1%81%D1%81%D1%8B%D0%BB%D0%BA%D0%B5.md), если его еще нет. Сохраняем изменения. Пример:

![Снимок экрана 2020-12-08 в 5.53.00 PM.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202020-12-08%20%D0%B2%205.53.00%20PM.png)

3. Нажимаем «Сгенерировать DKIM»:

![Снимок экрана 2020-12-08 в 5.56.56 PM.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202020-12-08%20%D0%B2%205.56.56%20PM.png)

4. Далее выполняем настройки по [инструкции](как-настроить-dkim-и-dmarc).

[Зачем нужна политика DMARC](https://mindbox.ru/academy/education/politika-dmarc/). Правила проверки email-рассылок и как ее внедрить.
