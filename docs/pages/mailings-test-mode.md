# Как протестировать автоматическую рассылку

## Зачем проводить тестирование рассылки

В автоматической рассылке, которая использует [событийные](%D0%BA%D0%B0%D0%BA%D0%B8%D0%B5-%D0%B1%D1%8B%D0%B2%D0%B0%D1%8E%D1%82-%D0%BF%D0%B0%D1%80%D0%B0%D0%BC%D0%B5%D1%82%D1%80%D1%8B-%D0%BF%D0%BE-%D0%B4%D0%BE%D1%81%D1%82%D1%83%D0%BF%D0%BD%D0%BE%D1%81%D1%82%D0%B8.md#sobytijnye-parametry) или [пользовательские](%D0%BA%D0%B0%D0%BA%D0%B8%D0%B5-%D0%B1%D1%8B%D0%B2%D0%B0%D1%8E%D1%82-%D0%BF%D0%B0%D1%80%D0%B0%D0%BC%D0%B5%D1%82%D1%80%D1%8B-%D0%BF%D0%BE-%D0%B4%D0%BE%D1%81%D1%82%D1%83%D0%BF%D0%BD%D0%BE%D1%81%D1%82%D0%B8.md#polzovatelskie-kastomnye-parametry) параметры, невозможна отправка тестовых сообщений.  
Конечный вид письма по ней можно увидеть только при наличии событий, которые и предоставляют данные для параметров.

Для проверки такой рассылки нужно добавить ее в сценарий или операцию и включить тестовый режим.  
Письма при этом будут формироваться, но клиентам отправляться не будут.

## Как включить тестирование рассылки

Тест включается из механики, использующей рассылку.

### В сценарии

Можно протестировать сценарий со всеми его кампаниями или только отдельную рассылку.

#### Тестировать рассылку

В шаге отправки нужной кампании включите опцию «Тестировать рассылку» и запустите сценарий:

![mailings-test-mode-workflow.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/mailings-test-mode-workflow.png)

Сценарий будет работать **как любой другой запущенный сценарий**: все настройки, блоки и группы шагов, кроме тестовой рассылки, будут выполняться.  
Сообщения из рассылки **будут формироваться, но не будут отправляться**.

Такой способ подойдет для проверки новой рассылки в уже рабочей механике, когда важно не терять прохождения за время тестирования.

Например, можно добавить тестовую рассылку в сценарий, не убирая из него существующую кампанию. Тогда старая рассылка продолжит отрабатывать по прохождениям клиентов, и параллельно с ней будут формироваться письма по новому шаблону:

![mailings-test-mode-two-mailings.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/mailings-test-mode-two-mailings.png)

Группа шагов с тестовой рассылкой помечается в сценарии:

![mailings-test-mode-two-mailings-on.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/mailings-test-mode-two-mailings-on.png)

#### Тестировать сценарий

[Тестирование сценария](workflow-test-mode.md) автоматически включает тестовый режим **для всех рассылок** в сценарии:

![workflow-test-mode-turn-on.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/workflow-test-mode-turn-on.png)

В тесте сценария можно посмотреть распределение клиентов по цепочкам **без фактического прохождения сценария**.

**Игнорируются блоки и настройки:**

- ожидание;
- группа шагов (при этом формируются тестовые сообщения);
- АБ-тест;
- частота срабатывания;
- дата начала и окончания работы.

Такой способ подойдет при создании нового сценария, когда важно проверить не только письма, но и корректность составления цепочек, а также в сценариях, где выполняется только шаг с отправкой рассылки, чтобы не учитывать тестовые прохождения.

Важно

Рассылка может использовать параметры, значение для которых должно появиться в рамках прохождения цепочки: выданный в сценарии промокод или ответ из вебхука.

Так как шаги в тесте сценария не выполняются, данных для этих параметров не будет.

Такие письма можно протестировать одним из двух способов: настроить отправку [на выбранный контакт](%D0%BA%D0%B0%D0%BA-%D0%BF%D1%80%D0%BE%D1%82%D0%B5%D1%81%D1%82%D0%B8%D1%80%D0%BE%D0%B2%D0%B0%D1%82%D1%8C-%D1%80%D0%B0%D1%81%D1%81%D1%8B%D0%BB%D0%BA%D1%83.md#otpravit-sebe-rassylku-cherez-scenarij) или запустить сценарий и использовать [тест рассылки](mailings-test-mode.md#testirovat-rassylku).

### В операции

В шаге отправки отметьте опцию «Тестировать рассылку»:

![mailings-test-mode-operation.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/mailings-test-mode-operation.png)

Все шаги будут выполяться как в любой другой операции.  
При этом сообщения из рассылки **будут формироваться без отправки**.

## Как посмотреть тестовые сообщения

### В рассылке

На странице редактирования рассылки кликните по меню → «Тестовые рассылки»:

![mailings-test-mode-view-list.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/mailings-test-mode-view-list.png)

В списке собраны тестовые сообщения из всех механик, использующих рассылку, а также тесты, отправленные из интерфейса кампании:

![mailings-test-mode-list.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/mailings-test-mode-list.png)

Сообщения можно переслать на выбранный email-адрес, имеющийся на проекте.  
За раз — не более пяти писем; они также появятся в списке после отправки:

![mailings-test-mode-list-resend.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/mailings-test-mode-list-resend.png)

### В сценарии

В блоке с рассылкой перейдите на вкладку «Сформированные сообщения» и нажмите на иконку глаза:

![mailings-test-mode-workflow-messages-in-block.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/mailings-test-mode-workflow-messages-in-block.png)

Тесты из всех блоков собраны на вкладке «Прохождения и рассылки» → «Сформированные сообщения»:

![mailings-test-mode-workflow-messages-in-all-blocks1.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/mailings-test-mode-workflow-messages-in-all-blocks1.png)

![mailings-test-mode-workflow-messages-in-all-blocks2.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/mailings-test-mode-workflow-messages-in-all-blocks2.png)

По каждому блоку выводятся рассылки для последних **десяти клиентов**.  
При повторных прохождениях будет показано последнее сформированное для клиента письмо.

### В операции

Посмотреть отдельно письма из операции нельзя, только в общем списке [из рассылки](mailings-test-mode.md#v-rassylke).

## Завершение теста и запуск рассылки

Чтобы запустить рассылку, нужно отключить режим тестирования в использующей ее механике.  
В сценариях и операциях включение и выключение теста **доступно только в режиме редактирования**.

Важно

Завершение теста сценария не влияет на переключатель «Тестировать рассылку» в шаге отправки. Он возвращается в то состояние, в котором был на момент настройки сценария.

Сформированные за время теста **сообщения отправить нельзя**.
