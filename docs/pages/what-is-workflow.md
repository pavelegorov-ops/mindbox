# Что такое сценарии и как ими пользоваться

Сценарий — это алгоритм взаимодействия с пользователями на определенном этапе клиентского пути, основанный на поведении до и во время прохождения подобранной цепочки.

## Зачем использовать сценарии

Сценарии позволяют:

- автоматически реагировать на изменения и действия клиентов;
- персонализировать коммуникации на основе всех имеющихся данных по пользователю;
- настраивать каскады для увеличения охвата механик;
- определять наиболее эффективные пути коммуникации на конкретных этапах.

### Блоки сценария

Цепочки сценария собираются из блоков, каждый со своей функцией и настройками:

![блоки](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%B1%D0%BB%D0%BE%D0%BA%D0%B8.png)

Поддерживается стабильная работа интерфейса сценариев **до 150 добавленных блоков**.

Стартовый блок **Настройки запуска**:

- **[Произошло событие](workflow-events.md)** — что запускает сценарий. Например, попадание клиента в базу, окончание сессии или изменение статуса заказа.
- **[По расписанию](workflow-schedule.md)** — запускать сценарий не по событию, а периодически: раз в сутки, по дням недели или месяца.

**[Условие](workflow-conditions.md)** — по каким клиентам и какого типа событиям отрабатывать.

**[Группа шагов](workflow-steps.md)** — какие действия выполнять в отношении клиентов.

**[Разделение](workflow-flow-splitter.md)** — выполнять разные шаги с заданной вероятностью.

**[Ожидание](workflow-delay.md)** — останавливать прохождение на заданное время.

**[АБ-тест](workflow-ab-tests.md)** — выполнять разные шаги в цепочке для определения наиболее эффективного.

**[Ограничение](workflow-limit.md)** — задавать лимит на прохождение цепочки.

Блоки соединяются в цепочку с помощью линий:

![what-is-workflow-chain.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/what-is-workflow-chain.png)

#### Массовое копирование и удаление блоков

Чтобы копировать или удалить несколько блоков за раз:

1. Выберите инструмент «Выделить несколько» на панели инструментов;
2. Выделите нужные блоки;
3. Удалите или скопируйте блоки по кнопке в правом углу выделенной области.

![what-is-workflow-select.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/what-is-workflow-select.png)

Горячие клавиши

- **выделить несколько** - Option (macOS) / Shift (Windows)
- **скопировать** — Cmd + C (macOS) / Ctrl + C (Windows)
- **вставить** — Cmd + V (macOS) / Ctrl + V (Windows)
- **удалить** — Backspace / Delete

Копировать блоки можно в том числе в другие сценарии на проекте.

### Частота применений к клиенту или заказу

Можно [задать лимит на частоту срабатываний](workflow-limit-per-customer.md) сценария: один раз за всё время, периодически или каждый раз:

![workflow-limit-start.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/workflow-limit-start.png)

### Время работы сценария

Можно задать интервал работы сценария.

Для этого:

1. Откройте настройки в правом верхнем углу экрана.
2. Укажите дату и время начала и/или окончания работы сценария.
3. При установке даты начала нажмите на кнопку «Запустить в будущем»; без этого сценарий автоматически **не запустится**:

![Снимок экрана 2023-02-02 в 10.29.14.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202023-02-02%20%D0%B2%2010.29.14%281%29.png)

*Сценарий работает только в марте 2023 года.*

- **Начало работы** — сценарий отрабатывает только по событиям, которые придут после этой даты.
- **Окончание работы** — аналогично ручной остановке сценария и работает по тем же [принципам](edit-workflow.md): клиенты в блоках ожидания останутся там на указанный срок, шаги выполняться не будут. Если сдвинуть дату, пока клиенты в ожидании, они пойдут дальше по цепочке.

### Ограничение сценария по сегменту

[Папка](folders.md), в которой находится сценарий, может быть ограничена сегментом:

![Снимок экрана 2024-04-02 в 08.12.28.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202024-04-02%20%D0%B2%2008.12.28.png)

В таком случае механика будет срабатывать только по клиентам, которые входят в сегмент. При этом они должны находиться в нем как на момент события, так и во время выполнения шагов. Иначе прохождение останавливается:

![Снимок экрана 2024-04-02 в 08.09.12.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202024-04-02%20%D0%B2%2008.09.12.png)  
*Клиент не был в сегменте на момент события.*

![Снимок экрана 2024-04-02 в 08.11.54.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202024-04-02%20%D0%B2%2008.11.54.png)  
*Клиент не был в сегменте при попадании в группу шагов.*

- Если черновик нельзя запустить из-за какого-то блока, можно его выделить кликом по кнопке «Показать ошибки»:

![Снимок экрана 2021-08-03 в 14.58.03.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-08-03%20%D0%B2%2014.58.03.png)

## Запуск сценария

### Тестовый режим сценария

С помощью [тестирования сценария](workflow-test-mode.md) можно проверить, что механика настроена корректно ещё до запуска: посмотреть распределение клиентов по цепочкам и сформировать тестовые сообщения.  
При этом группы шагов не выполняются, а ожидания пропускаются:

![workflow-test-mode-in-progress.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/workflow-test-mode-in-progress.png)

### Редактирование сценария

Чтобы изменить настройки сценария:

1. Нажмите на кнопку «Редактировать».  
   Создается черновая версия, которая не влияет на запущенный сценарий. Он продолжает работать как раньше.
2. Внесите изменения.
3. Кликните на «Запуск» → черновик запускается, предыдущая версия останавливается.
4. Для сброса версии нажмите в меню на «Удалить черновик».

[Как изменение сценария влияет на прохождения клиентов.](edit-workflow.md)

- Кликом можно перейти в настройки версии на момент её работы. Чтобы вернуться назад, нажмите на соответствующую кнопку.

## Добавление комментариев

Комментарии помогают сохранять и передавать контекст сложных сценариев прямо на канве. Это упрощает совместную работу и позволяет сохранять важную информацию о логике сценария или задачах.

### Как добавить комментарий

- Перейдите в режим комментирования по кнопке в боковом меню.
- Кликните по канве в нужном месте, чтобы добавить новый комментарий.
- Введите текст (до 500 символов) и сохраните.

![workflow-add-comment.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/workflow-add-comment.png)

После добавления:

- перемещайте комментарий по канве,
- изменяйте размер выделенной области,
- удаляйте лишние комментарии.

## Массовое управление сценариями

Одновременно запускайте, останавливайте или удаляйте несколько сценариев из списка кампаний:

- Отберите нужные сценарии с помощью фильтров
- Выделите их с помощью чекбоксов
- Выберите действие (запустить, остановить, удалить)

![scenarios-mass-manage](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/scenarios-mass-manage.png)

**Примеры использования:**

- Механика состоит из нескольких сценариев, которые нужно запустить одновременно.
- Остановить все сценарии с проблемами на время редактирования (галочка «Сценарии с проблемами»).
- Найти все тестовые сценарии, выбрать ненужные и удалить.
