# Как массово открепить дисконтные карты

После открепления карты стирается ее статус, так что ее можно будет выдать повторно даже при блокировке в прошлом.

Чтобы открепить карты, перейдите в раздел **Настройки** → **Клиенты и действия** → **Дисконтные карты**:

![bulk-discountcard-unlink-path.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/bulk-discountcard-unlink-path.png)

## Через интерфейс

1. С помощью чекбоксов выберите карты, которые нужно открепить.
2. Нажмите на кнопку «Открепить карты»:

   ![bulk-unlink-button.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/bulk-unlink-button.png)
3. Подтвердите действие:

   ![bulk-unlink-accept.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/bulk-unlink-accept.png)
4. Появится ссылка на задачу, в которой можно отслеживать статус выполнения:

   ![bulk-unlink-link.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/bulk-unlink-link.png)

## Через импорт файла

1. Нажмите на **Импорт, открепление и удаление**:

   ![Снимок экрана 2021-04-30 в 10.17.32 — копия.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-04-30%20%D0%B2%2010.17.32%C2%A0%E2%80%94%20%D0%BA%D0%BE%D0%BF%D0%B8%D1%8F.png)
2. Выберите операцию «Открепление дисконтных карт» и скачайте пример файла:

   ![bulk-discountcard-unlink-example.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/bulk-discountcard-unlink-example.png)
3. В колонке `Number` перечислите номера карт:

   ![bulk-discountcard-unlink.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/bulk-discountcard-unlink.png)
4. Загрузите файл и запустите открепление карт по кнопке «Добавить задачу»:

   ![bulk-discountcard-unlink-upload.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/bulk-discountcard-unlink-upload.png)
5. Появится ссылка на задачу:

   ![bulk-discountcard-unlink-link.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/bulk-discountcard-unlink-link.png)

Были откреплены карты с номерами 1234500 и 1234501:

![bulk-discountcard-unlink-result.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/bulk-discountcard-unlink-result.png)
