# Как выдать действие в карточке клиента

Задача: выдать действие одному клиенту.

Зачем?  
Например, есть сценарий, который запускается при выдаче определенного действия. Надо, чтобы клиент попал в этот сценарий.

В карточке клиента для выдачи доступны действия категории I уровня **«Личные действия клиента»**.

Если клиентов много, то можно воспользоваться [массовым импортом действий](как-массово-импортировать-действия-по-файлу).

---

1. На вкладке **Клиенты** нажимаем на ФИО нужного и переходим в его карточку:

![Снимок экрана 2022-06-19 в 15.19.00.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-06-19%20%D0%B2%2015.19.00.png)

2. Выбираем в меню «Выдать действие»:

![Снимок экрана 2022-06-19 в 15.19.23.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-06-19%20%D0%B2%2015.19.23.png)

3. Выбираем шаблон действия (и бренд на многобрендовых проектах) и нажимаем «Добавить»:

![Снимок экрана 2022-06-19 в 15.20.00.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-06-19%20%D0%B2%2015.20.00.png)

- Действие появляется у клиента в профиле в разделе «Лента активности → Действия»:

![Снимок экрана 2022-06-19 в 15.20.36.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-06-19%20%D0%B2%2015.20.36.png)
