# Экспорт данных для аналитики

Интеграция для аналитики позволяет читать большие объемы данных быстро и надежно.

**Для экспорта доступны данные по сущностям:**

- Заказы и позиции заказов;
- Точки контакта;
- Изменения баланса бонусных счетов;
- Рассылки;
- Папки;
- Статусы рассылок;
- Тематики подписки;
- Объединения клиентов;
- АБ-тесты;
- Варианты АБ-тестов;
- Участники АБ-тестов;
- Сегментации и сегменты;
- История сегментов клиентов.

Функционал будет дополняться.

## Особенности и ограничения интеграции

- Можно создать не более одной интеграции;
- Данные для аналитики обновляются раз в сутки к 00:00 UTC;
- Данные из автоудаления попадают в аналитику, удаленные вручную — нет;
- Точность данных для аналитики составляет 99%. Это означает, что не менее 99% данных, которые есть на проекте, доступны для экспорта.

## Как создать интеграцию

Для того, чтобы завести новую точку интеграции, зайдите в раздел **Интеграции** и нажмите «Добавить интеграцию»:

![image.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/image%28403%29.png)

Выберите пресет «Данные для аналитики»:

![image.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/image%28404%29.png)

Создайте точку интеграции по кнопке «Создать»:

![image.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/image%28405%29.png)

Параметры доступа:

- **URL хранилища данных** — адрес, по которому будут доступны данные после создания точки интеграции.
- **Секретный ключ** — необходим для получения доступа к данным.
- **Ключ шифрования** — необходим для получения зашифрованных данных.
