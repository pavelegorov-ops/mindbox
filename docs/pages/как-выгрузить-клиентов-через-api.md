# Как экспортировать данные через API

Чтобы выгрузить данные через API:

1. Перейдите в раздел «Кампании», затем в ту кампанию, где нужно создать операцию.

Нажмите «Добавить» и выберите «Операцию» (подробнее об операциях можно узнать [тут](%D0%BE%D0%BF%D0%B5%D1%80%D0%B0%D1%86%D0%B8%D0%B8-v-%D0%BE%D1%81%D0%BD%D0%BE%D0%B2%D0%BD%D1%8B%D0%B5-%D1%81%D0%B2%D0%B5%D0%B4%D0%B5%D0%BD%D0%B8%D1%8F.md)

![Снимок экрана 2020-10-20 в 16.32.43.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202020-10-20%20%D0%B2%2016.32.43.png)

2. Настройки операции:

- точка [интеграции](%D0%BA%D0%B0%D0%BA-%D1%81%D0%BE%D0%B7%D0%B4%D0%B0%D1%82%D1%8C-%D0%B8-%D0%BD%D0%B0%D1%81%D1%82%D1%80%D0%BE%D0%B8%D1%82%D1%8C-%D1%82%D0%BE%D1%87%D0%BA%D1%83-%D0%B8%D0%BD%D1%82%D0%B5%D0%B3%D1%80%D0%B0%D1%86%D0%B8%D0%B8.md), через которую будет осуществляться запрос
- шаг «Экспорт - выгрузить клиентов»
- выберите данные для экспорта

![Снимок экрана 2020-10-27 в 21.38.05.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202020-10-27%20%D0%B2%2021.38.05.png)

3. Контракт операции можно получить, если редактировать операцию и нажать «Посмотреть описание»

![Снимок экрана 2020-09-24 в 20.46.42.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202020-09-24%20%D0%B2%2020.46.42%281%29.png)

4. Подробнее о контракте экспорта клиентов описано на [Developers](https://developers.mindbox.ru/docs/%D0%BE%D0%B1%D1%89%D0%B8%D0%B9-%D0%BF%D1%80%D0%B8%D0%BD%D1%86%D0%B8%D0%BF-%D1%8D%D0%BA%D1%81%D0%BF%D0%BE%D1%80%D1%82%D0%BE%D0%B2) в разделе «Экспорты»
