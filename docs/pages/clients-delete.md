# Как удалить клиентов по фильтру

Клиенты удаляются полностью, без сохранения информации.

Удаляются также все их действия, включая данные о рассылках и заказах, что может привести к статистическим изменениям в отчетах.

1. Переходим в раздел **Данные** → **Клиенты**:

![страница клиентов.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D1%81%D1%82%D1%80%D0%B0%D0%BD%D0%B8%D1%86%D0%B0%20%D0%BA%D0%BB%D0%B8%D0%B5%D0%BD%D1%82%D0%BE%D0%B2.png)

2. Строим фильтр, по которому хотим удалить клиентов. Например, удалить клиентов с невалидными адресами:

![Снимок экрана 2022-06-08 в 19.43.41.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-06-08%20%D0%B2%2019.43.41.png)

3. Выбираем всех, кого хотим удалить:

![Снимок экрана 2022-06-08 в 19.44.05.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-06-08%20%D0%B2%2019.44.05.png)

4. В меню нажимаем «Удалить»:

![Снимок экрана 2022-06-08 в 19.44.46.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-06-08%20%D0%B2%2019.44.46.png)

Подтверждаем:

![Снимок экрана 2022-06-08 в 19.45.12.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-06-08%20%D0%B2%2019.45.12.png)

Получаем ссылку на задачу:

![Снимок экрана 2022-06-08 в 19.45.47 — копия.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-06-08%20%D0%B2%2019.45.47%C2%A0%E2%80%94%20%D0%BA%D0%BE%D0%BF%D0%B8%D1%8F.png)

5. Ждем успешного выполнения задачи:

![Снимок экрана 2022-06-08 в 19.49.46.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202022-06-08%20%D0%B2%2019.49.46.png)

Готово — клиенты удалены:
