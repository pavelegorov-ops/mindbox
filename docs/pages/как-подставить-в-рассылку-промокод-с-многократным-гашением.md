# Как подставить в рассылку промокод с многократным гашением

Задача: подставить в рассылку промокод из пула с многократным гашением.

Такие коды находятся в пулах со следующими настройками в разделе «Использование»:

![reusable-promocode.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/reusable-promocode.png)

Пул должен быть в статусе «Можно использовать»

Используем [параметр](%D1%87%D1%82%D0%BE-%D1%82%D0%B0%D0%BA%D0%BE%D0%B5-%D1%88%D0%B0%D0%B1%D0%BB%D0%BE%D0%BD%D0%B8%D0%B7%D0%B0%D1%82%D0%BE%D1%80.md) вида:

```
${MultiplePromoCodes.WithTypePool.FirstAvailable.Value}
```

Pool — системное имя параметра.

Параметр складывается из:  
MultiplePromoCodes. + WithType + *Название параметра в шаблонизаторе* . + FirstAvailable. + Value

Рассмотрим пул со следующими настройками:

![Снимок экрана 2021-05-11 в 22.28.20.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-05-11%20%D0%B2%2022.28.20.png)

Вывод значения:

```
${MultiplePromoCodes.WithTypeMnogo.FirstAvailable.Value}
```

Дата старта использования:

```
${MultiplePromoCodes.WithTypeMnogo.FirstAvailable.StartDateTime}
```

Дата окончания использования:

```
${MultiplePromoCodes.WithTypeMnogo.FirstAvailable.ExpirationDateTime}
```
