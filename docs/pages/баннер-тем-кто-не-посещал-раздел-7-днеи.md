# Как добавить баннер для тех, кто не посещал раздел 7 дней

Для добавления попапа требуется зайти на проект (название проекта.mindbox.ru).

По [ссылке](%D0%BA%D0%B0%D0%BA-%D1%81%D0%BE%D0%B7%D0%B4%D0%B0%D1%82%D1%8C-%D0%BF%D0%BE%D0%BF-%D0%B0%D0%BF.md) - инструкция по созданию поп-апа - здесь описано как добавлять трекер на сайт, тестировать форму и как настраивать условия показа.

На данный момент вы можете выбрать из более чем 100 примеров. Для этого вам нужно зайти в “Кампании” в меню слева, выбрать нужную кампанию из списка кампаний, затем нажать “**Попапы**” - “**Добавить**” - “**Попап**”.

## Выбираем шаблон

Находим из предложенных вариантов нужную форму, нажимаем “Выбрать”.

![Снимок экрана 2021-01-25 в 22.57.44.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-01-25%20%D0%B2%2022.57.44%281%29.png)

После выбора шаблона укажите сайт:

![выбрать сайт.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%B2%D1%8B%D0%B1%D1%80%D0%B0%D1%82%D1%8C%20%D1%81%D0%B0%D0%B9%D1%82.png)

## Внешний вид формы

В разделе «Попап» нажмите «Изменить», затем — «Редактировать»:

![редактировать попап.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D1%80%D0%B5%D0%B4%D0%B0%D0%BA%D1%82%D0%B8%D1%80%D0%BE%D0%B2%D0%B0%D1%82%D1%8C%20%D0%BF%D0%BE%D0%BF%D0%B0%D0%BF.png)

### Адаптируем шаблон под сайт

1. Все тексты;  
   Если в тексте нужен перенос строки используйте тег в поле ввода на месте переноса < br >.
2. Картинки и иконки;
3. Кнопка формы - здесь можно настроить какое действие будет у кнопки (переход по ссылке или закрытие попапа);
4. Далее настраиваем отступы и размеры для мобильных устройств и десктопа;
5. Далее настраиваем размеры шрифтов и общие настройки для шрифтов

Здесь можно указать настройки для шрифта или использовать [свой шрифт](%D0%BA%D0%B0%D0%BA-%D0%B4%D0%BE%D0%B1%D0%B0%D0%B2%D0%B8%D1%82%D1%8C-%D1%81%D0%B2%D0%BE%D0%B8-%D1%88%D1%80%D0%B8%D1%84%D1%82-%D0%B2-%D0%BF%D0%BE%D0%BF-%D0%B0%D0%BF.md) с сайта.

6. Рамки и границы формы;
7. Скрытие элементов формы;
8. Цвета формы;

Выберите подходящие цвета. Рекомендуем для подбора цвета с формы использовать расширение для браузера [Eye Dropper](https://chrome.google.com/webstore/detail/eye-dropper/hmdcmlfkchdmnmnmheododdhjedfccka?hl=ru) или же использовать номер цвета с брендбука компании.

### Определите расположение формы на экране

По умолчанию форма показывается посредине экрана. Изменить расположение формы на экране можно с помощью кнопки в нижнем левом углу экрана:

![Снимок экрана 2021-01-25 в 23.00.35.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-01-25%20%D0%B2%2023.00.35.png)

По умолчанию на мобильных устройствах и планшете применяются такие же условия, как и на десктопе. Но можно изменить эти настройки, особенно, если вы используете отступы на десктопе (чтобы на мобильных устройствах форма не улетела за края экрана из-за отступов).

![Снимок экрана 2021-01-25 в 23.02.54.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-01-25%20%D0%B2%2023.02.54.png)

## Настраиваем таргетинг

Так будет выглядеть фильтр по тем, кто за последние 7 дней посетил меньше 1 раза раздел сайта, который содержит в URL “**sale**”.

![Снимок экрана 2021-01-26 в 11.52.27.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-01-26%20%D0%B2%2011.52.27.png)

Далее переходим в “**Редактирование шаблона**”. Для этого нажимаем “**Изменить**” напротив пункта “**Внешний вид формы**”.

![Снимок экрана 2021-01-25 в 23.00.10.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-01-25%20%D0%B2%2023.00.10%281%29.png)
