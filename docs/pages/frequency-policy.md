# Контроль частоты рассылок

Контроль частоты рассылок позволяет **ограничить количество рассылок** на клиента в сутки в рамках бренда и каналов.

## Включение и настройка

1. Перейдите в раздел **Настройки** → **Оптимизация коммуникаций** → **Контроль частоты рассылок** и включите функцию:

![frequency-policy-find.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/frequency-policy-find.png)

Контроль частоты начинает действовать сразу. По умолчанию стоит лимит в 30 сообщений в день.

2. Задайте **общее ограничение** по бренду:

![frequency-policy-total.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/frequency-policy-total.png)

- Подсчет — по [статусу](customer-message-statuses.md) «Отправлена»
- Расчетный период — календарные сутки с 00:00 по 23:59 по часовому поясу проекта
- Каналы: Email, SMS, Viber, MobilePush, WebPush

**Не учитываются:**

- транзакционные рассылки;
- тестовые письма.

1. Можно задать **ограничения в рамках отдельных каналов**:

![Снимок экрана 2024-10-09 в 16.20.42.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202024-10-09%20%D0%B2%2016.20.42.png)

Сумма значений по каналам может быть больше общего ограничения. В таком случае отправка может быть остановлена из-за превышения лимита в канале или суммарно во всех коммуникациях.

> Например, контроль частоты настроен по скриншоту выше.  
>   
> Пользователь уже получил SMS и email → за текущие сутки ему получится отправить не более двух пушей.

Если не задано значение для канала, ограничение канала равно общему лимиту бренда.

> Равнозначные настройки:  
> ![Снимок экрана 2024-10-09 в 16.17.32.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202024-10-09%20%D0%B2%2016.17.32.png)  
> ![Снимок экрана 2024-10-09 в 16.17.13.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202024-10-09%20%D0%B2%2016.17.13.png)

4. Можно указать **сегмент исключения**: клиенты, на которых контроль частоты действовать не будет.

![frequency-policy-segment.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/frequency-policy-segment.png)

- Сегмент должнен быть [статическим](segments-clients.md#3-staticheskij);
- При попадании или выходе из сегмента изменения для клиента вступают в силу на следующий день.

5. Сохраните настройки бренда.

При редактировании настроек изменения применяются сразу.

## После достижения лимита

Рассылки сверх порога не отправляются.

Клиенту выдается статус неотправки с соответствующей причиной (*«[Коммуникационная политика] Клиент уже получил максимум сообщений сегодня»*):

![неотпр.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%BD%D0%B5%D0%BE%D1%82%D0%BF%D1%80.png)

## Игнорировать в рассылке

Чтобы игнорировать контроль частоты в рамках рассылки, в ее разделе **Общие настройки — Профиль** включите опцию «Высокий приоритет»:

![frequency-policy-ignore.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/frequency-policy-ignore.png)

Получатели с достигнутым лимитом не будут исключаться из рассылки, но сама отправка будет учитываться в подсчете коммуникаций для клиентов.

Эту настройку можно переключать в том числе в автоматических рассылках в статусе «Готова к использованию».
