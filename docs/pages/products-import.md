# Как импортировать продукты

1. Переходим на вкладку **Данные** → **Продукты**:

![Снимок экрана 2021-08-24 в 14.37.32.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-08-24%20%D0%B2%2014.37.32.png)

2. Нажимаем «Импорт» → «Импорт продуктов»:

![Снимок экрана 2021-08-24 в 16.21.09.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-08-24%20%D0%B2%2016.21.09.png)

3. Выбираем операцию «Импорт продуктов». Для скачивания доступен шаблон файла с примером:

![Снимок экрана 2021-08-24 в 16.23.19.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-08-24%20%D0%B2%2016.23.19.png)

Под шаблоном с примером расположены названия колонок для импорта с описанием и подробностями.

Обязательной для заполнения колонкой является идентификатор во внешней системе.

**Категорию** выбирать необязательно, но в таком случае продукты нельзя будет отфильтровать по этому условию.  
Продукт может быть одновременно в нескольких категориях. В таком случае перечисляем их в ячейке с разделителем |.  
Если в файле указать категорию, которой нет на проекте, для продукта создастся верхнеуровневая «Неизвестная категория».

5. Заполняем файл.

Пример:

![Снимок экрана 2021-08-24 в 17.14.42.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-08-24%20%D0%B2%2017.14.42.png)

6. Добавляем файл и нажимаем «Добавить задачу»:

![Снимок экрана 2021-08-24 в 17.15.15.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-08-24%20%D0%B2%2017.15.15.png)

7. Появляется ссылка на задачу:

![Снимок экрана 2021-08-24 в 17.15.28.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-08-24%20%D0%B2%2017.15.28.png)

8. Ждём завершения задачи:

![Снимок экрана 2021-08-24 в 17.16.38.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-08-24%20%D0%B2%2017.16.38.png)

9. Проверяем, что продукты появились на проекте:

![Снимок экрана 2021-08-24 в 17.21.13.png](https://storage.yandexcloud.net/assets-help-mindbox-ru/images/%D0%A1%D0%BD%D0%B8%D0%BC%D0%BE%D0%BA%20%D1%8D%D0%BA%D1%80%D0%B0%D0%BD%D0%B0%202021-08-24%20%D0%B2%2017.21.13.png)
