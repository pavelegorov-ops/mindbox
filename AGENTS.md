# AGENTS.md — вход для агентов

**Полная навигация по репо — в [`CLAUDE.md`](CLAUDE.md). Прочитай его,
независимо от того, каким агентом ты являешься.** Здесь — только то,
что нужно знать до его чтения.

## Что это

Локальная база знаний по платформе MindBox: публичный **движок**
(скрейперы документации, генератор сценариев, приёмы работы с админкой)
плюс **приватные данные тенанта**, подключаемые отдельным клоном в
`private/<имя>/`. Активный тенант — единственный подкаталог `private/`
кроме `_template/` (сейчас: `private/usmall-mindbox/`).

## Чего нет в свежем клоне

Корпуса документации `docs/`, `developers/`, `journal/` — **derived и
не коммитятся** (.gitignore): они скрейпятся локально с официальных
сайтов MindBox. Если их нет или они пустые — см. [BOOTSTRAP.md](BOOTSTRAP.md);
рукописные `CLAUDE.md` внутри корпусов при этом остаются в git.
BM25-индекс `journal/*/search_index.pkl` тоже собирается локально
(`python scripts/build_bm25.py`).

## Главные маршруты

- Вопросы «как настроить X в MindBox» → `docs/` (Help), интеграции/API →
  `developers/`; в обоих сначала `summaries.json`, потом страницы.
- Данные тенанта (сценарии, письма, пуши, операции, поля рассылок) →
  `private/<имя>/README.md` — там карта и таблица «где быстро найти ответ».
- Impact-анализ «что сломается, если удалить сегмент/шаблон» →
  `private/<имя>/scenarios/rendered/dependencies.md`.
- Приёмы выгрузки из админки и известные грабли → `notes/`.

## Правила поиска

- Ищи по Markdown/YAML: `rg -g "*.md" -g "*.yaml" <запрос>` — широкий
  grep тонет в HTML-снапшотах писем и страниц.
- На Windows читай файлы в UTF-8 (PowerShell: `-Encoding utf8`),
  иначе кириллица превращается в mojibake.
- Ссылки вида `../knowledge/...`, `../CLAUDE.md` ведут во внешний
  воркспейс CRM — в отдельном клоне этого репо они не работают.

Ничего не коммить и не пушить без явной команды пользователя.
