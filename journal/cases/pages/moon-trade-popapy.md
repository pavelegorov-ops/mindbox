# Увеличили собираемость email для MOON-Trade в 3 раза с помощью попапов

[Во втором материале рассказываем, как компания зарабатывает 5,5% выручки](moon-trade.md) от общего дохода интернет-магазина с помощью email-канала и персональных рекомендаций.

## Гипотеза

После запуска 24 автоматических коммуникаций в email-канале взялись за [персонализацию сайта](/products/personalization/). Первоначальная гипотеза заключалась в том, что всплывающие окна позволят быстрее собрать базу контактов для email-рассылок. За два месяца запустили четыре всплывающих формы.

## Результаты

Под условия таргетинга всплывающих форм попадает около половины пользователей сайта (**46%**). Под все условия для показа форм выполняет больше половины из них (**59%**). Из них **3,5%** клиентов оставляют адрес электронной почты во всплывающих окнах. На графике — глобальная статистика по всем всплывающим окнам за две недели.

![Доля клиентов, оставляющих контакты во всплывающих окнах, от всех посетителей сайта](https://image.mindbox.ru/draw/8115e42d-18ef-42ea-a3a8-93523f0d22ee.png/-/size/1600/webp/1 "Доля клиентов, оставляющих контакты во всплывающих окнах, от всех посетителей сайта")

### История тестирования главного всплывающего окна со специальным предложением для сбора адресов

Всплывающие механики реализовали с помощью продукта «Персонализация сайта» на базе платформы [Popmechanic](https://popmechanic.io/). Менеджер Popmechanic помог сформулировать первые гипотезы и запустить тестирование.

Чтобы собирать email-адреса новых клиентов, настроили всплывающее окно со специальным предложением. Изначально это был попап, который показывается только новым клиентам.

После устроили тест: сравнили обычный попап с интерактивным — в нем добавили «колесо удачи». Конверсия клиентов из анонимных в оставивших почту увеличилась в 3,5 раза. Первый попап собирал **0,8%** от всех увидевших всплывающее окно. Попап с интерактивом собирал **2,8% клиентов от всего посетителей, попавших под условия всплывающего окна**.

На запуск тестирования потратили менее часа: не требовалось участие IT-специалистов или маркетолога для запуска новых форм. К тому же функционал [Popmechanic](https://popmechanic.io/) позволяет:

1. Быстро запускать AB-тесты виджетов, сохраняя существующие интеграции с внешними сервисами и условия отображения форм.
2. Выбрать готовый шаблон «Колеса фортуны» — его не нужно верстать и программировать.

## Какие кампании запустили

Загрузили данные клиентов из всех источников в [CDP](/products/cdp/). После этого начали запускать автоматические кампании. Сначала email-рассылки, затем — персонализацию сайта. Рассылки — для увеличения выручки, персонализация — для сбора «лидов» и конверсии в первый заказ.

Для интеграции персонализации сайта потребовалось только поставить код инициализации сервиса на сайте. Кампании запускались без привлечения IT. Расскажем про несколько кампаний персонализации сайта.

### Всплывающее окно с колесом фортуны

Это всплывающее окно мы описали выше. Показывается только новым клиентам и представляет из себя рулетку. Клиент вводит адрес электронной почты и получает письмо с одним из нескольких возможных призов.

![Всплывающее окно с интерактивными элементами](https://image.mindbox.ru/draw/23b7128b-b963-478a-907d-1948ca1eab5d.gif/-/size/1600/webp/1 "Всплывающее окно с интерактивными элементами")

### Попап для сохранения корзины

Если новый клиент сайта добавляет товар в корзину и выполняет несколько ключевых условий, ему показывается попап с предложением заморозить цены на товары в корзине на ближайшие несколько дней в обмен на адрес электронной почты.

![](https://image.mindbox.ru/draw/b77cf0f3-0c1f-47a4-b9ab-3253782abd2c.png/-/size/1600/webp/1 "Предложение заморозить цены")

### Приветственное всплывающее окно для жителей Воронежа

Чтобы клиенты получали персонализированные предложения на сайте, любой контент можно таргетировать в разрезе поведения клиента (история покупок, подписок, взаимодействие с рассылками) и других данных: место проживания, используемое устройство, источник перехода или текущие день и месяц. Используя эти возможности, маркетолог MOON-Trade настроил всплывающее окно, которое показывается только новым посетителям сайта из Воронежа.
