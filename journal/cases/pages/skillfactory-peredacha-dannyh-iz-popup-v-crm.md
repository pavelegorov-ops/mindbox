# SkillFactory увеличил С1 на 3,39%, настроив  корректную передачу данных из попапов в CRM

SkillFactory ― онлайн-школа, в которой можно получить профессию аналитика, разработчика, дизайнера или маркетолога.

## Задача: настроить корректную передачу данных с сайта в AmoCRM

SkillFactory размещает на сайте и лендингах попапы, которые использует для двух целей:

- собрать контакты;
- перенаправить пользователей на другой лендинг, например, чтобы зарегистрироваться на вебинар.

Когда пользователи взаимодействуют с попапами, необходимо, чтобы их данные автоматически попадали в AmoCRM. В данные входят не только их контакты, но и дополнительная информация, например [UTM-метки](https://mindbox.ru/journal/education/chto-takoe-utm-metki/) — utm_source и utm_campaign, чтобы знать, из какого канала и страницы пришел клиент.

Когда SkillFactory делали попапы в другом сервисе, у них не получалось настроить правильную передачу данных. Из-за этого некоторые дополнительные поля не попадали в карточку клиента в AmoCRM. Например, туда не попадало поле «курс», которое показывает, каким именно курсом интересовался пользователь.

Как следствие, менеджерам по продажам приходилось тратить больше времени на подготовку подходящего предложения для клиента.

У попапов на другой платформе была неплохая механика, но для нас не подходила из-за ограниченного количества настроек. Мы не могли дальше расти в ассоциативной выручке, поэтому приостановили запуск попапов. Для наших бизнес-целей нам больше подошел Mindbox.

Настроить корректную передачу данных в другом сервисе не получилось, поэтому перед SkillFactory встала дополнительная задача: бесшовно переехать на Mindbox, не потеряв функциональность.

## Решение: перенести попапы в Mindbox, чтобы настроить передачу всех необходимых данных в AmoCRM

[Как передать данные из формы на проект](https://help.mindbox.ru/docs/%D0%BA%D0%B0%D0%BA-%D0%BF%D0%B5%D1%80%D0%B5%D0%B4%D0%B0%D1%82%D1%8C-%D0%B4%D0%B0%D0%BD%D0%BD%D1%8B%D0%B5-%D0%B8%D0%B7-%D1%84%D0%BE%D1%80%D0%BC%D1%8B-%D0%BD%D0%B0-%D0%BF%D1%80%D0%BE%D0%B5%D0%BA%D1%82)

В Mindbox SkillFactory собирает нужные данные, настроив те же два вида попапов:

1. Попап для сбора контактов: имя, телефон, email. Например, блогер постит у себя ссылку с UTM-меткой. Когда клиент переходит по ней, ему показывают попап. Лид попадает в Mindbox, который через вебхуки передает данные по нему в AmoCRM, сохраняя при этом исходные UTM-метки.

![](https://image.mindbox.ru/draw/kLp0LvVUxhpjxRA6gxoHr1cVezhXkTqjO9GWORXD.png/-/size/1600/webp/1 "Картинка")

С помощью таких попапов отдел продаж может связаться с клиентом, чтобы договориться о покупке курса

2. Попап для перехода на другой лендинг. После клика на попап пользователь попадает на другой лендинг, например бесплатного продукта, где он может зарегистрироваться. При этом Mindbox обеспечивает передачу UTM-меток на всем пути движения клиента.

![Такие попапы связывают сайт с другими продуктами компании](https://image.mindbox.ru/draw/x91icQsgkOqaL3rDKA9icIXrVpcDCqSruCVtK3yp.png/-/size/1600/webp/1 "Картинка")

Такие попапы связывают сайт с другими продуктами компании

По словам SkillFactory, у Mindbox есть ещё одно преимущество по сравнению с предыдущим сервисом — возможность сегментировать аудиторию для демонстрации попапов по нескольким условиям:

- «100% скролла» — клиенту показывают попап после того, как он пролистает страницу до самого низа;
- «на выход» — попап появляется на экране, когда клиент собирается закрыть страницу;
- «только на ПК» — попапы показываются только на определенных устройствах.

## Результат: данные легко анализировать и использовать в работе, потому что они хранятся в одной системе

После запуска механики решилась проблема с аналитикой: данные с сайта через Mindbox попадают в AmoCRM, где с ними может работать отдел продаж, а результативность попапов можно отслеживать в отчетах по лидам Mindbox. При этом SkillFactory продолжает использовать привычные виды попапов и может сегментировать их по каналам трафика.

Мы довольны результатом: теперь со стороны бизнес-процессов сделки формируются корректно. Мы получаем больше лидов и сейчас решаем, как масштабировать механику. Например, в канале performance запустили попапы, которые ведут на [страницу с подборкой курсов со скидками](https://contented.ru/sale?utm_source=yandex&utm_medium=cpc&utm_campaign=none_cd_all_yandex_cpc_sale_brand-poisk_world_sf_all&utm_content=all&utm_term=none). В результате в Q2 увеличили C1 в бренде Yandex на 1,67%, Google ― 3,39% и выручку канала на 660 037 рублей

С начала июня 2023 года мы завели попапы в каналах influence, performance и CRM. Есть планы завести их на других каналах и сделать геймифицированные попапы для «черной пятницы» и Нового года.
