Mindbox стал для нас мастер-CDP, позволившей реализовать технические решения на основе уже имеющегося функционала и закрыть все коммуникационные и потребности в хранении данных.

Мы используем данные, собранные и упорядоченные платформой, для принятия стратегических решений. Так, команда аналитиков Mindbox помогла нам построить срезы аудитории — с этими профилями пользователей сейчас работают наши аналитики.

При этом Mindbox — не просто статичное место для хранения данных, а полноценный партнер, способный реализовать самые инновационные решения.

Продукт Mindbox  
[CDP](/products/cdp/?frompage=ploom)

На момент запуска Ploom на российском рынке уже были представлены системы нагревания табака от других производителей, поэтому JTI IP было важно максимально быстро и качественно построить инфраструктуру проекта и подключить к ней e-commerce, офлайн-точки продаж и персональных менеджеров. Принципиально было отсечь от любых коммуникаций тех, кто не является потребителем никотинсодержащей продукции, и тех, кому еще не исполнилось 18.

Расскажем в кейсе об особенностях построенной экосистемы коммуникаций — она основана на решениях, разработанных JTI IP совместно с нами:

- Сбор данных совершеннолетних потребителей никотинсодержащей продукции через планшеты в торговых объектах
- Отсеивание несовершеннолетних посетителей сайта ploom.ru и при необходимости проверка их возраста вручную
- Сбор заявок на аренду устройства для нагревания табака Ploom и выдачу QR-кодов для его приобретения по специальной цене в розничных магазинах
- Сегментация клиентов JTI IP при звонках в службу поддержки и в информационных рассылках
- Общение с клиентами JTI IP с помощью чат-бота и избавление их от лишних действий при регистрации в базе совершеннолетних потребителей никотинсодержащей продукции
- Построение отчетов на машинном обучении на основе данных из Mindbox

**Предыстория проекта: почему JTI IP выбрал нашу платформу.** JTI IP унаследовал Mindbox как мастер-CDP от российского подразделения Japan Tobacco International. Digital CRM Lead JTI IP Егор Трушников уже имел опыт работы с платформой и посчитал её функционал достаточным для создания омниканальной экосистемы Ploom.

## Как собираем информацию о клиентах в торговых объектах

В «Авиапарке» и других крупных торговых центрах находятся торговые павильоны Ploom (так называемые pop-up stores):

![](https://image.mindbox.ru/draw/dcd5a1ee-53ab-48bd-a58b-a00697e8a502.jpg/-/size/1600/webp/1 "Торговые павильоны Ploom")

У каждого консультанта в павильоне есть планшет с программным обеспечением, которое является совместной разработкой JTI IP и Mindbox.

По запросу консультанты информируют совершеннолетних посетителей торгового павильона о характеристиках устройства для нагревания табака Ploom. В случае, если такой посетитель регистрируется в базе совершеннолетних потребителей никотинсодержащей продукции, его данные автоматически передаются в Mindbox. Здесь клиенты JTI IP делятся на сегменты в зависимости от ряда критериев, например от того, хотят ли они взять устройство для нагревания табака Ploom в аренду или уже купили его.

![Сегментация](https://image.mindbox.ru/storage/475defb4-0794-4fe1-8d4c-0aa94ee9a0b8.png)

## Как проверяем возраст посетителей сайта ploom.ru

**Для покупок.** На сайте можно купить устройство для нагревания табака Ploom и аксессуары к нему, но только, если вам исполнилось 18 лет. Чтобы соответствовать этому требованию, нужно отсечь несовершеннолетних посетителей сайта.

![Покупки на сайте ploom.ru возможны только после регистрации. Если указать дату рождения, при которой посетителю сайта заведомо меньше 18 лет, кнопка «Проверка возраста» не активируется](https://image.mindbox.ru/draw/27f01d4f-9d75-41ba-a8c9-122c77893776.jpg/-/size/1600/webp/1 "Покупки на сайте ploom.ru возможны только после регистрации")

Покупки на сайте ploom.ru возможны только после регистрации. Если указать дату рождения, при которой посетителю сайта заведомо меньше 18 лет, кнопка «Проверка возраста» не активируется

Проверка происходит автоматически — на стороне провайдера идентификации, по номеру телефона. Если по техническим причинам это невозможно, просим клиента загрузить скан документа, удостоверяющего личность:

![](https://image.mindbox.ru/draw/556b78bc-5e28-4f75-b3c5-f46d6d78f34c.jpg/-/size/1600/webp/1 "Проверка возраста")

Затем скан передается в Mindbox и оттуда — модераторам для ручной проверки. После подтверждения возраста посетителю открывается доступ к личному кабинету и интернет-магазину сайта.

**Для аренды.** На сайте также можно заказать аренду устройства для нагревания табака Ploom, заполнив анкету или написав менеджеру в удобном для посетителя мессенджере.

![После заполнения анкеты или общения с менеджером данные передаются в Mindbox](https://image.mindbox.ru/draw/e044463e-ee0b-4280-88ee-6b1fdb7185e6.jpg/-/size/1600/webp/1 "После заполнения анкеты или общения с менеджером данные передаются в Mindbox")

После заполнения анкеты или общения с менеджером данные передаются в Mindbox

Кроме основного сайта ploom.ru есть еще два:

![reg.ploom.ru нужен для получения QR-кода на специальную цену](https://image.mindbox.ru/draw/e3f9409a-2e82-4c87-9e16-3f7d0b18fbd4.jpg/-/size/1600/webp/1 "reg.ploom.ru нужен для получения QR-кода на специальную цену")

reg.ploom.ru нужен для получения QR-кода на специальную цену

На discoverploom.ru реализована такая же схема передачи данных, как и на ploom.ru: если клиент JTI IP оформляет заявку на аренду устройства для нагревания табака Ploom, информация об этом поступает в Mindbox и клиент JTI IP попадает в сегмент «Заявка на аренду».

На reg.ploom.ru всё немного сложнее: контактные данные не просто передаются в платформу — на нашей стороне также происходит проверка их уникальности. Это необходимое условие для онлайн-выдачи QR-кода.

## Как используем сегментацию клиентов JTI IP

**Для передачи информации на горячую линию.** После того как клиент JTI IP оставляет заявку на аренду устройства для нагревания табака Ploom, с ним связывается оператор горячей линии, чтобы назначить встречу с персональным менеджером.

В процессе аренды, а также при покупке устройства для нагревания табака Ploom, оператор горячей линии может позвонить клиентам JTI IP, чтобы помочь им разобраться с работой устройства, либо попросить оценить, насколько они довольны.

Информация о назначении персонального менеджера, а также результаты звонков и опросов автоматически попадают в Mindbox.

**Для триггерных рассылок.** Письма отправляются в зависимости от сегмента клиента JTI IP: покупатели или арендаторы. По просьбе JTI IP не показываем здесь примеры конкретных писем.

## Как общаемся с клиентами JTI IP с помощью чат-бота

Чат-бот используется для улучшения пользовательского опыта и работает в Telegram и на сайте ploom.ru. Сейчас чат-бот дает возможность зарегистрироваться в базе совершеннолетних потребителей никотинсодержащей продукции, подтвердить возраст, оформить аренду устройства для нагревания табака Ploom и так далее — всего шесть возможных сценариев.

![Начало переписки с чат-ботом в Telegram](https://image.mindbox.ru/draw/5f09ae57-731b-495b-b48a-b2e892266c93.jpg/-/size/1600/webp/1 "Начало переписки с чат-ботом в Telegram")

Начало переписки с чат-ботом в Telegram

В ближайшее время добавим товарные карточки — при нажатии клиент JTI IP будет попадать в интернет-магазин сайта ploom.ru, причем дополнительная авторизация для этого не потребуется. Если у клиента JTI IP нет личного кабинета, он будет создаваться на основе данных из Mindbox. Если возраст и личность клиента JTI IP уже подтверждены, доступ к личному кабинету на сайте ploom.ru сразу будет полным, без ограничений.
