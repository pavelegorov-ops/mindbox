# 3 часа → 1 час на верстку подборки товаров в рассылке. Как конструктор Mindbox экономит время команды Dreams by Alena Akhmadullina

Каждая рассылка Dreams by Alena Akhmadullina — это визуальная история, где важен каждый образ и деталь. Раньше создание идеальной раскладки товаров занимало до трех часов ручной работы. А если нужно было заменить один или несколько — приходилось верстать письмо заново.

Команда начала использовать новую функцию конструктора Mindbox — карточки товаров подтягиваются в письмо из фида продуктов. Для массовых рассылок товары можно выбрать вручную по артикулам, для автоматических — система сама формирует подборку. В результате время на верстку сократилось втрое, а товар в письме теперь можно заменить за несколько секунд.

## Задача: сократить время на подготовку рассылок

DREAMS by Alena Akhmadullina — вторая линия дизайнера Алены Ахмадуллиной в сегменте средний плюс. Коллекции DREAMS by Alena Akhmadullina состоят из выделенных капсул Smart, Romantic, Casual, Basic, которые решают любую стилистическую задачу современной женщины.

Капсулы поступают в продажу частями в течение сезона — невозможно анонсировать всю коллекцию сразу. Поэтому в каждой рассылке команда миксует товары из разных капсул и создает тематические блоки с визуальными историями.

Подборки товаров верстали вручную. Для каждой позиции маркетолог отдельно загружал картинку, прописывал название, указывал цену. Для акционных товаров нужно было добавить зачеркнутую старую цену — выделить текст, выбрать шрифт, поставить зачеркивание. На верстку одной рассылки с подборкой уходило 2–3 часа.

Данные о товарах не обновлялись автоматически. Если рассылку готовили заранее, перед отправкой приходилось вручную проверять актуальность цен и названий.

Любые правки превращались в проблему. Чтобы заменить один товар в подборке, нужно было заново прописать все параметры: загрузить новое изображение, ввести название и цену. Это занимало время и увеличивало риск ошибок.

Чтобы сократить время на подготовку рассылок и избавиться от ручного обновления данных, команда решила протестировать автоматический вывод в конструктор рассылок товаров из фида.

## Решение: использовать автоматическую подгрузку данных о товарах из фида

Mindbox добавил в конструктор рассылок функцию, которая позволяет собирать товарные подборки с автоматическим обновлением данных из фида.

**Как работает механика**

![](https://image.mindbox.ru/storage/pN3uIixy9WrwDTXAFIL2A9imFyWMHpYGKTbMnqNZ.png)

[

](https://image.mindbox.ru/storage/ouHMBXZJT0u0aa3qMToj5AcwB8M6NEKzlQt3ccKT.mp4)

Товары можно размещать по одному, по два или по три в ряд. Чтобы заменить товар, достаточно ввести новый артикул — все данные обновятся автоматически за несколько секунд

В настройках можно скрыть любые элементы карточки товара: название, цену, кнопку. Изменение применяется ко всем товарам в блоке сразу. Также настраиваются отступы между карточками, между блоками и по краям. Можно убрать отступы между изображениями полностью — для создания композиций на едином фоне.

В автоматические рассылки подтягиваются стандартные изображения товаров из фида — обычно это фотографии на белом фоне. Для массовых рассылок можно вручную заменить любое изображение на кадр из фотосессии: с моделью в полный рост, крупным планом или в интерьере.

## Результат: время на подготовку рассылки сократилось втрое

Механика дала два эффекта: операционный и маркетинговый.

**Операционная эффективность**

Верстка рассылки с товарной подборкой теперь занимает час вместо 2–3 часов. Раньше замена одного товара требовала переверстки: загрузить новое изображение, прописать название и цену. Теперь достаточно ввести в конструкторе новый артикул — все данные обновятся за несколько секунд.

**Маркетинговая эффективность**

Для проверки механики провели АВ-тест массовой рассылки с распределением аудитории 50 на 50: половине отправили письмо с подборкой товаров, половине — без.
