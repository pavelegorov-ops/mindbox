# В 1,7 раза больше повторных заказов благодаря автоматическим сценариям рассылок.

[Secret Kitchen](https://secret-kitchen.ru/) — сеть гастромаркетов, которая объединяет рестораны с разными концепциями: японский Ricers, азиатский Gimnasia, итальянский Cheesus и американский Reshetka. У каждого направления своя команда поваров во главе с бренд-шефом. Формат работы Dark Kitchen позволяет предложить клиенту блюда ресторанного уровня по цене службы доставки.Secret Kitchen успешно работает в Москве, Волгограде и Воронеже, а в планах компании дальнейшее развитие в Москве и городах России.

## Задача: увеличить количество повторных заказов и снизить затраты на коммуникацию с клиентами

Раньше коммуникация с клиентами велась в одном канале и не была системной. Для этого им отправляли SMS с промокодом через личный кабинет сотового оператора. Процесс был трудоемким, потому что каждый раз перед отправкой требовалось:

- сегментировать базу клиентов.
- вручную исключить из рассылки тех, кто недавно получал какие-либо SMS или делал заказ.
- загрузить номера клиентов в личный кабинет оператора, чтобы отправить им рассылку.

Secret Kitchen подключил Mindbox со следующими целями:

- Увеличить количество повторных заказов. Для этого запустили автоматические сценарии для некоторых сегментов клиентов.
- Снизить затраты на коммуникацию с клиентами. Вместо дорогих SMS начали использовать условно бесплатный канал для привлечения клиентов — мобильные пуши.
- Систематизировать работу с повторными заказами.

## Решение: реактивировать клиентов с помощью автоматических сценариев в SMS и мобильных пушах

[RFM-анализ: метод сегментации клиентов для оптимизации рассылок](/journal/education/chto-takoe-rfm-analiz/)

Чтобы понять, кого именно надо реактивировать, базу клиентов разделили на сегменты с помощью RFM-анализа. Получилось восемь сегментов в зависимости от количества и давности покупок: «новички», «растущие», «потерянные» и другие.

С помощью RFM-анализа мы сегментировали клиентскую базу в зависимости от покупательской активности. В Mindbox настроили автоматические сценарии. По сценарию чем дольше клиент не совершает заказ, тем более выгодное предложение отправляем: начисляем баллы → дарим бесплатное блюдо →отправляем промокоды на скидку. Средняя конверсия в продажи по каждому сценарию — 5–8%.

Компания решила сосредоточиться на коммуникации с тремя сегментами: «одноразовые», «упущенные» и «потерянные». «Одноразовые» — это те, кто совершил один заказ в течение определенного периода. «Упущенные» — те, кто сделал больше двух заказов, а «потерянные» — те, кто раньше заказывал, но перестал. Для сегментов «упущенные» и «потерянные» решили использовать только SMS, а для «одноразовых» — мобильные пуши и SMS.

Для выбранных сегментов в Mindbox создали автоматические сценарии рассылок. Сценарий запускается, как только клиент попадает под параметры сегмента для этого сценария. Если клиент сделал один заказ Х дней назад, он попадает в сегмент «упущенные». Система автоматически отправит ему промокод на следующий заказ. Сценарий для каждого клиента запускается автоматически, но не чаще одного раза в месяц. Такое ограничение позволяет не перегружать клиентов сообщениями от бренда.

Для сегмента «одноразовые» сценарий работает в двух каналах: мобильные пуши и SMS. Это позволяет сократить расходы на коммуникацию, потому что клиентам, которые используют мобильное приложение, отправляют условно бесплатные пуши. Дорогие SMS отправляют только тем, кто не установил приложение. Механика запускается лишь для сегмента «одноразовые», потому что новые клиенты недавно скачали мобильное приложение и, скорее всего, прочитают мобильный пуш.

Для сегмента «потерянные» сценарий работает так:

- После того как клиент попал в сегмент, система проверяет, соглашался ли он на получение SMS и не отправлялись ли ему другие рассылки в течение двух дней.
- Если согласие есть, а рассылки не отправлялись, клиенту уходит SMS с промокодом с ограниченным сроком действия. Если клиент получал другие рассылки в течение двух дней, система не отправляет ему новое сообщение.
- Через Х дней система проверяет, сделал ли клиент заказ. Если нет, то ему отправляется повторное SMS.

Сценарий для сегмента «упущенные» такой же, как для сегмента «потерянные», только с дополнительным фильтром по местонахождению клиента. Дополнительная сегментация помогает компании отправлять разные предложения для клиентов из Москвы и из других регионов.

Мобильные пуши хорошо работают для сегмента «одноразовые», а для остальных клиентов SMS конвертируются в покупки лучше. Это связано с тем, что «старые» клиенты не так часто устанавливают мобильное приложение. Например, сегмент «потерянные» пользуются мобильным приложением на 25% реже, чем «одноразовые».

Конверсия в заказ у «одноразовых» в мобильном пуше и в SMS примерно одинаковая — 5–8%. Но бесплатные мобильные пуши позволяют экономить до 10% бюджета на рассылки.

## Результаты: снизили расходы на 10% и увеличили повторные покупки в 1,7 раза

- на

  10 %

  снизили расходы на рассылки

Secret Kitchen сократили расходы на коммуникацию на 10% за счет того, что с частью клиентов удалось связаться с помощью условно бесплатных мобильных пушей.

Раньше клиенты возвращались за заказами, когда вспоминали о компании самостоятельно или не возвращались совсем. SMS с промокодами помогли вернуть клиентов к заказам: в течение года около 12% клиентов из сегмента «потерянные» перешли в сегмент «растущие», а число повторных заказов увеличилось в 1,7 раза.

## Как настроить автоматический сценарий для реактивации клиентов в Mindbox

Прежде чем настроить сценарий для отправки рассылки, нужно создать триггерную рассылку и пул промокодов для нее. Вот инструкции, [как создать триггерную email-рассылку](https://help.mindbox.ru/docs/email-trigger) и [как добавить промокоды в проект](https://help.mindbox.ru/docs/%D0%BA%D0%B0%D0%BA-%D0%B4%D0%BE%D0%B1%D0%B0%D0%B2%D0%B8%D1%82%D1%8C-%D0%BF%D1%80%D0%BE%D0%BC%D0%BE%D0%BA%D0%BE%D0%B4%D1%8B-%D0%B2-%D0%BF%D1%80%D0%BE%D0%B5%D0%BA%D1%82).

Как создать сценарий:

1. Нажать в нужной кампании «добавить сценарий» и назвать его.

![](https://image.mindbox.ru/storage/M8rGVaA8okpSxySDVSlgWhaZX6X9DWkHTxnTHXdH.webp "Картинка")

2. Определить событие для запуска сценария. Например, клиент попал в базу минимум год назад, у него есть заказы, но не за последние три месяца.

![](https://image.mindbox.ru/storage/KgbElvMhmOiSLeyxDivMW8JhdresHbZQfGYkFBLZ.webp "Картинка")

3. Установить расписание запуска сценария: раз в день при наступлении события.

![](https://image.mindbox.ru/storage/0h9wkKwXT1Zo7alWp2yq9p7pbFYvy5qEqyQbJ1Oj.webp "Картинка")

4. Определить группу шагов, которые запустятся при наступлении события, — выдать промокод и отправить рассылку.

![](https://image.mindbox.ru/storage/j7N5WIebFZCLPkbz3J5XwJ6htEZKzfTKKxbe2qry.webp "Картинка")

5. Ограничить количество срабатываний одним разом в N дней, чтобы не надоедать клиенту частыми сообщениями.

![](https://image.mindbox.ru/storage/hme0cv3uaOL0JPoXmJVx9K8VegREqksxk5DW8DWP.webp "Картинка")

6. Запустить готовый сценарий.

![](https://image.mindbox.ru/storage/WjWsKiVBLfhnGHIZJz0UhUWGOwoEDSL3O70CgEx4.webp "Картинка")
