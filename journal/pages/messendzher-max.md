# Перспективы продвижения в мессенджер MAX: реклама, API и возможности для бизнеса

WhatsApp и Telegram работают в России нестабильно, поэтому в СМИ и соцсетях часто обсуждают их возможную блокировку. Если это произойдет, компании могут потерять связь с клиентами.

Национальный мессенджер MAX называют «русским WeChat». Он уже предлагает чат-боты и мини-приложения, а в будущем в него обещают добавить расширенную статистику по чатам, возможность оплачивать товары и отправлять рассылки.

## Каким компаниям в первую очередь нужно подключить MAX

MAX позиционируется как национальный мессенджер. Сейчас здесь появляются каналы государственных и образовательных сервисов, СМИ, социальных служб и чиновников. Например, каналы делового издания «Ведомости», правительства и президента России, мэра Москвы Сергея Собянина. Поэтому в первую очередь регистрироваться в MAX нужно компаниям, которые сотрудничают с госструктурами и университетами, занимаются грантовыми проектами.

Я думаю, что MAX не просто так запустили летом. С осени сюда уже начали переводить школьные чаты, которые раньше были на образовательной платформе «Сферум». На очереди — училища и университеты.

Скоро появится поколение, которое выросло на MAX.

Конкуренция в MAX пока невысокая. Компании-первопроходцы смогут занять удачные короткие имена для своих ботов и каналов и привлечь аудиторию, которая использует MAX для работы, например госслужащих.

[Список интернет-сервисов, которые остаются доступными во время ограничений](https://digital.gov.ru/news/vazhnye-internet-servisy-ostayutsya-dostupnymi-vo-vremya-ogranichenij)

Недавно у MAX появилось важное преимущество перед Whatsapp и Telegram. Минцифры добавило MAX в список сервисов, которые не отключат даже при ограничении мобильного интернета. Компаниям, которые используют мессенджеры для коммуникации с клиентами, лучше иметь запасной чат или канал в MAX. Если другие каналы окажутся недоступными, общение с аудиторией можно будет продолжить в «русском WeChat».

## Какие маркетинговые инструменты доступны в MAX

В мессенджере уже можно подключить чат-боты и мини-приложения.

[Как с помощью чат-ботов автоматизировать бизнес-процессы](chat-bot-dlya-avtomatizacii-biznesa.md)

### Чат-боты

Они помогают:

- увеличивать продажи, например, информируя покупателей об акциях;
- регистрировать пользователей в программе лояльности;
- записывать клиентов на услуги без привлечения менеджеров.

![Интерфейс чат-бота в MAX похож на интерфейс Telegram. Иллюстрация: business.max.ru](https://image.mindbox.ru/draw/v110CwRXLlATBFFYkqmOP8kkQoydgNLrN5IWp9Kj.jpg/-/size/1600/webp/1 "Картинка")

Интерфейс чат-бота в MAX похож на интерфейс Telegram. Иллюстрация: business.max.ru

Создать чат-бота в MAX можно двумя способами:

[Библиотеки MAX Bot API для разработчиков](https://dev.max.ru/docs/chatbots/bots-coding/library)

**Самостоятельно с помощью разработчика.** Если есть ресурсы, компании создают собственного бота с неограниченными функциями. Как правило, к программистам обращаются компании с нестандартными задачами. Например, у бренда одежды Zarina программа лояльности работает через чат-бот.

[Как составить схему чат-бота](shema-chat-bota.md)

**В конструкторах-партнерах MAX, например Botmother и JetBot.** Здесь можно собрать сценарий для чат-бота с нуля или взять готовый шаблон.

MAX поддерживает разметку Markdown, которая позволяет форматировать текст в чат-боте, добавлять эмодзи и ссылки. Помимо текста, чат-боты в MAX могут отправлять изображения, видео, аудио и файлы, например прайс-листы.

[MAX для бизнеса](https://business.max.ru/)

Компания может подключить сразу несколько чат-ботов. Для этого нужно:

1. Зарегистрироваться на платформе MAX для бизнеса. На октябрь 2025 года войти на платформу не могут ИП, самозанятые, физлица, нерезиденты и компании, оформленные не в России.
2. Создать профиль организации по ИНН и пройти верификацию, отправив запрос на business_support@max.ru.
3. Настроить чат-бота. Добавить его название и описание, никнейм длиной 11–60 символов с обязательным окончанием «bot» или «_bot» и сайт компании.
4. Пройти модерацию. Она займет до 48 часов в рабочие дни.

Платформа сгенерирует токен — уникальный идентификатор бота, с помощью которого он будет взаимодействовать с API MAX. Токен нужен, например, для настройки бота в конструкторе.

### Мини-приложения

Мини-приложение в мессенджерах — это бюджетный аналог мобильного приложения. В мини-апах пользователи просматривают и оплачивают товары, общаются с менеджером или участвуют в розыгрышах.

[Как работать с API](kak-rabotat-s-api.md)

Мини-приложения работают по API. Чтобы упростить их разработку и настройку, создатели MAX выложили в открытый доступ нужные библиотеки:

[MAX Bridge](https://dev.max.ru/docs/webapps/bridge)

[Библиотека React-компонентов](https://dev.max.ru/ui)

- MAX Bridge — посредник для обмена данными между мессенджером и устройством пользователя;
- библиотеку React-компонентов MAX UI, которая позволяет стилизовать мини-приложение под интерфейс мессенджера.

Подключение и управление мини-приложением происходит на платформе MAX для бизнеса.

Клиенты бизнеса могут попасть в мини-приложение только через чат-бот. Вероятно, когда компании смогут создавать в MAX каналы, ссылку на приложение можно будет разместить и в них, по аналогии с Telegram.

![](https://image.mindbox.ru/draw/wgUh8QPvROxJ4BTUIZ460kE2qRMoFbBXefGPcNMB.jpg/-/size/1600/webp/1 "Картинка")

Если у компании есть мини-приложение, в чат-боте появляется синяя иконка. Клиент нажимает на нее и открывается мини-ап. Иллюстрация: dev.max.ru

## Какие инструменты для бизнеса появятся в мессенджере MAX

[Документация MAX для разработчиков](https://dev.max.ru/docs)

Сегодня доступна бета-версия мессенджера с ограниченным набором инструментов: чат-ботами и мини-приложениями. Однако, судя по официальному сайту и открытой документации, у MAX большой потенциал для маркетинга. Есть вероятность, что скоро в нем появятся:

**Каналы компаний.** Сегодня они доступны только приглашенным компаниям и блогерам.

Каналы помогут бизнесу прогревать аудиторию и формировать комьюнити бренда. Для этого, например, можно будет показывать фотографии товара и проводить опросы.

[MAX API](https://dev.max.ru/docs-api/objects/User)

Судя по данным в MAX API, владельцы каналов и публичных чатов смогут видеть ID подписчиков, которые непросто получить в Telegram, и время их последней активности в чате.

По ID блокируют ботов и недобросовестных пользователей, а также вознаграждают инициативных участников. Информация об активности подписчиков поможет предотвратить отток. Например, если студент перестал читать уведомления об уроках в чате онлайн-школы, можно отправить ему личное сообщение и попытаться вновь заинтересовать учебой.

Работающий в MAX мини-ап можно будет выкладывать и продвигать в «Госуслугах» или VK — «Яндекс Go» к себе вряд ли пустит.

[Инструкция для бизнеса по настройке входа через «Госуслуги»](https://partners.gosuslugi.ru/catalog/esia)

**Интеграцию с «Госуслугами».** Скорее всего, пользователи смогут регистрироваться в мини-апах или программах лояльности в чат-боте с помощью учетной записи на «Госуслугах». Это быстрее, чем заполнять форму вручную, поэтому количество регистраций, а с ним и база контактов могут увеличиться.

Чтобы внедрить регистрацию через «Госуслуги», компания должна получить квалифицированную электронную подпись, зарегистрироваться в сервисе и подать заявку.

## Какое будущее ждет MAX

![автор](https://image.mindbox.ru/draw/1nSf553A1iHBb1IBQUovsnyUNnfHEd-metadUc2TkE0SjBNZ1kyRWVBVUttUXRSektwRDY5WVRzQnF5M2VXZFpHMi5qcGc=-.jpg/-/size/286/webp/1 "Автор отзыва")

Старший маркетолог Mindbox

Скорее всего, MAX повторит ошибки Telegram. В 2017 году Telegram на несколько часов «упал» из-за всплеска пользовательской активности, поэтому невозможно было ничего отправить. Думаю, MAX тоже может столкнуться с подобным из-за большой нагрузки.

Из мессенджера хотят сделать суперприложение со множеством настроек. Новые функции придется вводить, тестировать и откатывать назад, потому что они не будут идеальными с первого раза. А еще предстоит бороться с атаками и взломами.

Самое страшное, что может случиться, — MAX станет тем, чем сейчас стал VK. Когда-то VK был отличным мессенджером и социальной сетью в одном флаконе — лучше, чем Telegram. Но платформа разрослась и заигралась в создание нового ненужного функционала. Боюсь, что с MAX может произойти то же самое.

Однако из технической документации MAX видно, что у мессенджера хорошая перспектива и появление новых инструментов для маркетинга — лишь вопрос времени. Здесь появятся привычные чат-боты и каналы с возможностью управлять чатами, что важно для комьюнити-маркетинга. На базе MAX получится создавать более продвинутые мини-приложения, чем в Telegram, — это заложено в функционале нового мессенджера.

Уверен, что в будущем мы добавим в Mindbox возможность настраивать рассылки для MAX и собирать по ним статистику.

Что можно делать в мессенджере Max?

Max ― российский мессенджер от VK для личного общения и работы. В нем можно:

― Отправлять текстовые сообщения, голосовые, стикеры, файлы. Создавать групповые чаты и каналы для рассылки новосте

― Проводить аудио- и видеозвонки с одним человеком или группой. Работает на телефоне и компьютере.

― Создавать списки дел, назначать задачи участникам чата, отслеживать выполнение. Подходит для командной работы.

― Подключать ботов для автоматизации: приём заявок, уведомления, FAQ. Есть API для создания своих ботов.

― Создавать публичные каналы для рассылки новостей подписчикам, как в Telegram. Подписчики не могут писать в канал, только читают сообщения автора.

Кто разработчик MAX?

Мессенджер Max разработан компанией VK (бывший Mail.ru Group). VK владеет социальной сетью ВКонтакте, Одноклассниками, сервисом VK Звонки и другими продуктами. Max создавался как российская альтернатива международным мессенджерам с фокусом на бизнес-коммуникации и интеграцию с экосистемой VK.

В каком мессенджере лучше общаться?

Выбор мессенджера зависит от задач и аудитории бренда:

Telegram ― для массовых рассылок через каналы, ботов с API, групповых чатов. Популярен в России, много готовых инструментов для бизнеса.

WhatsApp ― для личного общения и небольших бизнесов. Самый массовый мессенджер в мире, есть WhatsApp Business для компаний.

Max ― для работы внутри команды и бизнес-коммуникаций в России. Интеграция с сервисами VK, управление задачами, российская разработка.

ВКонтакте ― для бизнеса, который работает с аудиторией ВКонтакте. Удобно вести коммуникации там же, где размещена реклама и контент.

Для бизнеса важно быть там, где находится целевая аудитория. Если клиенты сидят в Telegram ― работать в Telegram. Если используют WhatsApp ― подключать WhatsApp Business. Универсального лучшего мессенджера нет.

Какой мессенджер самый надежный?

Надежность мессенджера оценивают по шифрованию сообщений, устойчивости к сбоям и частоте обновлений. Например, Max и Telegram поддерживают сквозное шифрование и резервное хранение данных, что делает их безопасным для персональной и рабочей переписки.
