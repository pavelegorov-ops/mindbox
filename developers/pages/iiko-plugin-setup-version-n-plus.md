# Настройка плагина iiko версии V8.1.0.62 и выше

**Шаг 1. Установка и настройка плагина**

Открыть [ссылку](https://rapid.iiko.ru/plugins/Smart%20MindBox/) и скачать zip-файл с последней версией плагина

Состав плагина:

Resto.Front.Api.MindBoxPlugin.dll – основной файл  
Resto.Front.Api.MindBoxPlugin.config – конфигурационный файл
Остальное файлы - дополнительные библиотеки, нужные для корректной работы плагина.
Создайте папку Resto.Front.Api.MindBoxPlugin в C:\Program Files\iiko\iikoRMS\Front.Net\Plugins\ и поместите туда все файлы плагина
После необходимо отредактировать конфигурационный файл.

В файл с настройками Resto.Front.Api.MindBoxPlugin.dll.config необходимо внести информацию. Уточните у менеджера Mindbox данные для заполнения следующих полей:

- "server" — адрес для обмена данными с Mindbox при вызовах API-методов. Зависит от контура проекта
- "endpoint” — системное имя точки интеграции
- "product_id” — системное имя внешней системы
- "brand" — системное имя бренда
- "balance_name” — системное имя балльного счета

А также заполните другие поля файла конфигурации:

- "send_product_id" — параметр, который отвечает за то, какое значение передается в externalId продуктов: ID блюда (guid) или его артикул. False - будет передаваться изменяемый артикул, True - будет передаваться ID блюда (неизменяемый guid)
- "send_sms_confirm” — true/false в зависимости от того, необходимо ли отправлять смс с кодом авторизации для подтверждения списания баллов при оплате
- "time_sendProducts" — время автоматической отправки номенклатуры из iikoOffice в Mindbox. Настраивается в формате 00:00:00. Отправка происходит по локальному времени кассы. Оставьте пустым/напишите cancel, чтобы отправка номенклатуры с этой кассы не происходила
- "discount_type" - укажите название скидки так, как она заведена в iikoOffice
- "secret_key” — секретный ключ точки интеграции

**Шаг 2. Проверка запуска плагина**  
Запустите iikoFront и дождитесь его полной загрузки. Если никаких сообщений не появилось, значит, все в порядке — плагин установлен. При лицензионных ограничениях сверху появится предупреждение
Проверьте корректность запуска по лог-файлу
%appdata%\iiko\CashServer\Logs\Resto.Front.Api.MindBoxPlugin.log

**Шаг 3. Добавление скидки**

- В iikoOffice перейдите в Дисконтная система - Скидки и надбавки - Добавить.
- Название и название в пречеке можете указать любое. После нажимаем далее
- Добавьте скидку как указано на картинках
- Пропишите наименование скидки в параметре discount_type файла конфигурации

![](https://storage.yandexcloud.net/assets-developers-mindbox-ru/images/ddd61edcc018487ea6f5d57224e20a8fa22f134f7aec1f99f72b10f6b158510e-image.png)

**Шаг 4. Настройка типа оплаты в iikoOffice**

- В iikoOffice перейдите в Розничные продажи - Типы оплат - Добавить.
- Введите наименование типа оплаты
- В поле Тип выберите "Внешний тип оплаты"
- В поле Безналичный тип выберите «MindBoxBonus». Если этого пункта нет в списке, то, скорее всего, не запустился плагин. Проверьте еще раз лог-файл.
- Установить галку "Проводить как скидку"
- В поле Скидка выберите заранее созданную скидку

![](https://storage.yandexcloud.net/assets-developers-mindbox-ru/images/c430db31a877bdc667518c34951c58aa8c102b19837d23bba5cec1ebbef4e60e-image.png)

Если плагин будет использоваться и для заказов доставки, то добавьте еще один тип оплаты и пропишите его наименование в параметре payment_type файла конфигурации

![](https://storage.yandexcloud.net/assets-developers-mindbox-ru/images/ef4a3aacadb11a78fefb0d80afb966e59efdcd8ebaa1600ed0da50b1641e447d-image.png)
