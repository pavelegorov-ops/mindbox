# Механика персонализации включена, но не показывается клиенту

Убедитесь, что механика работает по тестовой ссылке.

Если нет - проверьте причины по [чеклисту](mechanics-not-working-test-link.md).

Если механика по тестовой ссылке отображается, но в “боевом” режиме клиенту не показывается, может быть несколько причин.
