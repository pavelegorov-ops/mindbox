# Работа с подарочными картами в операциях сохранения заказов

## Выдача/активация карты

## Сценарий для оффлайн:

Клиент приходит в магазин и выбирает сертификат определенного номинала. При покупке касса сообщает в Mindbox номер приобретенной карты и ее номинал. Данная карта передается как отдельный товар. После успешного завершения заказа карта считается “активированной” - ее можно использовать в последующих заказах.

## Сценарий для онлайн:

Актуально для покупки физического сертификата с доставкой клиенту. При покупке бэк сайта сообщает в Mindbox номер приобретенной карты и ее номинал. Данная карта передается как отдельный товар. После успешного завершения заказа карта считается “активированной” - ее можно использовать в последующих заказах.

## Технические изменения в операциях:

Изменяются операции *сохранения заказа клиента.*

Пример:

- Offline.AuthorizedPreorder, Website.AuthorizedPreorder (пречек авторизованный)
- Offline.UnauthorizedPreorder, Website.UnauthorizedPreorder (пречек неавторизованный)
- Offline.AnonymousPreorder, Website.AnonymousPreorder (пречек анонимный)
- Offline.CreateAuthorizedOrder, Website.CreateAuthorizedOrder (заказ авторизованный)
- Offline.CreateUnauthorizedOrder, Website.CreateUnauthorizedOrder (заказ неавторизованный)
- Offline.CreateAnonymousOrder, Website.CreateAnonymousOrder (заказ анонимный)
- Offline.SaveOfflineOrder, Website.SaveOfflineOrder (сохранение оффлайн-заказа)

При покупке подарочной карты в заказ в узел customer -> order -> lines должна быть добавлена новая линия:

Пример:

```
<line>
        <quantity>{Количество SKU (или продукта, если SKU не передан)}quantity>
        <status>
          <ids>
            <externalId>{Статус позиции заказа}externalId>
          ids>
        status>
        <product>
          <ids>
            <id>test_card_nominal_1000id> - ID технического продукта
          ids>
        product>
        <basePricePerItem>1000basePricePerItem> - номинал карты
        <lineId>{Идентификатор линии заказа}lineId>
        <lineNumber>{Порядковый номер позиции заказа}lineNumber>
        <giftCard>
          <ids>
            <number>test_1000number> - номер карты
          ids>
        giftCard>
    line>
```

## Возможные ошибки:

| **ErrorMessage** | **Описание** |
| --- | --- |
| Запрашиваемая сумма не соответствует доступной сумме пула | В basePricePerItem передана сумма, отличающаяся от номинала пула |
| Необходимо указать либо номер подарочной карты, либо брать из пула | Одновременно переданы два параметра: **/order/lines/line/giftCard/getFromPool** (активация любой доступной карты из пула) и **/order/lines/line/giftCard/ids/number** (активация переданного номера карты). Метод допускает использование только одного из параметров |
| Нельзя активировать подарочную карту из этого статуса | В запросе передана уже активированная или заблокированная карта. К продаже доступны только карты в статусе «Не активирована» |
| Не удалось взять карту из пула | В пуле нет доступных карт для активации. К продаже доступны только карты в статусе «Не активирована» |

## Использование сертификата:

## Сценарий для оффлайн/онлайн:

При покупке клиент может воспользоваться картой, чтобы оплатить заказ. Для онлайна можно предусмотреть ввод номера сертификата в отдельное поле или отказаться от оплаты физической картой заказа в интернет-магазине. После использования в заказе карта будет считаться погашенной.

## Технические изменения в операциях:

Изменяются операции *сохранения заказа клиента.*

Пример:

- Offline.AuthorizedPreorder, Website.AuthorizedPreorder (пречек авторизованный)
- Offline.UnauthorizedPreorder, Website.UnauthorizedPreorder (пречек неавторизованный)
- Offline.AnonymousPreorder, Website.AnonymousPreorder (пречек анонимный)
- Offline.CreateAuthorizedOrder, Website.CreateAuthorizedOrder (заказ авторизованный)
- Offline.CreateUnauthorizedOrder, Website.CreateUnauthorizedOrder (заказ неавторизованный)
- Offline.CreateAnonymousOrder, Website.CreateAnonymousOrder (заказ анонимный)
- Offline.SaveOfflineOrder, Website.SaveOfflineOrder (сохранение оффлайн-заказа)

При использовании карты в заказе в узел customer -> order -> payments должен быть отправлен новый тип оплаты:

```
<payment>
        <type>giftCardtype>
        <id>{Номер карты}id>
        <amount>{Размер платежа с помощью подарочной карты}amount>
        <cvv>{CVV подарочной карты}cvv>
    payment>
```

CVV должен передаваться в запросе, если в заказе используется подарочная карта из пула с требованием CVV. Подробнее в [статье](https://help.mindbox.ru/docs/gift-cards-what-is).

В операциях расчета заказа (пречек авторизованный, пречек неавторизованный, пречек анонимный) при передаче оплаты подарочной картой вернется статус подарочной карты в узле /order/paymentsInfo/paymentInfo/giftCard/status:

- not found - подарочная карта не найдена
- canBeUsed - может быть использована (продана, возможна оплата картой)
- inactive - не активирована (не была продана, оплата такой картой невозможна)
- alreadyUsed - погашена
- blocked - заблокирована
- expired - истек срок действия подарочной карты

## Возможные ошибки:

| ErrorMessage | Описание |
| --- | --- |
| Подарочная карта с номером *[Номер карты]* уже использована | В запросе передана погашенная подарочная карта. В заказе можно использовать только карты в статусе «Активирована» |
| Недостаточно баланса на подарочной карте с номером *[Номер карты]* | Сумма оплаты превышает доступный остаток на карте |
| Подарочная карта с номером *[Номер карты]* не найдена | На проекте нет подарочной карты с переданным в запросе номером |
| CVV подарочной карты с номером *[Номер карты]* отклонен | В запросе передан некорректный CVV-код |
| Подарочная карта с номером *[Номер карты]* не активирована | В запросе передана неактивированная подарочная карта. В заказе можно использовать только карты в статусе «Активирована» |
| Подарочная карта с номером *[Номер карты]* заблокирована | В запросе передана заблокированная подарочная карта. В заказе можно использовать только карты в статусе «Активирована» |
| Истек срок действия подарочной карты с номером *[Номер карты]* | В запросе передана подарочная карта с истекшим сроком действия |

Если в узле payments передано несколько подарочных карт и одна из них недоступна к использованию, в ответе также вернется валидационная ошибка с причиной и номером подарочной карты, оплата по которой невозможна.
