# Нет продуктов для рекомендации

**Как проверить:**

1. Открыть виджет по тестовой ссылке
2. Открыть консоль в инструментах разработчика
3. Перезагрузить страницу
4. В консоли ввести в поиске mindbox
5. Посмотреть, есть ли предупреждение, которое содержит идентификатор виджета и ошибку `no data from mindbox`:

![](https://storage.yandexcloud.net/assets-developers-mindbox-ru/images/ea2ba0c-image.png)

**Как исправить:**

- Проверьте, что алгоритм пересчитался хотя бы один раз.
- Если пересчет завершился, а продуктов всё равно нет, определите возможные причины с помощью [статьи](https://help.mindbox.ru/docs/%D0%BF%D1%80%D0%B8%D1%87%D0%B8%D0%BD%D1%8B-%D0%BF%D0%BE-%D0%BA%D0%BE%D1%82%D0%BE%D1%80%D1%8B%D0%BC-%D1%80%D0%B5%D0%BA%D0%BE%D0%BC%D0%B5%D0%BD%D0%B4%D0%B0%D1%86%D0%B8%D0%B8-%D0%BD%D0%B5-%D0%BF%D0%BE%D0%B4%D1%81%D1%82%D0%B0%D0%B2%D0%BB%D1%8F%D1%8E%D1%82%D1%81%D1%8F.html).
- Если на этом этапе важно проверить только внешний вид виджета, а не его наполнение, подставьте любой посчитанный алгоритм и потом замените его на нужный, убедившись, что он работает.
