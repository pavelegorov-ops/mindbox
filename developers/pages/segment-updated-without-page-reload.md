# Обновление сегмента в таргетинге механики произошло без перезагрузки страницы

**Как проверить**

1. Зайдите на страницу, где работает механика
2. Проверьте, может ли на странице быть какое-то событие, которое изменит состав сегмента из таргетинга механики (к примеру, авторизация)
3. Проверьте, перезагружается ли страница после этого события

Если нет - механика персонализации не учтет это изменение в таргетинге, форма может отображаться некорректно.

**Как исправить**

Сразу после события, влияющего на изменение таргетинга, вызывайте `PopMechanic.update()`
