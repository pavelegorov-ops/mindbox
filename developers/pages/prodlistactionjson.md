# javascript

## Описание метода

Осуществляется в трекере с помощью вызова метода `async` или `performOperation` с передачей идентификаторов продуктов. Название операции и набор принимаемых полей настраиваются в системе Майндбокс.

```
mindbox('async', {
  operation: '<Название операции>',
  data: {
    customer: {
      ids: {
      	<Идентификатор>: '<Значение идентификатора>',
      },
    },
    productList: [
      {
        product: {
          ids: {
            <Идентификатор>: '<Значение идентификатора продукта>'
          }
        },
        productGroup: {
          ids: {
            <Идентификатор>: '<Значение идентификатора группы продуктов>'
          }
        },        
        count: <Выбранное количество единиц продукта>,
        pricePerItem: <Цена за одну единицу продукта. Необходимо передать одну из цен>,
        priceOfLine: <Цена за продукты с учетом количества. Необходимо передать одну из цен>
      }
      ...
    ]
  }
});
```
