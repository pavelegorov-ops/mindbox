# Методы для интеграции чат-ботов с Fasttrack

Эта статья описывает методы API для интеграции Mindbox с сервисом Fasttrack (<https://fstrk.io/>). Настройка операций, точек интеграции, дополнительных полей и сегментаций описана [инструкции](https://help.mindbox.ru/docs/chat-bots-integration).

## **Общий формат запроса**

Подробнее о домене запроса, заголовках и формате запроса в статье про [работу с запросами в V3 API.](v3.md)

Все запросы выполняются по следующему шаблону:

**URL:**

```
POST https://api.mindbox.ru/v3/operations/sync?endpointId={endpointId}&operation={operationName}
```

**Headers:**

```
Content-Type: application/json; charset=utf-8
Accept: application/json
Authorization: SecretKey {Секретный ключ}
```

**Параметры URL:**

- `endpointId` — идентификатор точки интеграции
- `operationName` — название операции (указано в описании каждого метода)
- `SecretKey` — секретный ключ для авторизации

## Методы

### Старт бота `ft.BotStart`

Создает клиента с переданным идентификатором `TGID` и действием «Старт бота» с информацией об акции и платформе.

**Параметры тела запроса:**

| **Параметр** | **Обязательность** | **Описание** |
| --- | --- | --- |
| `customer.ids.TGID` | ✅ | Идентификатор клиента в чат-боте |
| `customer.customFields.inbotTG` | ✅ | Флаг присутствия клиента в боте. Значение: `"True"` |
| `pointOfContact` | ❌ | Точка контакта. Необходима, если указана в диплинке |
| `customerAction.customFields.advertID` | ❌ | Идентификатор рекламной акции из диплинка |
| `customerAction.customFields.botPlatform` | ✅ | Платформа бота: `tg`, `vk`, `max`, `wa` |

**Тело запроса:**

```
{
  "pointOfContact": "<Идентификатор магазина (если указан в диплинке)>",
  "customer": {
    "customFields": {
      "inbotTG": "True"
    },
    "ids": {
      "TGID": "<Идентификатор клиента в чат-боте>"
    }
  },
  "customerAction": {
    "customFields": {
      "advertID": "<Идентификатор акции(если указан в диплинке)>",
      "botPlatform": "<Платформа бота - tg/vk/max/wa>"
    }
  }
}
```

**Ответ:**

```
{
    "status": "Success"
}
```

### Создание клиента `ft.CreateCustomer`

Создает нового клиента с переданным идентификатором `TGID` и мобильным телефоном `mobilePhone`, а также регистрирует подписки клиента на рассылки.

**Параметры тела запроса:**

| **Параметр** | **Обязательность** | **Описание** |
| --- | --- | --- |
| `customer.ids.TGID` | ✅ | Идентификатор клиента в чат-боте |
| `customer.mobilePhone` | ✅ | Мобильный телефон клиента |
| `customer.customFields.subTG` | ❌ | Согласие на рассылки в чат-боте. Значение: `"True"` |
| `customer.subscriptions[]` | ❌ | Глобальная подписка на все рассылки бренда (Email, SMS и др.). Значение: `"True"` |

Системное имя бренда для `subscriptions[]` можно найти:

- В описании операции на проекте
- На странице **Настройки → Бренды**
- Запросить у менеджера проекта

**Тело запроса:**

```
{
  "customer": {
    "mobilePhone": "<Мобильный телефон>",
    "ids": {
      "TGID": "<Идентификатор клиента в чат-боте>"
    },
    "customFields": {
      "subTG": "<Согласие на рассылки в чат-боте - True>"
    },
    "subscriptions": [
      {
        "<Системное имя бренда>": "<Согласие на все рассылки бренда - True>"
      }
    ]
  }
}
```

**Ответ:**

```
{
    "status": "Success"
}
```

### Дополнить клиента `ft.FillUpCustomer`

Находит клиента по номеру телефона и дополняет карточку клиента переданными данными. [Как работает дополнение](https://help.mindbox.ru/docs/steps-edit-client#klient-avtorizovannyj-dopolnit).

**Параметры тела запроса:**

| **Параметр** | **Обязательность** | **Описание** |
| --- | --- | --- |
| `customer.mobilePhone` | ✅ | Мобильный телефон |
| `customer.birthDate` | ❌ | Дата рождения |
| `customer.sex` | ❌ | Пол: `M`/`W`, `man`/`woman`, `male`/`female` |
| `customer.timeZone` | ❌ | Часовой пояс |
| `customer.lastName` | ❌ | Фамилия |
| `customer.firstName` | ❌ | Имя |
| `customer.middleName` | ❌ | Отчество |
| `customer.fullName` | ❌ | ФИО (альтернатива отдельным полям) |
| `customer.email` | ❌ | Email |

Передавайте ФИО клиента либо с помощью `fullName`, либо по отдельности через `lastName`, `firstName` и `middleName`.

**Тело запроса:**

```
{
  "customer": {
    "birthDate": "<Дата рождения>",
    "sex": "<Пол - M/W, man/woman, male/female>",
    "timeZone": "<Часовой пояс>",
    "lastName": "<Фамилия>",
    "firstName": "<Имя>",
    "middleName": "<Отчество>",
    "fullName": "<ФИО>",
    "email": "",
    "mobilePhone": "<Мобильный телефон>"
  }
}
```

**Ответ:**

**Если клиента нет в Mindbox,** вызов выполнится со статусом `Success`, но клиент создан не будет.

```
{
    "status": "Success"
}
```

### Подтвердить телефон `ft.ConfirmPhone`

Подтверждает переданный номер телефона клиента. Необходим, если на проекте настроено [подтверждение номера телефона](https://help.mindbox.ru/docs/email-and-mobile-confirmation#chto-takoe-podtverzhdenie-kontakta).

**Параметры тела запроса:**

| **Параметр** | **Обязательность** | **Описание** |
| --- | --- | --- |
| `customer.mobilePhone` | ✅ | Мобильный телефон клиента |
| `customer.ids.mindboxId` | ✅ | Идентификатор клиента в Mindbox |

**Тело запроса:**

```
{
  "customer": {
    "mobilePhone": "<Мобильный телефон>",
    "ids": {
      "mindboxId": ""
    }
  }
}
```

**Ответ:**

#### Номер телефона переданного клиента подтвержден

```
{
      "status": "Success"
  }
```

#### Клиент с переданным идентификатором не найден

| `customer.middleName` | ❌ | Отчество |
| `customer.fullName` | ❌ | ФИО (альтернатива отдельным полям) |
| `customer.email` | ❌ | Email |

Передавайте ФИО клиента либо с помощью `fullName`, либо по отдельности с помощью `lastName`, `firstName` и `middleName`.

**Тело запроса:**

```
{
  "customer": {
    "birthDate": "<Дата рождения>",
    "sex": "<Пол - M/W, man/woman, male/female>",
    "timeZone": "<Часовой пояс>",
    "lastName": "<Фамилия>",
    "firstName": "<Имя>",
    "middleName": "<Отчество>",
    "fullName": "<ФИО>",
    "email": "",
    "mobilePhone": "<Мобильный телефон>"
  }
}
```

**Ответ:**

**Если клиента нет в Mindbox,** вызов выполнится со статусом `Success`, клиент с новыми данными создан не будет.

```
{
    "status": "Success"
}
```

| `executionDateTimeUtc` | ✅ | Дата и время генерации тикета в формате UTC |

### Событие в боте `ft.ChatBotEvent`

Используется для передачи информации о действиях клиента в боте. Список идентификаторов событий определяется клиентом.

Метод создаст нового клиента, если передан незарегистрированный номер телефона.

**Параметры тела запроса:**

| **Параметр** | **Обязательность** | **Описание** |
| --- | --- | --- |
| `customer.mobilePhone` | ✅ | Мобильный телефон клиента |
| `customerAction.customFields.chatBotEventType` | ✅ | Тип события в чат-боте |

**Тело запроса:**

```
{
  "customer": {
    "mobilePhone": "<Мобильный телефон>"
  },
  "customerAction": {
    "customFields": {
      "chatBotEventType": "<Тип события в чат-боте>"
    }
  }
}
```

**Ответ:**

```
{
    "status": "Success"
}
```
