# Интеграция с Segmel

**Segmel** — платформа персонализации маркетинга, основанная на машинном обучении. Сервис помогает выстраивать персонализированные коммуникации с клиентами для оптимизации стоимости заказа и маркетинговых кампаний.

[segmel.com](http://segmel.com)

## Возможности интеграции

- Автоматически сегментация аудитории по уровню заинтересованности, поведению и ценности для бизнеса.
- Оптимизация рекламных кампаний.
- Увеличение конверсий в заказ.
- Аналитика и отчеты для мониторинга ключевых метрик маркетинга (конверсия, удержание, ROMI, LTV).

## Порядок интеграции

- Менеджер Mindbox передает контакты представителей проекта для связи Segmel;
- Совместно с менеджером Mindbox и Segmel определяются метрики для прогнозирования;
- Выполняются [настройки в Mindbox](https://help.mindbox.ru/docs/segmel-integration);
- Передаются URL и секретный ключ точки интеграции в Segmel;
- Настраивайте механики и коммуникации с использованием сегментов. Менеджер Mindbox сообщит,
- когда будут готовы данные (процесс сбора данных и обучения ML-моделей занимает около 2-3 недель);
