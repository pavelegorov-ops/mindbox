# 2. Вызов операций с помощью JavaScript SDK Mindbox

Вызывайте созданные операции с фронтенда сайта с помощью JavaScript SDK Mindbox.

Важно вызывать операции при каждом событии просмотра продукта и категории, а также при каждом обновлении состава корзины.

При обновлении состава корзины в операции нужно передавать полный, актуальный состав.

### Таргетинг по корзине и продуктам/категории работает по тем данным, которые передаются в операции в тот момент, когда пользователь находится на той или иной странице.

Для корректной работы таргетинга по корзине важно вызывать операцию с актуальным составом корзины на каждой странице, где этот таргетинг должен сработать.

Возможные сценарии:

- при добавлении товара со страницы товар
- при посещении страницы корзины
- при добавлении товара в корзину со страницы категории
- при удалении товара из корзины
- при очищении корзины кнопкой “очистить корзину” на странице корзины
- при посещении страницы корзины с пустой корзиной
- при оформлении заказа, когда товары из корзины уходят в статус "купленные
