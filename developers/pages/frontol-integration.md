# Интеграция Frontol

**Frontol** - это программное обеспечение для автоматизации работы кассира.  
[frontol.ru](https://frontol.ru)

## Возможности интеграции

- Расчет скидок
- Расчет персональных скидок
- Начисление бонусов
- Списание бонусов
- Применение промокодов
- Проверка баланса
- Отображение анкеты клиента
- Подтверждение телефона
- Подтверждение списания бонусов
- Регистрация клиентов (ФИО, телефон, email, дата рождения)

## Ограничения интеграции

- Для интеграции требуется установить модуль [Frontol Priority API](https://frontol.ru/catalog/frontol-6/?sphrase_id=5752#additional_modules)
- Нельзя редактировать клиента
- Нельзя изменять анкету регистрации
- Подарочные карты не поддерживаются
- Версия Frontol 6.0+

## Создание интеграции

1. На платформе Mindbox создаются необходимые [операции](https://help.mindbox.ru/docs/%D0%B8%D0%BD%D1%82%D0%B5%D0%B3%D1%80%D0%B0%D1%86%D0%B8%D1%8F-frontol)
2. Менеджер Mindbox передает данные в разработку для создания проекта
3. Менеджер Mindbox передает клиенту инструкцию по настройке Frontol, "Точку интеграции" и "Секретный ключ"
4. Сотрудник со стороны клиента настраивает ПО Frontol
5. После этого интеграция считается выполненной.

[Инструкция по созданию интеграции](https://help.mindbox.ru/docs/%D0%B8%D0%BD%D1%82%D0%B5%D0%B3%D1%80%D0%B0%D1%86%D0%B8%D1%8F-frontol)
