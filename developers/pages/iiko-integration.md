# Интеграция iiko

[iiko](https://iiko.ru/solutions) — специализированная система ERP-класса, предназначенная для автоматизации ресторанного бизнеса. Касса, склад, персонал, кухня, финансы, отчетность — все в единой системе.

## Возможности интеграции

- Плагин работает с iiko версии 7.9 и выше, для его работы необходима лицензия MindBoxPlugin
- Расчет скидок
- Расчет персональных скидок
- Начисление бонусов
- Списание бонусов
- Проверка баланса
- Отображение анкеты клиента
- Подтверждение списания бонусов
- Регистрация клиента через кассу
- Автоматическая отправка номенклатуры в Mindbox
- Печать базовой информации на чеках
- Работа с промокодами

## Ограничения текущей версии интеграции

- Для интеграции требуется установить плагин (обратитесь к менеджеру iiko)
- Подарочные карты не поддерживаются
- Не поддерживается интеграция с облачным колл-центром iiko
- Не поддерживается работа с несколькими балльными счетами

## Создание интеграции

1. На платформе Mindbox создаются необходимые операции и [настраивается проект](https://help.mindbox.ru/docs/iiko-integration.html)
2. Менеджер Mindbox передает клиенту:
   - Системное имя точки интеграции
   - Системное имя балльного счета
   - Системное имя внешней системы
   - Системное имя бренда
   - "server" — адрес для обмена данными с Mindbox при вызовах API-методов
3. Необходимо скопировать секретный ключ интеграции. Это может сделать сотрудник с пермиссией "Управление секретными данными". При возникновении сложностей обратитесь к менеджеру Mindbox
4. Сотрудник со стороны клиента настраивает ПО iiko
5. После этого интеграция считается выполненной.
