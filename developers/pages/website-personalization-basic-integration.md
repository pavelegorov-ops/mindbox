# Базовая интеграция

### В результате этой интеграции вы сможете:

- размещать попапы, встроенные блоки и виджеты рекомендаций у вас на сайте
- настраивать таргетинг по сегменту клиента, его географии, устройству, количеству визитов на сайт, страницам, которые клиент посетил
- настраивать таргетинг по взаимодействию клиента с другими механиками персонализации
- настраивать таргетинг для работы на конкретных страницах или страницах, содержащих определенный CSS элемент или определенное значение в URL
- настраивать таргетинг через JS сужение или Google Optimize

Для базовой интеграции нужно:

1. [Установить трекер Mindbox](tracker-installation.md)
2. [Создать любую механику персонализации](step-2-run-mechanics.md) в админке Mindbox и подождать, пока трекер синхронизируется со списком кампаний
3. [Подключить модуль](step-3-connect-module.md) на странице “Подписка и оплата” для запуска кампании
4. [Проверить корректность работы интеграции](step-4-verify-basic-integration.md)

### Если сайт работает как SPA (сменяет страницы без перезагрузки)

1. Перед трекером Mindbox нужно добавить тег:

   ```
   <script> 
      window.PopMechanic = {watchLocation: false}; 
   script>
   ```
2. После смены страницы нужно вызывать в JS:

```
window.PopMechanic && window.PopMechanic.update && window.PopMechanic.update()
```
