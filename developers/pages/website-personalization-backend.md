# Передача данных с бэкенда

Для передачи данных с бэкэнда сайта, нужно:

1. Создать операции с соответствующим шагом;
2. Вызывать любые операции для просмотра страниц продукта/категории и изменения состава корзины с бекенда сайта или из сторонней системы;
3. Дополнительно вызывать в трекере методы для персонализации, не создавая для этого отдельные операции;
4. Выбрать и установить методы для персонализации в настройках точки интеграции.
