# Расчет цен в каталоге и на карточке товара

## Описание метода

Операция используется в каталоге интернет-магазина или на карточке товара.

В запросе передается список идентификаторов товаров и их текущая цена.  
В ответ возвращается пересчитанные цены с учетом скидок (с детализацией по каждой примененной акции), количество баллов, которое будет начислено при покупке товара и текстовые сообщения для отображения рядом с товаром.

Для учета внешних акций их нужно заранее импортировать в систему.

В одном запросе нельзя передать больше 100 товаров.

```
{
    "customer": {
        "ids": {
            "mindboxId": ""
        }
    },
    "productList": {
        "area":{
            "ids":{
                "externalId":"<Внешний идентификатор зоны>"
            }
        },
        "items" : [
            {
                "product": {
                    "ids": {
                        "testExternalSystem": ""
                    }
                },
                "basePricePerItem": "<Базовая цена товара за единицу товара>",
                "minPricePerItem": "<Минимальная цена товара за единицу товара>",
                "requestedPromotions":[
                    {
                        "type": "discount",
                        "promotion": {
                            "ids": {
                                "externalId": "<Внешний идентификатор промоакции>"
                            },
                            "type": "<Тип акции:discount>"
                        },
                        "amount": "<Размер скидки>"
                    }
                ]
            }
        ]
    }
}
```

## Описание статуса обработки

| Статус | Описание |
| --- | --- |
| Calculated | Все скидки успешно рассчитаны |
| PersonalDiscountsCalculationIsUnavailable | Рассчитаны только публичные скидки. Расчет персональных скидок в данный момент недоступен. |
| DiscountsCalculationIsUnavailable | Расчет всех скидок в данный момент недоступен. |
