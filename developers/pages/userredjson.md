# javascript

### В инструкции описаны **примеры** POST-запросов. Интеграция с Mindbox не будет работать, если использовать запросы из примеров ниже без редактирования.

Операции именно под вашу задачу создает и описывает в техническом задании менеджер проекта, если у вас нет такого документа, то обратитесь к вашему менеджеру.

## Описание метода

Осуществляется в трекере с помощью вызова метода `async` с дополнительными полями. Название операции и набор принимаемых полей настраиваются в системе Майндбокс.

При любом редактировании надо передавать аутентификационный тикет. Это сделано для защиты от злоумышленников. Тикет действует пол часа, поэтому его нужно формировать каждый раз перед вызовом операции редактирования.

```
mindbox('async', {
  operation: '<Название операции>',
  data: {
    customer: {
      authenticationTicket: '<Аутентификационный тикет>',
      lastName: '<Фамилия клиента>',
      firstName: '<Имя клиента>',
      middleName: '<Отчество клиента>',
      mobilePhone: '<Мобильный телефон клиента>',
      email: '<Емэйл клиента>',
      password: '<Пароль>',
      customFields: {
          <Дополнительное поле>: '<Значение дополнительного поля>',
          <Дополнительное поле со множеством значений>: [
            '<Значение дополнительного поля>',
            '<Значение дополнительного поля>'
        ],
      },
      subscriptions:[
        {
          pointOfContact: '<Канал коммуникации Email/SMS/тд>',
          topic: '<Тематика рассылок>',
          isSubscribed: <Статус подписки true/false>
        }
      ]
  	}
  }
});
```

- Алгоритм генерации тикета описан вот [здесь](website-authorization-ticket.md).

Чтобы затереть поле, надо передать `'%CLEAR%'` вместо значения поля.

## Примеры операций

#### Редактирование в личном кабинете

```
mindbox('async', {
  operation: 'EditCustomer',
  data: {
    customer: {
      authenticationTicket: '56D6169641757468656E74696361746|CA49A96250AB940A81C1E48BEF66BC48B8711',
      lastName: 'Петров',
      firstName: 'Иван',
      middleName: 'Владимирович',      
      mobilePhone: '79374134389',
      email: 'pivan@mindbox.ru',
      password: 'Qwerty',
      subscriptions: [
        {
          pointOfContact: 'Sms',
          topic: 'SweetsOfLife',
          isSubscribed: true
        }
      ]
    }
  }
});
```
