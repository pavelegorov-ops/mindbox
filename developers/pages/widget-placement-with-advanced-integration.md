# Размещения виджета с реко по продукту или категории с расширенной интеграцией

Если у вас реализован один из способов расширенной интеграции, определение продукта или категории, к которым формируются рекомендации, будет осуществляться автоматически.

Для корректной работы важно передавать все события, связанные с просмотрами продуктов или категории.

### Если сайт работает как SPA (сменяет страницы без перезагрузки)

**Перед** вызовом `window.PopMechanic.update` необходимо передать информацию о новой странице через вызов операции просмотра категории/продукта.

```
window.PopMechanic && window.PopMechanic.update && window.PopMechanic.update()
```
