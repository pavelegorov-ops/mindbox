# Справочник тегов

Датасет тегов действий/рассылок

---

### exports.CDP.Tags

| Поле | Тип | Описание | Пример |
| --- | --- | --- | --- |
| internalId | string | Идентификатор тега | a5c1f183-f6da-43db-9c49-abfe4e09058a |
| name | string | Название тега | Лучшее предложение |
| systemName | string | Системное имя тега | BestOffer |
| creationDateTimeUtc | datetime | Дата создания тега в формате UTC | 2025-02-27 11:41:31.890 |
| _isDeleted | bool (nullable) | Признак, что тег был удален в Mindbox | True |
| _rowversion_ts | datetime | Временная метка в формате UTC, когда данные стали доступны для экспорта | 2024-10-15 10:00:00.000 |
