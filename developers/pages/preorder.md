# Предварительный расчет заказа с процессингом

AuthorizedPreorder

---

## Набор шагов

Операция расчета скидок перед продажей, или пречека, состоит из следующего набора шагов:

| Шаг | Описание |
| --- | --- |
| Клиент - Авторизованный - Получить существующего, ищем по... | Предназначен для поиска клиента в базе данных Mindbox. Поиск может происходить по различным (одному или нескольким) параметрам, которые выбираются из выпадающего списка. |
| Заказ - Процессинг - Расчет заказа - с режимом арбитража в Mindbox | Предназначен для расчета итоговой стоимости заказа со всеми применимыми к нему скидочными акциями, помокодами и т.д. [Арбитраж](https://help.mindbox.ru/docs/promotion-rules) между применяемыми акциями будет действовать так, как он задан в Mindbox. |
| Действие - Переопределить точку контакта | Предназначен для записи, в какой именно точке контакта (магазине) происходит расчет заказа. Это нужно делать, например, для того чтобы применились (или не применились) акции, у которых выставлено ограничение по месту действия. Подробнее о промоакциях и их настройках можно прочитать [тут](https://help.mindbox.ru/docs/how-to-create-a-discount-promo). |
| Клиент - Получить данные по текущему клиенту (Статус обработки, идентификаторы клиента) | Предназначен для того, чтобы в ответ операция вывела статус выполнения (успешно ли она рассчитала заказ), а также различные идентификаторы клиента для дальнейшего взаимодействия с ним. |

## Описание метода

Осуществляется с помощью POST-запроса. Название операции настраивается в системе Mindbox.

Сервис используется в корзине интернет-магазина или на кассе оффлайн-магазина. В сервис передается полный состав заказа со всеми внешними акциями, которые нужно к нему применить.

В ответ возвращается информация о заказе с пересчитанными ценами (с учетом активных в данный момент промоакций, промокодов и других скидок), и детальной информации о всех скидках, запрошенных покупателем.

В процессе расчета скидок Mindbox может разделить одну линию на несколько. Подробнее о распределении скидок можно почитать [тут](https://help.mindbox.ru/docs/split-and-spread). В этом случае в ответе вернется несколько линий с одинаковым lineId, по которому клиент может понять, какая именно позиция была разделена. Клиент должен корректно обработать такую ситуацию и каждой новой линии присвоить свой уникальный идентификатор для последующих запросов.

При этом Mindbox автоматически проставит порядковые номера позиций в узле lineNumber.
Порядковые номера позиций влияют на логику применения скидок. В дальнейших запросах необходимо передавать порядковые номера, полученные от Mindbox.

### Описание узла Order

Узел **Order** передает детальную информацию о рассчитываемом заказе.

- Узел **Ids** передает информацию об Id уже созданного заказа.
  Id уже существующего заказа указывается для того, чтобы пересчитать его с новыми данными (например, если решили убрать или добавить один из продуктов в состав заказов). Расчет заказа будет произведен с теми акциями и бонусами, которые были доступны клиенту на момент первого сохранения заказа.
- Узел **area** — это узел, передающий информацию о зоне (например, об области или часовом поясе), в которой оформляется заказ.
- Узел **bonusPoints** — это узел, передающий информацию о баллах к списанию за заказ. В поле **amount** необходимо передать количество баллов, которое хочется списать. Если переданная сумма скидки баллами превысит стоимость заказа, система автоматически спишет число баллов, эквивалентное стоимости линий, не превышая его.
- Узел **coupons** — это узел, передающий информацию о промокодах, которые необходимо применить к заказу. В поле **Code** передаем значение нужного промокода.
- Поле **deliveryCost** передает стоимость доставки заказа. Доставка учитывается в общей стоимости при оплате, однако это поле необязательно.
- Массив **lines** передает информацию обо всех линиях чека. В одной линии могут содержаться только одинаковые продукты. Для каждой отдельной линии есть свой узел, который передает информацию о ней. Узел содержит:

  - Узел **Product**, который передает информацию о конкретной позиции в линии. В нем указываются **Ids** продукта — идентификатор продукта во внешней системе.
  - Поле **lineNumber** — это порядковый номер линии, должен по порядку возрастать с каждой новой линией в заказе. Данное поле является необязательным. Если оно не заполнено, Mindbox проставит порядковые номера автоматически.
  - Поле **lineId** — это уникальный идентификатор линии заказа. Это необязательное поле, оно может генериться автоматически.
    Несмотря на первичное сходство, lineNumber и lineId - это разные параметры. Различия проявляются в ситуации, когда при расчете заказа одна линия поделилась на несколько. Подробно о ситуациях, в которых линия заказа может быть разбита на части, можно почитать [тут](https://help.mindbox.ru/docs/split-and-spread). Если происходит сплит и из одной линии чека мы получаем две, ее номер меняется и увеличивается у новой линии, а их идентификатор остается прежним. Это сделано для того, чтобы по идентификатору было понятно, откуда взялась новая линия, с чем она была слита, а по ее номеру было понятно, к какой именно стоимости (и к каким бонусам) апеллировать при возврате.
  - Поле **quantity** — количество товаров в линии. Может быть как целым, так и дробным числом, в зависимости от специфики товара. Принимает максимум 3 знака после запятой.
  - Поле **quantityType** — тип количества товара (целое или дробное). Его нужно передавать (с типом **double**) только в случае, если количество товара должно быть дробным.
  - Поле **basePricePerItem** — цена за единицу продукции в линии. Обязательное поле, у всех продуктов в одной линии значение должно быть одинаковым. Принимает максимум 2 знака после запятой.
  - Поле **minPricePerItem** — минимальная цена за единицу продукции в линии. Необязательное поле, показывает стоимость товара, ниже которой, даже при действии всех возможных скидок, опускаться нельзя. У всех продуктов в одной линии это значение должно быть одинаковым. Принимает максимум 2 знака после запятой.
  - Поле **customFields** — это узел, передающий дополнительную информацию по продуктам в линии. Необязательный узел.
  - Поле **status** — это системное имя статуса позиций в линии.
  - Узел **requestedPromotions** — узел, для применения внешних промоакций.

    - В поле **externalId** указываем идентификатор внешней промоакции, которую нужно применить.
      - В поле **type** указываем, что это внешняя акция (**discount**).
        - В поле **amount** передаем размер скидки в рублях.

### Создание внешних промоакций

Перед применением внешних промоакций их нужно добавить в систему через API или операцию.
Они появятся в дереве промоакций, и после этого их можно будет применять к заказу.

- Узел **payments** передает информацию о способах оплаты, примененных к заказу. В поле **type** передается тип оплаты.
- Узел **cashdesk** в поле **Ids** передает идентификатор кассы, где производится оплата. Поле необязательное.

### Описание узла Customer

Узел **customer** несет информацию о клиенте, переданном в запросе операции.

Данные о клиенте, которые операция будет возвращать, можно указать в ее настройках.

- Поле **processingStatus** показывает, какой статус процессинга у клиента, по которому производился расчет заказа. Может принимать одно из значений:

  - **NotChanged** — было редактирование клиента без изменений;
  - **Changed** — было редактирование клиента с изменениями;
  - **Created** — клиент был успешно создан;
  - **NotFound** — клиент не найден в системе;
  - **Found** — клиент успешно найден в системе;
  - **AlreadyExists** — клиент уже существует;
  - **Ambiguous** — по указанным данным поиска найдено несколько клиентов.
- Поля **firstName**, **middleName** и **lastName** передают Имя, Отчество и Фамилию клиента соответственно, если они заполнены.
- Поле **email** передает почту клиента, если она заполнена.
- Поле **isEmailInvalid** показывает, валидный или невалидный e-mail у клиента:

  - **False** - если e-mail валидный;
  - **True** - если e-mail невалидный.
- Поле **mobilePhone** передает номер мобильного телефона клиента, если он заполнен.
- Поле **isMobilePhoneInvalid** показывает, валидный или невалидный телефон у клиента.
- Поле **isMobilePhoneConfirmed** показывает, подтвержден ли мобильный телефон клиента.
- Поле **pendingMobilePhone** передает номер мобильного телефона клиента, который ожидает подтверждения после смены.
- Узел **area** содержит в себе внешний идентификатор географической зоны покупателя, который передается в поле **externalId**, а также название географической зоны, к которой относится покупатель, передающееся в поле name.
- Поле **birthDate** передает информацию о дате рождения покупателя.
- Поле **sex** передает информацию о поле покупателя.
- Поле **changeDateTimeUtc** передает информацию о дате и времени регистрации покупателя.

### Описание узла Order

Узел **Order** возвращает подробную информацию по заказу клиента, переданному в запросе метода.

В узле возвращаются цены на позиции с учетом всех промоакций, которые потенциально могут к ним примениться.

Кроме того, возвращается список доступных скидок с детализацией по ним.

- Поле **processingStatus** передает статус процессинга заказа и принимает значение **Calculated** в случае успешного расчета заказа.

  - **PersonalDiscountsCalculationIsUnavailable** — это статус недоступности расчета персональных скидок (возникает при недоступности клиента или сервиса);
  - **DiscountsCalculationIsUnavailable** — это статус недоступности расчета скидок (возникает при недоступности сервиса).
- Поле **totalPrice** — это финальная стоимость заказа после применения всех скидок и бонусов, с учетом стоимости доставки. Значение данного поля подставляется в аналогичное в запросе операции начала сохранения заказа.
- Поле **deliveryCost** передает стоимость доставки заказа.
- Массив **lines** передает информацию обо всех линиях заказа и о примененных к ним бонусах и скидках.

  - Узел **product** передает внешний идентификатор продукта в линии в поле **productId**.
  - Поле **lineId** передает идентификатор линии заказа.
  - Поле **lineNumber** передает номер линии заказа.
  - Поле **quantity** передает количество продуктов в линии.
  - Поле **basePricePerItem** передает стоимость единицы продукции в линии.
  - Поле **minPricePerItem** передает минимальную стоимость единицы продукции в линии.
  - Поле **discountedPriceOfLine** передает стоимость линии с учетом всех примененных скидок и бонусов.
  - Поле **status** передает статус позиций в линии.
  - Узел **customFields** передает дополнительные поля линии.
  - Массив **appliedPromotions** передает данные обо всех промоакциях, применившихся к линии.

    - Поле **type** передает тип примененной промоакции.
    - Узел **promotion** передает идентификатор промоакции, внешний или в системе Mindbox, в поле **Ids**. Поле **name** передает название промоакции. Поле **type** передает тип промоакции, внешняя или внутренняя (**external/Mindbox**).
    - Блок **limits** передает информацию о лимитах по конкретной промоакции:
    - Поле **type** передает информацию о том, что именно ограничивается лимитами, или по чему они агрегируются. Может принимать значение **orderLimit** (лимит на заказ), **personalLimit** (лимит на персональное использование акции), **groupLimit** (лимит на саму акцию).
    - Поле **untilDateTimeUtc** передает дату завершения действия лимита.
    - Узел **amount** передает информацию о количественных ограничениях лимита. Поле **type** может принимать либо значение **quantity**, либо значение **discountAmount**, то есть ограничивает лимит количество использований промоакции или же размер максимальной скидки для выдачи по акции соответственно. Поле **value** отображает значение лимита.
    - Узел **used** передает информацию о том, сколько лимитов по акции уже использовано и сколько еще осталось.

      - Поле **usageServiceStatus** показывает, доступны ли еще лимиты для использования:
        - **available** — лимиты еще остались
        - **unavailable** — возвращается в случае, если сервис лимитов временно недоступен.
        - Если лимит **исчерпан**, промоакция не возвращается в ответе.
      - Поле **amount** передает количество использованных раз.
    - Узел **balanceType** передает информацию о балансе, на который были начислены или с которого были списаны бонусные баллы. Поле **systemName** передает системное имя балльного счета. Поле **name** передает название балльного счете. Поле **amount** передает размер скидки в случае списания баллов и количество начисленных баллов в случае их начисления.
    - Поле **expirationDateTimeUtc** передает дату сгорания баллов.
    - Поле **amount** передает размер скидки.
    - Узел **coupon** передает значение примененного промокода в поле **code**.
    - Узел **pool** передает информацию о пуле, из которого был взят промокод. Поле **Ids** передает идентификаторы пула промокодов, внешние и внутренние (**externalId/MindboxId**). Поле **name** передает название пула промокодов. Поле **description** передает описание пула промокодов.
    - Массив **placeholders** передает информацию о тексте, отображаемом текстовой акцией, примененной к заказу. Поле **ids** передает идентификаторы зоны вывода текста. Узел **content** передает информацию о самом тексте для вывода.
- Массив **couponsInfo** передает информацию о промокодах клиента, примененных к заказу.

  - Поле **discountAmountForCurrentOrder** передает размер скидки промокодом к данному заказу.
  - Узел **coupon** передает информацию о примененном к заказу промокоде. Поле **code** передает значение примененного промокода.
  - Поле **status** передает статус промокода. Принимает одно из значений:

    - Unavailable — В данный момент использование промокодов недоступно;
    - NotFound — Промокод не найден;
    - NotIssued — Промокод не выдан;
    - Used — Промокод уже был использован;
    - YetNotActive — Срок действия промокода еще не наступил;
    - AlreadyNotActive — Срок действия промокода истек;
    - CanBeUsed — Промокод может быть использован в заказе;
    - CanNotBeUsedForCurrentOrder — Логика применения промокода не подходит для данного заказа;
    - Blocked — Промокод заблокирован.
  - Узел **pool** передает информацию о пуле, из которого был взят промокод. Поле **Ids** передает идентификаторы пула промокодов, внешние и внутренние (**externalId/MindboxId**). Поле **name** передает название пула промокодов. Поле **description** передает описание пула промокодов.
  - Поле **availableFromDateTimeUtc** передает информацию о дате и времени начала действия промокода.
  - Поле **availableTillDateTimeUtc** передает информацию о дате и времени окончания действия промокода.
  - Поле **usedDateTimeUtc** передает информацию о дате и времени использования промокода.
- Массив **bonusPointsInfo** передает информацию о баллах клиента.

  - Поле **status** передает информацию о статусе обработки балльного процессинга. Может принимать одно из 2 значений:
  - **Unavailable** — в случае, если операции с баллами не могут быть произведены;
  - **Success** — в случае, если процессинг успешно проведен.
  - Поле **availableAmountForCurrentOrder** передает максимальное количество баллов, которое возможно списать за данный заказ. Подробнее о том, зачем существуют ограничения по списанию баллов, можно прочесть [тут](https://help.mindbox.ru/docs/split-and-spread).
  - Поле **spentAmountForCurrentOrder** передает количество баллов, потраченное на заказ.
  - Узел **balanceType** передает информацию о балльном счете, с которого списались баллы. В поле **systemName** передается системное имя балльного счета. В поле name передается название балльного счета.
  - Узел **balance** передает информацию о балансе баллов, лежащих на балльном счету, с которого произошло списание за заказ. Поле **total** передает информацию об общем количестве бонусов на счету. Поле **available** передает информацию о доступном для использования количестве баллов. Поле **blocked** передает информацию о заблокированных баллах на счету, то есть о тех, срок активации которых еще не наступил.
- Массив **bonusPointsChanges** передает информацию об изменениях баланса по заказу.

  - Узел **balanceType** передает информацию о балансе, с которым произошли изменения. Поле **systemName** передает системное имя балльного счета. Поле name передает название балльного счета.
  - Поле **earnedAmount** передает количество баллов, которое будет начислено за заказ.
  - Поле **spentAmount** передает количество баллов, которое будет списано за заказ.

### Примечание

Если на проекте используется целочисленный балльный счет, то к заказу можно применить только количество баллов, кратное единице товаров. Например, на 2 единицы товара нельзя потратить нечетное количество баллов. В этом случае Mindbox автоматически округлит переданное количество баллов в меньшую сторону. Округление количество баллов вернется в узел discountsInfo/discountInfo/spentAmountForCurrentOrder.
