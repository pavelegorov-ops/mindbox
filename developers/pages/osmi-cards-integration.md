# Интеграция OSMI Cards

**OSMI Cards** - это платформа для создания и управления электронными картами лояльности Wallet  
[osmicards.com](https://osmicards.com)

## Возможности интеграции

- Выдача карты лояльности
- Отображение истории баланса бонусов
- Обновление данных карты

## Ограничения интеграции

Если требуется осуществлять дополнительные коммуникации с клиентами, помимо обновления информации о бонусах или клиенте, то необходимо создавать нужные механики отдельно

## Создание интеграции

1. На платформе Mindbox создаются необходимые [механики](https://help.mindbox.ru/docs/%D0%B8%D0%BD%D1%82%D0%B5%D0%B3%D1%80%D0%B0%D1%86%D0%B8%D1%8F-osmi-cards).
2. Менеджер Mindbox передает в OSMI Cards название точки интеграции и секретный ключ.
3. Менеджер OSMI Cards прописывает полученные данные в своей системе.
4. Клиент совместно с OSMI Cards составляет определяет отображаемую информацию дисконтной карты.
5. Менеджер OSMI Cards отправляет в Mindbox:

- токен
- URL для API
- шаблон названия дисконтной карты
- название поля клиент
- название поля баллы
- название дополнительного поля (при необходимости)  
  Полученные данные используются для создания вебхука.

6. На платформе Mindbox заводятся вебхуки.
7. Менеджер Mindbox добавляет токен в вебхук в заголовок Authorization.
8. После этого интеграция считается выполненной.

[Инструкция по созданию механик](https://help.mindbox.ru/docs/%D0%B8%D0%BD%D1%82%D0%B5%D0%B3%D1%80%D0%B0%D1%86%D0%B8%D1%8F-osmi-cards)
