# Ограничения при работе с API

| Ограничение | Ответ от системы | Как обрабатывать |
| --- | --- | --- |
| Обработка запросов к API в рамках одной операции и одного эндпоинта ограничена скоростью 8 000 запросов в минуту | При превышении скорости - 429 Too Many Requests | Нужно повторить запросы позже с экспоненциальной задержкой и отправлять последующие запросы с более низкой скоростью. Данные, отправленные в запросе с ответом 429, не будут обработаны и сохранены в Mindbox. |
| Обработка запроса к API в рамках операции "Предварительный расчет заказа" ограничена. Если на проекте больше 10% запросов "Предварительный расчет заказа" с количеством строк более 50 в течение 2 минут. Исключение: 1 запрос в течение 2 минут допускается и не попадает под квоту; подсчет квоты начинается со 2 запроса в течение 2 минут. | При превышении количества запросов с большим количеством строк - 429 Too many requests. Only 10% of calculations for orders with over 50 lines per 2 minute(s) are allowed. | При необходимости расчета повторно отправить запрос через 2 минуты. |
