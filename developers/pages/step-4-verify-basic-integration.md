# 4. Проверка базовой интеграции

Для проверки корректной работы кода персонализиции на сайте введите в консоль команду:

`PopMechanic`

Если в ответ приходит `loaded: true`, значит код персонализации на сайте установлен

![](https://storage.yandexcloud.net/assets-developers-mindbox-ru/images/fc62290-image.png)

Если в ответ приходит `PopMechanic is not defined`, проверьте возможные причины по [чек-листу](mechanics-not-working-test-link.md)

![](https://storage.yandexcloud.net/assets-developers-mindbox-ru/images/c8e87f5-image.png)
