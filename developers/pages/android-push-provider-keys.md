# Получение ключей провайдеров пушей

### Результат

- Получены ключи доступа для необходимых провайдеров пушей
- Внесены данные в форму "Настройка отправки мобильных push-уведомлений Android" для нужной точки интеграции
- Готовность к отправке push-уведомлений через Mindbox

# Настройка push-сервисов

Mindbox поддерживает интеграцию с основными push-сервисами для отправки уведомлений на мобильные устройства. Выберите сервис или несколько сервисов который используете в вашем приложении

## Доступные провайдеры

- **Firebase Cloud Messaging (FCM)** - для приложений в Google Play
- **Huawei** - для приложений в Huawei AppGallery
- **RuStore** - для приложений в магазине RuStore

### **Важно**: Настройка push-сервисов требуется для:

- Отправки транзакционных и маркетинговых push-уведомлений
- Трекинга доставки и кликов по уведомлениям
- Сегментации пользователей по каналам коммуникации
- Сбора статистики по эффективности push-кампаний
