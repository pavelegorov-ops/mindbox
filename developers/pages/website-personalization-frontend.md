# Передача данных с фронтенда

Для передачи данных с фронтенда сайта, нужно:

1. Создать операции с соответствующим шагом;
2. Вызывать эти операции на страницах продуктов и категорий с фронтенда сайта с помощью JavaScript SDK Mindbox;
3. Выбрать и установить эти операции в настройках точки интеграции.

Передача данных с фронтенда позволяет одновременно передавать действия просмотра продуктов и категорий и изменения состава корзины в карточку клиента и использовать их для таргетинга механик персонализации.
