# Состав заказов клиентов

Датасет позиций заказов. У датасета нет признака _isDeleted, так как позиция заказа не может быть удалена - может быть удален весь заказ

---

В текущей реализации не экспортируются дополнительные поля заказов и дополнительные поля позиций заказов

### exports.ProcessingOrders.Purchases

| Поле | Тип | Описание | Пример |
| --- | --- | --- | --- |
| orderId | string | Внутренний идентификатор заказа, к которому относится позиция | 3890 - целое число для неанонимных заказов или a4fb2db8-7681-493c-89f2-e7c450598041 - guid для анонимных заказов |
| pricePerItem | decimal (25,5) | Стоимость позиции | 101.99 |
| priceOfLine | decimal (25,5) | Стоимость линии чека с учетом скидок | 203.98 |
| quantity | float | Количество единиц продуктов. Может быть не целым, если товар весовой | 2 |
| quantityType | string | Тип количества продукта - целое число / дробное число | int |
| lineId | string | Идентификатор линии чека | 1 |
| lineNumber | int | Порядковый номер линии чека | 1 |
| statusInternalId | string | Внутренний идентификатор статуса линии чека | 8e9695e5-7890-11ec-aba9-005056010ebd |
| productInternalId | string | Внутренний идентификатор продукта | 50041 |
| _rowversion_ts | datetime | Временная метка изменения заказа в формате UTC, в рамках которого произошло изменение пoзиций | 2024-10-15 10:00:00.000 |
