# Справочник тематик рассылок

### exports.Mailings.SubscriptionTopics

| Поле | Тип | Описание | Пример |
| --- | --- | --- | --- |
| internalId | String | Идентификатор тематики | a4fb2db8-7681-493c-89f2-e7c450598043 |
| systemName | String | Системное имя тематики | Advertisement |
| name | String | Имя тематики | Реклама |
| brandInternalId | String | Системное имя бренда | Nike |
| _isDeleted | Bool | Признак, что событие было удалено (не автоудалением!) в Mindbox | False |
| _rowversion_ts | DateTime | Временная метка в формате UTC, когда данные стали доступны для экспорта | 2024-08-21 10:10:10.000 |
