# Экспорт изменения сегментации продуктов

## Общий контракт постановки задачи экспорта

Общий контракт постановки задачи экспорта описан [здесь](exports-overview.md)

## Контракт экспорта изменения сегментации продуктов

Во входных параметрах можно указать:

- Дату "от" в формате UTC. Тогда в выгрузку попадут только продукты, которые вошли или вышли из запрошенной сегментации
- externalID сегментации продуктов, если таковая не была выбрана в настройках шага операции.

Если **запросить без указания даты в запросе**, то в результирующем файле будет по строчке на каждый продукт, который когда либо был в этой сегментации, в зависимости от того числится ли продукт в сегментации в текущий момент, будет указываться свойство "inSegmentation", а в свойстве "segment" будет указан сегмент, в который продукт засчитан

Если же **запрос с использованием даты "от"** то в запросе будут строчки только тех продуктов, которые на текущий момент зачислены или наоборот выпали из сегментации.

## Формат выгружаемого файла

**Описание базовых полей экспорта**

```
{
  "productSegments": [
    {
      "product": {
        "ids": {
          "mindboxId": "<Идентификатор продукта в Mindbox>",
          "<Тип идентификатора>": "<Внешний идентификатор продукта>"
        }
      },
      "inSegmentation": true,
      "segment": {
        "ids": {
          "externalId": "<Внешний идентификатор сегмента>"
        }
      }
    },
    {
      "product": {
        "ids": {
          "<Тип идентификатора>": "<Внешний идентификатор продукта>"
        }
      },
      "inSegmentation": false
    }
  ]
}
```
