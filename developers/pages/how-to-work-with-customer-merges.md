# Как работать с объединением клиентов

Данные могут поступать от CRM, сайтов, мобильных приложений, колл-центра, магазинов. CDP обнаруживает дубли и склеивает записи об одном и том же клиенте в единый профиль.  
Чтобы посчитать, например, среднюю выручку на клиента с заказом за период, нужно взять выручку за период и разделить на количество уникальных клиентов с заказом.

Что делать, если один заказ клиент совершил с телефона, а другой через пару дней с планшета?

Mindbox объединит таких клиентов в одного, но в экспортируемых данных о заказах клиентов заказы будут привязаны к разным id клиента.

Чтобы получить последний актуальный id клиента в заказе нужно таблицу заказов (`Orders`) связать с таблицей объединений клиентов (`MergedCustomers`) по ключу `unmergedCustomerId`.

В итоге, у вас должен получиться примерно такой код:

```
SELECT 
COALESCE ( mc.mergedCustomerId, o.unmergedCustomerId ) AS customerId,
*
FROM 
Orders o
LEFT JOIN MergedCustomers mc ON mc.unmergedCustomerId = o.unmergedCustomerId
```
