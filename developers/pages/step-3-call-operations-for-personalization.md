# 3. Вызов операций для работы персонализации

Дополнительно вызывайте в трекере следующие методы, не создавая для этого отдельные операции.

Это позволит использовать данные о просмотрах и изменениях корзины для работы персонализации, не дублируя действия в системе.

- Для просмотра продукта

```
mindbox("personalization.viewProduct", {
  data: {
    viewProduct: {
      product: {
      	ids: {
        	"<Идентификатор>": "<Значение идентификатора продукта>"
      	}
    	}
    }
  }
});
```

- Для просмотра категории

```
mindbox("personalization.viewCategory", {
  data: {
    viewProductCategory: {
      productCategory: {
          ids: {
        	"<Идентификатор>": "<Значение идентификатора категории>"
      	}
    	}
    }
  }
});
```

- Для корзины

```
mindbox("personalization.setCart", {
    data: {
        productList: [
            {
                product: {
                    ids: {
                      	<Идентификатор>: '<Значение идентификатора продукта>'
                    }
                },
                customFields: {
                  	<Идентификатор>: '<Значение идентификатора дополнительного поля>'
                },
                count: <Количество товара>,
                pricePerItem: <Цена за единицу товара>,
                priceOfLine: <Цена за линию>
            }
        ]
    }
});
```

### Важно

- Идентификаторы продукта и категории настраиваются в системе Майндбокс.
- Значения идентификаторов должны соответствовать тем, что уже добавлены в базу Майндбокс.

### Таргетинг по корзине и продуктам/категории работает по тем данным, которые передаются в операции в тот момент, когда пользователь находится на той или иной странице.

Для корректной работы таргетинга по корзине важно вызывать операцию с актуальным составом корзины на каждой странице, где этот таргетинг должен сработать.

Возможные сценарии:

- при добавлении товара со страницы товар
- при посещении страницы корзины
- при добавлении товара в корзину со страницы категории
- при удалении товара из корзины
- при очищении корзины кнопкой “очистить корзину” на странице корзины
- при посещении страницы корзины с пустой корзиной
- при оформлении заказа, когда товары из корзины уходят в статус "купленные
