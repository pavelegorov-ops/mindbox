# Инструкция по работе с кассой IIKO

## Авторизация и редактирование данных

Для авторизации по номеру телефона или дисконтной карте нажмите на кнопку “Дополнения”

![](https://storage.yandexcloud.net/assets-developers-mindbox-ru/images/ca9cc72cb3159f7a0fe76ac9c09f96334cd46914a6af377c767351991509cd44-6.png)

Далее откроется окно способа авторизации. Выберите “Mindbox”

![](https://storage.yandexcloud.net/assets-developers-mindbox-ru/images/6f97b643894eeaea96c173a3bf3e8db338f118a3a7d35c9b9e8c3dba494f1d69-7.png)

Выберите нужный тип авторизации и введите номер телефона/дисконтной карты в появившемся окне

Если клиент не найден, вам будет предложено зарегистрировать клиента

![](https://storage.yandexcloud.net/assets-developers-mindbox-ru/images/3a1a96eabe972499dc4e1f2ffc0ebe50e09c6489e2afa25079275fbc6c2e0f00-8.png)

В случае регистрации по номеру телефона откроется окно для ввода кода подтверждения

![](https://storage.yandexcloud.net/assets-developers-mindbox-ru/images/79cc2e53ae5c5d3290cc682a1ea2ec6b219c485ff0646071685c0de34bebf941-9.png)

В это окно необходимо внести:

- код подтверждения из смс, отправленной вашему клиенту — если в настройках точки интеграции указано “подтверждать номер телефона”
- любую комбинацию — если в настройках точки интеграции указано “не подтверждать номер телефона”

О настройках точки интеграции вы можете узнать у вашего менеджера Mindbox

После авторизации гостя откроется карточка клиента. В ней можно редактировать данные клиента. Например, добавить имя и дату рождения

![](https://storage.yandexcloud.net/assets-developers-mindbox-ru/images/b70841fedd689d437fcb053ae5d54c0cff2f2b3633069ee20f2c06399448370a-Screenshot_2025-04-01_at_13.03.16.png)

## Оплата заказа

Для проведения оплаты необходимо нажать на кнопку “Касса”. Откроется страница оплаты

![](https://storage.yandexcloud.net/assets-developers-mindbox-ru/images/305de54d8ea46feb965d62fdbeddaca45364dcd9e8fe91b9670f6dab4ba88062-11.png)

Здесь можно добавить тип оплат. Например, безналичный расчет баллами Mindbox Bonus. Для этого выберите нужный тип оплаты и укажите сумму списания

![](https://storage.yandexcloud.net/assets-developers-mindbox-ru/images/4b3f901bc70b109f09e5671b15e251a4be24ddaa0c2ada531e174665718dd1e7-12.png)

После добавления всех нужных типов оплат нажмите на кнопку “Оплатить”

![](https://storage.yandexcloud.net/assets-developers-mindbox-ru/images/f3a11e1b6380a5a7112ace3367f102da7ac4102fd68fb5f0d7de9ca8135ee39b-13.png)

В случае, если в настройках плагина выбрано “подтверждать списание баллов” необходимо будет ввести код из смс, пришедшего гостю. После этого заказ будет оплачен. Распечатается чек с основной информацией о клиенте: номер телефона/дисконтной карты, количество списанных/начисленных баллов, итоговый баланс

## Отправка номенклатуры в Mindbox

Номенклатура отправляется автоматически ежедневно во время, указанное в файле конфигурации. При необходимости можно отправить номенклатуру вручную. Для этого на главном экране кассы нажмите на кнопку "Дополнения"

![](https://storage.yandexcloud.net/assets-developers-mindbox-ru/images/e2e14bf1bb256cbbde8fc4a1f727b0719c7a81e4c110b81920c51f17a38d2843-Screenshot_2025-04-01_at_13.06.04.png)

После этого нажать на кнопку "Mindbox - выгрузка меню"

![](https://storage.yandexcloud.net/assets-developers-mindbox-ru/images/633b2d4769e949d4b3d7f2510bdd943fe1c1a9fcde938c4a15d955a968318410-Screenshot_2025-04-01_at_13.06.50.png)

Вся номенклатура будет отправлена в Mindbox. Данные о продуктах обновятся

## Дополнительная информация

- При сохранении заказа в Mindbox в поле pointOfContact (точка контакта) передается crmid заведения. Если в заведении несколько касс, связанных между собой - будет передаваться одинаковый crmid - это позволяет работать с заказами конкретного заведения через фильтры Mindbox
