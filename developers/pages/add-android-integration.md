# Настройка точек интеграции

### Результат выполнения шага «Настройка точек интеграции для Android приложения»:

- создана и настроена точка интеграции с уникальным идентификатором.

### Интеграция

Для интеграции мобильных приложений необходимо завести интеграции в административном разделе вашего проекта.

Используйте пресеты:

- Android приложение

![](https://storage.yandexcloud.net/assets-developers-mindbox-ru/images/152fa18-__2022-08-01__16.13.25.png)

Системные имена лучше заводить по такому шаблону:

`{{project-name}}.AndroidApp`

*{{project-name}} — название проекта — автоматически задается в название интеграции.*

Точка контакта генерируется автоматически на основе названия интеграции. Ее можно заменить любой другой ранее созданной точкой.
