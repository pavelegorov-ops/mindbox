# Интеграция с приложением «Кошелёк»

[Кошелёк](https://b2b.koshelek.app) — это мобильное приложение для управления картами лояльности.

Приложение собирает мобильные карты лояльности ритейлеров на единой площадке и предлагает пользователям вступать в программы лояльности, которые доступны в их городах.

## Возможности интеграции

• Выпуск новых карт лояльности с регистрацией участника в момент выпуска электронной карты.
• Перенос существующей пластиковой карты в электронный вид с валидацией держателя.
• Сбор и обогащение данных по новым и существующим участникам программы лояльности.
• Отображение личного кабинета участника программы лояльности.
• Отправка рекламных и триггерных пушей с поддержкой каскада.

## Создание интеграции для CDP и модуля Лояльности на Mindbox

С помощью этой интеграции можно выпускать, привязывать и обновлять карты в приложении «Кошелёк» напрямую из Mindbox.

1. На платформе Mindbox создаются [необходимые механики](create-integration-for-cdp-and-loyalty-module.md).
2. Менеджер Mindbox передает Кошельку название точки интеграции и секретный ключ.
3. Клиент передаёт Кошельку реестр уникальных номеров карт или клиентов (id клиента) для выдачи новым участникам лояльности через приложение «Кошелёк». Номера не должны совпадать с номерами, ранее выпущенными в пластике или присвоенными клиентам другими способами. Реестр передаётся в CSV формате [в таком виде](https://developers-staging.koshelek.app/cm_loyalty_offline_api/files_exchanging/#1:~:text=%D0%BC%3B%3B2000%3B10%3B5000%3Bactive-,2.%20%D0%A0%D0%B5%D0%B5%D1%81%D1%82%D1%80%20%D1%81%D0%B2%D0%BE%D0%B1%D0%BE%D0%B4%D0%BD%D1%8B%D1%85%20%D0%BD%D0%BE%D0%BC%D0%B5%D1%80%D0%BE%D0%B2%20%D0%BA%D0%B0%D1%80%D1%82%20%D0%BB%D0%BE%D1%8F%D0%BB%D1%8C%D0%BD%D0%BE%D1%81%D1%82%D0%B8,-%D0%A0%D0%B5%D0%B5%D1%81%D1%82%D1%80%20%D0%BF%D0%B5%D1%80%D0%B5%D0%B4%D0%B0%D0%B5%D1%82%D1%81%D1%8F%20%D0%BF%D0%B0%D1%80%D1%82%D0%BD%D1%91%D1%80%D0%BE%D0%BC). Кошелёк размещает полученный реестр на sFTP сервере Cardsmobile и запрашивает новый реестр по мере исчерпания доступных номеров для регистрации новых участников программы лояльности.
4. Кошелёк собирает предложение в каталоге для тестирования.
5. После публикации предложения в каталоге интеграция считается выполненной.
6. Для отправки пушей выполните инструкцию ниже (пункты 2-7).

## Создание интеграции для отправки пушей в приложение «Кошелёк»

С помощью этой интеграции можно настроить отправку пушей в приложение «Кошелёк» даже при использовании внешней программы лояльности, не связанной с Mindbox. Главное, чтобы в Mindbox у клиентов был признак о том, что у них установлено приложение «Кошелёк».

1. Разработка интеграции между Кошельком и внешней лояльностью по [API Cardsmobile](https://developers-staging.koshelek.app/) (консультация на стороне Кошелька по вариантам подключения).
2. Кошелёк по запросу создаёт учётную запись под партнёра, который планирует отправлять пуши из CDP и передаёт доступы в виде логина/пароля (в форме архива) менеджеру Mindbox.
3. Менеджер Mindbox настраивает отправку запросов на сервис <https://api.cardsmobile.ru/push/>, где запросы на отправку пуша авторизуются под уникальным логином/паролем партнёра.
4. Менеджер Mindbox передаёт Кошельку «обратный» URL-адрес, который Кошелёк будет использовать для информирования о доставке и прочтении отправляемых по API пуш-сообщений.
5. Менеджер Mindbox [настраивает](cardsmobile-integration-mechanics-for-loyalty-module.md) получение и сохранение со стороны Кошелька статусов доставки и открытия. При использовании сторонней программы лояльности нужно уметь выделять клиентов, у которых есть приложение. Для этого можно создать дополнительное поле по клиенту и передавать в него данные о наличии приложения.
6. Кошелёк и менеджер Mindbox тестируют отправку пушей на карты (например, тестовые карты или карты менеджеров со стороны партнёра и Кошелька).
7. После успешных тестов интеграция считается выполненной.
