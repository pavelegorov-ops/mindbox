# Как сверить данные по заказам с отчетом

Описание логики сверки данных с отчетом "Метрики бизнеса"

---

Сверять будем данные, выгруженные в ваше хранилище данных с агрегированными данными в отчете "Метрики бизнеса" в административной панели Mindbox.  
Для начала выберем период, за который нужно сравнить данные и укажем его в отчете:

![](https://storage.yandexcloud.net/assets-developers-mindbox-ru/images/b040ea8ae7d481e0e9cd0d776d3f70be54b7c109d355d7831d33c733514f94f8-image.png)

Как видно на изображении выше, мы будем сверять данные за октябрь 2025 года. Обратите также внимание на плашку, когда данные были обновлены в отчете - на изображении указана дата 02.11.2025. Эта дата нам потребуется в дальнейшем в запросе.

Теперь нам необходимо из сырых данных в вашем хранилище получить сумму заказов за октябрь 2025 года. Запрос будет выглядеть следующим образом:

```
SELECT SUM(c.paidAmount) -- суммируем выручку по всем заказам
FROM (
    SELECT 
        *,
        ROW_NUMBER() OVER (PARTITION BY id ORDER BY _rowversion_ts DESC) as rn
    FROM Orders_raw
    WHERE 
        firstDateTimeUtc >= toDateTime('2025-08-31 21:00:00') --приводим дату из UTC 0 к UTC+3
        AND firstDateTimeUtc <= toDateTime('2025-09-30 21:00:00') --приводим дату из UTC 0 к UTC+3
        AND _rowversion_ts <= toDate('2025-11-02') --учитываем только сырые данные до 02.11.2025
) AS c
WHERE 
    c.rn = 1 
    AND (isNull(c._isDeleted) OR c._isDeleted = false)
```

Обратите внимание, что в запросе учтены сырые данные до 02.11.2025 - именно в эту дату был пересчитан отчет. Чтобы исключить влияние отмен или возвратов заказов, которые могли произойти после этой даты, стоит учитывать только данные до этой даты.  
Также в запросе выбраны только заказы с 31.08.2025 21:00:00 по 30.09.2025 21:00:00, так как даты экспортируются в часовом поясе UTC 0, а отчет учитывает часовой пояс, указанный в настройках проекта Mindbox (в данном примере это часовой пояс UTC+3)

Выполнение этого запроса позволит вам получить точно такую же сумму выручки, что и в отчете "Метрики бизнеса"
