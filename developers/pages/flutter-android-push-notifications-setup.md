# Android | Настройка пуш-уведомлений

Mindbox поддерживает три варианта интеграции push-уведомлений на Android. Выберите подходящий провайдер.

## Варианты интеграции

[Firebase Cloud Messaging (FCM)](firebase-send-push-notifications-flutter.md#/)

Для устройств с Google Mobile Services.

[Huawei Push Kit (HMS)](huawei-send-push-notifications-flutter.md#/)

Для приложений в AppGallery и устройств Huawei без GMS.

[RuStore Push](rustore-send-push-notifications-flutter.md#/)

Для приложений, распространяемых через RuStore.

## Что дальше

Каждое руководство включает настройку окружения, интеграцию Mindbox SDK и проверку получения уведомлений.

Mindbox поддерживает три способа доставки push-уведомлений на Android. Выбор зависит от того, где распространяется ваше приложение.
