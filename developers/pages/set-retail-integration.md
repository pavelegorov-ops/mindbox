# Интеграция Set Retail

**Set Retail** - это программное обеспечение для автоматизации работы кассира.  
[crystals.ru](https://www.crystals.ru/avtomatizacija-torgovli)

## Возможности интеграции

- Расчет скидок
- Расчет персональных скидок
- Начисление бонусов
- Списание бонусов
- Проверка баланса
- Отображение анкеты клиента
- Подтверждение списания бонусов
- Регистрация клиента через кассу

## Ограничения интеграции

- Для интеграции требуется установить плагин (обратитесь к менеджеру Set Retail)
- Версия Set Retail 10+
- Подарочные карты не поддерживаются
- Редактирование клиентов через кассу недоступны

## Создание интеграции

1. На платформе Mindbox создаются необходимые [операции](https://help.mindbox.ru/docs/%D0%B8%D0%BD%D1%82%D0%B5%D0%B3%D1%80%D0%B0%D1%86%D0%B8%D1%8F-set-retail)
2. Менеджер Mindbox передает клиенту: "Точку интеграции", "Секретный ключ", "Системное имя бонусного счета"
3. Сотрудник со стороны клиента настраивает ПО Set Retail
4. После этого интеграция считается выполненной.

[Инструкция по созданию интеграции](https://help.mindbox.ru/docs/%D0%B8%D0%BD%D1%82%D0%B5%D0%B3%D1%80%D0%B0%D1%86%D0%B8%D1%8F-set-retail)
