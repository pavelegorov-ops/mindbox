# Справочник вариантов АБ-тестов

Справочник вариантов АБ-тестов. При определении варианта для пользователя запускаются алгоритм, результатом которого является число от 0 до 100. Если получившееся число попадает в диапазон варианта (modulus lower и upper), этот вариант считается выбранным

---

### exports.AbTests.AbTestVariants

| Поле | Тип | Описание | Пример |
| --- | --- | --- | --- |
| internalId | String | Идентификатор варианта АБ-теста | a4fb2db8-7681-493c-89f2-e7c450598041 |
| name | String | Название варианта АБ-теста | Вариант с промокодом |
| abTestId | String | Идентификатор АБ-теста | a4fb2db8-7681-493c-89f2-e7c450598041 |
| modulusLowerInclusive | Int | Нижняя граница диапазона значений варианта (диапазон от 0 до 100) | 0 |
| modulusUpperExclusive | Int | Верхняя граница диапазона значений варианта (диапазон от 0 до 100) | 50 |
| _isDeleted | Bool | Признак, что вариант АБ-теста был удален в Mindbox | True |
| _rowversion_ts | DateTime | Временная метка в формате UTC, когда данные стали доступны для экспорта | 2024-08-21 10:10:10.000 |
