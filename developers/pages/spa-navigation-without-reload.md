# Сайт работает как SPA (сменяет страницы без перезагрузки)

Персонализация проверяет принадлежность к сегменту в момент инициализации трекера - когда страница загружается или обновляется.

Если сайт работает как SPA (сменяет страницы без перезагрузки), при переходе между страницами персонализация не знает, что надо опять проверить принадлежность к сегменту, поэтому механика отображается некорректно.

**Как проверить**

- При переходе по страницам не меняется url
- При переходе по страницам вкладка Network не перезагружается с нуля, там только добавляются новые запросы

**Как исправить**

1. Перед трекером Mindbox нужно добавить тег:

   ```
   <script> 
      window.PopMechanic = {watchLocation: false}; 
   script>
   ```
2. После смены страницы нужно вызывать в JS:

```
window.PopMechanic && window.PopMechanic.update && window.PopMechanic.update()
```

### Если ваша механика использует таргетинг, связанный с категорией или продуктом, нужно:

- при переходе на страницу вызвать операцию просмотра категории или продукта
- затем вызывать метод обновления `window.PopMechanic.update()`   
  Если перед методом обновления не будет вызова операции просмотра категории или продукта, эта механика не будет работать корректно.
