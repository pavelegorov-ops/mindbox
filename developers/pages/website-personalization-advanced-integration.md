# Расширенная интеграция

### В результате этой интеграции вы сможете:

- настраивать таргетинг по продуктам и категориям, с которыми клиент взаимодействует
- настраивать таргетинг по корзине клиента

**Использование расширенной интеграции возможно только вместе с базовой. Без базовой интеграции она работать не будет.**

**Если базовая интеграция еще не реализована, вернитесь[к шагам по ее настройке](website-personalization-basic-integration.md).**

Есть два варианта интеграции:

1. с фронтенда сайта с помощью JavaScript SDK Mindbox
2. с бекенда сайта или из сторонней системы

Если у вас еще не настроена передача данных, **рекомендуем использовать передачу с фронтенда сайта**. Это позволит одновременно передавать действия в систему и использовать таргетинг в персонализации.

Если у вас уже настроена передача данных с бекенда сайта или вы не можете использовать передачу с фронтенда по каким-то причинам, потребуется небольшая доработка - действия будут передаваться с помощью операций с бэкенда сайта, а таргетинг персонализации будет работать по методам, вызываемым с фронтенда.

Для корректной работы таргетинга по продукту/категории и корзине важно передавать все события, связанные с ними.

### Если сайт работает как SPA (сменяет страницы без перезагрузки)

**Перед** вызовом `window.PopMechanic.update` необходимо передать информацию о новой странице через вызов операции просмотра категории/продукта или обновлении корзины

```
window.PopMechanic && window.PopMechanic.update && window.PopMechanic.update()
```
