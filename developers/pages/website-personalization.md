# Общая информация

**Персонализация сайта** — это изменение внешнего вида сайта в зависимости от данных о клиенте и его поведении.

Персонализация сайта включает в себя:

- попапы - всплывающие окна,
- встроенные блоки - статично встраиваемые элементы,
- виджеты рекомендаций - встроенный блок с динамическими продуктовыми рекомендациями.

[Особенности работы персонализации и возможные механики](https://help.mindbox.ru/docs/%D0%BF%D0%B5%D1%80%D1%81%D0%BE%D0%BD%D0%B0%D0%BB%D0%B8%D0%B7%D0%B0%D1%86%D0%B8%D1%8F-%D1%81%D0%B0%D0%B8%D1%82%D0%B0)

---

Для работы с персонализацией сайта возможно два типа интеграции: базовая и расширенная.

**Базовая интеграция** позволяет размещать механики персонализации у вас на сайте и использовать таргетинг по сегменту клиента и данным, которые хранятся у клиента в браузере.

**Расширенная интеграция** позволяет дополнительно использовать таргетинг по продуктам и категориям, с которыми клиент взаимодействует, и по корзине клиента.

Использование расширенной интеграции возможно только вместе с базовой. Без базовой интеграции она работать не будет.
