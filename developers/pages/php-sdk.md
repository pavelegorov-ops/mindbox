# PHP SDK

[Mindbox PHP SDK](https://github.com/mindbox-moscow/php-sdk#mindbox-php-sdk) - это библиотека для упрощённого взаимодействия вашего PHP приложения с API Mindbox.

**Ключевые возможности библиотеки:**

- Синхронные и асинхронные вызовы операций для API v3;
- Обёртки для наиболее часто используемых операций Mindbox;
- Логирование запросов и ответов API;
- Возможность подключить собственный логгер (реализующий \Psr\Log\LoggerInterface);
- Возможность выбора HTTP клиента: PHP cURL, PHP Stream.

**Для начала работы с Mindbox SDK изучите**

- [Гайд по установке и настройке Mindbox PHP SDK](https://github.com/mindbox-moscow/php-sdk/blob/master/docs/getting_started.md)
