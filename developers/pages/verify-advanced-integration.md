# Проверка расширенной интеграции

Для проверки, что данные передаются корректно, в консоли браузера можно исполнить следующую команду:

```
mindbox("personalization.invokeWithPageData", pd => console.log(pd));
```

Для просмотра страниц и категорий в ответе будет указан тип страницы: продукт или категория, а также ID этого продукта или категории.

Для установки корзины в ответе будет массив cart, в котором указан тот состав корзины, который используется для таргетинга.

Если информация не совпадает с тем, что видит пользователь на фронтэнде сайта, необходимо проверить правильность интеграции.
