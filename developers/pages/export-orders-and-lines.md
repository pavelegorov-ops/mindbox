# Экспорт заказов и позиций заказов

## Общий контракт постановки задачи экспорта

Общий контракт постановки задачи экспорта описан [здесь](exports-overview.md)

## Контракт экспорта заказов и позиций заказов

Во входных параметрах можно указать даты за которые Mindbox вернет изменения заказа в формате UTC. Тогда в выгрузку попадут только заказы, действия которых были изменены в заданный период.

```
POST https://api.mindbox.ru/v3/operations/sync?endpointId={endpointId}&operation={operation}
Accept: application/json
Content-Type: application/json
Authorization: SecretKey {Секретный ключ}

{
  "exportId": "<Идентификатор экспорта>",
  "sinceDateTimeUtc": "<Дата и время самого раннего изменения заказа (UTC, YYYY-MM-DD hh:mm)>",
  "tillDateTimeUtc": "<Дата и время самого позднего изменения заказа невключительно (UTC, YYYY-MM-DD hh:mm)>",
  "exportOutput": {
    "type": "<Тип выгрузки FTP/SFTP>",
    "directory": "<Папка для выгрузки экспорта>",
    "credentials": {
      "userName": "<Логин пользователя>",
      "password": "<Пароль>",
      "sshPrivateKey": "<Приватный SSH ключ закодированный в Base64>"
    },
    "server": {
      "url": "",
      "port": "<Порт сервера>"
    }
  }
}
```

## Ответ экспорта заказов и позиций заказов

```
{
  "status": "<Результат выполнения запроса: Success в случае успеха, ValidationError в случае ошибки пользователя, ProtocolError в случае ошибки интеграции, InternalServerError в случае недоступности сервера.>",
  "exportId": "<Идентификатор экспорта, который нужно передать в следующем запросе>",
  "exportResult": {
    "processingStatus": "<Статус готовности файла>",
    "cancellationReason": "<Причина отмены экспорта>",
    "urls": [
      "<Ссылка на файл с результатом>"
    ]
  }
}
```

В узле **bonusPointsInfoPerBalanceType** выводятся только ненулевые суммарные списания и начисления по каждому из затронутых в промоакции балльных счетов.

Если в одном из действий по заказу на балльный счет были произведены начисления или списания, которые в процессе обновления заказа отменились (например, в случае возврата позиции), балльный счет не будет выводиться в данном узле с нулевыми списаниями и начислениями по нему.

В **appliedPromotions** в узле **type** указывается тип примененной промоакции.

Если с примененной акцией связан промокод, он вернется в ответе. При использовании внешних промокодов, процессинг которых не на стороне Майндбокс, узел **promotion** будет отсутствовать.

Поддерживаются следующие типы:

- **discount** — скидка, может применяться только к позиции заказа
- **deliveryDiscount** — скидка, может применяться только на заказ
- **earnedBonusPoints** — начисление бонусных баллов за заказов
- **spentBonusPoints** — списание бонусных баллов для оплаты заказа
- **issuedCoupon** — выданный купон за заказ
- **message** — сообщение покупателю
