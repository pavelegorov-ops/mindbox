# 2. Вызов операций из бэкенда сайта или из сторонней системы

Вызывайте любые операции для просмотра страниц продукта/категории и изменения состава корзины с бэкенда сайта или из сторонней системы.

Эти операции будут сохранять данные о действиях клиента в системе, но не будут использоваться для работы персонализации сайта.
