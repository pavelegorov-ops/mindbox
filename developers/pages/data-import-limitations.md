# Ограничения при импорте данных

**Размер обрабатываемых файлов:**

- до 300 мегабайт при загрузке через административную панель;
- до 200 мегабайт для POST запросов;
- до 2 048 мегабайт при импорте файлов через ftp-интеграцию.

**Кодировка:**

- utf-8
- windows-1251
