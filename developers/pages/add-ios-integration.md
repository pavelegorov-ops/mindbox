# Настройка точки интеграции

### Результат шага «Настройка точек интеграции для iOS приложения»:

- создана и настроена точка интеграции с уникальным идентификатором.

# Интеграция

Для интеграции мобильных приложений необходимо добавить интеграции в административном разделе вашего проекта.

Используйте пресеты:

- iOS приложение

![](https://storage.yandexcloud.net/assets-developers-mindbox-ru/images/a9d5cbd-__2023-01-10__18.15.00.png)

Системные имена лучше заводить по такому шаблону:

`{project-name}`.IosApp

*`{project-name}`— название проекта — автоматически задается в название интеграции.*

Точка контакта генерируется автоматически на основе названия интеграции. Ее можно заменить любой другой ранее созданной точкой.
