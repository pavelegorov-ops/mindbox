# Импорт региональных данных продуктов

## Описание метода

Осуществляется с помощью POST-запроса. Адрес запроса можно получить в системе Майндбокс. Идентификаторы товаров в импорте должны совпадать с идентификаторами товаров, передаваемых в заказах и действиях с продуктом.

```
POST https://api.mindbox.ru/v3/operations/bulk?endpointId={`уникальный идентификатор сайта и т.п.`}&operation=ImportRegionalData&csvCodePage=65001&externalSystem={`Идентификатор внешней системы`}&transactionId={`Значение ключа идемпотентности в формате GUID`}
HTTP/1.1

Authorization: SecretKey `{Секретный ключ}`
Accept: application/xml
Content-Type: text/csv;charset=utf-8
```

- csvCodePage - идентификатор кодовой страницы Windows для CSV-файла. Предпочтительно использовать 65001 (UTF-8). Опциональный параметр.
- csvColumnDelimiter - символ, использующийся для разделения колонок в CSV-файле. Опциональный параметр.
- csvTextQualifier - символ, добавляющийся в начале и в конце значения колонки, позволяя использовать в нём символы, обычно не разрешённые. Опциональный параметр.
- transactionId - ключ идемпотентности, позволяющий избежать повторного выполнения запроса. Ключ идемпотентности обязательно создавать в формате GUID (рекомендуется версия 4). Для повторных запросов c повторяющимся ключом в ответ вернется статус `TransactionAlreadyProcessed`. Опциональный параметр.
- данный сервис разрешает поставить не более 60 импортов в час. После превышения порога вы будете получать 429 Too Many Requests до тех пор, пока количество поставленных задач за час не опустится ниже 60.
- максимальный размер принимаемого файла 200мб. В случае, если необходимо загрузить больший объем данных, данные нужно разбить на несколько файлов.

## Описание полей

| Заголовок | Описание | Обязательность |
| --- | --- | --- |
| Пример: WebsiteId | Идентификатор товара | Обязательно |
| Name | Наименование | Необязательно |
| Description | Описание | Необязательно |
| PictureUrl | Ссылка на изображение товара | Необязательно |
| IsAvailable | Доступен ли товара в данный момент | Необязательно |
| Url | Ссылка на страницу с описанием товара на сайте | Необязательно |
| Price | Цена продукта | Необязательно |
| OldPrice | Старая цена продукта | Необязательно |
| AreaExternalId | Идентификатор зоны | Обязательно |
