# Массовый импорт заказов

В инструкции описаны **примеры** POST-запросов. Интеграция с Mindbox не будет работать, если использовать запросы из примеров ниже без редактирования.

Операции именно под вашу задачу создает и описывает в техническом задании менеджер проекта, если у вас нет такого документа, то обратитесь к вашему менеджеру.

Рекомендуем использовать только для исторических данных.  
Через импорт нельзя передавать данные в реальном времени, что влияет на такие механики, как брошенная корзина, транзакционные сообщения и т.д.

## Описание метода

Осуществляется с помощью POST-запроса. Адрес и параметры запроса настраиваются в системе Майндбокс.

```
POST https://api.mindbox.ru/v3/operations/bulk?endpointId={уникальный идентификатор сайта и т.п.}&operation=RetailOrder.Import&transactionId={Значение ключа идемпотентности в формате GUID}

Authorization: SecretKey {Секретный ключ}
Accept: application/json
Content-Type: text/csv;charset=utf-8
```

- csvCodePage - идентификатор кодовой страницы Windows для CSV-файла. Предпочтительно использовать 65001 (UTF-8).
- csvColumnDelimiter - символ, использующийся для разделения колонок в CSV-файле.
- csvTextQualifier - символ, опционально добавляющийся в начале и в конце значения колонки, позволяя использовать в нём символы, обычно не разрешённые.
- endpointId - точка доступа, из которой будут взяты настройки интеграции. Значение настраивается в системе.
- transactionId - ключ идемпотентности, позволяющий избежать повторного выполнения запроса. Ключ идемпотентности обязательно создавать в формате GUID (рекомендуется версия 4). Для повторных запросов c повторяющимся ключом в ответ вернется статус `TransactionAlreadyProcessed`.
- данный сервис разрешает поставить не более 60 импортов в час. После превышения порога вы будете получать 429 Too Many Requests до тех пор, пока количество поставленных задач за час не опустится ниже 60.
- максимальный размер принимаемого файла 200мб. В случае, если необходимо загрузить больший объем данных, данные нужно разбить на несколько файлов.

## Описание полей

| Заголовок | Описание |
| --- | --- |
| OrderIds**WebsiteID** | Идентификатор заказа |
| CustomerIds**WebsiteID** | Идентификатор клиента |
| OrderCreationDateTimeUtc | Дата и время создания заказа |
| OrderLastUpdateDateTimeUtc | Дата и время изменения заказа |
| PointOfContact | Идентификатор сайта/магазина, в котором изменили заказ |
| OrderPaymentType | Тип оплаты |
| OrderLineProductIds**website** | Идентификатор продукта |
| OrderLineQuantity | Количество товаров (для каждого ProductIds) в заказе |
| OrderLinePriceOfLine | Конечная цена за линию чека для клиента с учетом персональных скидок |
| OrderTotalPrice | Сумма заказа с учетом всех скидок |
| OrderLineStatus | Текущий статус покупки |

**WebsiteID** замените на системные имена идентификатора заказа и клиента, установленные на вашем проекте.  
**website** - на системное имя идентификатора внешней системы продуктов.  
Например, при использовании идентификатора заказа BackendID название поля будет OrderIdsBackendID, с внешней системой backend - OrderLineProductIdsbackend.
