# Интеграция модуля для 1С:Розница

**1С:Розница** - программное обеспечение, которое автоматизирует небольшой магазин, или используется как кассовое решение в составе других продуктов 1С для большой распределенной организации.  
[1С:Розница](https://v8.1c.ru/retail/)

## Возможности интеграции

- Расчет скидок
- Расчет персональных скидок
- Начисление бонусов
- Списание бонусов
- Проверка баланса
- Отображение анкеты клиента
- Подтверждение списания бонусов
- Редактирование клиента
- Регистрация клиента
- Кастомизация анкеты клиента
- Подарочные карты

## Ограничения интеграции

- Версия: розница 2.3+
