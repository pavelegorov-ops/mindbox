# Заказы клиентов

Датасет основных полей заказов: содержит общую сумму, дату и точки контакта заказа. Каждое изменение статуса заказа будет генерировать отдельную запись в этом датасете.

---

В текущей реализации не экспортируются дополнительные поля заказов и дополнительные поля позиций заказов и информация о скидочных акциях в заказах.

### exports.ProcessingOrders.Orders

| Поле | Тип | Описание | Пример |
| --- | --- | --- | --- |
| id | string | Внутренний идентификатор заказа | 3890 - целое число для неанонимных заказов или a4fb2db8-7681-493c-89f2-e7c450598041 - guid для анонимных заказов |
| unmergedCustomerId | int64 (nullable) | Внутренний идентификатор клиента, совершившего заказ. Пустой для анонимных заказов | 123985 |
| firstDateTimeUtc | datetime (nullable) | Дата первого события заказа в формате UTC | 2024-10-15 10:00:00.000 |
| firstPointOfContactInternalId | string (nullable) | Внутренний идентификатор точки контакта первого события заказа | a4fb2db8-7681-493c-89f2-e7c450598041 |
| firstBrandInternalId | string (nullable) | Системное имя бренда, в рамках которого оформлен заказ | Nike |
| price | decimal (25,5) (nullable) | Сумма заказа без скидок. Может быть пуста, если заказ анонимный | 510,00 |
| priceWithDiscounts | decimal (25,5) (nullable) | Сумма заказа со скидками. Может быть пуста, если заказ анонимный | 483,17 |
| deliveryPrice | decimal (25,5) (nullable) | Сумма доставки без скидок. Может быть пуста, если заказ анонимный | 100,50 |
| deliveryPriceWithDiscounts | decimal (25,5) (nullable) | Сумма доставки со скидками. Может быть пуста, если заказ анонимный | 91,80 |
| paidAmount | decimal (25,5) (nullable) | Фактически оплаченная клиентом сумма за заказ | 500,00 |
| pointOfContactInternalId | string (nullable) | Внутренний идентификатор точки контакта текущего события заказа | 11 |
| |_isDeleted | bool (nullable) | Признак, что заказ удален в Mindbox | True |
| |_rowversion_ts | datetime | Временная метка в формате UTC, когда данные стали доступны для экспорта | 2024-10-15 10:00:00.000 |
