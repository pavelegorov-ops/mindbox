# Интеграция rkeeper

[rkeeper](https://rkeeper.ru) — специализированная система ERP-класса, предназначенная для автоматизации ресторанного бизнеса. Касса, склад, персонал, кухня, финансы, отчетность — все в единой системе.

## Возможности интеграции

- Плагин работает с rkeeper версии 7 и выше, для его работы необходима лицензия от <https://www.delavto.ru/r-keeper/>
- Расчет скидок
- Расчет персональных скидок
- Начисление бонусов
- Списание бонусов
- Проверка баланса
- Подтверждение списания бонусов
- Вывод информации о баллах на чек
- Возможность работы с внешними скидками rkeeper

## Ограничения текущей версии интеграции

- Для интеграции требуется установить плагин (обратитесь к менеджеру для уточнения деталей)
- Подарочные карты не поддерживаются
- Не поддерживается работа с промокодами
- Не поддерживается регистрация клиента на кассе
- Нет возможности выводить подсказки на кассу/чек
- Нет возможности работать с анонимными клиентами

## Создание интеграции

1. Скачивается файл для работы с FarCards [модуль](https://drive.google.com/file/d/1GVZTkLrRfwC-NM4mvXvUg-EbKwW9Vi6r/view?usp=share_link)
2. На платформе Mindbox создаются необходимые операции
3. Менеджер Mindbox передает клиенту:
   - Системное имя точки интеграции
   - Системное имя балльного счета
   - Системное имя внешней системы
4. Необходимо скопировать секретный ключ интеграции. Это может сделать сотрудник с пермиссией "Управление секретными данными". При возникновении сложностей обратитесь к менеджеру Mindbox
5. Сотрудник со стороны клиента настраивает ПО rkeeper по [инструкция](https://drive.google.com/file/d/1KxRtDChaXngRMDX6MJOeCcbvOyQJMh7X/view?usp=sharing)
6. После этого интеграция считается выполненной.
