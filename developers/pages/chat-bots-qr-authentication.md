# Аутентификация клиента по QR-коду на кассе

Метод позволяет авторизовать клиента на кассе, предъявив QR-код из чат-бота вместо ввода номера телефона.

## Как формируется QR-код

1. Клиент запрашивает QR-код в чат-боте.
2. Чат-бот отправляет запрос в операцию Mindbox ["[FT] Генерация QR-кода авторизации"](chat-bots-methods.md#генерация-qr-кода-авторизации-ftgenerateloyaltycode) для получения кода авторизации.
3. Формируется строка для QR-кода в формате: `QR:{номер_телефона}:{уникальный_код}.`
4. QR-код генерируется и отображается клиенту в чат-боте.

Срок действия кода авторизации зависит от настроек операции ["[FT] Генерация QR-кода авторизации"](chat-bots-methods.md#генерация-qr-кода-авторизации-ftgenerateloyaltycode) на проекте.

## **Как выполняется авторизация на кассе**

1. Кассир сканирует QR-код клиента из чат-бота с помощью кнопки для авторизации по QR-коду.
2. Система парсит полученную строку по разделителю `:` и извлекает номер телефона и уникальный код.
3. Отправляется метод для получения данных клиента **Offline.CheckCustomer** (системное имя операции может отличаться на проекте). Стандартные параметры метода описаны в [документации](get-customer-data.md).
4. Отправляется метод проверки кода авторизации **Offline.CheckMobilePhoneAuthorizationCode** (системное имя операции может отличаться на проекте) с передачей номера телефона и уникального кода из QR. Стандартные параметры метода описаны в [документации](secret-code-authentication.md).
5. При успешном ответе (аналогично стандартной авторизации по номеру телефона) клиент считается авторизованным, и касса получает его данные.
