# Интеграция через Albato

**[Albato](https://albato.ru/)** — это сервис для интеграций. Через него можно связать разные системы друг с другом и настроить обмен данными с помощью конструктора.

C помощью Albato можно передавать в Mindbox данные из систем, которые есть в каталоге Albato, например, из Insales.

## Возможности интеграции

- Создание и обновление данных по клиенту: передача контактов клиента, ФИО, внешнего идентификатора, подписок, дополнительных полей (по возможности, если система отдает такую информацию в конструкторе Albato)
- Создание и обновление данных по заказу: состав заказа, статус позиций, сумма заказа, стоимость доставки и дополнительные поля (по возможности, если система отдает такую информацию в конструкторе Albato)

## Ограничения интеграции

С помощью базового функционала можно передавать события, которые перечислены выше. Дополнительные поля по клиенту или заказу можно настраивать и передавать [по инструкции](https://help.mindbox.ru/docs/%D0%BF%D0%BE%D0%B4%D0%BA%D0%BB%D1%8E%D1%87%D0%B5%D0%BD%D0%B8%D0%B5-mindbox-%D0%BA-albato#%D0%BF%D0%B5%D1%80%D0%B5%D0%B4%D0%B0%D1%87%D0%B0-%D0%B4%D0%BE%D0%BF%D0%BE%D0%BB%D0%BD%D0%B8%D1%82%D0%B5%D0%BB%D1%8C%D0%BD%D1%8B%D1%85-%D0%BF%D0%BE%D0%BB%D0%B5%D0%B9-%D1%87%D0%B5%D1%80%D0%B5%D0%B7-albato).

## Создание интеграции

1. В кабинете Albato настроить [подключение с платформой Mindbox](https://help.mindbox.ru/docs/%D0%BF%D0%BE%D0%B4%D0%BA%D0%BB%D1%8E%D1%87%D0%B5%D0%BD%D0%B8%D0%B5-mindbox-%D0%BA-albato#%D0%BA%D0%B0%D0%BA-%D0%BD%D0%B0%D1%81%D1%82%D1%80%D0%BE%D0%B8%D1%82%D1%8C-%D0%BF%D0%BE%D0%B4%D0%BA%D0%BB%D1%8E%D1%87%D0%B5%D0%BD%D0%B8%D0%B5-albato-%D0%BA-mindbox).
2. В кабинете Albato настроить подключение к внешней системе, откуда будут передаваться данные в Mindbox.
3. В кабинете Albato [настроить связки для передачи данных](https://help.mindbox.ru/docs/%D0%BF%D0%BE%D0%B4%D0%BA%D0%BB%D1%8E%D1%87%D0%B5%D0%BD%D0%B8%D0%B5-mindbox-%D0%BA-albato#%D0%BA%D0%B0%D0%BA-%D0%BD%D0%B0%D1%81%D1%82%D1%80%D0%BE%D0%B8%D1%82%D1%8C-%D0%BF%D0%B5%D1%80%D0%B5%D0%B4%D0%B0%D1%87%D1%83-%D0%B4%D0%B0%D0%BD%D0%BD%D1%8B%D1%85-%D0%B2-mindbox) (на каждое событие нужна отдельная связка).

[Инструкция по созданию интеграции](https://help.mindbox.ru/docs/%D0%BF%D0%BE%D0%B4%D0%BA%D0%BB%D1%8E%D1%87%D0%B5%D0%BD%D0%B8%D0%B5-mindbox-%D0%BA-albato#%D0%BA%D0%B0%D0%BA-%D0%BD%D0%B0%D1%81%D1%82%D1%80%D0%BE%D0%B8%D1%82%D1%8C-%D0%BF%D0%BE%D0%B4%D0%BA%D0%BB%D1%8E%D1%87%D0%B5%D0%BD%D0%B8%D0%B5-albato-%D0%BA-mindbox).
