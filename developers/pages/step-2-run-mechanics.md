# 2. Создание механики

1. Перейдите в раздел **Кампании** -> **Список кампаний**
2. Выберите **Создать кампанию** -> **Попап**

![create-popap.png](https://storage.yandexcloud.net/assets-developers-mindbox-ru/images/f6e75a9-image.png)

3. Выберите любой шаблон из списка и создайте из него попап, указав сайт, на котором должна работать персонализация

![create-popap-2.png](https://storage.yandexcloud.net/assets-developers-mindbox-ru/images/fb8fe40-image.png)

4. Подождите, пока трекер синхронизируется со списком кампаний

Это может занять несколько часов.  
Для ускорения можно воспользоваться комбинацией клавиш CTRL+F5 или CMD+SHIFT+R на странице вашего сайта.
