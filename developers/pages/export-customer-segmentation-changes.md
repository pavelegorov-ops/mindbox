# Экспорт изменения сегментации клиентов

## Общий контракт постановки задачи экспорта

Общий контракт постановки задачи экспорта описан [здесь](exports-overview.md)

## Контракт экспорта изменения сегментации клиентов

**Пример запроса**

```
https://api.mindbox.ru/v3/operations/sync?endpointId={endpointId}&operation={operation}

Accept: application/json
Content-Type: application/json
Authorization: SecretKey {Секретный ключ}

{
  "sinceDateTimeUtc": "<Начальная дата и время, с которой необходимо получить изменения (UTC, YYYY-MM-DD hh:mm)>",
  "segmentation": {
    "ids": {
      "externalId": "<Внешний идентификатор сегментации>"
    }
  }
}
```

Во входных параметрах можно указать:

- Дату "от" в формате UTC. Тогда в выгрузку попадут только клиенты, которые вошли или вышли из запрошенной сегментации
- externalId сегментации клиентов, если таковая не была выбрана в настройках шага операции.

Если **запросить без указания даты в запросе**, то в результирующем файле будет по строчке на каждого клиента, который когда либо был в этой сегментации, в зависимости от того числится ли клиент в сегментации в текущий момент, будет указываться свойство "inSegmentation", а в свойстве "segment" будет указан сегмент, в который клиент засчитан

Если же **запрос с использованием даты "от"** то в запросе будут строчки только тех клиентов, которые на текущий момент зачислены или наоборот выпали из сегментации.

## Формат выгружаемого файла

**Описание базовых полей экспорта**

```
{
  "customerSegments": [
    {
      "customer": {
        "ids": {
          "mindboxId": "<Идентификатор клиента в Mindbox>",
          "<ИД1>": "<Внешний ИД клиента>",
          "<ИД2>": "<Другой внешний ИД клиента>"
        }
      },
      "inSegmentation": true,
      "segment": {
        "ids": {
          "externalId": "<Внешний идентификатор сегмента>"
        }
      }
    },
    {
      "customer": {
        "ids": {
          "mindboxId": "<Идентификатор клиента в Mindbox>",
          "<ИД1>": "<Внешний ИД клиента>",
          "<ИД2>": "<Другой внешний ИД клиента>"
        }
      },
      "inSegmentation": false
    }
  ]
}
```
