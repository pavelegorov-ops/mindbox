# В механике не указаны необходимые настройки

**Как проверить**

1. Откройте механику персонализации в Mindbox
2. Перейдите к разделу **Общие настройки** - проверьте, заполнено ли поле **Сайт**
3. Для виджетов дополнительно:
   - проверьте, выбрана ли внешняя система продукта
   - перейдите к разделу **Алгоритм рекомендаций** - проверьте, выбран ли алгоритм
4. Если какая-то из настроек не заполнена - механика работать не будет

**Как поправить**

- Если не заполнено поле **Сайт** - раскройте доступные варианты и выберите тот, который соответствует точке интеграции сайта, где должна работать механика.
- Если не заполнена внешняя система продукта - выберите подходящую. [Подробнее в внешних системах продуктов здесь](https://help.mindbox.ru/docs/%D0%BA%D0%B0%D0%BA-%D1%81%D0%BE%D0%B7%D0%B4%D0%B0%D1%82%D1%8C-%D0%B2%D0%BD%D0%B5%D1%88%D0%BD%D1%8E%D1%8E-%D1%81%D0%B8%D1%81%D1%82%D0%B5%D0%BC%D1%83)
- Если не указан алгоритм рекомендаций - выберите и сохраните алгоритм. [Подробнее об алгоритмах здесь](https://help.mindbox.ru/docs/%D0%B0%D0%BB%D0%B3%D0%BE%D1%80%D0%B8%D1%82%D0%BC%D1%8B-%D1%80%D0%B5%D0%BA%D0%BE%D0%BC%D0%B5%D0%BD%D0%B4%D0%B0%D1%86%D0%B8%D0%B8)
